# 応用情報の教材を書く担当への指示

`scripts/prompts/write_materials.md`（書式・構成・禁止事項の本体）と合わせて読む。
担当バンドル番号 NN は呼び出し側から渡される。

## 手順

1. **`scripts/prompts/write_materials.md` を必ず先に読む**
2. `data/ap/material_bundles/bundle_NN.json` を Read する。
   その論点が実際に出題された過去問（正解つき）が入っている
3. `data/ap/materials_v2/bundle_NN.json` に**1回の Write で**書き出す
4. `python3 scripts/check_materials.py --data data/ap --dir data/ap/materials_v2` を実行し、
   自分のバンドルに関する指摘があれば直してから終える

## 満たすべき最低条件

**その論点に紐づく過去問を、書いた教材だけを読んで解けること。**
バンドルの `questions` を1問ずつ見て、「この教材だけで正解にたどり着けるか」を自問する。

- **計算問題があるなら、式を必ず本文に書く。** 「公式を暗記するだけでは解けません」と
  書きながら肝心の式が無い、という失敗が実際に起きた。式は `explanation` にも入れる
- **判断の基準は「出題パターン」節ではなく本文に置く。** パターン節を外しても解ける状態にする
- 応用情報は「用語を知っているか」ではなく**「計算・判断ができるか」**を問う。手順を書く

## 禁止

- **選択肢の記号（ア・イ・ウ・エ）を書かない。** 教材は問題と切り離して読まれる
- Markdown は `### 見出し` / `- 箇条書き` / `1. 番号` / `**太字**` の4つだけ。
  表・リンク・コードブロックは使えない
- 数式はプレーンテキスト（`2^10`、`log2 n`、`√(2)`、`分子/分母`）

## 出力形式

```json
{"bundle": NN, "materials": [
  {"topic_id": 12, "term": "損益分岐点",
   "explanation": "一覧に出る短い説明（式があるならここにも入れる）",
   "detail": "### しくみ\n…\n\n### 出題パターン\n…"}]}
```

**バンドルにある論点すべてを、`topic_id` を変えずに出力すること。**

最終メッセージは、書いた論点数と、書きにくかった論点があればその理由だけ簡潔に。
