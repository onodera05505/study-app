# 説明テストの採点基準（採点担当は教材を根拠に採点する。学習者の自己申告は見ない）

各語について、学習者の説明を対応する教材（`units/` の該当単位）と照らし、次の 3 段で採点する。
- **2**: 定義の芯が合っていて、IT に詳しくない人に通じる（教材の言い回しでなくてよい。例や対比で言えていればよい）
- **1**: 方向は合っているが芯が抜けている・別の概念と混ざっている・「〜のようなもの」で止まっている
- **0**: 誤り、または「分からない」、または空

出力: `{"grades": {"語": 2, ...}, "comments": {"語": "1 行（何が合い何が抜けたか）"}}`。
採点担当は教材以外の知識で正誤を決めない（教材に無いことを学習者が書いても、教材の趣旨と矛盾しなければ減点しない）。
