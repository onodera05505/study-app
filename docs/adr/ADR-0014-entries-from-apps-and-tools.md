# ADR-0014 入口の一覧 — 2 つの app の経路と、道具の置き場の直下のソースのファイル全部から機械で導く

## Context

原本 harness は、境界の入口と契約の操作を、プロジェクトが出す入口の一覧（`harness.config.json` の `commands.list_entries`）で双方向に突き合わせる（R-1206。`harness lint entries`）。fixed の契約の操作に合わない入口と、入口の無い fixed の操作が違反になる。契約の外に入口を置く宣言は無い。

このプロジェクトの入口は 2 種類ある。

- 学び側とまなびばの app が受ける経路（契約の `transport: http`・`direction: inbound`）
- 作り手と運用の道具（`scripts/`。契約の `transport: local-store`・`direction: inbound` の「道具を回す操作」）

道具の一部だけが契約の操作を持つ。本人は 2026-11-19 に、道具を全部入口として並べ、契約に無い道具には今の動きを写した契約の操作と要件を足すと決めた（`brain/PREMISES.md`）。

道具の置き場には、ほかの道具から読み込まれるだけで単独では回さない部品も同じ階層に混ざっている。1 つのファイルが、ファイル名と違う名前の操作や複数の操作を受け持つ物もある（CLAUDE.md の「操作 → 入口」が文章で挙げている）。

## Decision

- **経路の入口は、app の登録から導く。** 学び側（`src/server/index.ts`）とまなびば（`portal/src/index.ts`）の既定の app に登録された method と path を、契約の `wire` の書き方（パラメーターは `{name}`）に直して出す。どの method にも立つ中継ぎ（`ALL` の登録）は出さない。
- **道具の入口は、`scripts/` の直下のソースのファイル（設定の `source.extensions` に入る拡張子の物）全部とする。** 中身（`__main__` の有無など）では選ばない。データのファイルと名前の表自身は入口に数えない。単独で回さない部品は直下に置かず、`scripts/lib/` に置く。入口かどうかを置き場の構造だけで決め、入口から外す印や表を持たない。
- **道具の操作の名前は、既定でファイル名（拡張子を除く）を camelCase にした物。** 語の区切りは `_` と `-`。 ファイル名と違う名前の操作・複数の操作を受け持つファイル、直下でない入口（契約の実例の受け渡し役）は、機械が読める 1 つの表 `scripts/entry_names.json` に「ファイル → 操作の名前の並び」で挙げる。表の鍵は、道具の置き場（`scripts/`）からの相対パスで書く。表に挙げたファイルは、挙げた名前だけを入口として出す。
- **一覧を出すコマンド自身も道具の入口で、契約の操作と要件を持つ。** 一覧は 1 行に 1 件の JSON で、経路は `kind: http`・`method`・`path`、道具は `kind: local-store`・`name` を持つ。
- 道具の中の読み書きの操作（ADR-0013。`direction: outbound`）は入口に数えない。

## Consequences

- よい: 道具を足すと一覧に必ず載り、契約の操作が無ければ門が止める。入口の出し忘れが起きない。
- よい: 名前が規則に従わない入口の正本が、文章（CLAUDE.md）から機械が読む表に移る。テストの担当と一覧のコマンドが同じ表を読む。
- 悪い: 部品を `scripts/lib/` へ移すので、読み込む側の道具の読み込み先が変わる（動きは変えない）。
- 悪い: 一度きりで役目を終えた道具も、直下に置いてある限り契約の操作と要件とテストが要る。消すか残すかは本人が決める。
- 悪い: 表に名前を書き間違えると、入口が別の名前で載る。契約との突き合わせ（文字の完全一致）で双方向に違反が出るので気づける。

## 却下した選択肢

- **契約に書いた道具だけを並べる**: 違反は 0 にできるが、契約の無い道具が検査の外に残る。本人が退けた。
- **`__main__` の有無や実行ビットで入口を見分ける**: 上から順に実行する形の道具（`__main__` を持たない）を落とす。中身の書き方で入口が増減し、置き場を見ただけでは分からない。
- **入口でないファイルを表に挙げて外す**: 除外の印に当たる。このプロジェクトは持たない（R-804）。
- **1 ファイル 1 操作にそろえ、名前の表を持たない**: fixed の契約の操作の名前を付け替えるか道具を割ることになり、承認済みの契約と手順書が広く動く。
