# REQ-497

> システムは、単元の読み物の本文で用語の記法で書かれた語のうち、投入が組み立てる用語集にある語を、UC-001 の REQ-008 と REQ-341 が決める用語の表示名に押すと説明が出る語である印を添えて置き、用語集に無い語を UC-001 の REQ-009 のとおり書かれた文字のまま置く。

## 検証方針

- **分割クラス**:
  - `#glossary-term-marked` — 用語集にある括弧書きの無い語が、表示名の直後の ※ を添えて出て、記法の括弧が残らない
  - `#paren-dropped` — 括弧書きを落としても何とも重ならない語は、括弧書きを落とした表示名に ※
  - `#paren-kept-same-as-other-term` — 括弧書きを落とすと用語集の他の語と同じになる語は、正式な表記のまま ※
  - `#paren-kept-same-as-other-shortened` — 括弧書きを落とすと他の語から括弧書きを落とした表記と同じになる語は、正式な表記のまま ※
  - `#not-in-glossary-plain` — 用語集に無い語は印を添えず書かれた文字のまま
  - `#term-in-bold` — 太字の中の記法でも、用語集にある語に ※
- **尽きている根拠**: 記法の語は用語集にあるか無いかで分かれ、ある語の表示名は REQ-008・REQ-341 の 3 通り（括弧書き無し・落とす・残す 2 種）で尽きる。太字の中は記法の解釈が変わりうるので別に置く
- **検証しない**: 用語集の元のうち glossary_overrides.json 以外（問題解説の誤答の term・論点の名前）から入る語（用語集の組み立ては投入の決まりで、この文はその結果の語の置き方を決める）
- **参照先**: `tests/server/UC-028_build_unit_reading.test.ts::UC-028 単元の読み物を作る: 単元の全論点を書き直した世代から選ぶ（buildUnitReading）`
