# REQ-507

> 単元の読み物を作るために読む教材の世代・単元の構成・論点の一覧・用語集の元・図の仕様のファイルに、契約の形として読めないファイルがあるとき、システムは単元の読み物を作らず、そのファイルを挙げて止める。

## 検証方針

- **分割クラス**:
  - `#materials-unreadable` — 単元の論点を持つ教材の世代のファイル（書き直した世代・前の世代）が JSON でないか空か、topic_id の無い行を持つ
  - `#unit-plan-unreadable` — 指定した単元の単元の構成のファイルが JSON でないか空
  - `#topics-unreadable` — 論点の一覧が読めない
  - `#glossary-source-unreadable` — 用語集の元（glossary_overrides.json）が読めない
  - `#figure-spec-unreadable` — 単元の論点の図の仕様が読めない
  - `#several-unreadable-listed` — 読めないファイルが 2 つあれば両方を挙げる
  - `#unreadable-before-gate` — 読めないファイルがあり、かつ単元の構成が門の止める理由に当たる（errors の 6 番目と 7 番目）
- **尽きている根拠**: 文が挙げる読むファイルは 5 種で、1 種 1 クラス。読めない形は JSON でない・空・必須の欄の無い行で、行の欄は契約が topic_id だけを決める
- **検証しない**: 単元の論点を持たない教材の世代のファイル・単元の外の論点の図の仕様・別の単元の単元の構成が読めないとき（読み物を作るために読むかを文が決めていない）。用語集の元のうち glossary_overrides.json 以外のファイル（どのファイルが用語集の元かを契約が決めていない）
- **参照先**: `tests/server/UC-028_refusals.test.ts::UC-028 読むファイルが契約の形として読めない（REQ-507）`
