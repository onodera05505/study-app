# REQ-498

> システムは、単元の読み物の図を、その図が指す配信の置き場の図の画像を PNG に描いた画像として、BR-054 が決める出力先の中の置く先に置いて単元の読み物から指し、図の説明文を、UC-001 の REQ-427 と同じくその図に結び付けた文字として 1 回だけ置く。

## 検証方針

- **分割クラス**:
  - `#svg-drawn-as-png` — 置き場の直下の svg の図が figures の下の同じ名前の PNG になり、読み物がそれを指す
  - `#subpath-kept` — 置き場のサブパスの下の図が figures の下に同じサブパスで PNG になる
  - `#png-source` — 元が png の図も同じ名前の PNG として入る
  - `#caption-once` — 図の説明文（差し込む図は図の仕様の説明文、図の行は行の説明文）が読み物に 1 回だけ、画像の代替文ではなく図のそばの文字として出る
  - `#no-outside-reference` — 読み物の図がどれも出力先の中の PNG を指し、配信の置き場を指さない
  - `#response-matches-files` — 応答の reading と figures が出力先のファイルと一致し、figures が読み物の指す図と一致する
  - `#topic-without-figure` — 図の仕様も図の行も持たない論点の区切りに図が無い
- **尽きている根拠**: 図の元は置き場の直下の svg・サブパスの svg・png の 3 つ、結び付きは説明文の 1 つ、指し先は出力先の内か外かで、応答との一致と図の無い論点を足して尽きる。図の行の指す先と置く先の形は BR-054 の形だけで決まり、形に合わない行（大文字・key の欠け・`..`・制御文字を含む指す先）は REQ-512 で止まるので、出力先の外を指す図の入力はここに無い
- **検証しない**: 説明文の結び付け方（「図の説明:」のような書き方を文が決めていない。画像の行と同じ行か前後で最も近い字の行にあることを見る）。実機の読み上げソフトでの届き方（GLOBAL の REQ-427 の行と同じ理由）
