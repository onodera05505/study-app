# UC-028 資格対策の単元を利用者と同じ見え方の読み物にして学習者役に通読させる

## 概要

作り手が、資格対策の学びの 1 単元を、利用者が画面で見るのと同じ並び・本文・用語・図の見え方で 1 本の単元の読み物にし、学習者役に通読させて、単元を通して読んだときのつまずきを学習者役の報告として受け取る。

## 事前条件

- 資格対策の学びが登録簿にあり、その単元の単元の構成・教材の世代・図の仕様・図の画像が学びの置き場と配信の置き場にある
- 適用される業務規則: BR-004, BR-026, BR-031, BR-048, BR-051, BR-054, BR-055, BR-061

## 主シナリオ

1. 作り手が、学びと単元と出力先を指定して単元の読み物を作る
2. システムが、単元の構成が単元の構成の門の止める理由に当たらないことを確かめる → BR-048
3. システムが、単元の構成の順に、全体像・まとまり・論点の名前と出題回数の印・前提の論点を並べる → BR-031, BR-051
4. システムが、論点ごとに配る本文を、用語と図を利用者が画面で見るのと同じ見え方にして並べ、図の画像を添える → BR-026
5. システムが、単元の読み物の項目の番号と論点の対応を作り手に示す
6. 作り手が、学習者役への単元の通読の指示に単元の値を埋め、単元の読み物と一緒に学習者役に渡す
7. 学習者役が、単元の読み物だけを頭から順に読み、学習者役の報告を返す
