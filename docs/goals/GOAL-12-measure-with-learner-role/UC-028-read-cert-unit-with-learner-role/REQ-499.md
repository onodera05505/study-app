# REQ-499

> システムは、単元の読み物に過去問・正解・問題解説・教材の世代の名前を含めず、図の画像の参照先を除く単元の読み物の文に論点の ID を含めず、項目の番号ごとの論点の ID・論点の名前・選んだ教材の世代を、単元の読み物の外で作り手に示す。

## 検証方針

- **分割クラス**:
  - `#no-question-content` — 単元の論点の過去問の問題文と、問題解説の正解の根拠・誤答の注が読み物に無い
  - `#no-topic-id` — 単元の論点の ID が読み物の文に数字として現れない
  - `#no-generation-name` — 教材の世代の名前が読み物に無い
  - `#items-to-maker` — 応答の items が項目の番号ごとに論点の ID・名前・選んだ世代を持つ（書き直した世代の単元と、論点ごとに違う前の世代を選ぶ単元）
- **尽きている根拠**: 文が含めないと決める物は過去問・正解・問題解説・論点の ID・世代の名前の 5 つで、作り手に示す物は items の 1 つ。過去問と問題解説は字の並びで見られる 1 クラスにまとめる
- **検証しない**: 正解（選択肢の記号 1 字で、本文の字と見分けられない。問題文と問題解説が無いことで押さえる）。図の画像の参照先に入る論点の ID（契約が図の PNG の名前を元の置き場のサブパスのまま決めるので、参照先を除いた文で見る）
- **参照先**: `tests/server/UC-028_build_unit_reading.test.ts::UC-028 単元の読み物を作る: 単元の全論点を書き直した世代から選ぶ（buildUnitReading）`・`::UC-028 単元の読み物を作る: 単元の全論点を前の世代から選ぶ（buildUnitReading）`
