# REQ-509

> 単元の読み物の図が XML として整わない SVG であるか、1 つの図が契約の描く待ち時間の上限のうちに描き終わらないか、ほかの理由で PNG に描けないとき、または 2 つ以上の図が BR-054 の置く先で同じ PNG の名前になるとき、システムはどの図も上書きせず、その論点と図を挙げ、コマンドが作ったファイルとディレクトリを出力先の中にもその外にも 1 つも残さず、呼ぶ前からあった出力先とその親を呼ぶ前と同じ中身のままにして止める。

## 検証方針

- **分割クラス**:
  - `#not-well-formed` — 図が XML として整わない SVG（途中で切れた・XML に無い実体参照）
  - `#not-drawable` — XML として整うが PNG に描けない（xmlns の無い SVG・図でない XML）
  - `#name-collision` — 拡張子だけ違う 2 つの図が同じ PNG の名前になる
  - `#same-name-other-subpath-ok` — 同じ名前でサブパスの違う図は同じ PNG の名前に当たらない
  - `#collision-before-not-drawable` — 同じ PNG の名前になる図があり、かつ描けない図がある（errors の「同じ PNG の名前になる図が 2 つ以上ある」と「図を PNG に描けない」）
  - `#created-dirs-removed` — 描けずに止めたとき、コマンドが作った出力先とその親を残さない
  - `#existing-parent-kept` — 描けずに止めたとき、呼ぶ前からあった親とその中身はそのまま
  - `#existing-empty-out-kept-empty` — 呼ぶ前からある空の出力先は、描けずに止めたあとも空のまま（ファイルもディレクトリも無い）
  - `#sources-untouched` — 描けずに止めたとき、配信の置き場の図の画像をどれも書き換えない
- **尽きている根拠**: 止める条件は描けない（整わない・整うが描けない）と名前の重なりで、重なりは拡張子だけの違いとサブパスの違いで当たる・当たらないが分かれる。止めたあとに残す物は、コマンドが作った場所・前からあった場所・図の元の 3 つで、場所の中身はファイルとディレクトリの両方で見る
- **検証しない**: 描く待ち時間の上限のうちに描き終わらない図（上限を超えて描き終わらない図を手元で確実に作れない）。作る間に同じ出力先に書かれたとき（errors の「作る間に同じ出力先に書かれた」）と描けない図の組み合わせ（同時の呼び出しの勝ち負けを決めて作れない。同時の呼び出しは REQ-511 が持つ）
- **参照先**: `tests/server/UC-028_refusals.test.ts::UC-028 図が同じ PNG の名前になるか、PNG に描けない（REQ-509）`・`tests/server/UC-028_build_unit_reading.test.ts::UC-028 単元の読み物を作る: 単元の全論点を書き直した世代から選ぶ（buildUnitReading）`
