# REQ-496

> システムは、単元の読み物の各論点の本文に、投入がその論点に選ぶ配る本文の説明と詳しい解説をこの順に全文置き、図を、配る本文が図の行（BR-054）を持つ論点ではその行の位置に、持たない論点では図の差し込みが入れる位置（UC-027 の REQ-470）に置く。

## 検証方針

- **分割クラス**:
  - `#explanation-then-detail-full` — 各論点の区切りに説明の段と詳しい解説の見出し・段が全部、説明・詳しい解説の順にある
  - `#selected-generation-body` — 投入が選ぶ世代（書き直した世代、前の世代では論点ごとに最も新しい世代）の本文が出て、前の世代にある同じ論点の別の本文は出ない
  - `#insert-after-explanation` — 書き直した世代から選んだ図の行を持たない論点の、差し込み位置が explanation の図が、短い説明の末尾（説明の最後の段の後・詳しい解説の最初の見出しの前）にある
  - `#insert-at-heading-section-end` — 書き直した世代から選んだ図の行を持たない論点の、差し込み位置が見出しの図が、その見出しの節の末尾（節の最後の段の後で、次の見出しの前か、後に見出しが無ければ詳しい解説の末尾）にある（後に見出しのある節と無い節の両方）
  - `#same-explanation-spec-order` — 書き直した世代から選んだ図の行を持たない論点の、短い説明を差し込み位置にする図が 2 枚以上あるとき、図の仕様に並ぶ順に上からある
  - `#same-heading-spec-order` — 書き直した世代から選んだ図の行を持たない論点の、同じ見出しを差し込み位置にする図が 2 枚以上あるとき、図の仕様に並ぶ順に上からある（後に見出しのある節と無い節の両方）
  - `#line-position` — 図の行を持つ論点（書き直した世代と前の世代の両方）で、図が行の前後の段の間にあり、前の世代では図の仕様の差し込み位置と違う位置でも行の位置にある
  - `#line-with-surrounding-space` — 行頭と行末に半角の空白・タブ・全角の空白を持つ図の行も図の行として、図がその行の位置にある
- **尽きている根拠**: 本文の置き方は「本文の全文と順」「どの世代の本文か」「図の位置」で、図の位置は図の行の有無で分かれ、行を持たない側は REQ-470 が位置を決めている書き直した世代の論点で、差し込み位置の 2 種（explanation と見出し）ごとに、置き場の中の位置（末尾）と、同じ差し込み位置に 2 枚以上あるときの並び（図の仕様の順）の 2 つで尽きる。見出しの節の末尾は、後に見出しのある節（次の見出しの直前）と無い節（詳しい解説の末尾）で文の言い方が分かれるので両方で見る。図の行の形（BR-054・MaterialFigureLine）が受け入れる側の端は、行頭と行末に置ける空白を持つ行で見る。図の行かどうかは BR-054 の形だけで決まり、配信の置き場を指すのに形に合わない行は REQ-512 で止まるので、図の位置の分かれ目に入らない
- **境界の扱い**: 位置は、見出しの行の直後に置く置き方と見分けるため、節に段を 2 つ持たせて最後の段の後かで見る（段が 1 つだと最初の段の末尾に置く置き方と見分けられない）。並びは、図の仕様の順が図の id の昇順・降順のどちらとも違う 3 枚で見て、図の仕様では差し込み位置の違う図を互い違いに並べる（id の順・逆順・差し込むたびに見出しの直後に入れる置き方と見分ける）
- **検証しない**: 前の世代から選んだ論点で図の行を持たない論点の、図の仕様にある図をどこに置くか（REQ-470 は前の世代の論点では置き方を変えないとだけ言い、行の無い図を足すかを決めていない。UC-027 の DEF-139）。図の仕様にあるのに図の行の無い図を、図の行を持つ論点で足すか（文が決めていない。UC-027 の DEF-139 と同じ）。本文の markdown の書き方の保ち方（太字・見出しの段の深さ。文は全文を置くことだけを決めるので段の文字で見る）
