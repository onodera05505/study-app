# REQ-502

> 作り手が登録簿に無い学びか、ロードマップ型の学びを指定して単元の読み物を作ろうとしたとき、システムは単元の読み物を作らずに断る。

## 検証方針

- **分割クラス**:
  - `#unregistered` — 登録簿に無い学び（置き場が作り物の根にあるときと、置き場の無いとき）
  - `#roadmap` — ロードマップ型の学び（作り物の根の下とリポジトリの形の 2 つの書き方）
  - `#roadmap-before-out-inside` — ロードマップ型で、かつ出力先が学びの置き場の中（errors の 2 番目と 3 番目）
- **尽きている根拠**: 登録簿が決める学びの種類は、無い・ロードマップ型・資格対策の 3 つで、資格対策は作る側（REQ-494 ほか）が持つ
- **参照先**: `tests/server/UC-028_refusals.test.ts::UC-028 入口の引数・学び・出力先・単元で断る（buildUnitReading）`
