# REQ-331

> 作り手が指定したパックの出力先が学びの置き場（どの学びの物でも）の中にあるか、既に中身のある場所のとき、システムはパックも写しも作らずに止める。

## 検証方針

- **分割クラス**:
  - `#inside-own-learning` — 出力先がその学びの置き場の中なら止める
  - `#inside-other-learning` — 出力先が別の学びか学びでない data の下なら止める
  - `#inside-by-other-spelling` — .. を含む相対パスや絶対パスで置き場の中を指しても止める
  - `#out-not-empty` — 出力先に中身があれば CONFLICT で止め、中身を変えない
  - `#existing-empty-dir-accepted` — 出力先が空のディレクトリなら作る
  - `#inside-before-not-empty` — 置き場の中で中身もあれば INVALID_INPUT（errors の 2 と 3）
  - `#not-empty-before-cycle-exists` — 中身があり写しもあれば CONFLICT で、どちらも書き換えない（errors の 3 と 4）
- **尽きている根拠**: 出力先の場所（置き場の中か外か、書き方の違い）× 中身（無い・空・ある）と隣の errors との組
- **検証しない**: data/ そのものを出力先にする場合（中か外か一意でない。どちらでも断る）。シンボリックリンクで置き場を指す場合
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts`
