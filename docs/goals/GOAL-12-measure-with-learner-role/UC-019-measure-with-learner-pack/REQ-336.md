# REQ-336

> 配る本文の図が XML として整わない SVG であるとき、1 つの図が契約の描く待ち時間の上限のうちに描き終わらないとき、またはほかの理由で図を PNG に描けないとき、システムはその単位と図を挙げて、パックも写しも、コマンドが作った出力先とその親のディレクトリも残さずに止める。

## 検証方針

- **分割クラス**:
  - `#not-well-formed` — 図が XML として整わない SVG（途中で切れた・要素が閉じない・XML で決まっていない実体参照・引用符が閉じない）なら INTERNAL で止め、単位と図を挙げ、パックも写しも残さない
  - `#not-drawable` — 図が XML として整っても PNG に描けなければ（図でない文・空のファイル・xmlns の無い SVG・図でない XML）INTERNAL で止め、単位と図を挙げ、パックも写しも残さない
  - `#created-dirs-removed` — 描けずに止めたとき、コマンドが作った出力先とその親のディレクトリを残さない
  - `#existing-parent-kept` — 描けずに止めても、前からあった出力先の親のディレクトリと中身は残す
- **尽きている根拠**: 描けない図は、XML として整わない物とそれ以外の描けない物の 2 つに分かれ、それぞれを数例と作り物の置き場の点で見る。後始末は、ディレクトリをコマンドが作ったか前からあったかの 2 値で見る。errors の前の項との組は REQ-337 が持つ
- **検証しない**: 描く待ち時間の上限（30 秒）を超える図（上限を超えて描き終わらない SVG を手元で確実に作れず、作れても 1 本の試験が上限を超える）。errors の後の項（作る間に同じ周の写しが書かれた）との組（同時の呼び出しの順序に依り、境界から一意に作れない。REQ-355 の側で同時の呼び出しを見る）。描き方の道具そのものが無い環境（REQ-306 #same-on-ci が、道具を外しても描けることを求める）
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts::配る本文の図を PNG に描けない（REQ-336）`、`tests/server/UC-019_build_figures_and_materials.test.ts::配る本文の図が XML として整わないか PNG に描けない（REQ-336）`
