# REQ-358

> 投入が配る本文を選ぶ教材の世代のファイルに、契約の教材の世代の形として読めないファイルがあるとき、システムはそのファイルを挙げて、パックも写しも作らずに止める。

## 検証方針

- **分割クラス**:
  - `#not-json` — 教材の世代（materials・materials_v2・materials_v3）のどれかのファイルが JSON として読めなければ INVALID_INPUT で止め、そのファイルを挙げ、パックも写しも作らない
  - `#row-without-topic-id` — 世代のファイルに topic_id の無い行（欄が無い・整数でない）があれば同じく止める
  - `#overridden-file-still-checked` — 後の世代に上書きされて配る本文に選ばれない前の世代のファイルでも、読めなければ止める
  - `#several-files-listed` — 読めないファイルが世代をまたいで複数あれば、すべて挙げる
  - `#after-roadmap-row-broken` — ロードマップに欠けた行もあれば、ロードマップの行を挙げて止める（errors の前の項が先）
  - `#before-body-missing` — 配る本文の無い単位もあれば、世代のファイルを挙げて INVALID_INPUT で止める（errors の後の項より先）
- **尽きている根拠**: 契約の世代のファイルの形（readDeliveredBody の errors）は JSON として読めるかと topic_id の有無の 2 つで、それぞれを全世代と作り物の置き場の点で見る。選ばれる・選ばれないファイルの 2 値と、読めないファイルの数の 1・複数で挙げ方を見る。errors の前後の組を 1 つずつ持つ
- **検証しない**: JSON として読め topic_id もあるが、ほかの欄（term・explanation・detail）が欠ける行（契約の世代のファイルの読めない条件に入らない。欠けた本文は REQ-319 の側）。世代のディレクトリの .json でないファイル（契約が世代のファイルとしない）
- **参照先**: `tests/server/UC-019_build_figures_and_materials.test.ts::配る本文を選ぶ教材の世代のファイルが読めない（REQ-358）`
