# REQ-304

> 作り手が周の番号を指定して学習者役のパックを作ったとき、システムはロードマップの単位を学ぶ順に、各単位の ID と属する回を添えて並べた一覧、単位ごとのファイル、ロードマップの単位の確認問題と、単位の ID を必須とする答えと自己申告の書き方を出し、説明テストの語の一覧を持つ学びではその語の説明テストも出す。

## 検証方針

- **分割クラス**:
  - `#order-id-and-round` — 一覧で単位が学ぶ順（単位の ID の順でない）に並び、各行に単位の ID、回の見出しの下に置かれる
  - `#unit-file-per-unit` — ロードマップの単位ごとに 1 ファイル、名前の番号の順が学ぶ順
  - `#quiz-questions` — ロードマップの単位の確認問題が問いと 4 つの選択肢とともに出る
  - `#answer-format` — 答えと自己申告の書き方が、answers 空・units の各行が単位の ID を持つ JSON で出る
  - `#explain-with-terms` — 語の一覧を持つ学びでは説明テストに一覧の語がすべて出る
  - `#no-explain-without-terms` — 語の一覧を持たない学びでは説明テストを出さない
  - `#response-lists-files` — 応答の files がパックの中に実在するファイルと一致する
- **尽きている根拠**: 出すもの（一覧・単位・確認問題・書き方・説明テスト）を 1 つずつと、説明テストの有無の 2 値で分けた。並びは学ぶ順と単位の ID の順を違えたロードマップで、順の取り違えを観測できる形にした
- **検証しない**: 日で束ねる学びの回の見出しの語（登録簿の値で契約に無い）。一覧・確認問題のファイルの書式（見出しや表の形）は契約が決めないので、語の有無と出現の順だけを見る
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts`
