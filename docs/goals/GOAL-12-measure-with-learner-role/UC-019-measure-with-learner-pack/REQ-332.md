# REQ-332

> 作り手が採点しようとして、指定した周の周の結果が既にあるとき、システムは採点を断り、その周の結果を書き換えない。

## 検証方針

- **分割クラス**:
  - `#result-exists` — その周の結果があれば CONFLICT で断り、書き換えない
  - `#result-exists-before-previous-unreadable` — 結果があり差を取る前の周の結果が読めなければ CONFLICT（採点の errors の 7 と 8）
  - `#result-exists-before-answers-missing` — 結果があり答えのファイルも無ければ CONFLICT（errors の 5 と 6）
- **尽きている根拠**: 結果の有無と隣の errors との組で尽きる
- **検証しない**: 断る理由の文言（契約に無い）
- **参照先**: `tests/server/UC-019_grade_learner_answers.test.ts`
