# REQ-318

> 作り手が登録簿に無い学びか、ロードマップを持たない学びを指定してパックを作るか採点しようとしたとき、システムはパックも写しも周の結果も残さずに断る。

## 検証方針

- **分割クラス**:
  - `#exam-learning-build` — 資格型の学びは、ロードマップ型と同じファイルを置いても作るのを断る
  - `#unregistered-build` — 登録簿に無い学びは作るのを断る
  - `#roadmap-file-missing-build` — ロードマップ型でもロードマップが無ければ作るのを断る
  - `#exam-learning-grade` — 資格型の学びは、写しを置いても採点を断る
  - `#unregistered-grade` — 登録簿に無い学びは採点を断る
  - `#roadmap-file-missing-grade` — ロードマップが無ければ採点を断る
  - `#not-roadmap-before-out-inside` — 資格型で出力先が置き場の中でも INVALID_INPUT（errors の 1 と 2）
  - `#not-roadmap-before-questions-missing` — 資格型で確認問題も無くても INVALID_INPUT（採点の errors の 1 と 2）
- **尽きている根拠**: 断る理由 3 つ（資格型・登録簿に無い・ロードマップのファイルが無い）× 入口 2 つと、隣の errors との組。種類は登録簿で決まることを、ファイルをそろえた資格型で見る
- **検証しない**: 断るときの理由の文言（契約に無い。観測するのはコードと何も残らないことだけ）
