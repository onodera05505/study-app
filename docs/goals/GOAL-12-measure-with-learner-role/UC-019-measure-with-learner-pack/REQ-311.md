# REQ-311

> 自己申告の理解の段・混ざった単位・説明の無かった語のキー名が、契約の自己申告の形にある別名で書かれているとき、システムは別名を決めた名前に写して採点する。

## 検証方針

- **分割クラス**:
  - `#understood-alias` — 理解の段の別名（understanding・understand）を understood として数える
  - `#confusing-alias` — 混ざった単位の別名 confusing_with を confusing として残す
  - `#unknown-terms-alias` — 説明の無かった語の別名（unclear_terms・unexplained_terms）を unknown_terms として集める
  - `#alias-equal-to-canonical` — 決めた名前と別名が同じ値で並ぶ行は食い違いとしない
- **尽きている根拠**: 別名は契約の LearnerAnswers の 3 欄 5 語で閉じている。欄ごとに 1 クラス（同じ欄の別名はデータで回す）と、同じ値が並ぶ境目
- **検証しない**: 契約に無い別名（読まないことを見る手段が周の結果に無い）
- **参照先**: `tests/server/UC-019_grade_learner_answers.test.ts`
