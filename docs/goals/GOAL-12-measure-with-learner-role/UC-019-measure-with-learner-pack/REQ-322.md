# REQ-322

> 作り手が指定した周のパックの写しが無いとき、システムは採点を止め、周の結果を残さない。

## 検証方針

- **分割クラス**:
  - `#no-snapshot` — その周の写しが無ければ採点を止め、結果を残さない
  - `#other-cycle-snapshot-only` — 別の周の写ししか無ければ、それで採点しない
  - `#no-snapshot-before-result-exists` — 写しは無いが結果があれば NOT_FOUND で、結果を書き換えない（errors の 4 と 5）
- **尽きている根拠**: 写しが全く無い・別の周だけある・結果だけある（UC の表の行）で尽きる
- **検証しない**: 断る理由の文言（契約に無い）
