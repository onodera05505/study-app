# REQ-333

> 学びの今の確認問題が無いか、契約の確認問題の形として読めないとき、システムはパックも写しも作らず、採点も止めて周の結果を残さない。

## 検証方針

- **分割クラス**:
  - `#questions-missing-build` — パックを作るとき今の確認問題が無ければ NOT_FOUND
  - `#questions-unreadable-build` — パックを作るとき今の確認問題が契約の形として読めなければ INVALID_INPUT で、読めないファイルを挙げる
  - `#unreadable-before-explain-terms-unreadable` — 確認問題も語の一覧も読めなければ、確認問題の束だけを挙げる（作る errors の 6 と 7 は同じコードなので挙げたファイルで見る）
  - `#questions-missing-grade` — 採点のとき今の確認問題が無ければ NOT_FOUND
  - `#questions-unreadable-grade` — 採点のとき読めなければ INVALID_INPUT
  - `#unreadable-before-no-snapshot` — 確認問題が読めず写しも無ければ INVALID_INPUT（採点の errors の 3 と 4）
  - `#missing-before-no-snapshot` — 確認問題が無く写しも無ければ NOT_FOUND
- **尽きている根拠**: 欠け方 2 つ（無い・読めない）× 入口 2 つと隣の errors との組。無いと読めないは同時に成り立たないので組にしない
- **検証しない**: 確認問題の置き場はあるが中に問題が 1 つも無い場合（「無い」か「読めない」か一意でない）
