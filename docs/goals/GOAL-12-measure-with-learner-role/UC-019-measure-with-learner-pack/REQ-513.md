# REQ-513

> 配る本文に、配信の置き場の図を指す前置きを含むのに図の行の形（BR-054）に合わない行があるとき、システムはパックも写しも作らず、その単位と行を挙げて止める。

## 検証方針

- **分割クラス**:
  - `#line-malformed` — 前置きを含み図の行の形に合わない行が 1 つあれば INVALID_INPUT で止め、単位の ID と書かれたままの行の組で挙げ、パックも写しも作らない（段・字・拡張子・説明文・記法・行の中の前後の文・1 行に 2 つ・前置きに触れるだけの文、詳しい解説と説明の両方）
  - `#several-lines-listed` — 形に合わない行が複数の単位や 1 つの単位の中に複数あれば、すべてを挙げる
  - `#well-formed-variants-ok` — 行頭と行末の空白・タブ・全角の空白や、`(` の続かない `]` を説明文に持つ行は図の行として読み、止めない
  - `#only-delivered-body-checked` — 配る本文に選ばれない前の世代の教材にだけ形に合わない行があっても止めない
  - `#body-missing-before-line-malformed` — 配る本文の無い単位と形に合わない行が両方あれば NOT_FOUND で、配る本文の無い単位だけを挙げる（作る errors の「配る本文の無い単位がある」と「図の置き場を指すのに図の行の形に合わない行がある」）
  - `#line-malformed-before-figure-missing` — 形に合わない行と画像の無い図が両方あれば INVALID_INPUT で、形に合わない行だけを挙げる（作る errors の「図の置き場を指すのに図の行の形に合わない行がある」と「配る本文が指す図の画像が無い」）
- **尽きている根拠**: 前置きを含む行を、図の行の形（`MaterialFigureLine`）の部分ごとに外す行と、形の内の境（空白・説明文の `]`）に分け、どの本文が見られるか（配る本文だけ）と、前後の errors の組を足して尽きる
- **検証しない**: 前置きを含まない行の扱い（この文の外）。形に合わない行を挙げる並び（文も契約も決めない）
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts::図の置き場を指すのに図の行の形に合わない行がある（REQ-513）`
