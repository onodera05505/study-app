# REQ-319

> ロードマップに、投入が教材のどの世代からも配る本文を選べない単位があるとき、システムはパックも写しも作らず、その単位を挙げて止める。

## 検証方針

- **分割クラス**:
  - `#unit-body-missing` — 1 単位の配る本文が無ければ止め、その単位の ID を挙げる
  - `#delivered-body-absent` — 配る本文が 1 つも無ければ止める
  - `#body-in-earlier-generation-ok` — 後の世代に無くても前の世代に配る本文がある単位では止めない
  - `#body-missing-before-figure-missing` — 本文の無い単位と画像の無い図が両方あれば本文の無い単位を挙げる（errors の 7 と 8 は同じコードなので挙げた単位で見る）
- **尽きている根拠**: 欠けの広さ（一部・全部）と、どの世代にも無いか前の世代にはあるかの境目、隣の errors との組で尽きる
- **検証しない**: 配る本文の項目はあるが説明か解説が空の単位（契約は minLength 1 だが「無い」に当たるか一意でない）
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts`
