# REQ-339

> その周より小さい番号の周の結果のうち最も大きい番号の物が契約の周の結果の形として読めないとき、システムはそれを挙げて採点を止め、周の結果を残さない。

## 検証方針

- **分割クラス**:
  - `#latest-earlier-unreadable` — より小さい番号のうち最も大きい周の結果が読めなければ止め、それを挙げ、周の結果を残さない
  - `#other-cycles-not-read` — 差を取る周でない、より前の周や後の周の結果が読めなくても止めない
  - `#unreadable-before-answers-missing` — 前の周の結果が読めず答えのファイルも無ければ INVALID_INPUT（採点の errors の 8 と 9）
- **尽きている根拠**: 読めなさを、JSON でない・cycle・rate・avg_understood の欠けや型の違い（readCycleResult の errors）としてデータで回す。差を取る周かどうかの 2 値と、後ろの errors との組で尽きる。前の errors との組は REQ-332 が持つ
- **検証しない**: 差を取る周の結果の cycle の値がファイル名の周と違う場合（読めないに当たるか文が決めない）
- **参照先**: `tests/server/UC-019_grade_learner_answers.test.ts`
