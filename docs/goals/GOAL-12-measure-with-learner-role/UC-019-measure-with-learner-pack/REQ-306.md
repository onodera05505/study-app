# REQ-306

> 単位の配る本文が図を含むあいだ、学習者役のパックはその図を、元の置き場のサブパスを保ち拡張子を .png にした PNG の画像として、元の図の文字（長音符・中黒を含む）を欠かさずに描いて含み、パックの本文の図はその PNG を指して、学習者役がパックの外に出ずに図を画像として開ける。

## 検証方針

- **分割クラス**:
  - `#svg-drawn-as-png` — 置き場の直下の svg の図が、figures の下に拡張子を .png にした PNG として入り、本文の図がそれを指す
  - `#subpath-kept` — 置き場のサブパスの下の図が、figures の下に同じサブパスの PNG として入る
  - `#png-source` — 元が png の図も同じ名前の PNG として入る
  - `#symbols-drawn` — 図の文字の中黒・長音符だけが違えば、パックの PNG の中身も違う
  - `#unit-without-figure` — 図を含まない単位のファイルは画像を指さない
  - `#no-outside-reference` — パックのどの本文も配信の置き場・パックの外・PNG でない画像を指さない
  - `#tall-and-wide-drawn-whole` — 縦長・横長の図を、元の図の幅と高さのまま切らずに描く（PNG の寸法が元の図の寸法と一致し、図の端に置いた文字だけが違う 2 つの図から作った PNG が違う）
  - `#same-on-ci` — 上の各クラスが、ubuntu の CI でも手元と同じく通る（描き方が OS に備わった道具に依らない）
- **尽きている根拠**: 元の図の形式（svg・png）× 置き場の深さ（直下・サブパス）と、図の有無、参照先がパックの外に漏れる場合、図の形（標準・縦長・横長）で尽きる。文字を欠かさず描くことは、その記号だけを違えた 2 つの図（縦長は下端、横長は右端に置く）から作った PNG が違うことで、切らずに描くことは PNG の寸法が元の図の幅と高さに一致することで見る。CI と同じことは、PATH から qlmanage・sips を持つディレクトリを外して作ったパックで見る
- **検証しない**: ubuntu の CI そのものでの実行（手元では PATH から macOS の道具を外して代える）。描いた文字が読めるか・欠けた字形（豆腐）で描かれていないか（画像の中の文字は機械で読めず、人が見る）。1 つの画像を複数の単位が指す場合（外から観測しても同じ）
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts`
