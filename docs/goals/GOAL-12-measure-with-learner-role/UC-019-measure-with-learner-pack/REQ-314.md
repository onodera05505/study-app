# REQ-314

> 作り手が周の番号を指定して採点したとき、システムは周の結果として、写しの全単位と問題ごとの単位・到達基準・分野で数えた全体と各別の正答、理解の段を書いた単位での理解の段の平均、詰まった単位、過信の単位、説明の無かった語を残して示し、説明テストの採点を添えたときはその得点を、より小さい番号の周の結果があるときは最も大きい番号の物との差を含める。

## 検証方針

- **分割クラス**:
  - `#tally-overall` — 写しの全問題の正答を score と rate に出す
  - `#tally-by-goal` — 到達基準ごとの正答
  - `#tally-by-field` — 分野ごとの正答
  - `#per-unit-all-units` — per_unit が写しの全単位（自己申告や問題の無い単位も）を持つ
  - `#unanswered-is-wrong` — 答えの無い問題を誤答に数え、選んだ答え無しで挙げる
  - `#avg-over-reported` — 理解の段の平均を書いた単位だけで取る
  - `#avg-none-reported` — 書いた単位が無ければ平均 0・数 0
  - `#stuck-by-understood` — 「分からなかった」単位は全問正解でも詰まった単位
  - `#stuck-by-zero-correct` — 問題を持ち 1 問も正解しない単位は詰まった単位
  - `#not-stuck-without-questions` — 問題を持たず「分からなかった」でない単位は詰まった単位でない
  - `#overconfident` — 「人に説明できる」で間違えた単位は過信の単位
  - `#not-overconfident` — 「人に説明できる」でも全問正解か問題の無い単位は過信でない
  - `#unknown-terms-collected` — 説明の無かった語を重ねずに集める
  - `#explain-score` — 説明テストの採点を添えると得点を出す
  - `#no-explain-no-field` — 添えなければ explain を持たない
  - `#delta-from-latest-earlier` — より小さい番号のうち最も大きい周との差を出し、大きい番号の周は見ない
  - `#no-earlier-no-delta` — より小さい番号の周の結果が無ければ差を持たない
  - `#result-saved` — 周の結果を cycle_<周>.json に残し、示した結果と同じ
  - `#tallied-by-snapshot` — 今の問題の到達基準や単位が変わっても写しで数える
- **尽きている根拠**: 文が挙げる周の結果の項目ごとに、含まれる場合と含まれない場合（詰まった・過信は用語集の 2 条件それぞれと否定）に分けた。差は前の周の有無と、前後の周が混ざる場合
- **検証しない**: 数の丸め（rate・平均は近似で比べる）。stuck_units・overconfident_units の並びの順（契約が決めない）
