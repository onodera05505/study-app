# REQ-329

> 作り手が指定した答えのファイルが無いか、契約の答えの形として読めないか、選んだ答えに選択肢の外の値があるとき、システムは採点を止め、周の結果を残さない。

## 検証方針

- **分割クラス**:
  - `#answers-missing` — 答えのファイルが無ければ NOT_FOUND
  - `#answers-unreadable` — 答えのファイルが契約の形として読めなければ INVALID_INPUT
  - `#out-of-choice` — 選んだ答えに選択肢の外の値があれば INVALID_INPUT
  - `#answers-unreadable-before-explain-missing` — 答えが読めず説明テストの採点も無ければ INVALID_INPUT（errors の 7 と 8）
- **尽きている根拠**: 文の条件 3 つと隣の errors との組。errors の 6 と 7（無いと読めない）は同時に成り立たないので組にしない
- **検証しない**: 空文字の選んだ答え（未回答か選択肢の外か一意でない）。写しに無い問題の識別子への答え（文が決めない）
- **参照先**: `tests/server/UC-019_grade_learner_answers.test.ts`
