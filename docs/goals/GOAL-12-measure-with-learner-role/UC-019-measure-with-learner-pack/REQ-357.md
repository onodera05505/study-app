# REQ-357

> システムは配る本文の図を、図の中の script を走らせず、図のファイルの外の資源を取りに行かずに PNG に描く。

## 検証方針

- **分割クラス**:
  - `#script-not-run` — 図の script（script 要素・読み込みの属性・外の script を読む要素）は描く間に走らず、図は PNG に描かれてパックが出来る
  - `#outside-not-fetched` — 図が図のファイルの外の資源（http の画像・CSS の読み込みと塗り・use・フォント・同じ置き場の隣のファイル）を指しても取りに行かず、図は PNG に描かれてパックが出来る
- **尽きている根拠**: 図が描く間に図の外へ働きかける手は、図の中のコードを走らせることと、図の外の資源を読むことの 2 つに分かれる。走ったか・読んだかは、手元に立てた受け口が受けた要求の数と、走れば・読めば全面を黒で覆う図の中央の画素で見る
- **境界の扱い**: 同じ置き場の隣のファイルも図のファイルの外として、読めば黒が描かれる画像で見る
- **検証しない**: file の参照で読まれる手元の任意のファイル（読まれたかを画素でも要求でも観測できない）。描く道具の起動そのものの隔たり（文は図が外へ働きかけないことだけを決める）
- **参照先**: `tests/server/UC-019_build_figures_and_materials.test.ts::図の中の script を走らせず、図のファイルの外の資源を取りに行かずに描く（REQ-357）`
