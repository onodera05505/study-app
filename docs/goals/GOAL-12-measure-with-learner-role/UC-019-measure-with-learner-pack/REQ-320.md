# REQ-320

> 配る本文の図の行（BR-054）が指す図の画像が置き場所に無いとき、システムはパックも写しも作らず、その単位と図を挙げて止める。

## 検証方針

- **分割クラス**:
  - `#figure-missing` — 本文が指す画像が無ければ止め、その図を属する単位の ID と本文の図の行の参照先の組で挙げる（svg・png、直下・サブパス）
  - `#figure-only-in-other-learning` — 同じ名前の画像が別の学びの置き場にしか無ければ止める
  - `#figure-missing-before-name-collision` — 画像の無い図と同じ PNG の名前になる図が両方あれば NOT_FOUND で、画像の無い図だけを挙げる（作る errors の「配る本文が指す図の画像が無い」と「同じ PNG の名前になる図が 2 つ以上ある」）
- **尽きている根拠**: 画像が無い場合と、別の学びの物で黙って埋まる場合（BR-026）で尽きる
- **検証しない**: 図の置き場を指すのに図の行の形に合わない行（図の行でなく、REQ-513 が持つ）
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts`
