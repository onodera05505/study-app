# REQ-305

> 学習者役のパックの各単位のファイルは、単位の名前と分野と単元を添え、その単位について利用者に配る本文（投入が教材の世代から論点ごとに選ぶ説明と詳しい解説で、出典と図の行を含む）を、図の参照先だけを変えて全文含む。

## 検証方針

- **分割クラス**:
  - `#unit-header` — 単位のファイルが単位の名前・分野・単元を添える
  - `#full-body` — 説明と詳しい解説（出典と図の行を含む）を、図の参照先を戻せば全文含む
  - `#latest-generation-per-unit` — 配る本文は単位ごとに後の世代の教材を選び、後の世代に無い単位は前の世代の物を出す
  - `#delivered-not-edited` — 直したが組み立て直していない教材はパックに出ず、配る本文が出る
- **尽きている根拠**: 単位のファイルの中身を、添える属性・本文の全文・本文の出どころ（単位ごとにどの世代を選ぶか・配る本文か直した教材か）に分けた
- **検証しない**: 本文の中の改行や空白の正規化（配る本文を文字どおり含むかだけを見る）。materials_v2 の世代（ファイルの置き方が契約に無く、フィクスチャは materials と materials_v3 の 2 世代で前後を見る）
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts`
