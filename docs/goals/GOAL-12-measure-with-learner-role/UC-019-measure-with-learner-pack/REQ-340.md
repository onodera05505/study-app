# REQ-340

> 作り手がパックを作る入口か採点の入口に、契約の引数の形の外の値（1 未満の周の番号、空の出力先や答えのファイル、学びの置き場の形でない学び）を渡したとき、システムは何も読まず書かずに断る。

## 検証方針

- **分割クラス**:
  - `#build-bad-cycle` — パックを作る入口に 1 以上の整数でない周の番号を渡すと断り、何も書かない
  - `#build-empty-out` — パックを作る入口に空の出力先を渡すと断る
  - `#build-bad-data` — パックを作る入口に学びの置き場の形でない学びを渡すと断る
  - `#build-all-bad-arguments-listed` — パックを作る入口で形の外の引数が複数あれば、すべての名前を挙げる
  - `#bad-args-before-not-roadmap-build` — 資格型の学びで周の番号も形の外なら、引数の誤りとして断る（作る errors の 1 と 2）
  - `#grade-bad-cycle` — 採点の入口に 1 以上の整数でない周の番号を渡すと断り、何も書かない
  - `#grade-empty-answers` — 採点の入口に空の答えのファイルを渡すと断る
  - `#grade-empty-explain` — 採点の入口に空の説明テストの採点のファイルを渡すと断る
  - `#grade-bad-data` — 採点の入口に学びの置き場の形でない学びを渡すと断る
  - `#grade-all-bad-arguments-listed` — 採点の入口で形の外の引数が複数あれば、すべての名前を挙げる
  - `#bad-args-before-not-roadmap-grade` — 資格型の学びで周の番号も形の外なら、引数の誤りとして断る（採点の errors の 1 と 2）
- **尽きている根拠**: 2 つの入口の request の欄ごとに、契約の型と範囲の外（周の番号は 0・負・小数・数でない、パスは空、学びは data/ の無い・大文字・末尾の /・.. ・数字）をデータで回し、複数の欄と前後の errors の組を足して尽きる。「何も読まず書かず」は作業場所のファイルが 1 つも変わらないことで見る
- **検証しない**: 必須の引数そのものを渡さない場合（コマンドの引数の読み方の慣習に依り、契約の形の外の値に当たるか一意でない）。何も読まないこと（読んだかは外から観測できず、書かないことだけを見る）
