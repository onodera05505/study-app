# REQ-340

> 作り手がパックを作る入口か採点の入口に、BR-055 の読み方で契約の引数の形の外になる引数を渡したとき、システムは何も読まず書かずに断り、その引数を BR-055 のとおりに挙げる。

## 検証方針

- **分割クラス**:
  - `#build-bad-cycle` — パックを作る入口に 1 以上の整数でない周の番号を渡すと断り、何も書かない
  - `#build-empty-out` — パックを作る入口に空の出力先を渡すと断る
  - `#build-bad-data` — パックを作る入口に学びの置き場の形でない学びを渡すと断る
  - `#build-missing-argument` — パックを作る入口で data・cycle・out のどれかの引数が無い（引数を付けない・名前だけで値が無い・契約の引数名の前の部分だけの名前でしか渡さない）と断り、その欄を挙げる
  - `#build-duplicated-argument` — パックを作る入口に同じ名前の引数を 2 回渡すと断る（前の値が形の外で後ろの値が形の内のときを含む）
  - `#build-all-bad-arguments-listed` — パックを作る入口で形の外の引数が複数あれば、BR-055 の並びで 1 回ずつ挙げる
  - `#build-extra-argument` — パックを作る入口に、契約の引数がそろったうえで契約に無い引数（契約に無い名前・契約の引数名の前の部分だけの名前・どの名前の値でもない語）を渡すと断り、その名前か語を挙げ、何も書かない
  - `#bad-args-before-not-roadmap-build` — 資格型の学びで周の番号も形の外なら、引数の誤りとして断る（作る errors の 1 と 2）
  - `#grade-bad-cycle` — 採点の入口に 1 以上の整数でない周の番号を渡すと断り、何も書かない
  - `#grade-empty-answers` — 採点の入口に空の答えのファイルを渡すと断る
  - `#grade-empty-explain` — 採点の入口に空の説明テストの採点のファイルを渡すと断る
  - `#grade-bad-data` — 採点の入口に学びの置き場の形でない学びを渡すと断る
  - `#grade-missing-argument` — 採点の入口で data・cycle・answers のどれかの引数が無い（引数を付けない・名前だけで値が無い・前の部分だけの名前でしか渡さない）と断り、その欄を挙げる
  - `#grade-duplicated-argument` — 採点の入口に同じ名前の引数を 2 回渡すと断る
  - `#grade-all-bad-arguments-listed` — 採点の入口で形の外の引数が複数あれば、BR-055 の並びで 1 回ずつ挙げる
  - `#grade-extra-argument` — 採点の入口に、契約の引数がそろったうえで契約に無い引数（契約に無い名前・契約の引数名の前の部分だけの名前・どの名前の値でもない語）を渡すと断り、その名前か語を挙げ、何も書かない
  - `#bad-args-before-not-roadmap-grade` — 資格型の学びで周の番号も形の外なら、引数の誤りとして断る（採点の errors の 1 と 2）
  - `#hyphen-value-in-shape` — `-` で始まる値（`--out -x`・`--answers -a.json`）を `=` の有無どちらで渡しても値として読み、引数の誤りとして断らない
- **尽きている根拠**: 2 つの入口の request の欄ごとに、契約の型と範囲の外（周の番号は 0・負・小数・数でない、パスは空、学びは data/ の無い・大文字・末尾の /・.. ・数字）をデータで回し、BR-055 が形の外とする引数の現れ方（欄の欠け・値の欠け・名前の重なり・余りの名前と語）を入口ごとに置き、複数の欄と前後の errors の組を足して尽きる。値と名前の見分けの境は `-` で始まる値の 1 クラスで、形の内の側に置く。「何も読まず書かず」は作業場所のファイルが 1 つも変わらないことで見る
- **検証しない**: 何も読まないこと（読んだかは外から観測できず、書かないことだけを見る）
