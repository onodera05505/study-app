# REQ-360

> 学習者役への指示が示す答えと自己申告の書き方は、契約の答えと自己申告の形と同じ欄の名前と型を持ち、各単位の行に単位の ID を必須とする。

## 検証方針

- **分割クラス**:
  - `#format-present` — 指示に answers と units を持つ JSON の書き方があり、answers と units を名に持つのに JSON として読めない書き方の候補は無い
  - `#unit-row-id-required` — 書き方の units は 1 行以上あり、どの行も 1 以上の整数の topic_id を持つ
  - `#fields-and-types-match` — 書き方の欄の名前はすべて契約の LearnerAnswers（トップと units の行）にあり、値の型が契約の型に合う
- **尽きている根拠**: 書き方と契約の形の一致は、書き方が機械で読めること・単位の ID が必須であること・欄の名前と型が契約の内にあることの 3 つに分かれる。契約の形は試験の中で contract.yaml から読み、書き写さない
- **検証しない**: 契約の欄のうち書き方に出さない物（別名と任意の欄。文は書き方に出す欄が契約と同じ名前と型であることを決め、すべての欄を出すことを求めない）。overall の中の欄（契約が中身の形を決めていない）。指示の地の文の書き方の説明
- **参照先**: `tests/server/UC-019_render_learner_instructions.test.ts::指示の答えと自己申告の書き方は契約の形と同じ（REQ-360）`
