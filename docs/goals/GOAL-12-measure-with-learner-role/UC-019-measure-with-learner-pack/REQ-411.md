# REQ-411

> 作り手が学習者役への指示を描き出す入口に、BR-055 の読み方で契約の引数の形の外になる引数を渡したとき、システムは何も読まず書かずに断り、その引数を BR-055 のとおりに挙げる。

## 検証方針

- **分割クラス**:
  - `#data-missing` — 学びが無い（引数を付けない・名前だけで値が無い・前の部分だけの名前でしか渡さない）なら断り、data を挙げ（前の部分だけの名前は続けてその名前も）、何も書かない
  - `#data-not-in-shape` — 学びが学びの置き場の形（前置きの無い data/<key> か、作り物の置き場の前置き付き）でなければ断り、data を挙げ、何も書かない
  - `#duplicated-argument` — 学びを 2 回渡せば（値を問わない）断り、data を 1 回挙げ、何も書かない
  - `#unknown-argument` — 契約に無い名前（前の部分だけの名前を含む）か、どの名前の値でもない語を渡せば断り、それらを現れた順にすべて挙げ、何も書かない
  - `#before-not-roadmap` — ロードマップを持たない学びに契約に無い引数も渡せば、引数の誤りとして挙げる（errors の後の項より先）
  - `#fixture-prefix-in-shape` — 作り物の置き場の前置きを持つ学びは形の内として描き出し、応答の path はその置き場の指示を指す
- **尽きている根拠**: 契約の引数は data 1 つで、BR-055 の形の外は 欠ける（値の無い名前・省略形を含む）・値が形の外・重なる・ほかの名前か語が足される の 4 つがすべて。形の外の data は、段の欠け・大文字・末尾の区切り・親への遡り・数字・前置きの誤り・空・`-` で始まる値の点で見る。形の内の境として作り物の置き場の前置きを 1 つ持つ
- **検証しない**: 「何も読まない」のうち、読んだかどうかそのもの（境界の外から観測できない。作業場所が変わらないことと、後の項の理由を返さないことで見る）
- **参照先**: `tests/server/UC-019_render_learner_instructions.test.ts::入口の引数が契約の形の外（REQ-411）`
