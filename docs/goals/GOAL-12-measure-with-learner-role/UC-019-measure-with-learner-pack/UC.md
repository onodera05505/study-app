# UC-019 学習者役のパックを作って読ませ、伝わったかを周の結果で測る

## 概要

作り手が、ロードマップ型の学びから周の番号を付けて学習者役のパックを作り、学習者役への指示と共に学習者役に渡し、返ってきた答えと自己申告をその周のパックの写しで採点して、どの単位が伝わりどこで詰まったかを周の結果として受け取る。

## 事前条件

- ロードマップ型の学びで、ロードマップ・確認問題と、利用者に配る本文がそろっている
- 適用される業務規則: BR-026, BR-031

## 主シナリオ

1. 作り手が、学びと周の番号と出力先を指定して学習者役のパックを作る
2. システムが、その周のパックの写しを残す
3. システムが、ロードマップ・単位ごとの配る本文と図・確認問題、語の一覧がある学びでは説明テストを、正解を含めずにパックへ出す
4. 作り手が、学びの学習者役への指示を雛形から描き出す
5. 作り手が、パックと学習者役への指示だけを学習者役に渡す
6. 学習者役が、ロードマップの順に単位を読み、確認問題に答え、単位ごとの自己申告と説明テストの答えを返す
7. 作り手が、同じ周の番号を指定して学習者役の答えを採点する
8. システムが、その周のパックの写しで採点し、周の結果を残して作り手に示す
