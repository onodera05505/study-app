# UC-019 学習者役のパックを作って読ませ、伝わったかを周の結果で測る

## 概要

作り手が、ロードマップ型の学びから周の番号を付けて学習者役のパックを作り、学習者役に渡し、返ってきた答えと自己申告をその周のパックの写しで採点して、どの単位が伝わりどこで詰まったかを周の結果として受け取る。

## 事前条件

- ロードマップ型の学びで、ロードマップ・確認問題と、利用者に配る本文がそろっている
- 適用される業務規則: BR-026, BR-031

## 主シナリオ

1. 作り手が、学びと周の番号と出力先を指定して学習者役のパックを作る
2. システムが、その周のパックの写しを残す
3. システムが、ロードマップ・単位ごとの配る本文と図・確認問題、語の一覧がある学びでは説明テストを、正解を含めずにパックへ出す
4. 作り手が、パックだけを学習者役に渡す
5. 学習者役が、ロードマップの順に単位を読み、確認問題に答え、単位ごとの自己申告と説明テストの答えを返す
6. 作り手が、同じ周の番号を指定して学習者役の答えを採点する
7. システムが、その周のパックの写しで採点し、周の結果を残して作り手に示す

## 事後条件

- 成功時: 作り手が、その周の正答の内訳・自己申告・詰まった単位・過信の単位・説明の無かった語と、前の周がある学びでは前の周との差を、周の結果として見ている
- 失敗時: いかなる状態変更も残っていない（部分適用なし。パックを作れないときはパックも写しも残さず、採点が止まったときは周の結果を残さない）
