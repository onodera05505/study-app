# REQ-308

> 作り手が学習者役のパックを作るとき、システムはその時点のロードマップに無い単位の確認問題を、パックにも写しにも入れない。

## 検証方針

- **分割クラス**:
  - `#off-roadmap-excluded` — ロードマップに無い単位の問題がパックにも写しにも入らない
  - `#roadmap-questions-kept` — ロードマップにある単位の問題はすべて写しに入る
- **尽きている根拠**: 問題の単位がロードマップにあるかの 2 値で尽きる。後者で「全部落とす」実装を弾く
- **検証しない**: ロードマップに無い単位の問題を出力に挙げるか（文が決めない）
