# REQ-337

> パックに入れる 2 つ以上の図が、同じサブパスで拡張子だけが違い同じ PNG の名前になるとき、システムはどの図も上書きせず、それらの単位と図を挙げて、パックも写しも作らずに止める。

## 検証方針

- **分割クラス**:
  - `#extension-only-differs` — 直下・サブパスで拡張子だけが違う図を別の単位が指せば止め、両方の単位と図を挙げ、どの画像も上書きしない
  - `#not-a-collision` — 同じ図を 2 つの単位が指す場合と、サブパスが違う場合は重なりとせずパックを作る
  - `#collision-before-not-drawable` — 名前の重なる図と描けない図が両方あれば INVALID_INPUT（作る errors の 12 と 13）
- **尽きている根拠**: 重なりの条件「同じサブパス・拡張子だけ違う・2 つ以上の図」を満たす場合（直下・サブパス）と、片方を外した場合（同じ図・違うサブパス）、後ろの errors との組で尽きる
- **検証しない**: 3 つ以上の図が重なる場合（2 つの場合と同じ条件で、挙げる数が増えるだけ）
- **参照先**: `tests/server/UC-019_build_learner_pack.test.ts`
