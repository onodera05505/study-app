# REQ-466

> 作り手が登録簿に無い学びか資格対策でない学びの束を作ろうとしたとき、またはその学びのシラバスか論点の一覧が無いか読めないとき、システムは束を 1 つも書き出さずに断る。

## 検証方針

- **分割クラス**:
  - `#unknown-learning` — 登録簿に無い学びは、置き場があっても両方の入口で INVALID_INPUT で断り、作業場に何も書き出さない
  - `#not-qualification` — 登録簿のロードマップ型の学びは、置き場があっても両方の入口で INVALID_INPUT で断り、作業場に何も書き出さない
  - `#learning-file-missing` — シラバスか論点の一覧が無ければ、両方の入口で NOT_FOUND で断り、何も書き出さない
  - `#learning-file-unreadable` — シラバスか論点の一覧が JSON として読めなければ、両方の入口で INVALID_INPUT で断り、何も書き出さない
  - `#registry-before-files` — 資格対策でなくシラバスも無ければ INVALID_INPUT（契約の errors の順）
  - `#missing-before-unreadable` — シラバスが無く論点の一覧も読めなければ NOT_FOUND（契約の errors の順）
- **尽きている根拠**: 断る条件は、登録簿（無い・ロードマップ型）と学びのファイル（シラバス・論点の一覧のそれぞれが無い・読めない）で尽きる。errors の隣り合う組のうち code の違う物を順のクラスにした
- **検証しない**: `data` の形に合わない値（引数の形の検査で、REQ の文が扱わない）。code の同じ隣り合う組（INVALID_INPUT 同士）の順（観測で区別できない）
- **参照先**: `tests/server/UC-026_build_rewrite_bundles.test.ts::登録簿に無い学び・資格対策でない学び・シラバスか論点の一覧が無いか読めない学びは何も書き出さずに断る（REQ-466）`
