# REQ-465

> 作り手が単元を指定して束を作る場合、システムは指定した単元の束だけを書き出し、指定した単元のどれかがその学びのシラバスに無ければ何も書き出さずに断る。

## 検証方針

- **分割クラス**:
  - `#only-specified-unit-inputs` — 単元の入力の束は指定した単元の束だけを書き出す
  - `#only-specified-rewrite` — 書き直しの束は指定した単元のまとまりの束だけを書き出す
  - `#unknown-unit` — シラバスに無い単元を指定に含めれば、両方の入口で INVALID_INPUT で断り、何も書き出さない
- **尽きている根拠**: 指定は、無い（論点のある全単元。REQ-461・463）・シラバスの単元だけ・シラバスに無い単元を含むの 3 つで、2 つの入口それぞれで見る
- **検証しない**: 同じ単元を 2 回指定した並び（文が扱わない）
- **参照先**: `tests/server/UC-026_build_rewrite_bundles.test.ts::単元を指定すれば、その単元の束だけを書き出す（REQ-465）`
