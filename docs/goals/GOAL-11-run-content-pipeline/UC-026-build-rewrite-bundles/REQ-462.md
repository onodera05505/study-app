# REQ-462

> 作り手が資格対策の学びの書き直しの束を作ったとき、システムは単元の構成のまとまりごとに 1 つ、単元の全体像とまとまりの名前と説明、学ぶ順に並べたまとまりの論点、各論点の最も新しい世代の教材・同一内容の組を 1 件に畳んだ紐づく過去問・同一内容の判定でその組に結んだ問題解説・図の仕様・前提の論点、そのまとまりの論点が触れる受け持ちを持つ束を書き出す。

## 検証方針

- **分割クラス**:
  - `#one-per-group` — まとまりごとに 1 つの束を単元の番号 2 桁とまとまりの順の名前で書き出し、そのパスを返す
  - `#bundle-header` — 束は束の名前・単元の番号と名前・全体像・そのまとまりの順と名前と説明・単元の全部のまとまりを持つ
  - `#learn-order` — 束の論点はそのまとまりの論点だけで、単元の構成の学ぶ順
  - `#topic-attributes` — 各論点は名前・分野・大項目・単元・小項目の名前・出題回数・周辺の用語を持つ
  - `#newest-generation` — 各論点の今の教材は最も新しい世代の名前と教材
  - `#questions-folded` — 紐づく過去問は同一内容を 1 件に畳み、代表は新しい回の問題で、契約の作り方の content_key・本文・選択肢・正解を持つ
  - `#question-explanations` — 各論点は、組の古い回の問題の ID で書いた解説も含め、同一内容の判定で組に結んだ問題解説を持つ
  - `#figures` — 図の仕様を持つ論点はそのパスと figures の写しを、持たない論点は null と空を持つ
  - `#prerequisites` — 各論点は前提の論点を他の単元の物も含めて番号と名前で持ち、無ければ空
  - `#owners-touching-group` — 束はそのまとまりの論点が触れる受け持ちだけを、受け持ちの論点が前のまとまりにあっても持つ
- **尽きている根拠**: 文の束の中身の要素ごとに 1 クラス。過去問は同一内容の組・1 問・0 問、解説は代表と違う回の ID で書いた物・代表の ID で書いた物・無し、図は有る・無い、前提は同じ単元・他の単元・無し、受け持ちは触れる・触れないを同じ仕込みに置く
- **検証しない**: 過去問の exam_label・has_figure・figure_description（契約で任意の欄）。束の問題解説の question_id の値（契約の「問題解説を書いた代表の過去問」が、解説を書いたときの ID か畳んだ組の代表かを決めていない。報告済み）。問題解説の choices の中身（解説の写しで、REQ の文は解説を持つことだけを言う）。本文や選択肢に空白文字を含む過去問の鍵（作り方の正規化の変種で、値の正本は BR-052 が置く content_key_of）
- **参照先**: `tests/server/UC-026_build_rewrite_bundles.test.ts::まとまりごとに 1 つ、書き直しに要る物を持つ書き直しの束を書き出す（REQ-462）`
