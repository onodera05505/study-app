# REQ-461

> 作り手が資格対策の学びの単元の入力の束を作ったとき、システムは論点が 1 つ以上あるシラバスの単元ごとに 1 つ、その単元の全論点を小項目の番号と論点の番号の順に並べ、各論点の名前・小項目・出題回数・周辺の用語と、教材の世代を古い順に重ねて論点ごとに最も新しい世代の教材を持つ束を書き出し、論点の無い単元の束は書き出さない。

## 検証方針

- **分割クラス**:
  - `#one-per-unit` — 単元を指定しなければ論点のあるシラバスの単元ごとに 1 つの束を書き出し、そのパスを返し、束は単元の番号・名前・分野・大項目を持つ
  - `#topicless-unit-skipped` — 論点が 1 つも無い単元の束は書き出さない
  - `#topic-order` — 束の論点は単元の全論点で、小項目の番号の順、同じ小項目の中は論点の番号の順
  - `#topic-attributes` — 各論点は名前・小項目の番号と名前・出題回数・周辺の用語を持つ
  - `#newest-generation` — 各論点の教材は、世代を古い順に重ねて論点ごとに最も新しい世代の物
  - `#ignores-unit-plans` — 単元の構成が無い・止める理由に当たる単元でも束を作る
- **尽きている根拠**: 文の要素（論点のある単元ごとに 1 つ・論点の無い単元は書かない・並び・論点の属性・教材の選び方）をそれぞれクラスにし、UC の表の「単元の入力の束は単元の構成を読まない」を加えた。教材の選び方は最も古い世代だけ・中間の世代まで・最も新しい世代まで有る論点を同じ仕込みに置く
- **検証しない**: 論点の無い単元を指定したとき（文は書き出さないとだけ言い、空の応答か断りかを観測で決める根拠が無い）。教材の本文の図の行の扱い（文が扱わない）
