# REQ-539

> 作り手がロードマップ型の学びの投入データを組み立てるときに、ロードマップに教材の無い単位か、確認問題の数が 1 単位あたりの確認問題の数と違う単位があるとき、または印を持つ学びで補足の論点を含めて登録簿の印の段に無い印の単位があるとき、システムは投入データを書き出さずに組み立てを止め、その単位の名前を示す。

## 検証方針

- **分割クラス**:
  - `#material-missing-stops` — ロードマップに教材の無い単位があれば、投入データを書き出さずに止まり、その単位の名前を示す
  - `#question-count-short-stops` — 確認問題の数が 1 単位あたりの数より少ない単位があれば、同じく止まり、その単位の名前を示す
  - `#question-count-over-stops` — 確認問題の数が 1 単位あたりの数より多い単位があれば、同じく止まり、その単位の名前を示す
  - `#tier-outside-registry-stops` — 印を持つ学びで、登録簿の印の段に無い印（段の下の外・上の外）の単位があれば、同じく止まり、その単位の名前を示す
  - `#tier-missing-stops` — 印を持つ学びで、印の欄を欠く単位があれば、同じく止まり、その単位の名前を示す
  - `#extra-tier-outside-stops` — 印を持つ学びで、補足の論点の印（候補の印）が段に無いか欠けていれば、同じく止まり、その論点の名前を示す
  - `#material-missing-before-question-count` — 教材の無い単位と確認問題の数が違う単位が両方あれば、教材の無い単位の名前を示して止まり、もう一方は示さない
  - `#question-count-before-tier-outside` — 確認問題の数が違う単位と段に無い印の単位が両方あれば、確認問題の数が違う単位の名前を示して止まり、もう一方は示さない
  - `#tier-outside-before-blank-subtitle` — 段に無い印の単位と副題の欄が空の単位（REQ-422）が両方あれば、段に無い印の単位の名前を示して止まり、もう一方は示さない
- **尽きている根拠**: 文の 3 つの条件を、確認問題の数は少ない・多い、印は段の外・欄が無い・補足の論点の印に分けた。errors の隣り合う組（教材の欠け→確認問題の数→段に無い印→副題）は両方に当たる入力を 1 つずつ置き、後の条件の単位を学ぶ順で先に置く
- **境界の扱い**: 学びの置き場は itc（日で束ね、補足の論点を持つ）と eng（章で束ね、印を持つ）の今のデータの写しで、写しのままで組み立てが通ることを先に確かめる。1 単位あたりの数は写しの各単位の数から 1 つ増減して作る。止めたときは学びの置き場の全ファイルが組み立ての前のままであることを見る
- **検証しない**: 印を持たない学びで印を見ないこと（itc の写しのままの組み立てで通る）
- **参照先**: `tests/server/UC-030_build_target_dataset.test.ts::UC-030 教材・確認問題の数・印が欠けた単位があれば投入データを書き出さない`
