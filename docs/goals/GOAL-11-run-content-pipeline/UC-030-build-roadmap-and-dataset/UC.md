# UC-030 ロードマップ型の学びのロードマップと投入データを論点の候補から組み立てる

## 概要

作り手が、ロードマップ型の学びの論点の候補とロードマップの設定からロードマップのデータを組み立て直し、必要なら単位の要約を差し替え、教材と確認問題がそろったあとで投入データを組み立てて、配る本文を投入へ回せる形にする。

## 事前条件

- ロードマップ型の学びが登録簿にあり、論点の候補とロードマップの設定が学びの置き場にある
- 投入データを組み立てるときは、ロードマップの単位の教材と確認問題が学びの置き場にある

## 主シナリオ

1. 作り手が、論点の候補とロードマップの設定から、ロードマップのデータを組み立て直す
2. システムが、設定の回の束ね方、設定が指す論点の ID、候補の名前と、章で束ねる学びでは候補の章の名前と印を確かめる
3. システムが、到達基準を持つ候補から単位を選び、選んだ単位の前提の候補を含めて学ぶ順に並べ、各単位の名前と副題を分けたままロードマップのデータに書き出し、到達基準に繋がらない候補を落とした候補として残す
4. システムが、書き手の教材の束がまだ無い学びでは、書き手への束の割り当ても書き出す
5. 作り手が、単位の論点の ID と新しい要約を渡して、要約を差し替える
6. システムが、ロードマップの設定の要約の差し替えと、ロードマップのデータのその単位の要約を同じ値に書き換える
7. 作り手が、教材と確認問題がそろった学びの投入データを組み立てる
8. システムが、ロードマップの各単位の教材と確認問題の数と印と副題の欄を確かめる
9. システムが、各単位の名前と副題を分けたまま、ロードマップに無い論点の教材を補足の論点として学ぶ順の末尾に置き、投入データを書き出す
10. 作り手が、組み立てが止まらずに投入データが書き出されたことを見る
