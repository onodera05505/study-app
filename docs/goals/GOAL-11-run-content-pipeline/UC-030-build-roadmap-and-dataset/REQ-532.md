# REQ-532

> 作り手が論点の候補からロードマップのデータを組み立て直すときに、ロードマップの設定の回の束ね方が日でも章でもなければ、システムはロードマップのデータを書き出さずに組み立てを止め、その束ね方を示す。

## 検証方針

- **分割クラス**:
  - `#other-word-stops` — 回の束ね方が日・章を表す値と違う語（契約の例の fixture の語を含む）なら、ロードマップのデータを書き出さずに止まり、その語を示す
  - `#non-string-stops` — 回の束ね方が文字列でない値（数・真偽・配列）なら、書き出さずに止まる
  - `#duplicate-term-before-unknown-grouping` — 契約の errors で直前にある「候補の中に名前が同じ単位がある」と両方に当たる入力では、名前の重なりを示して止まり、束ね方は示さない
- **尽きている根拠**: 回の束ね方の欄の値は、章の値・欄が無い（REQ-563 が日に決める）・それ以外の文字列・文字列でない値に分かれ、止まるのは後の 2 つ。errors の次の項目（章で束ねる設定の候補の欠け）は束ね方が章のときだけ当たるので、この項目と同時には当たらない
- **境界の扱い**: 止めたときの状態は、学びの置き場の全ファイルが組み立ての前のままであることで見る。理由は契約の先頭の決まりどおり標準出力で見る
- **検証しない**: 日を表す値そのもの（契約・REQ・設定の例のどれも、日を欄の値で書く形を決めていない。欄が無いときは REQ-563）。欄が null のとき（「値が無い」か「日でも章でもない値」かが文から一意に決まらない）
- **参照先**: `tests/server/UC-030_build_roadmap.test.ts::UC-030 回の束ね方が日でも章でもなければ止める`
