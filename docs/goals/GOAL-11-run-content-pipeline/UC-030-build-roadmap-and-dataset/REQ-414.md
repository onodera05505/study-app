# REQ-414

> 作り手がロードマップ型の学びの投入データを組み立てたとき、システムはロードマップの各単位の名前と副題を分けたまま投入データに移し、副題を持たない単位には副題を持たせない。

## 検証方針

- **分割クラス**:
  - `#subtitle-carried-apart` — ロードマップのデータで副題を持つ単位は、投入データでも名前と副題がそれぞれ元の文字のまま分かれて入る
  - `#no-subtitle-none` — ロードマップのデータで副題を持たない単位は、投入データで副題を持たず、名前も元の文字のまま入る
- **尽きている根拠**: 単位ごとの入力は副題の有無の 2 通りで、名前と副題の文字の中身は値の変種。
- **境界の扱い**: 名前に括弧書きを含み副題を持たない単位を `#no-subtitle-none` の点に置き、組み立てが名前から副題を切り出さないことを見る。
- **検証しない**: 投入データから D1 への流し込みと応答（REQ-413 が応答まで通して見る）。副題の欄が空・空白だけ・文字列でも null でもないデータ（組み立てを止めることを REQ-422 が持つ）。
- **参照先**: `tests/server/UC-009_subtitle_dataset.test.ts::投入データの組み立て（UC-009）`
