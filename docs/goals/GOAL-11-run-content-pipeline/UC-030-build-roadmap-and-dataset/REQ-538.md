# REQ-538

> 学びの置き場に書き手の教材の束があるあいだ、作り手が論点の候補からロードマップのデータを組み立て直しても、システムは書き手への束の割り当てを作り直さず、ロードマップのデータだけを書き出す。

## 検証方針

- **分割クラス**:
  - `#assignment-kept` — 学びの置き場に書き手の教材の束（materials の束）があると、組み立て直しても束の割り当て（material_bundles）のファイルの並びと中身は組み立ての前のまま
  - `#roadmap-still-written` — 同じとき、ロードマップのデータは候補から組み立て直して書き出す
- **尽きている根拠**: この状態で組み立て直したときの書き出し先は、束の割り当てとロードマップのデータの 2 つ
- **検証しない**: 書き手の教材の束が無いときに割り当てを書き出すこと（どの REQ も持たない。主シナリオの step 4 としてシナリオテストが見る）。教材の束はあるが割り当てが無いとき（「作り直さない」が新しく作ることも含むかを文が決めていない）。materials が空のディレクトリのとき
