# REQ-535

> 作り手が論点の候補からロードマップのデータを組み立て直したとき、システムは除く一覧に無い候補のうち到達基準を 1 つも持たない候補を、含める一覧にあっても単位にせず、その名前をロードマップのデータに到達基準に繋がらずに落とした候補として残す。

## 検証方針

- **分割クラス**:
  - `#no-goal-dropped` — 到達基準を 1 つも持たない候補（空の一覧・欄が無い）は重みが一番でも単位にならず、その名前がロードマップのデータの単位の並びの外に残る
  - `#included-no-goal-dropped` — 含める一覧にあっても同じく単位にならず、名前が単位の並びの外に残る
- **尽きている根拠**: 到達基準を持たない候補は、含める一覧にある・無いで扱いが分かれうるので 2 つ。到達基準の持たなさ方は空の一覧と欄が無いの 2 つで、どちらも同じクラスに入れる
- **検証しない**: 落とした候補を持つ欄の名前と形（契約が決めていないので、名前が単位の並びの外にあることだけを見る）。除く一覧にある到達基準の無い候補と、到達基準を持つ候補が落とした候補に入らないこと（欄が決まっていないので「無い」ことを観測できない）
- **参照先**: `tests/server/UC-030_build_roadmap.test.ts::UC-030 到達基準に繋がらない候補を落とした候補として残す`
