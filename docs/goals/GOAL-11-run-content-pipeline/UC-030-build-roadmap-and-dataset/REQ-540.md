# REQ-540

> 作り手がロードマップ型の学びの投入データを組み立てたとき、システムはロードマップの単位に無い論点の教材を補足の論点として、登録簿の補足の分野と補足の回に入れて学ぶ順の末尾に置き、その論点の確認問題を補足の回に入れる。

## 検証方針

- **分割クラス**:
  - `#extra-in-extra-field-and-round` — ロードマップの単位に無い論点の教材は、登録簿の補足の分野と補足の回に入る
  - `#extra-after-roadmap-units` — 補足の論点は、学ぶ順でロードマップのどの単位よりも後ろに置かれる
  - `#extra-questions-in-extra-round` — 補足の論点の確認問題は補足の回に入る
  - `#roadmap-units-not-extra` — ロードマップの単位の論点とその確認問題は、補足の分野にも補足の回にも入らない
- **尽きている根拠**: 教材のある論点はロードマップの単位にある・無いの 2 つに分かれ、無い側は文の置き先（分野・回・学ぶ順・確認問題の回）ごとに、ある側はそこに入らないことを見る
- **境界の扱い**: 補足の論点は、写した itc の教材のうちロードマップの単位に無い論点を、その時の写しから求める
- **検証しない**: 補足の論点どうしの並び順（文が決めていない）
