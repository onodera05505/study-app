# REQ-534

> 作り手が論点の候補からロードマップのデータを組み立て直すときに、ロードマップの設定の含める一覧にある論点の ID が除く一覧にもあれば、システムはロードマップのデータを書き出さずに組み立てを止め、その ID を示す。

## 検証方針

- **分割クラス**:
  - `#overlap-stops` — 含める一覧の論点の ID が除く一覧にもあれば（重ならない ID が混ざっていても）、書き出さずに止まり、その ID を示す
  - `#disjoint-built` — 2 つの一覧に同じ ID が無ければ止まらず、含める ID は単位に、除く ID は単位の外になる
- **尽きている根拠**: 2 つの一覧の関係は、重なる ID がある・無いの 2 つ。errors の最後の項目なので後ろに隣り合う項目は無く、前の項目との組は REQ-533 の `#tier-outside-before-included-and-excluded` が見る
- **検証しない**: 一覧の ID がどの候補にも当たらないとき（REQ-434）
- **参照先**: `tests/server/UC-030_build_roadmap.test.ts::UC-030 含める一覧と除く一覧の両方にある ID があれば止める`
