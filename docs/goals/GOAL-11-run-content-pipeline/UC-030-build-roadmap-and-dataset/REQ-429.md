# REQ-429

> 作り手が論点の候補からロードマップのデータを組み立て直したとき、システムは候補の各単位の名前と副題を分けたままロードマップのデータに移し、候補で副題を持たない単位には副題を持たせない。

- **分割クラス**:
  - `#subtitle-carried-apart` — 候補で副題を持つ単位は、ロードマップのデータでも名前と副題がそれぞれ元の文字のまま分かれて入る
  - `#no-subtitle-absent` — 候補で副題を持たない単位は、ロードマップのデータで副題の欄を持たず、名前も元の文字のまま入る
- **尽きている根拠**: 単位ごとの入力は副題の有無の 2 通りで、名前と副題の文字の中身は値の変種。
- **境界の扱い**: 名前に括弧書きを含み副題を持たない単位を `#no-subtitle-absent` の点に置き、組み立てが名前から副題を切り出さないことを見る。
- **検証しない**: 候補の副題の欄が空・文字列でない値（移った先で REQ-422 が止める）。章で束ねる学び（副題の移し方は束ね方に依らないと文が決めている）。
