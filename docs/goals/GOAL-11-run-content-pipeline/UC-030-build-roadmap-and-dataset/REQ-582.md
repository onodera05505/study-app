# REQ-582

> 作り手が投入データを組み立てるときに、渡した学びが登録簿に無いか、学びの置き場にロードマップのデータが無ければ、システムは投入データを書き出さずに断る。

## 検証方針

- **分割クラス**:
  - `#unknown-learning-with-roadmap` — 登録簿に無い学びの置き場に、ロードマップのデータ・教材・確認問題がそろっていても、INVALID_INPUT で断り、投入データを書き出さない
  - `#unknown-learning-before-roadmap-missing` — 登録簿に無い学びで、置き場にロードマップのデータも無いと、INVALID_INPUT で断る（ロードマップが無いことより先）
  - `#roadmap-missing` — 登録簿にある学びの置き場に、教材と確認問題はあるがロードマップのデータが無いと、NOT_FOUND で断り、置き場を組み立ての前のまま残す
  - `#learning-dir-missing` — 登録簿にある学びの置き場そのものが無いと、NOT_FOUND で断り、置き場を作らず何も書き出さない
- **尽きている根拠**: 文の条件は「登録簿に無い」と「ロードマップのデータが無い」の 2 つ。登録簿に無い側は、組み立てに要る物がそろっているか（登録簿だけで断るか）と、ロードマップのデータも無いか（契約の errors の順で先の項目が勝つか）の 2 つ。ロードマップのデータが無い側は、置き場があってそのファイルだけが無いか、置き場ごと無いかの 2 つ
- **境界の扱い**: 断ったときは、終了コード 1 で、標準出力に断りの名前を持つ ToolError を出し、例外の跡（Traceback）を残さない（契約の先頭の決まりと、2026-11-19 の本人の決定）
- **検証しない**: 登録簿にあるがロードマップ型でない学び（文が決めていない）。ロードマップのデータが無いことと、契約の errors の次の項目（教材の無い単位がある）が両方成り立つ入力（教材の無い単位はロードマップのデータの単位で決まるので、ロードマップのデータが無いと作れない）
- **参照先**: `tests/server/UC-030_tool_refusals.test.ts::UC-030 登録簿に無い学びかロードマップのデータが無い学びは投入データを組み立てずに断る（REQ-582）`
