# REQ-537

> 作り手が論点の候補からロードマップのデータを組み立て直したときに、並べ終えた学ぶ順で前提の単位が自分より後ろにある単位があれば、システムはロードマップのデータを書き出したうえで、その単位と前提の単位の名前を警告として示す。

## 検証方針

- **分割クラス**:
  - `#prereq-behind-warned` — 並べ終えた学ぶ順で前提の単位が自分より後ろにある単位があれば、終了 0 でロードマップのデータを書き出し、その単位と前提の単位の名前を出力に示す
- **尽きている根拠**: 互いを前提にし合う 2 単位は、どう並べてもどちらかの前提が後ろに来るので、並べ方によらずこの状態を作れる
- **境界の扱い**: 警告は標準出力か標準エラーのどちらかで見る（契約が標準出力と決めているのは、断ったときの断りの種類の名前と理由を持つ形だけ）
- **検証しない**: 前提がどれも前にあるときに警告が出ないこと（警告の文の形を契約が決めていないので、無いことを観測できない）
- **参照先**: `tests/server/UC-030_build_roadmap.test.ts::UC-030 前提が後ろに来る単位を警告として示す`
