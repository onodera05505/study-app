# REQ-472

> 資格対策の学びに単元の構成が 1 つも無いあいだ、システムは単元の構成を持つ表へ行を入れも消しもしない投入を組み立て、流したあとにその表から無くなる行を、その投入で消える論点に結ばれた行だけにする。

## 検証方針

- **分割クラス**:
  - `#no-rows-inserted` — 単元の構成の行を持たない DB に、単元の構成が 1 つも無い学びの投入を流す
  - `#existing-rows-kept` — 単元の構成の行を持つ DB に、単元の構成が 1 つも無い学びの投入を流す
  - `#rows-of-removed-topic-go` — 単元の構成の行を持つ DB に、単元の構成が 1 つも無く論点を減らした学びの投入を流すと、減った論点に結ばれた行（まとまりへの所属・前提）だけが無くなり、他の行は残る
- **尽きている根拠**: 表の行の行方は、入る（無い）・残る・論点と一緒に無くなるの 3 つで、DB が単元の構成の行を持つか持たないか、投入で消える論点があるか無いかで尽きる
- **検証しない**: 配る本文の選び方（REQ-467 が持つ）
