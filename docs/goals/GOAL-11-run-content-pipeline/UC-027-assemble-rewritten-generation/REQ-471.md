# REQ-471

> 図の仕様の差し込み位置が教材に実在するかの確認、図の差し込み、実データの描画の検査は、どれも配る本文と同じ選び方で論点ごとの教材の世代を選ぶ。

## 検証方針

- **分割クラス**:
  - `#check-rewritten-heading-found` — 書き直した世代から選ぶ論点で、差し込み位置が書き直した世代にだけある見出し
  - `#check-superseded-heading-missing` — 書き直した世代から選ぶ論点で、差し込み位置が置き換わった前の世代にだけある見出し
  - `#check-previous-heading-found` — 前の世代から選ぶ論点で、差し込み位置がその世代の見出し
  - `#attach-into-delivered-generation` — 図の差し込みが図を入れる世代と、選んだ論点の数
  - `#render-checks-delivered-generation` — 描画の検査で、書き直した世代の教材に誤りがある
  - `#render-skips-superseded-generation` — 描画の検査で、書き直した世代に置き換わった前の世代の教材にだけ誤りがある
- **尽きている根拠**: 文が挙げる 3 つの道具ごとに、配る本文と同じ世代を見ていること（選んだ世代の中身で判定が決まる）と、置き換わった世代を見ていないこと（置き換わった世代の中身で判定が変わらない）を押さえる。図の差し込みは置き換わった世代に入れても配る本文に出ないので、配る本文に図があることで見る。
- **検証しない**: 描画の検査の誤りの種類（描画の誤りの判定は BR-025・BR-026 の側。ここでは実在しない画像を指す図の行を代表にする）。
- **参照先**: `tests/server/UC-027_assemble_generation.test.ts::差し込み位置の確認・図の差し込み・描画の検査は配る本文と同じ選び方で世代を選ぶ（UC-027）`
