# REQ-542

> 作り手が教材に図を差し込んだとき、前の世代から選んだ論点で図の仕様にあるのに本文に行の無い図があれば、システムはその図の行を、差し込み位置が短い説明なら短い説明の末尾に、見出しなら見出しの行の直後に（同じ見出しの図は後に足した図が上に来る）、見出しが教材に無ければ短い説明の末尾に足す。

## 検証方針

- **分割クラス**:
  - `#missing-explanation-figure-appended` — 前の世代から選んだ論点の、差し込み位置が短い説明で本文に行の無い図
  - `#missing-heading-figure-after-heading-line` — 前の世代から選んだ論点の、差し込み位置が見出しで本文に行の無い図（節に本文がある）
  - `#missing-same-heading-later-on-top` — 前の世代から選んだ論点の、同じ見出しを差し込み位置にする本文に行の無い図が 3 枚あるときの並び
  - `#missing-heading-absent-to-explanation` — 前の世代から選んだ論点の、差し込み位置の見出しが教材に無い本文に行の無い図
  - `#rerun-adds-nothing` — 図の差し込みをもう一度かけたとき（足した図の行が増えも動きもしない）
- **尽きている根拠**: 文は足す先を差し込み位置の 3 つ（短い説明・教材にある見出し・教材に無い見出し）で分けるので 1 クラスずつ置き、同じ見出しに 2 枚以上足すときの並びを別に置く。足した図は 2 回目には本文に行があるので、もう一度かけたときを別に置く。
- **境界の扱い**: 位置と並びは空でない行の並びで見る（空行は画面に出ない）。短い説明は 2 つ以上の段落と箇条で作り、見出しの節には本文を置く（末尾と直後を見分ける）。同じ見出しの 3 枚は、図の仕様の順が図の id の昇順・降順のどちらとも違う並びにし、図の仕様の順に足すとして、後に足した図が上に来る並び（図の仕様の逆の順）を期待する。図の画像は配信の置き場にある物で作る（画像が無い図は REQ-488）。
- **検証しない**: 本文に行が既にある図の置き方（REQ-470 の `#previous-placement-kept` が持つ）。書き直した世代から選んだ論点（REQ-470 が持つ）。`allToExplanation` を渡したとき（どの REQ の文にも無い）。図の行の前後の空行の数（文が決めていない）。
