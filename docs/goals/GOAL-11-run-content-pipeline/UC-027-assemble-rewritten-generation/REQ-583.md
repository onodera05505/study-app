# REQ-583

> 作り手が流したあとの DB を投入と突き合わせるときに、突き合わせる投入（渡した投入か、学びの置き場の投入）が無ければ、システムは DB を見ずに断る。

## 検証方針

- **分割クラス**:
  - `#given-seed-missing` — 渡した投入のファイルが無いと、NOT_FOUND で断り、DB を見ない（配備の道具を呼ばない）
  - `#default-seed-missing` — 投入を渡さず、学びの置き場に投入が無いと、NOT_FOUND で断り、DB を見ない
  - `#given-seed-is-directory` — 渡した投入のパスがディレクトリだと、NOT_FOUND で断り、DB を見ない
  - `#default-seed-is-directory` — 投入を渡さず、学びの置き場の投入の位置がディレクトリだと、NOT_FOUND で断り、DB を見ない
  - `#unknown-learning-before-seed-missing` — 登録簿に無い学びで、突き合わせる投入も無いと、INVALID_INPUT で断る（投入が無いことより先。契約の errors の順）
- **尽きている根拠**: 文の「突き合わせる投入」は渡した投入か学びの置き場の投入の 2 つに尽き、「無い」はその位置に何も無いか、ディレクトリがあるかの 2 つに尽きるので、2 × 2 に 1 つずつ置く。契約の errors の隣の項目（登録簿に無い学び）とは、両方が成り立つ入力で先の項目が勝つことを 1 つで見る
- **境界の扱い**: 文の「投入が無い」は、その位置に投入のファイルとして読める物が無いことで、その位置がディレクトリのときも無いに数える
- **検証しない**: 本番の保存先を見る指定（手元の DB を見る指定なし）。テストから本番の保存先に届く経路を作らないため、どの場合も手元の DB を見る指定で回す
- **参照先**: `tests/server/UC-027_verify_seed_missing.test.ts::突き合わせる投入が無ければ、流したあとの突き合わせは DB を見ずに断る（UC-027）`
