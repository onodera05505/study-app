# REQ-469

> 作り手が投入を組み立てるときに、教材の門の止める理由に当たる単元の構成があれば、システムは投入を書き出さずに止め、その単元と理由を示す。

## 検証方針

- **分割クラス**:
  - `#stop-without-writing` — 止める理由に当たる単元の構成が 1 つあり、他の単元の構成は通るとき（形として読めない・欠けた欄・まとまりに入らない論点・実在しない論点・前提が自分自身）、投入を書き出さない
  - `#show-unit-and-reason` — 同じ入力で、止めた単元と理由を示す
  - `#warning-only-not-stopped` — 警告だけが当たる単元の構成（論点が 3 に届かないまとまり）
  - `#unregistered-learning-before-plan-stop` — 登録簿に無い学びに、止める理由に当たる単元の構成がある（errors の INVALID_INPUT が CONFLICT より先）
- **尽きている根拠**: 単元の構成は「止める理由に当たる／警告だけ／何も当たらない」に分かれ、何も当たらない側は REQ-468 が持つ。止める側は書き出さないことと示すことの 2 つの約束を別に置く。止める理由の種類ごとの判定は UC-024 が持つので、ここは門と同じ判定がかかることを代表の 5 種で見る。
- **検証しない**: 止める理由の全 18 種（判定の正本は UC-024 の門とそのテスト）。示す文言の形（ファイル名と種類の名前が出ることだけを見る）。
- **参照先**: `tests/server/UC-027_assemble_generation.test.ts::止める理由に当たる単元の構成があれば投入を書き出さずに止める（UC-027）`
