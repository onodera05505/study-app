# REQ-470

> 作り手が資格対策の学びの教材に図を差し込んだとき、システムは学びを問わず、どの世代から選んだ論点でも図の仕様に無い図の行を配る本文に残さず、書き直した世代から選んだ論点では図の仕様にある図の行を 1 枚につき 1 行だけ、差し込み位置が短い説明の図は短い説明の末尾に、差し込み位置が見出しの図はその見出しの節の末尾（次の見出しの行の直前、後に見出しが無ければ詳しい解説の末尾）に、同じ差し込み位置の図は図の仕様に並ぶ順に上から置き、前の世代から選んだ論点では図の仕様にある図の置き方（どの図が短い説明にあり、どの図がどの見出しの節にあるかと、その並び）を変えない。

## 検証方針

- **分割クラス**:
  - `#rewritten-after-explanation` — 書き直した世代から選んだ論点の、差し込み位置が explanation の図
  - `#rewritten-after-heading` — 書き直した世代から選んだ論点の、差し込み位置が detail の見出しの図（学びは IT パスポート）
  - `#rewritten-explanation-end` — 書き直した世代から選んだ論点の、本文のある短い説明を差し込み位置にする図（置き場の中の位置）
  - `#rewritten-heading-end-before-next-heading` — 書き直した世代から選んだ論点の、本文があり後に見出しがある節の見出しを差し込み位置にする図（置き場の中の位置）
  - `#rewritten-heading-end-of-detail` — 書き直した世代から選んだ論点の、本文があり後に見出しが無い節の見出しを差し込み位置にする図（置き場の中の位置）
  - `#rewritten-same-explanation-spec-order` — 書き直した世代から選んだ論点の、短い説明を差し込み位置にする図が 2 枚以上あるときの並び
  - `#rewritten-same-heading-spec-order` — 書き直した世代から選んだ論点の、同じ見出しを差し込み位置にする図が 2 枚以上あるときの並び
  - `#rewritten-existing-line-not-at-end` — 書き直した世代から選んだ論点の本文の、差し込み位置の中の末尾でない所（見出しの行の直後・短い説明の途中）に、図の仕様にある図の行が既にあるとき
  - `#rewritten-existing-line-in-other-place` — 書き直した世代から選んだ論点の本文の、差し込み位置と別の置き場（別の見出しの節・短い説明・詳しい解説）に、図の仕様にある図の行が既にあるとき
  - `#rewritten-existing-lines-in-other-order` — 書き直した世代から選んだ論点の本文の差し込み位置の末尾に、図の仕様にある図の行が図の仕様と違う並びで既にあるとき
  - `#rewritten-existing-line-stale-caption` — 書き直した世代から選んだ論点の本文に、図の仕様にある図の行が図の仕様と違う説明文で既にあるとき（差し込んだあとその図の行は差し込み位置に 1 行だけある）
  - `#rewritten-existing-line-duplicated` — 書き直した世代から選んだ論点の本文に、図の仕様にある同じ図の行が 2 行既にあるとき（差し込んだあとその図の行は差し込み位置に 1 行だけある）
  - `#rerun-same-placement` — 図の差し込みをもう一度かけたとき（置き場と、置き場の中の本文の行と図の行の順が 1 回目と同じ）
  - `#rewritten-unlisted-figure-dropped` — 書き直した世代から選んだ論点の本文にある、図の仕様に無い図の行
  - `#previous-unlisted-figure-dropped` — 前の世代から選んだ論点の本文にある、図の仕様に無い図の行
  - `#no-spec-file-unlisted-dropped` — 図の仕様のファイル（`material_figures/<論点>.json`）が無い論点の本文にある図の行（書き直した世代と前の世代の両方の論点の explanation と detail に置く）
  - `#previous-placement-kept` — 前の世代から選んだ論点の、図の仕様にある図（本文の置き方が図の仕様の差し込み位置と違う。差し込む前の配る本文の置き方と比べる）
  - `#bracket-caption-unlisted-dropped` — 図の説明文に角かっこ（`A[1]`）を含む、図の仕様に無い図の行（書き直した世代と前の世代の両方の論点に置く）
  - `#previous-bracket-caption-placement-kept` — 前の世代から選んだ論点の、図の説明文に角かっこを含む図の仕様にある図（差し込む前の配る本文と同じ節に同じ数だけある）
  - `#rewritten-bracket-caption-rerun-once` — 書き直した世代から選んだ論点の、図の説明文に角かっこを含む図に、図の差し込みを 2 回かけたとき（差し込み位置に 1 回だけある）
  - `#indented-unlisted-dropped` — 行頭に空白（半角の空白・タブ・全角の空白）のある、図の仕様に無い図の行（書き直した世代と前の世代の両方の論点の explanation と detail に置く）
  - `#rewritten-indented-listed-once` — 書き直した世代から選んだ論点の本文の差し込み位置に、図の仕様にある図の行が行頭に空白付きで既にあるとき（差し込んだあと差し込み位置に 1 行だけある）
  - `#previous-indented-placement-kept` — 前の世代から選んだ論点の、行頭に空白のある図の仕様にある図の行（差し込む前の配る本文と同じ節に同じ数だけある）
  - `#src-control-char-unlisted-dropped` — 指す先の途中に、画面が空白と読まない制御文字（U+0085・U+001C〜U+001F）を含む、図の仕様に無い図の行（書き直した世代と前の世代の両方の論点の explanation と detail に置く）
- **尽きている根拠**: 本文の図の行は「図の仕様にあるか」と「どの世代から選んだ論点か」で 4 つに分かれる。図の仕様にある図は、書き直した世代の側を 4 つの軸で分ける。どの置き場に入るかは差し込み位置の 2 種（explanation と見出し）で尽きる。置き場の中の位置は、文が末尾を決めている置き場の形の 3 つ（短い説明・後に見出しがある節・後に見出しが無い節）で尽きる。同じ差し込み位置に 2 枚以上あるときの並びは、短い説明と見出しの 2 つで尽きる。差し込む前の本文に図の仕様にある図の行が既にあるときは、行が決まった所にある（もう一度かけたとき）、差し込み位置の中の末尾でない所にある、別の置き場にある、末尾にあって並びが違う、の 4 つで尽きる（文は置く先を行が既にあるかで変えていない）。既にある行の中身は、説明文が図の仕様と違う行と、同じ図の行が 2 行ある本文を別に置く（文の「1 枚につき 1 行だけ」は、既にある行の文字や数が図の仕様と違っても変わらない。行の文字が図の仕様の行と同じときだけ外す置き方と、図 1 枚につき最初の 1 行だけ外す置き方は、この 2 つでしか見分けられない）。軸どうしの掛け合わせは取らない（文が軸ごとに独立に決めている）。前の世代の側は置き方を変えないことを、差し込み位置と違う置き方で押さえる（同じなら差し込み直しと見分けられない）。図の仕様に無い図の行は世代ごとに 1 クラスで、explanation と detail の両方に置いて見る。図の仕様のファイルが無い論点の図の行も図の仕様に無い図の行で（図の仕様に載る図が無い）、図の仕様のファイルがあってそこに載っていない行とは図の仕様を読めるかが違うので、両方の世代の論点を 1 つの仕込みに置いて別の 1 クラスにする。差し込みは繰り返しかけられる道具なので、2 回目の結果を別に置く。図の行は、図の説明文が記法の区切りと同じ角かっこを含むかで本文の図の行と読めるかが変わりうるので、含む行を「図の仕様に無い行」「前の世代の論点の図の仕様にある行」「書き直した世代の論点の 2 回目の差し込み」の 3 つの約束について別に置く（含む行が図の行と読めないと、残る・増える）。図の仕様に無い行の世代の軸は含まない行の 2 クラスで押さえ、含む行は両方の世代の論点を 1 つの仕込みに置いて見る。行頭の空白も同じで、画面は行頭に空白のある図の行も図として出す（REQ-004）ので、行頭に空白のある行は図の行であり、図の行と読めないと残る・増える。そこで行頭に空白のある行を同じ 3 つの約束について別に置き、空白の種類（半角の空白・タブ・全角の空白）は図の仕様に無い行の 1 クラスの中の 3 点で見る。指す先に制御文字を含む行も、画面は指す先の中の U+0085 と U+001C〜U+001F を空白と読まずに図として出す（REQ-004）ので図の行であり、図の行と読めないと残る。指す先がその字を含む図は図の仕様に無い図なので、約束は「図の仕様に無い行」の 1 つだけに当たり、1 クラスに置く。字は U+0085・U+001C・U+001F の 3 点で見る（U+001C〜U+001E は同じ扱いの字が並ぶので端の U+001C で代表し、扱いの違いうる U+001F を別に見る）。
- **境界の扱い**: 置き場の中の位置と並びは、空でない行の並びで見る（空行は画面に出ない）。位置のクラスは本文のある置き場で見る（本文の無い節は、見出しの行の直後と節の末尾が同じ所になり見分けられない）。置き場の本文は 2 つ以上の段落と箇条で作る（段落が 1 つだと、最初の段落の末尾に置く置き方と見分けられない）。並びのクラスは、短い説明と見出しのどちらの置き場でも、図の仕様の順が図の id の昇順・降順のどちらとも違う 3 枚で見る（id の順や逆順に並べる置き方と見分ける）。既にある行の並びのクラスも同じで、置き場ごとに、図の仕様の順が id の昇順・降順のどちらとも違い、既にある並びがそのどれとも違う 3 枚で見る。図の仕様に無い図の行は、画像が配信の置き場にあるもので作る（画像の有無で残すかが変わらないことを、画像の無い図で問題を示す REQ-488 と分ける）。
- **検証しない**: IT パスポート以外の学び（前の世代に差し込み位置を使わない置き方が残っているのは IT パスポートなので、学びを問わないことはそこで押さえる。写しを 2 学び分作る費用に見合わない）。差し込み位置の見出しが教材に無いときと、図の画像が置き場に無いとき（REQ-488 が持つ）。`allToExplanation` を渡したときの置き方（どの REQ の文にも無い）。図の行の前後の空行の数（文が決めていない）。節の中に段の違う見出し（`####` など）がある教材と、差し込み位置と同じ見出しの行が 2 つある教材（文の「次の見出しの行」「その見出し」がどの行を指すかを一意に読めない）。前の世代から選んだ論点で、図の仕様にあるのに本文に行が無い図を足すかと、差し込んだ図の数に外した図の行を数えるか（文が決めていない。DEF-139）。
- **参照先**: `tests/server/UC-027_assemble_generation.test.ts::図の仕様に無い図の行を残さず、書き直した世代の論点の図を差し込み位置に入れ、前の世代の論点の図の置き方は変えない（UC-027）`（置き場の中の位置・並び・既にある図の行は、その中の `置き場の中の位置と、同じ差し込み位置の図の並び`。図の仕様のファイルが無い論点は、その中の `図の仕様のファイルが無い論点の図の行`）
