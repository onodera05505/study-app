# REQ-487

> 作り手が登録簿に無い学びの投入の組み立て・実データの描画の検査・投入後の突き合わせを求めたとき（試験名を別に渡したときも）、または学びの置き場が無い学びの図の差し込み・図の仕様の検査を求めたとき、システムは何も書き出さずに断る。

## 検証方針

- **分割クラス**:
  - `#build-unregistered` — 登録簿に無い学びの投入の組み立て
  - `#build-unregistered-with-exam-name` — 試験名と書き出し先を別に渡した、登録簿に無い学びの投入の組み立て
  - `#render-unregistered` — 登録簿に無い学びの実データの描画の検査
  - `#verify-unregistered` — 登録簿に無い学びの投入後の突き合わせ
  - `#attach-no-place` — 学びの置き場が無い学びの図の差し込み
  - `#check-specs-no-place` — 学びの置き場が無い学びの図の仕様の検査
- **尽きている根拠**: 文が挙げる道具と断る条件の組（登録簿で断る 3 つの道具と、置き場で断る 2 つの道具）に 1 クラスずつ置き、文が名指す「試験名を別に渡したとき」を別に置く。
- **検証しない**: 登録簿にあるが置き場の無い学びの投入の組み立て・描画の検査・突き合わせ（文が決めていない）。断る理由の文言（契約は `reason` が空でないことだけを決める）。登録簿に無い学びで止める理由に当たる単元の構成もあるとき（REQ-469 の `#unregistered-learning-before-plan-stop`）。
- **参照先**: `tests/server/UC-027_assemble_generation.test.ts::登録簿に無い学びか置き場の無い学びは、何も書き出さずに断る（UC-027）`
