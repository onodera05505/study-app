# REQ-487

> 作り手が登録簿に無い学びの投入の組み立て・流す前の投入の検査・実データの描画の検査・投入後の突き合わせを求めたとき（試験名を別に渡したときも）、登録簿に無い学びを断ると指定して登録簿に無い学びの配る本文の教材を求めたとき、または学びの置き場が無い学びの図の差し込み・図の仕様の検査を求めたとき、システムは何も書き出さずに断る。

## 検証方針

- **分割クラス**:
  - `#build-unregistered` — 登録簿に無い学びの投入の組み立て
  - `#build-unregistered-with-exam-name` — 試験名と書き出し先を別に渡した、登録簿に無い学びの投入の組み立て
  - `#render-unregistered` — 登録簿に無い学びの実データの描画の検査
  - `#verify-unregistered` — 登録簿に無い学びの投入後の突き合わせ
  - `#attach-no-place` — 学びの置き場が無い学びの図の差し込み
  - `#check-specs-no-place` — 学びの置き場が無い学びの図の仕様の検査
  - `#check-seed-unregistered` — 検査する投入がある、登録簿に無い学びの流す前の投入の検査（契約の errors の INVALID_INPUT）
  - `#check-seed-unregistered-seed-missing` — 検査する投入も無い、登録簿に無い学びの流す前の投入の検査（errors の隣り合う NOT_FOUND と INVALID_INPUT の両方に当たる入力）
  - `#delivered-materials-unregistered` — 登録簿に無い学びを断る指定（`registered`）を渡した、登録簿に無い学びの配る本文の教材（契約の errors の INVALID_INPUT。教材を出さない）
- **尽きている根拠**: 文が挙げる道具と断る条件の組（登録簿で断る 5 つの道具＝投入の組み立て・流す前の投入の検査・描画の検査・突き合わせ・断る指定を渡した配る本文の教材と、置き場で断る 2 つの道具）に 1 クラスずつ置き、文が名指す「試験名を別に渡したとき」を別に置く。流す前の投入の検査は、契約の errors で投入が無いこと（NOT_FOUND）が登録簿（INVALID_INPUT）より先なので、両方に当たる入力を別に置く。
- **検証しない**: 登録簿にあるが置き場の無い学びの投入の組み立て・描画の検査・突き合わせ（文が決めていない）。断る指定に加えて断るかどうかだけを見る指定（`refusalOnly`）を渡した、登録簿に無い学びの配る本文の教材（断る指定だけのときと同じ断り方で、契約の例も無い）。断る理由の文言（契約は `reason` が空でないことだけを決める）。登録簿に無い学びで止める理由に当たる単元の構成もあるとき（REQ-469 の `#unregistered-learning-before-plan-stop`）。
