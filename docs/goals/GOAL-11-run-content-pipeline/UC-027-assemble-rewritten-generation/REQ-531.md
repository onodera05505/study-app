# REQ-531

> 作り手が流す前の投入を検査するときに、過去問の出典の試験名と年度ラベル・回ごとの問題数・同一内容の組の正解・過去問と教材が指す図の画像・論点の出題頻度と紐づく過去問の件数・問題解説と用語集の行き先・利用者のデータの表への書き込みのどれかに問題があれば、システムはそれらを問題として示して失敗で終える。

## 検証方針

- **分割クラス**:
  - `#clean-seed-passes` — 組み立てたままの投入（問題が無いときは成功で終える。下の各クラスの対照）
  - `#citation-exam-name` — 過去問の出典の試験名が登録簿の学びの名前と違う投入
  - `#citation-year-label` — 過去問の出典の年度ラベルがその回の年度ラベルと違う投入
  - `#question-count-per-exam` — ある回の過去問が 1 問欠けた投入（紐付けと問題解説と出題頻度は欠けた問に合わせる）
  - `#same-content-answer-split` — 同一内容の組（本文と選択肢が同じ過去問。内容の鍵もそろえる）の正解が割れた投入
  - `#question-figure-missing` — 過去問が指す図の画像が置き場に無い
  - `#material-figure-missing` — 教材が指す図の画像が配信の置き場に無い
  - `#frequency-mismatch` — 論点の出題頻度が紐づく過去問の件数と違う投入
  - `#explanation-target-missing` — 問題解説の行き先（内容の鍵）の過去問が無い投入
  - `#glossary-target-missing` — 用語集の行き先（結ぶ論点）が無い投入
  - `#user-data-write` — 利用者のデータの表（進捗）に書き込む文を含む投入
- **尽きている根拠**: 文が挙げる問題の種類ごとに 1 クラス置き、2 つの要素を持つ種類（出典の試験名と年度ラベル・過去問と教材の図の画像・問題解説と用語集の行き先）は要素ごとに分ける。どれも、問題の無い投入（対照）から 1 か所だけ変えて作る。
- **境界の扱い**: 投入は手元で組み立てた物を、問題の種類ごとに 1 か所だけ書き換えた別のファイルにして `sql` で渡す（図の画像は置き場から 1 枚だけ外して戻す）。「問題として示す」は、出力に書き換えた物の手がかり（回・問・内容の鍵・画像のファイルの名前・表の名前・用語のどれか）が現れることで見る。
- **検証しない**: 問題の文言と形（契約の response は終了コードだけを決める）。問題が 2 種類以上重なった投入（どれかがあれば失敗で終えることは種類ごとに押さえ、重なりで終わり方は変わらない）。検査する投入が無いとき（契約の errors の NOT_FOUND。REQ-565 が持ち、登録簿に無い学びとの順は REQ-487 が持つ）。
