# REQ-565

> 作り手が流す前の投入を検査するときに、検査する投入が無ければ、システムは中身を検査せずに断る。

## 検証方針

- **分割クラス**:
  - `#given-seed-missing` — 登録簿にある学びで、渡した投入のファイルが無い
  - `#default-seed-missing` — 登録簿にある学びで、投入を渡さず、学びの置き場に投入が無い
- **尽きている根拠**: 文の「検査する投入」は、渡した投入と学びの置き場の投入の 2 つ（UC-027 の表の行）で、1 つずつ置く。どちらも断り（NOT_FOUND）と、学びの置き場に何も書き出さないことを見る。
- **検証しない**: 登録簿に無い学びで投入も無いとき（契約の errors の隣り合う 2 つの両方に当たる入力で、REQ-487 の `#check-seed-unregistered-seed-missing` が持つ）。渡した投入のパスがディレクトリのとき（「投入が無い」に当たるかを文が決めていない）。
- **参照先**: `tests/server/UC-027_seed_check_missing_seed.test.ts::検査する投入が無ければ、流す前の投入の検査は中身を見ずに断る（UC-027）`
