# UC-027 書き直した世代の教材と単元の構成を配る本文に組み立てる

## 概要

作り手が、門を通った書き直した世代の教材に図を差し込み、単元の構成と一緒に投入へ組み立て、実データの描画の検査を通して、配る準備を整える。

## 事前条件

- 資格対策の学びが登録簿にあり、教材の世代・図の仕様・図の画像・単元の構成が学びの置き場にある
- 書き直した世代の教材が、教材の門と様式の門を通っている
- 適用される業務規則: BR-025, BR-026, BR-048

## 主シナリオ

1. 作り手が、書き直した世代の教材に図を差し込む
2. システムが、論点ごとに配る本文と同じ選び方で教材の世代を選び、書き直した世代から選んだ論点の図を図の仕様の差し込み位置に入れる
3. 作り手が、投入を組み立てる
4. システムが、単元の構成が教材の門の止める理由に当たらないことを確かめる → BR-048
5. システムが、書き直した世代を最も新しい世代として配る本文を選び、単元の構成と一緒に投入に組み立てる
6. 作り手が、実データの描画の検査をかける
7. システムが、配る本文と同じ選び方で選んだ教材を描き、決めた記法だけが解釈されていることを確かめる → BR-025, BR-026
8. 作り手が、検査が通ったことを見て、配備に回す
