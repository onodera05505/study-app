# REQ-433

> 作り手が教材の図を描くときに、図の説明文が無い、空の文字列、空白だけの文字列、または文字列でない値の図があれば、システムはその図を描かずに止め、その図を示す。

## 検証方針

- **分割クラス**:
  - `#caption-absent` — 説明文の欄を持たない図があると、終了 0 でなく、その図を描かず、その図の論点と図の番号を示す
  - `#caption-empty` — 説明文が空の文字列の図があると、終了 0 でなく、その図を描かず、その図の論点と図の番号を示す
  - `#caption-blank` — 説明文が空白だけの文字列（半角・全角の空白、タブ・改行の混ざり）の図があると、同じく止めてその図を示す
  - `#caption-not-string` — 説明文が文字列でない値（null・数・真偽・配列・オブジェクト）の図があると、同じく止めてその図を示す
- **尽きている根拠**: 文が名指す欠けは「無い」「空の文字列」「空白だけの文字列」「文字列でない値」の 4 つで、空白の種類と値の型は各クラスの値の変種。どれも、説明文を持つ図と並べた中に 1 枚だけ置き、その 1 枚を示すかを見る。
- **検証しない**: 説明文を持つ他の図をその実行で描くかどうか（文は止めることだけを決め、他の図の扱いを決めていない）。複数の欠けた図を全部示すか（文は「その図」を示すことだけを決める）。
