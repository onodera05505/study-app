# REQ-341

> 本文に出す用語から末尾の括弧書きを落とした表記が、用語集の他の語の用語、または他の語から末尾の括弧書きを落とした表記と同じになる場合、システムはその用語の括弧書きを落とさず、用語集の正式な表記のまま本文に出す。

## 検証方針

- **分割クラス**:
  - `#same-as-other-term` — 末尾の括弧書きを落とした表記が、用語集の他の語の用語（括弧書きの無い語）と同じになる用語（括弧書きを残し正式な表記のまま出す）
  - `#same-as-other-shortened` — 末尾の括弧書きを落とした表記が、他の語から末尾の括弧書きを落とした表記と同じになる用語（重なる語のどれも括弧書きを残し正式な表記のまま出す）
- **尽きている根拠**: 括弧書きを落とした表記が重なる相手は、用語集の他の語の用語そのものか、他の語から括弧書きを落とした表記かの 2 つで尽きる（両方に当たる語はどちらのクラスでも「残す」が同じ）。重ならない語は REQ-008 が持つ。
- **検証しない**: 重なる相手の側の、末尾に括弧書きの無い語の表示名（REQ-008 の `#display-name-without-paren` と観測が重なる）。用語の説明の見出し（REQ-008 の `#pop-heading-official-form` が持ち、重なりによらず正式な表記）。
- **参照先**: `tests/client/markdown.test.tsx::用語の表示名の重なり（UC-001）`
