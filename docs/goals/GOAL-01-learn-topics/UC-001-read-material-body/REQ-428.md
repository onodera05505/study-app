# REQ-428

> 作り手が教材の図を描いたとき、システムは図の説明文を、見える文字としても読み上げに届く文字としても、図の画像の中に持たせない。

## 検証方針

- **分割クラス**:
  - `#caption-not-visible` — 説明文を持つ図を描いた SVG は、title・desc を除く要素の文字に説明文のどの切れ端も持たない（4 つの型すべて）
  - `#caption-not-accessible` — 説明文を持つ図を描いた SVG は、title・desc の中身とどの属性の値（aria-label など）にも説明文のどの切れ端も持たない（4 つの型すべて）
- **尽きている根拠**: SVG の中で文字が届く先は、描かれて見える文字と、読み上げに届く文字（title・desc・属性）の 2 つに尽きる。図の型（blocks・sequence・matrix・chart）は描き方が別なので、各クラスで 4 つの型を値の変種として回す。
- **境界の扱い**: 説明文の一部だけが入るのも持たせたことにするため、説明文を 4 字ずつずらした切れ端で見る（説明文は図のラベルと字の重ならない語で書く）。
- **検証しない**: 画面が説明文を図に結び付けて 1 回だけ示すこと（教材の代替文から画面に出す側の要件 REQ-427 が持つ）。説明文の文体・字数（`--check` の門の持ち分）。
- **参照先**: `tests/server/UC-001_figure_caption.test.ts::図の説明文を図の画像に持たせない（UC-001）`
