# REQ-008

> システムは、本文に出す用語の表示名から末尾の括弧書きを落とし、用語の説明の見出しには用語集の正式な表記を出す。

## 検証方針

- **分割クラス**:
  - `#display-name-drops-paren` — 末尾に括弧書きのある用語（本文の表示名は括弧書きを落とす）
  - `#display-name-without-paren` — 末尾に括弧書きの無い用語（本文の表示名はそのまま）
  - `#pop-heading-official-form` — 末尾に括弧書きのある用語を押した入力（用語の説明の見出しは用語集の正式な表記）
- **尽きている根拠**: 入力は用語の末尾に括弧書きがあるか無いかの 2 つ、出す場所は本文の表示名と用語の説明の見出しの 2 つ。括弧書きの無い語は表示名と見出しがどちらも正式な表記で同じになるため、見出しのクラスは括弧書きのある語だけで足りる。
- **検証しない**: 括弧書きの無い語の説明の見出し（`#display-name-without-paren` と観測が重なる）。括弧の種類ごとの違いと表記そのもの（用語集の投入データが正本）。
