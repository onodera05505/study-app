# REQ-008

> システムは、用語の説明の見出しには用語集の正式な表記を出し、本文に出す用語の表示名からは、REQ-341 が括弧書きを残す語を除き、末尾の括弧書きを、括弧の中身が読み・英字表記・それ以外の補足のどれであっても落とす。

## 検証方針

- **分割クラス**:
  - `#display-name-drops-paren` — 末尾に括弧書きがあり、落とした表記が用語集の他の語の用語とも、他の語から末尾の括弧書きを落とした表記とも同じにならない用語（本文の表示名は括弧書きを落とす）
  - `#display-name-without-paren` — 末尾に括弧書きの無い用語（本文の表示名はそのまま）
  - `#pop-heading-official-form` — 末尾に括弧書きのある用語を押した入力（用語の説明の見出しは用語集の正式な表記）
- **尽きている根拠**: 本文の表示名についての入力は、末尾に括弧書きが無い語・括弧書きがあり落とした表記が他の語の用語とも他の語から括弧書きを落とした表記とも同じにならない語・括弧書きがあり落とした表記が他の語の用語と同じになる語・括弧書きがあり落とした表記が他の語から括弧書きを落とした表記と同じになる語の 4 つで尽き（後の 2 つが両方成り立つ語は REQ-341 の側に入る）、後の 2 つは REQ-341 が持つ。見出しは括弧書きの有無と他の語との重なりによらず正式な表記で、括弧書きの無い語は表示名と見出しが同じになるため、見出しのクラスは括弧書きのある語だけで足りる。
- **検証しない**: 括弧書きの無い語の説明の見出し（`#display-name-without-paren` と観測が重なる）。落とした表記が他の語の用語、または他の語から括弧書きを落とした表記と同じになる語の本文の表示名（REQ-341 が持つ）。括弧の種類ごとの違いと表記そのもの（用語集の投入データが正本）。
