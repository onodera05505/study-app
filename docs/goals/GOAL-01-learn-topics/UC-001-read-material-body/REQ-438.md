# REQ-438

> 作り手が教材の図を描くときに、図の仕様書（`scripts/prompts/material_figures_spec.md`）が「項目で組む型」と定める型の図で、そのうち線を持つ型に何が流れるか・何を渡すかの名前を持たない線がある図か、名前だけの項目が仕様書の定める割合を超える図があれば、システムはその図を描かずに止め、その図と理由を示す。

## 検証方針

- **分割クラス**:
  - `#edge-label-absent` — label を持たない線（キーが無い・null）が 1 本でもある箱と矢印の図は、終了 0 でなく、その図を描かず、その論点と図の番号と線の理由を示す（ふつうの矢印・向きの無い線・破線・自己ループを値の変種に）
  - `#edge-label-blank` — label が空の文字列か空白だけ（半角・全角・タブ・改行）の線がある図も、名前を持たない線として同じく止めて示す
  - `#one-line-boxes-over-half` — 1 行だけ（名前だけ）の箱が全ノードの半分を超える図は、同じく止めて、その図と箱の理由を示す
  - `#one-line-boxes-at-most-half` — 1 行だけの箱がちょうど半分以下で、どの線も label を持つ図は止めずに描く（割合の境界の内側）
  - `#next-label-absent` — 段の間の矢印の next_label を持たない（キーが無い・null）段がある段階図（最後の段を除く）か循環（最後の段から最初の段へ戻る矢印を含む全段）は、止めてその図と段の間の矢印の理由を示す（型と段の位置を値の変種に）
  - `#next-label-blank` — next_label が空の文字列か空白だけ（半角・全角・タブ・改行）の段も、名前を持たない線として同じく止めて示す（型を値の変種に）
  - `#one-line-items-over-half` — 段階図・循環・層・分解図・時間軸・包含の図で、label が 1 行だけ（名前だけ）の項目（段・層・部位・出来事・領域）が全項目の半分を超える図は、止めてその図と項目の理由を示す（型と割合を値の変種に）
  - `#one-line-items-at-most-half` — 同じ型で、1 行だけの項目がちょうど半分以下で、段の間の矢印がどれも next_label を持つ図は止めずに描く。項目でない名前（包含の範囲・分解図の物・循環の中央・層の注記・時間軸の軸）が 1 行でも数えない（型を値の変種に）
  - `#only-outside-hit-ignored` — `--only` で論点を絞ったとき、絞った外の論点に門に当たる図（名前の無い線・名前だけの項目の超過）があっても止めず、絞った論点の図を描いて終了 0
  - `#only-inside-hit-stops` — `--only` で絞った論点に門に当たる図があれば、その図を描かずに止めて論点と図の番号と理由を示す（その論点だけに絞る・決まりに従う論点と並べて絞るを値の変種に）
  - `#check-unscoped-judges-all` — `--check` を絞り無しで回すと、どの論点にある門に当たる図も示して終了 0 で終わらない
- **尽きている根拠**: 文が名指す止める理由は「名前を持たない線」と「名前だけの項目の割合の超過」の 2 つで、当たる型は図の仕様書が「項目で組む型」と定める 7 つ（箱と矢印・段階図・循環・層・分解図・時間軸・包含）で、線の名前の決まりはそのうち線を持つ箱と矢印・段階図・循環に当たる。線は箱と矢印の edges と、段階図・循環の段の間の矢印（next_label）の 2 種で、持つ鍵が違うので別のクラスにする。線の名前の欠けは「無い（キー無し・null）」と「中身の無い文字列」に分かれ、線の向き・形・自己ループ、段の位置（先頭・途中・循環の戻り）は値の変種で回す。項目の割合は、箱（nodes）と 5〜10 の型の項目（stages／layers／parts／events／regions）で配列も理由の語も違うので別のクラスにし、それぞれ超える側と超えない側（境界）の 2 クラスで、仕様書の値（半分）を「以上」と取り違えた実装を境界のクラスが落とす。項目でない名前を数える実装も境界の内側のクラスが落とす。理由は、図の仕様書の語（線・箱・段の間・段・層・部位・出来事・領域）か JSON のキー（edge・node・next_label・stages・layers・parts・events・regions）で示されることを見る。「描くとき」の範囲は図の仕様書の「描く・検証する」が決め、`--only` で絞れば絞った論点の図、絞り無しの `--check` なら全部の図になる。門に当たる図が範囲の外か内かの 2 クラスで、範囲を無視して全部を判定する実装（外の図で止まる）と、絞ると門を飛ばす実装（内の図を描く）を落とす。絞り無しの `--check` のクラスが、判定の範囲を絞った論点に限ったまま全部の検証に漏れを作る実装を落とす。門に当たる理由は線（edges・next_label）と項目（箱・5〜10 の型の項目）の両方を値の変種に回す。
- **境界の扱い**: ちょうど半分（4 個中 2 個・6 個中 3 個）は描く側、半分を 1 個でも超える（3 個中 2 個・5 個中 3 個）は止める側。段階図の最後の段に next_label が無いのは矢印の先が無いからで名前の無い線ではなく、描く側（境界の内側のクラスの図がそうなっている）。止める図は決まりに従う図と並べた中に 1 枚だけ置く。
- **検証しない**: 止めた実行で、門に当たらない他の図を描くかどうか（文は止めることだけを決める。絞った範囲の内に門に当たる図があって止めた実行も同じで、並べて絞った決まりに従う論点の図の有無は見ない）。これは `#only-outside-hit-ignored` と別の問いで、あちらは門に当たる図が絞った外にしか無く止めない実行で、絞った論点の図が描かれることを見る。`--check` の出方のうち、門に当たる図が全部の図に入ること以外（理由の並び・描かないこと。文は「描くとき」を決める）。`--only` と `--check` を併せた実行（絞った外を判定しないことは `#only-outside-hit-ignored` で足り、併せて別の決まりは無い）。手順・やり取り（sequence）・2 軸の分類（matrix）・数値のグラフ（chart）の図（図の仕様書がこの 3 つを項目で組む型でないと定めており、文が当たらない）。項目の数の上下限・label の 4 行以上・段階図の最後の段の next_label・項目の label の欠け（図の仕様書の別の決まりで、文の止める理由でない）。2 行目が空の箱・項目の数え方（仕様書は `\n` で 2 行以上にすることだけを定め、空の 2 行目を名前だけに数えるかを決めていない）。理由の文言そのもの。
