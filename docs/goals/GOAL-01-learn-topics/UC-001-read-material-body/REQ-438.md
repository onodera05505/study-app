# REQ-438

> 作り手が教材の図を描くときに、箱と矢印の図で、何が流れるかの名前を持たない線がある図か、名前だけの箱が図の仕様書（`scripts/prompts/material_figures_spec.md`）の定める割合を超える図があれば、システムはその図を描かずに止め、その図と理由を示す。

## 検証方針

- **分割クラス**:
  - `#edge-label-absent` — label を持たない線（キーが無い・null）が 1 本でもある箱と矢印の図は、終了 0 でなく、その図を描かず、その論点と図の番号と線の理由を示す（ふつうの矢印・向きの無い線・破線・自己ループを値の変種に）
  - `#edge-label-blank` — label が空の文字列か空白だけ（半角・全角・タブ・改行）の線がある図も、名前を持たない線として同じく止めて示す
  - `#one-line-boxes-over-half` — 1 行だけ（名前だけ）の箱が全ノードの半分を超える図は、同じく止めて、その図と箱の理由を示す
  - `#one-line-boxes-at-most-half` — 1 行だけの箱がちょうど半分以下で、どの線も label を持つ図は止めずに描く（割合の境界の内側）
  - `#only-outside-hit-ignored` — `--only` で論点を絞ったとき、絞った外の論点に門に当たる図（名前の無い線・名前だけの箱の超過）があっても止めず、絞った論点の図を描いて終了 0
  - `#only-inside-hit-stops` — `--only` で絞った論点に門に当たる図があれば、その図を描かずに止めて論点と図の番号と理由を示す（その論点だけに絞る・決まりに従う論点と並べて絞るを値の変種に）
  - `#check-unscoped-judges-all` — `--check` を絞り無しで回すと、どの論点にある門に当たる図も示して終了 0 で終わらない
- **尽きている根拠**: 文が名指す止める理由は「名前を持たない線」と「名前だけの箱の割合の超過」の 2 つ。線の名前の欠けは「無い（キー無し・null）」と「中身の無い文字列」に分かれ、線の向き・形・自己ループは描き方が別なので値の変種で回す。箱の割合は超える側と超えない側（境界）の 2 クラスで、仕様書の値（半分）を「以上」と取り違えた実装を境界のクラスが落とす。理由は、図の仕様書の語（線・箱）か JSON のキー（edge・node）で示されることを見る。「描くとき」の範囲は図の仕様書の「描く・検証する」が決め、`--only` で絞れば絞った論点の図、絞り無しの `--check` なら全部の図になる。門に当たる図が範囲の外か内かの 2 クラスで、範囲を無視して全部を判定する実装（外の図で止まる）と、絞ると門を飛ばす実装（内の図を描く）を落とす。絞り無しの `--check` のクラスが、判定の範囲を絞った論点に限ったまま全部の検証に漏れを作る実装を落とす。門に当たる理由は線と箱の両方を値の変種に回す。
- **境界の扱い**: ちょうど半分（4 個中 2 個・6 個中 3 個）は描く側、半分を 1 個でも超える（3 個中 2 個・5 個中 3 個）は止める側。止める図は決まりに従う図と並べた中に 1 枚だけ置く。
- **検証しない**: 止めた実行で、門に当たらない他の図を描くかどうか（文は止めることだけを決める。絞った範囲の内に門に当たる図があって止めた実行も同じで、並べて絞った決まりに従う論点の図の有無は見ない）。これは `#only-outside-hit-ignored` と別の問いで、あちらは門に当たる図が絞った外にしか無く止めない実行で、絞った論点の図が描かれることを見る。`--check` の出方のうち、門に当たる図が全部の図に入ること以外（理由の並び・描かないこと。文は「描くとき」を決める）。`--only` と `--check` を併せた実行（絞った外を判定しないことは `#only-outside-hit-ignored` で足り、併せて別の決まりは無い）。箱と矢印以外の型（文が blocks に限る）。2 行目が空の箱の数え方（仕様書は `\n` で 2 行以上にすることだけを定め、空の 2 行目を名前だけに数えるかを決めていない）。理由の文言そのもの。
