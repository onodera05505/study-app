# REQ-013

> 用語の説明が開いている間に利用者が同じ用語をもう一度押す、説明の外を触る、または Esc を押したとき、システムはその説明を閉じる。

## 検証方針

- **分割クラス**:
  - `#same-term-pressed-again` — 説明が開いている間に同じ用語をもう一度押した入力
  - `#press-outside` — 説明が開いている間に説明の外を触った入力
  - `#escape-key` — 説明が開いている間に Esc を押した入力
- **尽きている根拠**: 閉じる契機は要件が挙げる 3 つで尽き、他の操作では閉じない。どの契機でも閉じた結果は同じなので、契機ごとに 1 クラス。
- **検証しない**: 説明が開いていない状態での同じ操作（UC.md の状態 × イベント表が不可と定める）。別の用語を押したときの入れ替わり（REQ-010 が持つ）。
- **参照先**: `tests/client/repay_UC-001_term_pop_figure.test.tsx::用語の説明を開いたまま（UC-001）`
