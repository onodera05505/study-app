# REQ-011

> 利用者が用語を押した場合、システムは読んでいた画面を移さない。

## 検証方針

- **分割クラス**:
  - `#no-navigation-on-press` — 用語を押した入力（読んでいた画面が移らない）
- **尽きている根拠**: 押す対象が紐づく論点のある用語でも無い用語でも「画面を移さない」は同じで、押すのは用語に限られる（導線を押したあとの移動は要件の外）。よって 1 クラス。
- **検証しない**: 導線を押したあとの行き先（REQ-010 の導線として観測する）。説明を閉じたあとに読んでいた場所に戻っているか（REQ-013 が持つ）。
- **参照先**: なし（未被覆。`tests/client/markdown.test.tsx::用語の説明（UC-001）` が 1 行の説明と併せて観測しているが、専用のテストが無い）
