# REQ-440

> 作り手が教材の図を描くときに、図の型ごとの形（型そのもの、項目の数、項目の名前の欠けと行数、項目・括弧・出来事・領域・絵記号の置き方、決められた語から選ぶ値）が図の仕様書（`scripts/prompts/material_figures_spec.md`）の定める形に合わない図があれば、システムはその図を描かずに止め、その図と理由を示す。

持ち分の境: 線の名前の欠けと名前だけの項目の割合は REQ-438、説明文の欠けは REQ-433、箱と線の少なさの警告は REQ-439 が持ち、この文はそれ以外の、図の仕様書が型の中身のエラーと定める形を持つ。

- **分割クラス**:
  - `#type-unknown` — type が 10 の型のどれでもない図（仕様書に無い名前・大文字の混ざり・空・null・欄が無い）は、終了 0 でなく、その図を描かず、その論点と図の番号と type の理由を示す
  - `#figure-id-duplicate` — 同じファイルの figures[].id が重複する図は、止めてその図と figures の id の重複の理由を示す（同じ型どうし・違う型どうしを値の変種に）
  - `#item-count-below` — 項目の数が型ごとの下限より 1 つ少ない図は、止めてその図と項目の理由を示す（段階図・循環の段、層、部位、出来事、axis.ticks、包含の範囲を値の変種に）
  - `#item-count-above` — 項目の数が型ごとの上限より 1 つ多い図は、止めてその図と項目の理由を示す（型を値の変種に）
  - `#item-count-at-bounds` — 項目の数が型ごとの下限・上限ちょうどの図は止めずに描く（型と端を値の変種に）
  - `#actor-count-outside` — sequence の登場人物が 2〜4 の外（1 人・5 人）の図は、止めてその図と登場人物の理由を示す
  - `#actor-count-inside` — 登場人物が 2 人と 4 人の sequence の図は止めずに描く
  - `#actor-id-duplicate` — sequence の actors に同じ id が 2 つ以上ある図は、止めてその図と、その id を示す
  - `#series-absent` — chart の系列が 0 本（空の series）の図は、止めてその図と系列の理由を示す
  - `#x-values-too-few` — chart の x.values が 2 つ未満（0 個・1 個）の図は、止めてその図と x.values の理由を示す（数値の軸・カテゴリの軸を値の変種に）
  - `#x-values-at-least-two` — x.values がちょうど 2 つの chart の図は止めずに描く（数値の軸・カテゴリの軸を値の変種に）
  - `#series-over-limit` — chart の系列が 4 本以上の図は、止めてその図と系列の理由を示す（4 本・5 本を値の変種に）
  - `#series-at-limit` — 系列が 3 本まで（1 本・3 本）の chart の図は止めずに描く
  - `#matrix-size-outside` — matrix の行か列の数が 2〜3 の外の図は、止めてその図と大きさの理由を示す（1 と 4 を行・列・両方の値の変種に）
  - `#matrix-size-inside` — matrix が 2×2・2×3・3×2・3×3 の図は止めずに描く
  - `#item-label-absent` — label が無い・null・空・空白だけの項目（段・層・部位・出来事・領域）がある図は、止めてその図と、label と項目の理由を示す（型と欠け方を値の変種に）
  - `#item-label-four-lines` — 項目の label が 4 行以上の図は、止めてその図と行の数の理由を示す（型を値の変種に）
  - `#item-label-three-lines` — 項目の label がちょうど 3 行の図は止めずに描く（型を値の変種に）
  - `#axis-label-absent` — timeline の axis.label が無い・null・空・空白だけの図は、止めてその図と axis の label の理由を示す
  - `#y-label-absent` — chart の y.label が無い・null・空・空白だけ（y の欄が無いも）の図は、止めてその図と y の label の理由を示す
  - `#steps-last-next-label` — 段階図の最後の段に中身のある next_label がある図は、止めてその図と最後の段の理由を示す（段の数と、空白に囲まれた中身を値の変種に）
  - `#steps-last-next-label-empty` — 段階図の最後の段の next_label が空・空白だけ・null の図は、無いのと同じに扱って止めずに描く
  - `#word-unknown` — 決められた語から選ぶ値（steps の direction・layers の shape・venn の layout・blocks の nodes[].shape と edges[].style と edges[].arrow・chart の kind）が決められた語でない図（必須の direction・layout・kind は欄が無いも）は、止めてその図とその鍵の理由を示す（鍵と、仕様書に無い語・大文字の混ざり・空を値の変種に）
  - `#word-allowed` — 同じ鍵が決められた語のどれか（省略できる layers と nodes の shape・edges の style と arrow は省略も）の図は止めずに描く
  - `#node-id-duplicate` — blocks の nodes[] に同じ id が 2 つ以上ある図は、止めてその図と、その id を示す
  - `#edge-endpoint-unknown` — 線の from か to が nodes に無い id を指す図は、止めてその図と、その id を示す（from・to・両端を値の変種に）
  - `#bracket-range-invalid` — 層の括弧が from > to か、from・to が層の位置の外の図は、止めてその図と括弧の理由を示す
  - `#bracket-overlap` — 層の括弧どうしの範囲が重なる図（端の 1 層の共有・包含・同じ範囲）は、止めてその図と括弧の理由を示す
  - `#bracket-label-absent` — label の無い（欄が無い・null）括弧がある図は、止めてその図と括弧の label の理由を示す
  - `#bracket-valid` — 括弧が層の位置の内で from ≤ to、重ならず label を持つ図（括弧無しも）は止めずに描く
  - `#whole-label-absent` — 分解図の whole が無いか whole の label が無い図は、止めてその図と分解する物の理由を示す
  - `#event-not-point-nor-period` — 時間軸の出来事が at だけでも from と to の組だけでもない図（どちらも無い・両方・片方だけ）は、止めてその図と出来事の理由を示す
  - `#event-position-out-of-range` — 出来事の位置が 0〜ticks の個数 −1 の外か、期間が from ≥ to の図は、止めてその図と出来事の理由を示す
  - `#event-position-in-range` — 点か期間の一方だけを持ち、位置が両端と小数を含めて範囲の内の出来事だけの図は止めずに描く
  - `#sets-id-duplicate` — venn の sets に同じ id が 2 つ以上ある図は、止めてその図と、その id を示す
  - `#venn-in-duplicate-id` — 1 つの regions[i].in に同じ id が 2 回ある図は、止めてその図と in の理由を示す（単独の領域・重なりの領域を値の変種に）
  - `#venn-in-unknown-set` — 包含の領域の in が sets に無い id を含む図は、止めてその図と、その id を示す
  - `#venn-regions-mismatch` — 包含の領域が layout に合わない図（欠け・重複・nested の先頭の組でない組・universe 無しの in: []・in: [] が 2 つ）は、止めてその図と領域の理由を示す
  - `#venn-regions-match` — 領域が layout の組をちょうど 1 つずつ持つ図（universe ありの in: [] 1 つも、in を sets と逆の順に書いたのも）は止めずに描く
  - `#icon-unknown` — 絵記号を置ける 7 か所（箱・登場人物・段階図と循環の段・層・分解する物・部位）に絵の語彙に無い名前の icon がある図は、止めてその図と icon の理由を示す
  - `#icon-misplaced` — 7 か所以外（時間軸の出来事と軸・包含の範囲と領域・箱と矢印の線・手順の矢印・chart の系列・matrix の軸・層の括弧・図の一番上の階層）に icon がある図は、止めてその図と icon の理由を示す
  - `#icon-allowed` — 絵の語彙の 23 の名前のどれも、7 か所のどこに書いても（名前×置き場の全部の組）止めずに描く
- **尽きている根拠**: 止める理由の空間は、図の仕様書の「`--check` が見ること」の表のエラーの行から REQ-438・433・439 の持ち分を除いた物で尽きる（各型の節と鍵の表が「エラー」と書く形は、どれも表に行を持つ）。表の行を、型そのもの・figures の id の重複・項目の数（下に外れる／上に外れる／内）・登場人物の数（外／内）と id の重複・系列の数（0 本／超える／内）・x.values の数（2 未満／2）・matrix の大きさ（外／内）・項目の label（欠け／行の数の外／内）・軸の名前（axis.label・y.label の欠け）・段階図の最後の段の next_label（中身あり／中身なし）・決められた語（外／内）・nodes の id の重複と線の端の無い id・層の括弧（範囲の外／重なり／label の欠け／内）・分解する物の label・出来事（点と期間の別／位置の外／内）・sets の id の重複と領域の in（同じ id の 2 回／無い id／layout との不一致／一致）・絵記号（語彙の外／置けない所／内）に束ね、理由が同じで型や鍵だけ違う物は値の変種に畳んだ。項目の数は配列の長さの上下限という 1 つの決まりなので、範囲の数（sets）と目盛りの数（axis.ticks）も同じクラスの変種にした。登場人物と系列は項目で組む型の項目でなく理由の語も違うので別のクラスにした。決められた語は「表の語の集合に入るか」という 1 つの決まりなので、7 つの鍵を 1 つのクラスの変種にした。止める側には描く側のクラスを対にし、範囲の取り違え（以上と超える）・語の大文字小文字の無視・省略できる語の拒み・3 行の拒み・2×3 と 3×2 の拒み・最後の段の空の next_label の拒み・in の順を比べる実装・置き場ごとに語彙を変える実装を落とす。id の重複（figures・nodes・actors・sets）と無い id の指し先は、他の全部のクラスの図（id が一意で端が nodes にある）が描く側なので対を立てない。どの図も、調べる 1 つの形のほかは決まりに従い（説明文あり・項目は名前＋一言の 2 行・線と段の間の矢印に名前）、決まりに従う別の論点の図と並べた中に 1 枚だけ置く。理由は文言を固定せず、図の仕様書の語か JSON のキーで見る（無い id と重複する id はその id そのもの）。
- **境界の扱い**: 項目の数は下限 −1 と上限 +1 が止める側、下限と上限ちょうどが描く側。登場人物は 1 人と 5 人が止める側、2 人と 4 人が描く側。系列は 0 本と 4 本が止める側、1 本と 3 本が描く側。x.values は 1 個が止める側、2 個が描く側。matrix は行か列の 1 と 4 が止める側、2 と 3 が描く側。label は 3 行が描く側、4 行が止める側。段階図の最後の段の next_label は空白だけ（半角・全角・タブ）が描く側、空白に囲まれた中身のある文字列が止める側。出来事の位置は 0 と ticks の個数 −1 ちょうどが描く側、その外の小数と from = to の期間が止める側。括弧は端の 1 層を共有すると重なり、隣り合う層で切れていれば描く側。
- **検証しない**: 線の名前の欠け・名前だけの項目の割合（REQ-438）、説明文の欠け（REQ-433）、箱と線の少なさの警告（REQ-439）。図の仕様書が目安で門は見ないと定める形（手順の 4〜6 個・matrix のセルの 3 行・循環の center と括弧の label の 2 行・層の note と whole の label の 1 行・格子の列 3〜4 と行 3）。括弧の label と whole の label が空の文字列か空白だけ（表は「label が無い」だけを書き、項目・軸の label のように空・空白だけを含めると書いていない）。表に行の無い形（chart の series の values の個数と数値・sequence の手順の from／to の指し先・matrix の cells の形と x／y の values の数の食い違い・x の label・強調の数・期間の重なり）。止めた実行で他の図を描くかどうか、複数の誤りを全部示すか（文は止めてその図と理由を示すことだけを決める）。`--only`・`--check` での判定の範囲（REQ-438 のクラスが見る）。理由の文言そのもの。
