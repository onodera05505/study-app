# REQ-427

> システムは、教材の図を図として出すとき、その画像の記法に書かれた図の説明文を、その図に結び付けた画面の文字として示し、図の画像そのものには説明文を持たせず、見た目と読み上げのどちらでも図の説明文を 1 回だけ届ける。

## 検証方針

- **分割クラス**:
  - `#single-figure` — 図が 1 枚の本文: 説明文は画像そのもの（代替文・title・aria-label・aria-labelledby / aria-describedby）に持たせず、その図に結び付いた画面の文字として、見た目で 1 回・読み上げで 1 回だけ出る
  - `#several-figures` — 説明文の違う図が複数ある本文: それぞれの説明文がそれぞれの図に結び付き、取り違えずに各 1 回だけ出る
- **尽きている根拠**: 入力は本文の中の教材の図の画像の記法の数と、それぞれの説明文だけで、1 枚と、説明文の違う複数枚（結び付きの取り違えが起こりうる）の 2 つで尽きる。説明文の出し方は用語集の状態（未取得・取得済み・取得失敗・説明が開いている）で分かれない（UC-001 の表の 4 行は同じ REQ を指す）ので、状態ごとのクラスは置かない。
- **境界の扱い**: 「結び付けた」は、画像を包む図（`figure` か `role="figure"`）の中の `figcaption`、またはその図が aria-labelledby / aria-describedby で指す図の中の要素に説明文があることで見る。「読み上げで 1 回」は、読み上げから外れていない（hidden・aria-hidden・inert・インラインの display / visibility で隠れていない）文字と、代替文・aria-label・title・画像が指す文字に説明文が現れる回数で数える。「見た目で 1 回」は、見えている文字と title の吹き出しに現れる回数で数える。
- **検証しない**: CSS のクラスで見た目だけを隠す書き方（jsdom は CSS を描かないので、クラスで隠れた文字は見えているものとして数える）。読み上げソフトごとの実際の読み方（図の名前を figcaption から取って読む回数は読み上げソフトに依る）。図の画像（SVG）の中に説明文が無いこと（REQ-428）。説明文の無い図（REQ-433 が作る段で止める）。図として出す置き場所の判定（REQ-004）。
- **参照先**: `tests/client/markdown.test.tsx::図の説明文（UC-001）`
