# REQ-004

> システムは、教材の図の置き場所を指す画像の記法だけを図として出し、他の場所を指す画像の記法は書かれた文字のまま出す。

## 検証方針

- **分割クラス**:
  - `#material-figure-path` — 教材の図の置き場所を指す画像の記法を含む本文（図として出る）
  - `#other-path` — 置き場所の外を指す画像の記法を含む本文（書かれた文字のまま出る）
- **尽きている根拠**: 画像の記法は指す先が教材の図の置き場所かそれ以外かの 2 値で尽きる。置き場所の中で画像が実在するかは画面の分岐にならない（BR-026 が投入の時点で実在を保証する）。
- **検証しない**: 画像が置き場所に実在するか、学びごとにディレクトリが分かれているか（BR-026・`scripts/check_seed.py`）。図を押したときの切り替え（REQ-006 が持つ）。
- **参照先**: `tests/client/markdown.test.tsx::本文の記法（UC-001）`
