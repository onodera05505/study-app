# REQ-264

> 用語集が取得済みである間、システムは本文の用語の記法で書かれた語のうち用語集にある語を、押せる語として出す。

## 検証方針

- **分割クラス**:
  - `#glossary-term-pressable` — 用語集が取得済みの状態で、用語の記法で書かれた語が用語集にある本文（その語が押せる要素として出る。語が 1 つでも、本文の中に用語集の語が複数あっても同じ）
- **尽きている根拠**: この要件の状態（用語集が取得済み）の下で、用語の記法で書かれた語は用語集にあるか無いかの 2 つに尽き、無い側は REQ-009 が持つ。語の位置や個数は押せるかどうかを分けないため、同値クラスは 1 つ。
- **検証しない**: 用語集が未取得の間（REQ-005）と取得できなかったとき（REQ-012）。用語集にある語と無い語が混ざる本文（この要件のクラスと REQ-009 のクラスで観測でき、混在そのものが変える振る舞いが無い）。太字の中の語（REQ-007）。押したあとに出る説明（REQ-010）。押せる語の見た目（色・下線。要件が決めていない）。
- **参照先**: `tests/client/markdown.test.tsx::用語の説明（UC-001）`
