# REQ-046

> 次に学ぶの候補が無い間、システムは、ホームに次に学ぶを示さない。

## 検証方針

- **分割クラス**:
  - `#home-hides-next-section` — 候補が無いとき、ホームが次に学ぶを示さない
- **尽きている根拠**: ホームが受け取るのは候補の列だけで、列が空である入力は 1 つしかない。候補があるときは REQ-044、論点の画面の側は REQ-269、取得の不達は REQ-047 が持つ。
- **検証しない**: 取得前と空を別の状態として持つことの表し方（BR-015・REQ-047 が持つ）。候補が無いことをホームで伝える文言（示さないことがこの要件の観測点）。
- **参照先**: `tests/client/home.test.tsx::次に学ぶ（UC-003）`
