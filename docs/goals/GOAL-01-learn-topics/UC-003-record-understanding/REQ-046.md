# REQ-046

> 次に学ぶの候補が無い間、システムは、ホームに次に学ぶを示さず、論点の画面には頻出の論点をひととおり学び終えたことと論点の一覧への導線を示す。

## 検証方針

- **分割クラス**:
  - `#home-hides-next-section` — 候補が無いとき、ホームが次に学ぶを示さない
  - `#detail-shows-list-link` — 候補が無いとき、論点の画面が次に学ぶを示さず、論点の一覧への導線を示す
  - `#detail-tells-finished` — 候補が無いとき、論点の画面が頻出の論点をひととおり学び終えたことを示す
- **尽きている根拠**: 候補が無い状態で示す場所はホームと論点の画面の 2 つで、論点の画面の観測点は「学び終えたこと」と「一覧への導線」の 2 つ。候補があるときは REQ-044 / REQ-045、取得の不達は REQ-047 が持つ。
- **検証しない**: 文言そのものは要件が決めていないため、学び終えたことが伝わる示しがあることだけを見る。
- **参照先**: `tests/client/home.test.tsx::次に学ぶ（UC-003）` / `tests/client/topic_detail.test.tsx::次に学ぶ論点`（`#detail-tells-finished` は被覆するテストが無い）
