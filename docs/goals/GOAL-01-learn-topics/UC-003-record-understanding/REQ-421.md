# REQ-421

> 論点の画面が理解度の操作を示しているあいだ、システムは学びの種類によらず、各選択肢に選ぶと記録される段階の名前を持たせ、今記録されている段階の選択肢を BR-045 に従い選ばれていることが分かる形で示す。

## 検証方針

- **分割クラス**:
  - `#choice-named-by-stage` — 理解度の 3 つの選択肢のそれぞれが、選ぶと記録される段階の名前を読み上げで得られる名前として持ち、段階ごとにちょうど 1 つある
  - `#recorded-stage-marked` — 記録が 1・2・3 のとき、その段階の選択肢だけが選ばれていることを示す状態（押されている・選ばれている）を持ち、ほかは持たない
  - `#no-record-marks-unlearned` — 記録が無いとき、未理解の選択肢だけが選ばれている状態になる（BR-029）
- **尽きている根拠**: 選択肢の名前は段階によらず 1 つの決まりで 1 クラス。選ばれている形の入力は記録の 1・2・3（値の変種）と記録なし（既定を置く所が別）の 2 クラス。学びの種類（資格対策・ロードマップ型）は値の変種として全クラスで回す。
- **境界の扱い**: 段階の名前がほかの段階の名前の一部である組（「理解」と「未理解」）では、選択肢と段階の対応を、自分の名前の一部でないほかの名前を含まないことで決める。
- **検証しない**: 押したあとの記録と失敗時の戻し（REQ-038・REQ-039）。色と見た目。段階の名前の値（`STATUS_LABEL` が正本で、期待値もそこから読む）。
