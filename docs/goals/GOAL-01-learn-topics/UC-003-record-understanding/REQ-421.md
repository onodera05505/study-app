# REQ-421

> 論点の画面が理解度の操作を示しているあいだ、システムは学びの種類によらず、各選択肢に選ぶと記録される段階の名前を持たせ、ロードマップ型の学びでは今記録されている段階（記録が無ければ BR-029 のとおり未理解）の選択肢を、資格対策の学びでは BR-050 に従い今示している理解度の段階（未のときはどれでもない）の選択肢を、BR-045 に従い選ばれていることが分かる形で示す。

## 検証方針

- **分割クラス**:
  - `#choice-named-by-stage` — 理解度の 3 つの選択肢のそれぞれが、選ぶと記録される段階の名前を読み上げで得られる名前として持ち、段階ごとにちょうど 1 つある（学びの種類によらない）
  - `#roadmap-recorded-stage-marked` — ロードマップ型で記録が 1・2・3 のとき、その段階の選択肢だけが選ばれている形を持つ
  - `#roadmap-no-record-marks-unlearned` — ロードマップ型で記録が無いとき、未理解の選択肢だけが選ばれている形になる（BR-029）
  - `#exam-shown-stage-marked` — 資格対策で示している理解度が 1・2・3 のとき、回答の履歴からの判定でも本人の上書きでも、その段階の選択肢だけが選ばれている形を持つ
  - `#exam-unanswered-marks-none` — 資格対策で示している理解度が未のとき、どの選択肢も選ばれている形を持たない
- **尽きている根拠**: 選択肢の名前は段階によらず 1 つの決まりで 1 クラス。選ばれている形は学びの種類で決まり方が違い、ロードマップ型は記録の有無（記録 1・2・3 は値の変種）、資格対策は示している段階が 3 段階のどれかか未か（判定・上書きの別は値の変種）で尽きる。
- **境界の扱い**: 段階の名前がほかの段階の名前の一部である組（「理解」と「未理解」）では、選択肢と段階の対応を、自分の名前の一部でないほかの名前を含まないことで決める。
- **検証しない**: 押したあとの記録と失敗時の戻し（REQ-038・REQ-039）。色と見た目。段階の名前の値（`STATUS_LABEL` が正本で、期待値もそこから読む）。資格対策で status が null の応答（契約上ロードマップ型だけの値）。
