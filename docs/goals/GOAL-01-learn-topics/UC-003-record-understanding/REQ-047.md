# REQ-047

> 次に学ぶの候補の取得が届かなかったとき、システムは、その取得の失敗を候補が無いこととしては示さない。

## 検証方針

- **分割クラス**:
  - `#fetch-failure-not-shown-as-empty` — 候補の取得が届かなかったとき、候補が無いときの示し方にせず、取れていないことが分かる示しになる
- **尽きている根拠**: 候補の取得の結果は成功（REQ-044 / REQ-045）・空（REQ-046）・不達（このクラス）の 3 通りで、不達の観測点は「空と同じ示しにしないこと」だけ。
- **検証しない**: 失敗の伝え方と読み直す手段は BR-014、取得前と空を別の状態として持つことは BR-015 の範囲。
- **参照先**: 被覆するテストが無い（ホームの取得が届かない場合を見る単体のテストが無い）。
