# REQ-270

> 利用者が本人として学びを使ったとき、システムはその日を本人が学びを開いた日として、同じ日につき高々 1 件だけ記録する。

## 検証方針

- **分割クラス**:
  - `#first-use-of-day` — その日の記録がまだ無い状態で本人として学びを使う（その日が 1 件記録される）
  - `#same-day-again` — 同じ日に重ねて使う（その日の記録が 2 件にならない）
  - `#next-day` — 暦日が変わってから使う（前の日の記録を残したまま、新しい日が 1 件増える）
- **尽きている根拠**: UC.md の表の 2 状態（今日の分をまだ記録していない／記録している）に、暦日が変わる場合を加えた 3 つ。どの画面を開いたかは記録の件数を分けない。
- **境界の扱い**: 暦日の切れ目（契約の `getHomeSummary` の `visits.today` が日本時間の暦日と決めている）が「同じ日」と「別の日」の境目。
- **検証しない**: 未認証の求め（BR-001）。記録の置き場所と列の形（R-102）。記録から算出する値（REQ-271）。
- **参照先**: 被覆するテストが無い
