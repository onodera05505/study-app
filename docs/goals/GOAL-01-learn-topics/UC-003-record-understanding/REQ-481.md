# REQ-481

> 資格対策の学びで論点に紐づく過去問への回答も理解度の記録も無いとき、システムはその論点の理解度を未理解として示さず、未として示す。

## 検証方針

- **分割クラス**:
  - `#no-counted-answer-is-unanswered` — BR-049 が数える回答も理解度の記録も無い論点は、論点の画面と一覧の行の応答で未（回答の履歴からの判定）になり、未理解にも記録なしにもならない
  - `#screen-shows-unanswered` — 未の論点を、論点の画面と一覧の行が「未」と示し、「未理解」と示さない
- **尽きている根拠**: 文は応答の段階（サーバ）と画面の示し方の 2 か所で成り立つので 2 クラス。「回答が無い」の側は、何も無い・他の利用者の回答と記録だけ・締める前の模試の回答だけ・未回答の行だけ・過去問が無い、のどれも数える回答が無い同じクラスの値の変種として回す。
- **検証しない**: ロードマップ型（記録が無い論点は未理解。BR-029 の範囲で、REQ-421 と REQ-041 が持つ）。色と見た目。
