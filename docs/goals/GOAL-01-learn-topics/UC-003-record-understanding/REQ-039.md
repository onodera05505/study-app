# REQ-039

> 理解度の記録が届かなかったとき、システムは、示している段階を選ぶ前の段階に戻す。

## 検証方針

- **分割クラス**:
  - `#revert-on-failure` — 記録が届かなかったとき、示している段階が選ぶ前の段階に戻る
- **尽きている根拠**: 記録の応答は届いた（REQ-040）と届かなかった（このクラス）の二分で、届かなかった側の観測点は段階を戻すことだけ。届かない理由（断りと通信の失敗）は戻し方に差を作らないため値の変種。
- **検証しない**: 失敗の理由を伝えることと画面の中身を消さないことは BR-014 の範囲で、この要件の文は段階を戻すことだけを持つ。
- **参照先**: `tests/client/topic_detail.test.tsx::理解度の記録`
