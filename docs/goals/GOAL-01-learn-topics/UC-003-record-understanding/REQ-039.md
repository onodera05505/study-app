# REQ-039

> 理解度の記録が届かなかったとき、システムは、示している段階を選ぶ前の段階に戻し、記録できなかったことを示して読んでいた教材を消さない。

## 検証方針

- **分割クラス**:
  - `#revert-on-failure` — 記録が届かなかったとき、示している段階が選ぶ前の段階に戻り、記録できなかったことが出て、読んでいた教材が残る
- **尽きている根拠**: 記録の応答は届いた（REQ-040）と届かなかった（このクラス）の二分で、届かなかった側の観測点は、段階が戻ること・記録できなかったことが出ること・教材が残っていることの 3 つが同じ入力で同時に観測できるため 1 クラス。届かない理由（断りと通信の失敗）は示し方に差を作らないため値の変種。
- **検証しない**: 失敗の理由ごとの文言の違い（文言の正本は画面のコード）。押し直せるようにすることと読み直す手段の置き方は BR-014 の範囲。
