# REQ-044

> 利用者がホームを開いたとき、システムは、次に学ぶの候補の上位を、論点と出題頻度と分野を添えて上から示す。

## 検証方針

- **分割クラス**:
  - `#home-shows-candidate-with-count-and-field` — ホームに、候補の論点と出題頻度と分野、およびその論点へ進む導線が出る
  - `#home-keeps-candidate-order` — 候補が複数あるとき、返った候補の順のまま上から出る
- **尽きている根拠**: ホームの入力は候補の列だけで、1 件（添える値を観測）と複数件（順を観測）に分かれる。0 件は REQ-046、取得の不達は REQ-047 が持つ。
- **検証しない**: いくつまで示すかの値は契約の `nextTopics` の上限が持つ。
- **参照先**: `tests/client/home.test.tsx::次に学ぶ（UC-003）`（`#home-keeps-candidate-order` は被覆するテストが無い）
