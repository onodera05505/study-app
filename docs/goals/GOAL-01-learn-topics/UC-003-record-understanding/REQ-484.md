# REQ-484

> 資格対策の学びで利用者の回答（論点に紐づく過去問と同一内容の過去問への回答を含む）が BR-049 の数える回答に加わったとき、システムは、そのあとに示す論点の理解度・分野と単元の集計・次に学ぶの候補に、その回答を反映した段階を示す。

## 検証方針

- **分割クラス**:
  - `#latest-wrong-is-unlearned` — 最新の回答が誤答なら、それより前に何日正解していても未理解
  - `#correct-one-day-is-partly` — 最後の誤答より後の正解が日本時間で 1 日だけなら、何回正解しても、UTC の日付が変わる時刻を跨いでも、やや理解
  - `#correct-two-days-is-understood` — 最後の誤答より後の正解が日本時間で 2 日以上なら、1 秒違い（UTC では同じ日）でも理解
  - `#days-counted-after-last-wrong` — 最後の誤答より前の正解の日は、同じ日でも数えない
  - `#no-decay-by-elapsed-days` — 最後の正解から日が経っても段階を下げない
  - `#drill-counted-before-finish` — 演習の回答は、締める前でも回答した時刻で数える
  - `#every-test-kind-counted` — 分野別演習・単元演習・弱点復習・回を指定した模試・ランダム構成の模試のどの回答も数える
  - `#mock-counted-after-finish` — 模試の回答は締めるまで数えず、締めたあとは数える
  - `#mock-time-is-finish-time` — 模試の回答の時刻は締めた時刻で、回答した時刻より後の演習の回答よりも新しくなりうる
  - `#own-answers-only` — 他の利用者の回答は本人の段階を変えない
  - `#same-content-answer-counted` — 論点に紐づく過去問と同一内容の過去問（どの論点にも紐づかない別の回）への回答も、その論点の回答として数える（それだけの回答でも未でなくなる）
  - `#same-time-by-question-order` — 同じ時刻の回答どうし（同じ模試の回答・同じ秒の演習の回答）は、出題の順で後の回答を後とする
  - `#reflected-after-answer-request` — 演習で回答を送ったあとに示す論点の理解度・分野と単元の集計・次に学ぶの候補が、その回答を反映している
  - `#aggregate-refetched-after-answer` — 演習で回答を送ったあと・模試を締めたあとに単元の一覧へ入り直すと、画面が覚えていた分野と単元の集計ではなく取り直した集計を示す
- **尽きている根拠**: 反映される段階は BR-049 の判定で、その入力は「最新の回答の正誤」×「最後の誤答より後に正解した日の数（1 か 2 以上）」の 4 分岐（最新が誤答・1 日・2 日以上と、誤答より前の日を数えない境目）と、「どの回答を数え、いつの回答とするか」（テストの種別、同一内容の過去問、演習と模試の時刻、同じ時刻どうしの順、締める前後、本人か）と、読む時点の経過日数に分かれる。`#reflected-after-answer-request` は、回答の操作そのもの（answerQuestion）のあとに各使い場所が取り直した値になることを見る。`#aggregate-refetched-after-answer` は、画面が覚える集計（REQ-018）が回答の加わった時点で捨てられることを見る。回答が数える回答に加わる時点は、演習では回答を送ったとき（answerQuestion）、模試では締めたとき（finishSession）の 2 つだけ（BR-049）なので、この 2 つを同じクラスの場合として置く。
- **境界の扱い**: 日の区切りは日本時間で、23:59:59 と翌日 00:00:00（UTC では同じ日）、08:59 と 09:00（UTC の日付が変わる）を置く。誤答と正解が同じ日の前後にある場合を置く。
- **境界の扱い（同じ時刻）**: 模試は回答した時刻をずらして同じ時刻に締め、出題の順と正誤の並びを逆にした 2 通りを置く。記録と同じ時刻の回答は REQ-482 の `#same-time-answer-keeps-record` が持つ。
- **検証しない**: 同一内容の過去問への回答を「同じ 1 問への回答」として扱うこと（判定は論点ごとの最新の回答・最後の誤答・正解した日だけで決まり、1 問と数えても 2 問と数えても段階が変わらないので、段階の境界から観測できない）。閾値と時差の値（正本はサーバの定数）。ロードマップ型（文の範囲外）。
