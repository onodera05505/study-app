# REQ-272

> 利用者がホームの集計を求めたとき、システムは本人の受験履歴の先頭から決めた件数まで、テストの種別・範囲の名前・問題数・正答数・締めた時刻を添えて返す。

## 検証方針

- **分割クラス**:
  - `#fields-attached` — 完了した受験が 1 件以上ある（各件にテストの種別・範囲の名前・問題数・正答数・締めた時刻が添う）
  - `#no-sessions` — 受験履歴が無い（空で返る）
  - `#capped-at-limit` — 決めた件数（契約の `getHomeSummary` の `recentSessions` の maxItems）を超える履歴（先頭から決めた件数までで止まる）
  - `#own-history-only` — 他の利用者の受験履歴がある状態（本人の分だけが返る）
- **尽きている根拠**: 入力は受験履歴の件数（0 ／ 決めた件数まで ／ それを超える）に尽き、それに持ち主の区別（本人か他人か）を加えた 4 つ。添える項目は契約の `recentSessions` の required が決めており、1 件以上のクラスで観測できる。
- **境界の扱い**: 決めた件数そのものは内側（全件返る）で、それを 1 件超える履歴が切り取る側。
- **検証しない**: 未認証の求め（BR-001）。締めていない受験の扱いと項目の値の作られ方（受験そのものは GOAL-02 の UC が持つ）。日々の記録（REQ-271）。
- **参照先**: 被覆するテストが無い
