# REQ-038

> 利用者が理解度の段階を選んだとき、システムは、記録の完了を待たずに、選ばれた段階を選ばれているものとして示す。

## 検証方針

- **分割クラス**:
  - `#selected-before-response` — 記録の応答が返る前から、押した段階が選ばれているものとして示される
- **尽きている根拠**: 「待たずに示す」の入力は記録の応答の到達だけで、未到達（このクラス）・不達（REQ-039）・成功（REQ-040 / REQ-041）に尽きる。どの段階を押したかは値の変種。
- **境界の扱い**: 選ばれているものとして示される段階はいつも 1 つであることを、このクラスの観測に含める。
- **検証しない**: 段階を選ぶ操作の形（要素の種類と属性）は要件が決めていないため、選ばれていることが分かる以上は見ない。
- **参照先**: `tests/client/topic_detail.test.tsx::理解度の記録`
