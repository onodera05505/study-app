# REQ-045

> 利用者が論点の画面を開いたとき、システムは、いま開いている論点を除いた次に学ぶの候補の先頭を、その論点へ進む導線として示す。

## 検証方針

- **分割クラス**:
  - `#next-topic-link-on-detail` — 候補があるとき、論点の画面にその論点へ進む導線が出る
  - `#excludes-current-topic` — いま開いている論点自身は、候補の先頭として示されない
- **尽きている根拠**: 論点の画面に添える候補は「自分以外の候補がある」「自分だけが候補」「候補が無い（REQ-046）」の 3 通りで、前の 2 つがこの 2 クラス。
- **検証しない**: いま開いている論点を除いた先頭が実データで何になるかは `scripts/check_api.py` が本番相当で見る。
- **参照先**: `tests/client/topic_detail.test.tsx::次に学ぶ論点`（`#excludes-current-topic` は被覆する単体のテストが無い）
