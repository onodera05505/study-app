# REQ-271

> 利用者がホームの集計を求めたとき、システムは本人が学びを開いた日の記録から、連続記録・これまでで最も長い連続記録・開いた日数の合計を算出して返す。

## 検証方針

- **分割クラス**:
  - `#today-only` — 学びを開いた日の記録が今日の 1 件だけ（3 つの値がいずれも 1）
  - `#consecutive-days` — 今日に続く途切れの無い記録（連続記録がその長さになり、合計も同じ日数になる）
  - `#broken-streak` — 間に開いていない日がある記録（連続記録は今日に続く分だけになり、最も長い連続記録は過去の分が残り、合計はすべての日数）
- **尽きている根拠**: 算出の入力は本人が学びを開いた日の集合だけで、ホームの集計を求めること自体が本人として学びを使うことなので（REQ-270）、集計の時点の集合は必ず今日を含む。今日を含む集合の形は「今日だけ」「今日に続く途切れの無い並び」「途切れのある並び」に尽き、返す 3 つの値はこの形の違いで区別できる。
- **検証しない**: 未認証の求め（BR-001）。記録が 1 件も無い集合と、今日の記録が無く昨日で終わる並び（集計を求めた時点で REQ-270 が今日を記録するため、境界から作れない）。暦日の決め方と記録の作られ方（REQ-270。同じ日の重複は REQ-270 が 1 件に抑える）。理解度の件数・次に学ぶ・直近の結果（REQ-043・REQ-272 ほか）。
