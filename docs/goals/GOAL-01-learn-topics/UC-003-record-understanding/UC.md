# UC-003 論点の理解度を記録して次に学ぶ論点を辿る

## 概要

利用者が、過去問への回答から判定される論点の理解度を見て、必要なら自分の見立てで上書きし、出題頻度が高くまだ理解していない論点を「次に学ぶ」として辿りながら学び進める。

## 事前条件

- 利用者（ACT-01）がログインしており、学びを 1 つ選んで論点の画面を開いている（論点を選ぶまでの導線は同じゴールの別 UC が持つ）
- 学びの種類が資格対策である（ロードマップ型では並びと導線と理解度の決まり方が違う。GOAL-03 の範囲。ただし論点の画面の理解度の操作の示し方は、学びの種類によらずこの UC が持つ）
- 過去問への回答は、演習と模試の別の UC で記録されている
- 適用される業務規則: BR-001, BR-014, BR-015, BR-018, BR-029, BR-030, BR-031, BR-040, BR-045, BR-049, BR-050

## 主シナリオ

1. 利用者が論点の画面を開く
2. システムが、その論点に紐づく過去問への本人の回答の履歴から判定した理解度（回答が無ければ未）を、回答の履歴からの判定か本人の上書きかの別とともに示す → BR-049, BR-050, BR-029
3. 利用者が理解度の 3 段階（未理解・やや理解・理解）のいずれかを選んで、判定を上書きする
4. システムが、記録の完了を待たずに、選ばれた段階を選ばれているものとして示す
5. システムが、選ばれた段階をその利用者のその論点の理解度の記録として残し、同じ論点の以前の記録を残さない
6. システムが、その論点に次に回答するまで、記録した段階を理解度として論点の画面と論点の一覧の行で段階の名前と段階ごとに違う記号の両方で示し、理解度の操作では今の段階の選択肢を色によらず見分けられる形で示し、分野・単元の集計にも反映する → BR-045, BR-050
7. 利用者がその論点の過去問に演習で回答する（テストの進め方は別の UC が持つ）
8. システムが、そのあとに示すその論点の理解度を回答の履歴からの判定に戻し、分野・単元の集計と次に学ぶの候補にも反映する → BR-049, BR-050
9. 利用者がホームを開く
10. システムが、出題頻度が高くまだ理解していない論点（未を含む）を「次に学ぶ」として上から示し、あわせて本人の連続記録と最近の結果を示す → BR-030
11. 利用者が示された論点を開く
12. システムが、その論点の画面に、いま開いている論点を除いた次に学ぶの先頭を示す

## 事後条件

- 成功時: 選んだ段階が利用者自身の理解度の記録として残り、その論点に次に回答するまで論点の画面・論点の一覧の行・分野と単元の集計・次に学ぶの候補がその段階を反映し、回答したあとは回答の履歴からの判定を反映している（理解の論点は次に学ぶに出ない）
- 失敗時: いかなる状態変更も残っていない（部分適用なし。示される段階も押す前のまま）
