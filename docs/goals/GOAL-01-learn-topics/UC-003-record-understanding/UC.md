# UC-003 論点の理解度を記録して次に学ぶ論点を辿る

## 概要

利用者が、読んだ論点に自分の理解度を残し、出題頻度が高くまだ理解していない論点を「次に学ぶ」として辿りながら学び進める。

## 事前条件

- 利用者（ACT-01）がログインしており、学びを 1 つ選んで論点の画面を開いている（論点を選ぶまでの導線は同じゴールの別 UC が持つ）
- 学びの種類が資格対策である（ロードマップ型では並びと導線が違う。GOAL-03 の範囲）
- 適用される業務規則: 該当する BR は未抽出（横断の候補は本文の BR候補 マーカー）

## 主シナリオ

1. 利用者が論点の画面で理解度の 3 段階（未理解・やや理解・理解）のいずれかを選ぶ
2. システムが、記録の完了を待たずに、選ばれた段階を選ばれているものとして示す
3. システムが、選ばれた段階をその利用者のその論点の理解度として記録し、同じ論点の以前の記録を残さない
4. システムが、記録した理解度を論点の画面と論点の一覧の行で段階の文字と印の両方で示し、分野・単元の集計にも反映する
5. 利用者がホームを開く
6. システムが、出題頻度が高くまだ理解していない論点を「次に学ぶ」として上から示す
7. 利用者が示された論点を開く
8. システムが、その論点の画面に、いま開いている論点を除いた次に学ぶの先頭を示す

## 事後条件

- 成功時: 選んだ段階が利用者自身の理解度として残り、論点の画面・論点の一覧の行・分野と単元の集計・次に学ぶの候補がその段階を反映している（理解にした論点は次に学ぶに出ない）
- 失敗時: いかなる状態変更も残っていない（部分適用なし。示される段階も押す前のまま）
