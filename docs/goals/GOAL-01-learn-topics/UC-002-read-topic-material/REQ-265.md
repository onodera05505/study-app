# REQ-265

> 論点の一覧の求めに、決めた並べ替えの値以外、または決めた範囲の外の件数が含まれる場合、システムは一覧を返さず、求めが受け付けられなかったことを示す。

## 検証方針

- **分割クラス**:
  - `#sort-outside-allowed` — 決めた並べ替えの値以外（契約の `listTopics` の `sort` の enum の外）を含む求め
  - `#limit-above-max` — 決めた上限（同 `limit` の maximum）を超える件数を含む求め
  - `#limit-below-min` — 決めた下限（同 `limit` の minimum）を下回る件数を含む求め
- **尽きている根拠**: この要件が拒む入力は契約の `listTopics` の request のうち値域を持つ 2 つの項目だけで、並べ替えは「決めた値か否か」、件数は「範囲の内・上を超える・下を下回る」に尽きる。他の絞り込み（field・middleNo・status）は値域を持たない（決めた外の値は無視される）ため、この要件の入力ではない。
- **境界の扱い**: 件数は下限と上限そのものが内側（受け付ける側）で、その 1 つ外がこの要件の側。並べ替えは enum の内と外の 2 値で境界を持たない。
- **検証しない**: 未認証と受け付けられない入力が同時のときの先後（契約の `errors` の並びが正本。R-1207。拒み自体は BR-001・REQ-002）。受け付けた求めが返す並びと絞り込み（REQ-474・REQ-021）と示す件数（REQ-032）。
- **参照先**: `tests/server/repay2_UC-002_topics_input.test.ts::論点の一覧の受け付けない求め（GET /api/topics。UC-002）`（3 クラス）、`tests/server/catalog.test.ts::論点の一覧（GET /api/topics）`（`#sort-outside-allowed`）
