# REQ-016

> 分野または単元の集計が取れなかったとき、システムは読み込み中である旨の表示を残さず、その集計の代わりに取れなかったことを示す。

## 検証方針

- **分割クラス**:
  - `#aggregate-failed` — 分野と単元の集計の取得が失敗した入力
- **尽きている根拠**: 取得の結果は成功と失敗の 2 つで、成功は REQ-014・REQ-015 が持つ。失敗は理由（通信が届かない・5xx・本文が読めない）が変わっても「読み込み中を残さず、取れなかったことを示す」が同じなので 1 クラス。
- **検証しない**: 失敗の理由ごとの文言の違い（要件は取れなかったことを示すまでで、文言の正本は画面のコード）。分野だけ取れて単元が取れない部分失敗（BR-014 の「取れた部分を出す」は横断の規則で、この要件の分割では扱わない）。
- **参照先**: `tests/client/topics.test.tsx::集計が取れないとき（UC-002）`
