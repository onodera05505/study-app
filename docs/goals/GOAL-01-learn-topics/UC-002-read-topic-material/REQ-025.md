# REQ-025

> 図の書き起こしに表として解釈できない並びや閉じていない囲みが含まれるとき、システムは示すことを中断せず、解釈できなかった部分を書かれた文字のまま示す。

## 検証方針

- **分割クラス**:
  - `#unparsable-table` — 表として解釈できない並びを含む書き起こしを持つ過去問
  - `#unclosed-markup` — 閉じていない囲みを含む書き起こしを持つ過去問
- **尽きている根拠**: 要件が挙げる解釈の失敗は「表として読めない並び」と「閉じていない囲み」の 2 つで、どちらも示すことを中断せず、解釈できなかった部分を書かれた文字のまま出す。解釈できる書き起こしは BR-025 の記法の側で、REQ-030 の本文と同じ経路を通る。
- **検証しない**: 解釈する記法の集合（正本は描画のコードで、実データ全件の描画は `scripts/check_render.sh` が見る）。
- **参照先**: `tests/client/choice_figure.test.ts::過去問の図の書き起こし` と `tests/client/repay_UC-002_topic_detail.test.tsx::紐づく過去問（UC-002）`
