# REQ-273

> 利用者が論点の教材からその論点のドリルを始めたとき、システムは、開いている論点を範囲とし種別を論点ドリルとした演習を、UC-004 の REQ-050 に従って始める。

## 検証方針

- **分割クラス**:
  - `#start-from-material-sends-this-topic` — 論点の教材の画面で論点ドリルを始める（開いている論点を範囲にした種別ドリルのテストを 1 つだけ作りに行く）
  - `#one-in-progress-drill-created` — 論点を範囲にした種別ドリルの求めを受ける（REQ-050 に従い進行中のテストが 1 つだけ作られ、種別は論点ドリル）
  - `#scope-limited-to-topic` — 他の論点にも過去問がある中で、論点を範囲にした種別ドリルの求めを受ける（範囲がその論点だけになり、REQ-050 が示す範囲の名前と問題数がその論点の分になる）
- **尽きている根拠**: このイベントの入力は「開いている論点」1 つだけで、要件の観測点は、画面がどの論点を範囲に作りに行くか、作られるテストの数・状態・種別、作られるテストの範囲の 3 つに尽きる。
- **検証しない**: 作られたテストの出題・回答・締めの振る舞い（UC-004 が持つ）。進行中のテストが既にあるとき（UC-004 の REQ-057）。
- **参照先**: `tests/client/repay2_UC-002_question_figure.test.tsx::論点の教材から論点ドリルを始める（UC-002）`（`#start-from-material-sends-this-topic`）、`tests/server/repay2_UC-002_drill_start.test.ts::論点の教材からドリルを始める（POST /api/sessions。UC-002）`（`#one-in-progress-drill-created`・`#scope-limited-to-topic`）
