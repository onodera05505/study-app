# REQ-030

> 利用者が教材の詳しい解説を開いたとき、システムはその詳しい解説を示し、開くまでは示さない。

## 検証方針

- **分割クラス**:
  - `#detail-toggle` — 詳しい解説を持つ論点で、詳しい解説を開く前と開いたあとの入力
- **尽きている根拠**: 詳しい解説の見え方は開く前と開いたあとの 2 つで、同じ 1 つの操作の前後なので 1 クラスで尽きる。詳しい解説が無い論点は REQ-026 が持つ。
- **検証しない**: 本文の記法の解釈（BR-025。実データ全件は `scripts/check_render.sh` が見る）。
