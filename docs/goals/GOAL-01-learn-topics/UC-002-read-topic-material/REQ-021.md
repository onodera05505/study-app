# REQ-021

> 利用者が並べ替え（出題頻度の順・名前の順）または理解度の絞り込みを選び直したとき、システムは論点の一覧をその並びと絞り込みで示し直す。

## 検証方針

- **分割クラス**:
  - `#resort` — 並べ替えを出題頻度の順から名前の順へ選び直した入力
  - `#refilter-status` — 理解度の絞り込みを、1 つ以上選んだ別の組み合わせへ選び直した入力
- **尽きている根拠**: 選び直せる手段は並べ替えと理解度の絞り込みの 2 つで、どちらも「選び直すと、その並びと絞り込みの一覧を示し直す」ことが観測の対象になる。理解度を 1 つも選ばない選び直しは REQ-022 が持つ。
- **検証しない**: 並べ替えに学ぶ順を選んだとき（学ぶ順が決まっている学びはこの UC の事前条件の外）。示し直した一覧の中身の正しさ（REQ-020 が持つ）。
