# REQ-020

> 利用者が単元を選んだとき、システムはその単元に属する論点を出題頻度の降順に並べ、論点ごとの出題頻度と理解度を添えて示す。

## 検証方針

- **分割クラス**:
  - `#topics-of-middle` — 複数の単元に論点がある状態で、単元を 1 つ選んだ入力
  - `#frequency-desc` — 出題頻度の異なる論点を持つ単元を選んだ入力（降順が観測できる）
  - `#status-shown` — 理解度の記録がある論点と記録が無い論点が混ざる単元を選んだ入力
- **尽きている根拠**: 単元を選んだあとの示し方は「どの論点を出すか」「どの順で出すか」「論点に何を添えるか」の 3 つで決まり、それぞれに入力の違い（選ぶ単元・出題頻度の違い・理解度の記録の有無）が対応する。論点が 0 件の単元は REQ-028、取れなかった場合は REQ-027 が持つ。
- **検証しない**: 出題頻度の値が実データと合っているか（`scripts/check_api.py`）。出題頻度が同じ論点どうしの順（要件が決めていない）。
- **参照先**: `tests/client/topics.test.tsx::論点の一覧（UC-002）`
