# REQ-423

> 利用者が資格対策の学びで論点を選んだとき、システムは論点の教材とともに、単元の一覧から分野と単元を経てその論点に至る階層の道筋を示す。

## 検証方針

- **分割クラス**:
  - `#path-from-unit-list-to-topic` — 資格対策の対象で論点を選ぶと、教材とともに、単元の一覧→その論点の分野→その論点の単元→その論点の順の道筋が 1 つ出る
- **尽きている根拠**: 入力は「どの資格対策の対象か」と「どの論点か」の 2 つだけで、どの組でも道筋の段（単元の一覧・分野・単元・論点）と並びは同じ規則で決まるため 1 クラスで尽きる。対象は登録簿の `kind: exam` の全件、論点は分野と単元が違う 2 件を値の変種として回し、選んでいない論点の分野・単元が混ざらないことも同じクラスで見る。ロードマップ型は REQ-424 が持つ。
- **検証しない**: 道筋の各段が押せるかと行き先、区切りの見た目は要件が決めていないため、名前が「階層の道筋」の要素に段の語がこの順で並ぶことだけを見る。教材が取れないときの画面は REQ-033 が持つ。
