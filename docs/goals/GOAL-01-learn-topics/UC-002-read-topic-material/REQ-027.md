# REQ-027

> 論点の一覧が取れなかったとき、システムは読み込み中である旨の表示を残さず、選んでいる単元と並べ替え・絞り込みの手段を保ったまま、一覧の場所に取れなかったことを示す。

## 検証方針

- **分割クラス**:
  - `#topic-list-failed` — 単元を選んだあと、論点の一覧の取得が失敗した入力
- **尽きている根拠**: 取得の結果は成功と失敗の 2 つで、成功は REQ-020、まだ取れていない間は REQ-028 が持つ。失敗は理由が変わっても示し方が同じなので 1 クラスで、保たれる物（選んでいる単元・並べ替えと絞り込みの手段）は同じ 1 つの観測に含む。
- **検証しない**: 失敗の理由ごとの文言の違い（文言の正本は画面のコード）。
- **参照先**: `tests/client/repay_UC-002_topics.test.tsx::論点の一覧（UC-002）`
