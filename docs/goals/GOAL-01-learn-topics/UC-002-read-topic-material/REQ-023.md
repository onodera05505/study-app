# REQ-023

> 利用者が論点を選んだとき、システムはその論点の教材と、その論点に紐づく過去問と、同じ小項目の他の論点を示す。

## 検証方針

- **分割クラス**:
  - `#citation-per-question` — 原本から変えていない過去問が紐づく論点を選んだ入力（BR-027 の出典）
  - `#modified-question` — 原本から変えた印が立つ過去問が紐づく論点を選んだ入力（BR-027 の一部改変）
  - `#same-content-questions` — 同一内容の過去問を持つ論点を選んだ入力（BR-028 の件数と他の出典）
  - `#siblings-shown` — 同じ小項目に他の論点がある論点を選んだ入力
- **尽きている根拠**: 示す物は教材・紐づく過去問・同じ小項目の他の論点の 3 つで、教材の本体は REQ-030、過去問の本文と答えは REQ-031・REQ-032、過去問の図は REQ-024 が持つ。この要件に残るのは過去問に併記する物（BR-027 の出典と一部改変、BR-028 の同一内容の件数と他の出典）と他の論点の有無で、それぞれが別の入力に対応する。教材や過去問が欠けている論点は REQ-026 が持つ。
- **検証しない**: 出典の文字列の組み立て（どの回の何問目かの対応は投入の検査 `scripts/check_seed.py` が持つ）。同じ小項目に他の論点が無いときの示し方（要件が決めていない）。
- **参照先**: `tests/client/citation.test.tsx::論点の学習画面の出典（UC-002）`
