# REQ-029

> 利用者が戻る導線を選んだとき、システムは論点の教材からは来た論点の一覧を示し、論点の一覧からは単元の一覧を示す。

## 検証方針

- **分割クラス**:
  - `#back-from-material` — 論点の教材から戻る導線を選んだ入力
  - `#back-from-topic-list` — 論点の一覧から戻る導線を選んだ入力
- **尽きている根拠**: 戻る導線を持つ層は論点の教材と論点の一覧の 2 つで（単元の一覧は起点で戻り先が無い）、層ごとに戻り先が 1 つに決まる。
- **検証しない**: ブラウザの履歴での戻り（BR-016 が履歴に頼らないことを決めており、置いた導線の側だけを見る）。
- **参照先**: `tests/client/topic_detail.test.tsx::論点の解説（UC-002）` と `tests/client/topics.test.tsx::論点の一覧（UC-002）`
