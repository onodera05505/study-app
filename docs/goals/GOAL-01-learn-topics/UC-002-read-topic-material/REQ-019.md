# REQ-019

> 利用者が分野を選んだとき、システムは単元の一覧を、その分野に属する単元だけに絞り込んで示す。

## 検証方針

- **分割クラス**:
  - `#filter-by-field` — 複数の分野の単元が示されている状態で、分野を 1 つ選んだ入力
- **尽きている根拠**: 絞り込みの入力は「分野を選んでいない（全分野）」と「分野を 1 つ選んだ」の 2 つで、前者は REQ-015 の最初の表示が持つ。選んだ分野に属する単元が残り、属さない単元が消えることは同じ 1 つの入力で両面を観測できる。
- **検証しない**: 単元が 0 件の分野を選んだとき（分野は単元を持つものだけが集計に現れるので、入力として作れない）。
- **参照先**: `tests/client/topics.test.tsx::単元の一覧（UC-002）`
