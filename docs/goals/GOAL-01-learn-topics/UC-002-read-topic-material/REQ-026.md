# REQ-026

> 選んだ論点に教材が無いとき、または紐づく過去問が無いとき、システムはその場所を空にせず、教材がまだ無いこと・紐づく過去問が無いことをそれぞれ示す。

## 検証方針

- **分割クラス**:
  - `#no-material` — 教材が無い論点を選んだ入力
  - `#no-questions` — 紐づく過去問が無い論点を選んだ入力
- **尽きている根拠**: 欠けうる場所は教材と紐づく過去問の 2 つで、片方だけ欠ける場合と両方欠ける場合の示し方は場所ごとに独立に決まる（2 つのクラスの組み合わせ）。両方そろっている場合は REQ-023 が持つ。
- **検証しない**: 教材が空の文字列と欠けのどちらで来るか（境界の形の正本は契約の `explanation`・`detail` の型）。
- **参照先**: `tests/client/repay_UC-002_topic_detail.test.tsx::論点の解説（UC-002）`
