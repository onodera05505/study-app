# REQ-267

> 利用者が過去問の図を押したとき、システムは、BR-035 に従いその図の表示を切り替える。

## 検証方針

- **分割クラス**:
  - `#toggle-to-natural-size` — 画面幅に合わせて出ている図を押す（原寸の表示に切り替わる）
  - `#toggle-back-to-fit-width` — 原寸で出ている図を押す（画面幅に合わせた表示に戻る）
- **尽きている根拠**: 図の表示は原寸と画面幅の 2 状態しかなく、押すイベントはその 2 状態からの 2 通りに尽きる。
- **検証しない**: 実際の拡大率・寸法と見た目（R-102。要件は切り替わることだけを決めている）。画像が置き場所に無いとき（BR-026）。書き起こしの開閉（REQ-024）。
- **参照先**: `tests/client/repay2_UC-002_question_figure.test.tsx::過去問の図の切り替え（UC-002）`
