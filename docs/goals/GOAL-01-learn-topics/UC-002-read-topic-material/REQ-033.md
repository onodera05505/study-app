# REQ-033

> 論点の教材が取れなかったとき、システムは読み込み中である旨の表示を残さず、教材と紐づく過去問の代わりに取れなかったことを示す。

## 検証方針

- **分割クラス**:
  - `#detail-fetch-failed` — 論点を選んだあと、論点の教材の取得が失敗した入力
- **尽きている根拠**: 取得の結果は成功と失敗の 2 つで、成功は REQ-023 が持つ。失敗は理由が変わっても「読み込み中を残さず、教材と紐づく過去問の代わりに取れなかったことを示す」が同じなので 1 クラス。
- **検証しない**: 契約の `INVALID_INPUT`・`NOT_FOUND` と通信の失敗の区別（要件は取れなかったことを示すまでで、区別を決めていない）。失敗の理由ごとの文言の違い（文言の正本は画面のコード）。
- **参照先**: `tests/client/topic_detail.test.tsx::論点の解説（UC-002）`
