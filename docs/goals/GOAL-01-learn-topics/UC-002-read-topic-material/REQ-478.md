# REQ-478

> 資格対策の学びで論点の一覧の行と論点の教材の画面に論点の出題頻度を示している間、システムはその出題頻度に BR-051 に従った出題回数の印を添え、ロードマップ型の学びには出題回数の印を示さない。

## 検証方針

- **分割クラス**:
  - `#tier-boundaries` — 出題頻度が 0・1・2・3・3 より多い論点を持つ一覧を求めた入力（BR-051 の段：0 は印なし、1・2・3 以上の 3 段）
  - `#tier-on-detail` — 前提の論点と同じまとまりの他の論点を持つ論点の教材を求めた入力（論点と、添える論点のそれぞれに出題頻度から求めた段）
  - `#no-tier-for-roadmap` — ロードマップ型の学びで、出題頻度を持つ論点の一覧を求めた入力（印を添えない）
  - `#mark-on-list-row` — 段の違う論点と段の無い論点を持つ一覧を示した画面の入力（行に段の数だけ ★、段の無い論点には無し）
  - `#mark-on-material` — 段の違う論点の教材を示した画面の入力（出題頻度とともに段の数だけ ★、段の無い論点には無し）
- **尽きている根拠**: 段を求めるのはサーバの 1 か所（BR-051）で、段の境目は 0／1／2／3 の 4 点とその上の 1 点で尽きる。印を添える場所は論点の一覧の行と論点の教材の 2 つで、画面は渡された段をそのまま ★ で示すので場所ごとに 1 クラス。学びの種類は資格対策とロードマップ型の 2 つで、ロードマップ型には印を返さないことを境界で見る。
- **境界の扱い**: 3 段の境目は出題頻度 3 ちょうど（3 段の側）とその 1 つ下の 2（2 段）で見る。
- **検証しない**: ロードマップ型の画面に ★ が出ないこと（ロードマップ型の画面は UC-009 が持ち、ここでは段を返さないことまでを見る。段の無い論点に ★ を出さないことは `#mark-on-list-row`・`#mark-on-material` が見る）。印の見た目（★ の色や大きさ。全体の検証しない範囲）。同一内容の過去問を数えたままの出題頻度（出題頻度の数え方は BR-028 で、投入の検査が持つ）。
