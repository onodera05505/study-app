# REQ-031

> 利用者が過去問の答えを開いたとき、システムは正解を示し、その過去問の問題解説を開く手段は正解を示したあとにだけ示す。

## 検証方針

- **分割クラス**:
  - `#answer-then-explanation` — 問題解説を持つ過去問で、答えを開く前と開いたあとの入力
- **尽きている根拠**: 正解と、問題解説を開く手段の有無は、答えを開いたかどうかの 2 つだけで決まり、同じ 1 つの操作の前後なので 1 クラスで尽きる。
- **検証しない**: 問題解説の本文の記法（BR-025。`scripts/check_render.sh`）。問題解説を持たない過去問での手段の有無（要件が決めていない）。
- **参照先**: `tests/client/topic_detail.test.tsx::紐づく過去問（UC-002）`
