# REQ-018

> 利用者が学びを開き続けている間、システムは一度取れた分野と単元の集計を、単元の一覧に入り直しても取り直さない。

## 検証方針

- **分割クラス**:
  - `#aggregate-remembered` — 集計が一度取れている状態で、単元の一覧に入り直した入力
- **尽きている根拠**: 入り直したときに取りに行く回数は 0 回か 1 回以上の 2 つで、この要件は 0 回であることだけを言う。覚えが無い状態からの初回は REQ-014・REQ-015、失敗を覚えないことは REQ-017 が持つ。
- **検証しない**: 学びを閉じたあとに覚えが消えること（要件は学びを開き続けている間だけを言う）。理解度を記録したときに覚えを捨てる規則（理解度を記録する UC が持つ）。
- **参照先**: `tests/client/topics.test.tsx::単元の一覧（UC-002）`
