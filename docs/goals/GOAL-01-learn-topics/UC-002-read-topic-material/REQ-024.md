# REQ-024

> 図を持つ過去問を示している間、システムは原本から切り出した図の画像と図の書き起こしを併記し、図の画像が無い過去問では書き起こしを本体として示す。

## 検証方針

- **分割クラス**:
  - `#figure-image-and-transcript` — 原本から切り出した図の画像と書き起こしの両方を持つ過去問を示している状態
  - `#transcript-only` — 図を持つが画像が無く、書き起こしだけを持つ過去問を示している状態
- **尽きている根拠**: 図を持つ過去問は、切り出した画像があるか無いかの 2 つしかなく、あれば画像と書き起こしの併記、無ければ書き起こしが本体になる。図を持たない過去問に画像を出さないことは `#figure-image-and-transcript` の観測に含む。
- **検証しない**: 画像そのものの見た目と切り出した位置の妥当さ（原本の画像との照合で、人が見る）。図の画像の配信が失敗したときの示し方（UC の例外系で未決）。
- **参照先**: `tests/client/topic_detail.test.tsx::紐づく過去問（UC-002）`
