# UC-002 分野から単元をたどり、論点の教材と紐づく過去問を読む

## 概要

利用者が、分野 → 単元 → 論点 の順にたどり、単元の構成に沿って出題回数の印を目安に論点を選び、その論点の教材と、その論点に紐づく過去問を読み終える。

## 事前条件

- 利用者が認証済みで、この学びの権限を持つ（認証と権限は別ゴールの範囲）
- 論点が分野・大項目・単元・小項目に紐づき、過去問が論点に紐づいている
- 資格対策の学び（学び全体を通した学ぶ順を持たない学び）である
- 単元の構成は学びのデータとして投入で入っている。構成を持つ単元と持たない単元がある。構成を持つ単元では、単元のすべての論点がちょうど 1 つのまとまりに入り、前提の論点は同じ学びにある論点を指す（投入の門は BR-048・REQ-469）
- 適用される業務規則: BR-001, BR-016, BR-025, BR-027, BR-028, BR-029, BR-031, BR-048, BR-049, BR-050, BR-051, BR-059

## 主シナリオ

1. 利用者が単元の一覧を開く。
2. システムが分野ごとの論点数・過去問数と、利用者の理解度の内訳を示す。 → BR-029
3. システムが大項目ごとにまとめた単元を、単元ごとの論点数・過去問数と「理解した数／論点数」つきで示す。
4. 利用者が分野を選び、単元を絞り込む。
5. 利用者が単元を選ぶ。
6. システムがその単元の論点を単元の構成の順に、論点ごとの出題頻度と出題回数の印と理解度つきで示す。単元の構成を持つ単元では、先頭に全体像を、まとまりごとにまとまりの名前と説明を見出しとして示す。 → BR-031, BR-051
7. 利用者が理解度の絞り込みを選び直す。
8. 利用者が論点を選ぶ。
9. システムが論点の教材と、紐づく過去問と、前提の論点への導線と、同じまとまり（単元の構成を持たない単元では同じ小項目）の他の論点を BR-031 の並びで示す。 → BR-027, BR-028, BR-031
10. 利用者が教材の詳しい解説を開く。 → BR-025
11. 利用者が過去問の答えを開き、続けて問題解説を開き、最初に示されなかった残りの過去問を開く。図を持つ過去問では、図の書き起こしを開き、図を押して原寸と画面幅を切り替える。
12. 利用者が戻る導線で、来た論点の一覧へ戻る。 → BR-016

## 事後条件

- 成功時: 利用者が選んだ論点の教材と、その論点に紐づく過去問の答えと問題解説を読み終え、来た論点の一覧に戻っている。論点の一覧は単元の構成の順で、各論点に出題回数の印が付いている。単元の一覧に入り直しても分野と単元の集計は取り直されない
- 失敗時: いかなる状態変更も残っていない（部分適用なし）
