# REQ-017

> 分野または単元の集計の取得が失敗したとき、システムはその失敗を覚えず、利用者が読み直しを求めたときに改めて取りに行く。

## 検証方針

- **分割クラス**:
  - `#failure-not-cached` — 集計の取得が一度失敗したあと、利用者が読み直しを求めた入力
- **尽きている根拠**: 失敗の覚え方は「覚える」「覚えない」の 2 つしかなく、覚えないことは「読み直しを求めると取りに行く回数が増える」の 1 つの観測で尽きる。
- **検証しない**: 成功した集計を覚えること（REQ-018 が持つ）。読み直しを求める手段の見た目。
- **参照先**: `tests/client/topics.test.tsx::集計が取れないとき（UC-002）`
