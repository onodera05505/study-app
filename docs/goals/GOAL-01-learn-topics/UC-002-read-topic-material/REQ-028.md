# REQ-028

> 論点の一覧をまだ取れていないとき、システムは該当する論点が無い旨を示さない。

## 検証方針

- **分割クラス**:
  - `#not-yet-fetched` — 論点の一覧をまだ取れていない（取りに行っている）入力
- **尽きている根拠**: 一覧の状態は未取得・取得できて 0 件・取得できて 1 件以上・失敗の 4 つで、この要件は未取得と 0 件の取り違えだけを禁じる。1 件以上は REQ-020、失敗は REQ-027 が持ち、0 件のときに該当なしを示すことは禁じていない。
- **検証しない**: 未取得を何として表すか（区別の表し方の正本はコード。BR-015）。
- **参照先**: `tests/client/topics.test.tsx::論点の一覧（UC-002）`
