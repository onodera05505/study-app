# REQ-032

> 利用者が論点を選んだとき、システムは紐づく過去問のうち先頭の決めた件数だけを示し、残りは件数を添えた手段で利用者が求めたときに示す。

## 検証方針

- **分割クラス**:
  - `#first-page-then-rest` — 決めた件数より多くの過去問が紐づく論点を選んだ入力
  - `#fewer-than-limit` — 決めた件数以下の過去問しか紐づかない論点を選んだ入力
- **尽きている根拠**: 入力は紐づく過去問の件数と決めた件数の大小の 2 つで尽きる（多いときは先頭だけを示して残りを件数つきの手段で開き、以下のときは残りが無い）。過去問が 0 件の論点は REQ-026 が持つ。
- **境界の扱い**: 決めた件数とちょうど同じ件数は `#fewer-than-limit` に入れる（残りが 0 件で、開く手段を出さない側）。
- **検証しない**: 決めた件数そのものの値（機械可読な設定で、正本は画面のコード。R-102）。
- **参照先**: `tests/client/topic_detail.test.tsx::紐づく過去問（UC-002）`
