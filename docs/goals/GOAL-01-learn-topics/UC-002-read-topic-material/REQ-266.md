# REQ-266

> システムは過去問の図の書き起こしを、書かれた順のまとまりに分けて示し、表の記法で書かれたまとまりは見出しつきの表として、囲みの記法で書かれたまとまりは行の並びを崩さない 1 つの囲みとして示す。

## 検証方針

- **分割クラス**:
  - `#blocks-in-written-order` — 文・表の記法・囲みの記法が混ざった書き起こし（書かれた順に別のまとまりに分かれる）
  - `#table-head-and-rows` — 表の記法で書かれたまとまり（見出しと行に分かれた表として示される）
  - `#code-lines-kept` — 囲みの記法で書かれたまとまり（行の並びを崩さない 1 つの囲みとして示される）
- **尽きている根拠**: 書き起こしのまとまりは要件が挙げる 3 種類（文・表の記法・囲みの記法）に尽き、観測点はまとまりの並びと、2 つの記法それぞれの示し方。読めない記法は REQ-025 が持つ。
- **検証しない**: 読めない表・閉じていない囲み（REQ-025）。書き起こしを畳んで出すか本体に出すか（REQ-024）。囲みの中身の意味づけ（擬似言語かどうかの判定はしない）。組合せ選択肢の整形（REQ-246）。
- **参照先**: `tests/client/choice_figure.test.ts::過去問の図の書き起こし`（`#blocks-in-written-order` のみ被覆。`#table-head-and-rows`・`#code-lines-kept` は被覆するテストが無い）
