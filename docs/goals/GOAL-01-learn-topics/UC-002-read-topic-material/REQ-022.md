# REQ-022

> 利用者が理解度の絞り込みを 1 つも選んでいないとき、システムは論点を取りに行かず、一覧を空として示したうえで、理解度を 1 つ以上選ぶよう促し、絞り込みをすべて戻す手段を示す。

## 検証方針

- **分割クラス**:
  - `#no-status-selected` — 理解度の絞り込みを 1 つも選んでいない入力
- **尽きている根拠**: 理解度の選択の数は 0 個と 1 個以上の 2 つで、1 個以上は REQ-021 が持つ。0 個はどの段階を外して 0 個になったかに依らず同じ扱いなので 1 クラス。
- **境界の扱い**: 3 つ選んだ状態から 1 つずつ外し、最後の 1 つを外して 0 個になる境界で取りに行かないことを見る（1 個のままでは取りに行く側）。
- **検証しない**: 絞り込みをすべて戻したあとに一覧が戻ること（REQ-021 の `#refilter-status` が持つ）。
- **参照先**: `tests/client/topics.test.tsx::論点の一覧（UC-002）`
