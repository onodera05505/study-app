# REQ-049

> 範囲の一覧と進行中のテストの有無のいずれかが取得できない場合、システムは、取得できた側はそのまま示し、取得できなかった側については取得できていないことと取り直す手段を示す。

## 検証方針

- **分割クラス**:
  - `#fields-failed` — 範囲の一覧だけが取れないとき、その側の理由と取り直す手段だけを出す
  - `#current-failed` — 進行中の有無だけが取れないとき、その側を取れていないものとして示し、範囲の一覧は出す
- **尽きている根拠**: 取得は範囲の一覧と進行中の有無の 2 つで、片側ずつ落ちる場合を両方見ている。両方落ちる場合は、独立した 2 つの表示が重なるだけで新しい振る舞いを作らない。
- **検証しない**: 両方が同時に取れない組み合わせ（上の理由）。取り直しの結果（成功したときの表示は `#fields-listed` と同じ経路）。
- **参照先**: `tests/client/practice.test.tsx::練習テストの画面`
