# REQ-348

> 現在の問題を求めたテストが見つからないものとして断られた場合、システムは、そのテストでは続けられないことと、練習テストへ戻る導線を示す。

## 検証方針

- **分割クラス**:
  - `#not-found-cannot-continue` — 現在の問題の取得が見つからないものとして断られると、そのテストでは続けられないことを示す（画面を開いた直後の取得と、断られた回答のあとの取り直しを値の変種に持つ）
  - `#back-to-practice` — 添えた導線をたどると練習テストへ戻る
- **尽きている根拠**: 文は「続けられないことを示す」と「練習テストへ戻る導線を示す」の 2 つを述べる。見つからない断りが起きる契機は、最初の取得と断られた回答のあとの取り直しの 2 つに尽き（UC.md の例外系の走査）、示し方は同じ。
- **検証しない**: 見つからない以外の取得の失敗（サーバの失敗・通信が届かない。REQ-278 が持つ）。見つからないときに REQ-278 の取り直す手段を併せて添えるかどうか（2 つの文はどちらも満たせ、この文は打ち消さない）。続けられない旨の文言（正本は画面のコード）。
- **参照先**: `tests/client/session.test.tsx::出題の画面`
