# REQ-070

> 利用者が進行中のテストから中断したとき、システムは、そこまでの回答とそのテストを進行中のまま残し、再開したときに現在の問題から続けられるようにする。

## 検証方針

- **分割クラス**:
  - `#suspend-keeps-answers` — 中断したとき、そこまでの回答とテストを消さずに残す
- **尽きている根拠**: 中断の振る舞いは 1 通り（残す）で、破棄（消す）とは別の操作として UC-006 が持つ。
- **検証しない**: 再開して現在の問題から続けられること（UC-006 の REQ-088 が持ち、練習テストの画面の再開のテストはそちらに属する）。
- **参照先**: `tests/client/session.test.tsx::出題の画面`
