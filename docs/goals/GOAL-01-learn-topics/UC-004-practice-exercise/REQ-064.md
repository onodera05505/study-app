# REQ-064

> 回答を受け付けたとき、システムは、そのテストの回答済みの問題数と残りの未回答の件数を、受け付けた回答を含めた値に改める。

## 検証方針

- **分割クラス**:
  - `#counts-updated-after-answer` — 回答を受け付けたあとの回答済みの問題数と残りの未回答の件数が、その回答を含めた値になる
- **尽きている根拠**: 改める値は回答済みの問題数と残りの未回答の件数の 2 つで、どちらも 1 件の受け付けで同時に決まる。
- **検証しない**: 受け付けられなかった回答で値が変わらないこと（REQ-067・REQ-072 が持つ）。
