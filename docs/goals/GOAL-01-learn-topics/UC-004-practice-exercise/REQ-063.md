# REQ-063

> 回答を受け付けたとき、システムは、正誤と正解の選択肢を示し、利用者が選んだ選択肢と正解の選択肢を見分けられるようにする。

## 検証方針

- **分割クラス**:
  - `#verdict-and-marks` — 回答のあとに正誤と正解の選択肢が出て、選んだ選択肢と正解の選択肢が別の印で見分けられる
- **尽きている根拠**: 見分けの対象は「正解の選択肢」「選んだ選択肢」「どちらでもない選択肢」の 3 通りで、1 件の回答でその 3 つを互いに比べている。
- **検証しない**: 正解した回答での見分け（選んだ選択肢と正解の選択肢が重なる場合で、印の対象が減るだけ）。模試で正誤を出さないこと（模試の UC が持つ）。
- **参照先**: `tests/client/session.test.tsx::出題の画面`
