# REQ-051

> システムは、演習の出題を選んだ範囲に紐づく過去問だけから組み、その件数を決めの問題数以下に収める。

## 検証方針

- **分割クラス**:
  - `#scope-drill` — 論点ドリルは、選んだ論点に紐づく過去問だけを範囲にする
  - `#scope-field-middle` — 分野別演習・単元演習は、その分野／単元に紐づく過去問だけを範囲にする
  - `#size-cap` — 範囲の過去問が決めの問題数より多いとき、出題の件数は問題数で止まる
- **尽きている根拠**: 範囲の決め方は種別ごとの 3 通りに尽き、件数は問題数以下か超えるかの 2 通りに尽きる。
- **境界の扱い**: 件数は「範囲が問題数より多い」側で見る。少ない側は範囲の全件がそのまま出るだけで、上限が効かない。
- **検証しない**: 範囲に紐づかない過去問が混ざらないことを本物のデータで確かめること（出題を組む条件の発行で見ており、投入済みのデータとの突き合わせは本番相当の API の検査が持つ）。決めの問題数の値（正本は `app_settings`。R-102）。
- **参照先**: `tests/server/session-builder.test.ts::buildQuestions（出題の組み立て）`
