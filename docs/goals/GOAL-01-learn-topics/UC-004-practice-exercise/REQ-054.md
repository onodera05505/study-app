# REQ-054

> システムは、弱点復習の出題を、利用者が間違えた過去問を最後に間違えた順に先へ詰め、残りを理解度を記録して未理解またはやや理解にした論点の過去問で出題頻度の高い論点から埋めて組む。

## 検証方針

- **分割クラス**:
  - `#wrong-recent-first` — 間違えた過去問を、最後に間違えた順で先に詰める
  - `#wrong-then-weak-fill` — 問題数に余りがあるとき、理解度の低い論点の過去問で後ろを埋める
  - `#weak-by-frequency` — 埋める側は出題頻度の高い論点から取る
  - `#weak-status-boundary` — 埋める側に入る理解度の段階は未理解とやや理解だけで、理解と記録の無い論点は入らない
  - `#wrong-only-incorrect` — 間違えた側は誤答の記録がある過去問だけで、埋める側は正誤で絞らない
  - `#wrong-fills-size` — 間違えた過去問だけで問題数に達するとき、埋める側を足さない
- **尽きている根拠**: 出題は「間違えた過去問」と「理解度の低い論点の過去問」の 2 つの集め方の連結で、それぞれの絞り込み（正誤・理解度）と並び（最後に間違えた順・出題頻度）、および連結の分かれ目（余りがある／無い）を見ている。
- **境界の扱い**: 理解度は段階の境目（やや理解は入り、理解は入らない）と、記録が無い論点を見る。問題数は間違えた過去問だけで満ちる側と満たない側の両方を見る。
- **検証しない**: 間違えた過去問も理解度の低い論点も無いときの出題（REQ-055 が持つ）。
