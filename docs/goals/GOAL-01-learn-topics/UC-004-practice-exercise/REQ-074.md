# REQ-074

> 締めに失敗した場合、システムは、まだ採点できていないことと失敗の理由を示し、同じ締めをもう一度行えるようにする。

## 検証方針

- **分割クラス**:
  - `#finish-failed-retryable` — 締めに失敗したとき、まだ採点できていないことと理由を示し、同じ締めをもう一度行える
- **尽きている根拠**: 締めは成功か失敗に尽き、成功は REQ-069・REQ-073 が持つ。やり直しは同じ締めを送り直せることで尽きる。
- **検証しない**: 失敗の理由の内訳（示す経路は同じで、理由の文はサーバの応答が正本）。
- **参照先**: `tests/client/session.test.tsx::出題の画面`
