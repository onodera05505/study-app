# REQ-065

> 現在の問題の問題解説が無い、または解釈できない形の場合、システムは、問題解説を示さずに正誤と正解の選択肢だけを示し、回答は受け付けたままにする。

## 検証方針

- **分割クラス**:
  - `#explanation-missing-columns` — 正解の根拠か選択肢ごとの説明が欠けている問題では、問題解説を作らない
  - `#explanation-malformed` — 選択肢ごとの説明が解釈できない形の問題では、問題解説を作らない
  - `#explanation-absent-renders-nothing` — 問題解説が無いとき、解説の枠そのものを出さない
- **尽きている根拠**: 問題解説が出ない原因は「欠けている」「解釈できない形」の 2 通りに尽き、その結果として画面に何も出ないことを別に見ている。
- **検証しない**: 問題解説が無くても正誤と正解の選択肢が出ること（REQ-063 が持つ）。回答が受け付けたまま残ること（REQ-061 の `#grade-against-snapshot` が持つ）。
- **参照先**: `tests/server/explanations.test.ts::explanationOf（問題ごとの解説）`、`tests/client/explanation.test.tsx::解説の表示`
