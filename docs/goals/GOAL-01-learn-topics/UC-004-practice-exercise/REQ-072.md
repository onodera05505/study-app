# REQ-072

> 未回答の問題が 1 問も残っていないテスト、または完了したテストに回答が送られた場合、システムは、採点も記録もせず、回答を受け付けられない理由を示す。

## 検証方針

- **分割クラス**:
  - `#answer-when-no-unanswered` — 未回答が 1 問も残っていないテストへの回答は、採点も記録もせず理由を示す
  - `#answer-after-completed` — 完了したテストへの回答は、採点も記録もせず理由を示す
- **尽きている根拠**: 回答を受け付けないテストの状態は「進行中で未回答なし」と「完了」の 2 通りで、どちらも別の状態として示す理由を持つ。
- **検証しない**: 制限時間を過ぎたテストへの回答（演習の種別には制限時間が無く、模試の UC が持つ）。
