# REQ-072

## 検証方針

- **分割クラス**:
  - `#<class-1>` — <この同値クラスの 1 行の意図>
- **尽きている根拠**: <なぜこの分割で入力空間が尽きるか>
- **検証しない**: <クラス化しない入力領域と理由（R-1104）>
- **参照先**: `<tests/ファイル>::<クラスまたは describe>`
