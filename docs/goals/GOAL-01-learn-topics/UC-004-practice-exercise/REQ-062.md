# REQ-062

> 回答を受け付けたとき、システムは、その問題の問題解説を示す。

## 検証方針

- **分割クラス**:
  - `#explanation-built` — 問題に在る正解の根拠と選択肢ごとの説明から、問題解説が組まれる
  - `#explanation-rendered` — 組まれた問題解説が、正解の根拠と選択肢ごとの 1 行として出る
- **尽きている根拠**: 問題解説は組む側と出す側の 2 段で、在る場合を両方見ている。無い場合と壊れている場合は REQ-065 が持つ。
- **検証しない**: 選択肢の説明に出る用語を押せる語にすること（本文の用語の振る舞いで、UC-001 が持つ）。
- **参照先**: `tests/server/explanations.test.ts::explanationOf（問題ごとの解説）`、`tests/client/explanation.test.tsx::解説の表示`
