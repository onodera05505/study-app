# REQ-244

> 分野を選んだあとの単元の一覧が取得できない場合、システムは、単元が出るはずだった場所に取得できなかったことと理由を示し、読み直す手段を添え、分野の一覧はそのまま残す。

## 検証方針

- **分割クラス**:
  - `#categories-failed` — 分野を選んだあとの単元の一覧が取れない入力（単元の場所に失敗と理由、読み直す手段、分野の一覧は残る）
- **尽きている根拠**: 単元の一覧の取得の結果は成功（REQ-048 の `#categories-after-field`）と失敗の 2 つで、この文は失敗だけを持つ。失敗の理由が変わっても示し方は同じ（BR-014）なので 1 クラスにし、失敗の場所・理由・読み直す手段・分野の一覧が残ることは同じ 1 つの観測に含む。
- **検証しない**: 失敗の理由ごとの文言（正本はコード）。範囲の一覧と進行中の有無の取得の失敗（REQ-049）。読み直しが成功したあとの表示（成功の経路と同じ）。
- **参照先**: —（未被覆。`tests/client/practice.test.tsx::練習テストの画面` は単元の一覧が取れた場合だけを見ており、取れない場合のテストが無い）
