# REQ-059

> 進行中のテストのあいだ、システムは、現在の問題とともに、そのテストの範囲の名前と、回答済みの問題数および問題数を示す。

## 検証方針

- **分割クラス**:
  - `#scope-and-progress` — 現在の問題とともに、範囲の名前と回答済みの問題数／問題数が出る
- **尽きている根拠**: 現在の問題に添える値は範囲の名前と進み具合の 2 つで、1 つのクラスで両方を見ている（どちらも進行中のあいだ常に出る値で、場合分けが無い）。
- **検証しない**: 範囲の名前の作り方（REQ-050 の `#scope-label-and-count` が持つ）。
