# REQ-060

> 未回答の問題を現在の問題として示すあいだ、システムは、その問題の正解と問題解説を示さない。

## 検証方針

- **分割クラス**:
  - `#no-answer-before-reply` — 回答を送る前の現在の問題には、正解も問題解説も出ない
- **尽きている根拠**: 現在の問題は回答前か回答後かに尽き、回答後は REQ-063（正誤と正解）と REQ-062（問題解説）が持つ。
- **検証しない**: 完了していないテストの結果を出さないこと（BR-021 の後段で、結果の画面を持つ UC が持つ）。
- **参照先**: 未検証
