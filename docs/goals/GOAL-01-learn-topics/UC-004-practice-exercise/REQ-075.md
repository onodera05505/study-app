# REQ-075

> 完了したテストが再び締められた場合、システムは、正答数と締めた時刻を変えず、最初に確定した結果を示す。

## 検証方針

- **分割クラス**:
  - `#second-finish-idempotent` — 完了したテストを再び締めても、正答数と締めた時刻が最初の締めのまま変わらない
- **尽きている根拠**: 締めは 1 回目か 2 回目以降かに尽き、1 回目は REQ-069・REQ-073 が持つ。
- **検証しない**: 自動の締めと利用者の締めが重なる場合（制限時間のある模試の UC が持つ）。
- **参照先**: `tests/server/repay_UC-004_sessions.test.ts`::締め
