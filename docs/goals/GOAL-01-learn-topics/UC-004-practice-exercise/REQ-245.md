# REQ-245

> 演習で過去問を出題しているあいだ、システムは、その問題の出典を利用者に読める回の名前で示して回の内部の値はそのまま出さず、原本から変えた問題には一部改変を併記する。

## 検証方針

- **分割クラス**:
  - `#citation-in-question` — 出題中の問題に、利用者に読める回の名前の出典が出て、回の内部の値は出ない
  - `#modified-in-question` — 原本から変えた印の有無で「一部改変」の併記が切り替わる
- **尽きている根拠**: 併記する物は出典と「一部改変」の 2 つ（BR-027）。出典は（読める名前で出る）か（内部の値が漏れる）の 1 観測に尽き、「一部改変」は改変の印の真偽の 2 値に尽きて、真と偽の両端を同じ 1 件で取る。出典を出さない側（自前に作った確認問題。BR-027）はこの UC の過去問の出題には現れない。
- **検証しない**: 出典の文字列の組み立て（画面は契約の `citation` をそのまま出す所で、組み立てはサーバ側の経路が持つ）。同一内容の件数と他の出典（BR-028・REQ-053）。結果の振り返りの出典（REQ-252）。
- **参照先**: `tests/client/citation.test.tsx::出題画面の出典（UC-004）`
