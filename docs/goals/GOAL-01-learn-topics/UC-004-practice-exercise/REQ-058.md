# REQ-058

> 進行中のテストに未回答の問題が残っているあいだ、システムは、未回答のうち最も小さい位置の問題を、その出題時スナップショットの内容で現在の問題として示す。

## 検証方針

- **分割クラス**:
  - `#smallest-unanswered` — 未回答のうち最も小さい位置の問題が現在の問題になる
  - `#snapshot-content` — 出題時スナップショットが問題文・選択肢・正解を出題した時点の内容で持つ
  - `#snapshot-citation` — 出題時スナップショットが出典を出題した時点の内容で持つ
  - `#snapshot-modified` — 一部改変の印を持つ過去問だけ、スナップショットにも印が立つ
- **尽きている根拠**: 示す問題の選び方（位置）と、示す内容の出所（スナップショットの各項目）の 2 軸で、内容は問題文・選択肢・正解・出典・改変の印という控えの全項目を見ている。
- **検証しない**: 問題データを後から直しても結果が変わらないこと（BR-020 の意図で、時間をまたぐ振る舞いは本番相当の検査が持つ）。
- **参照先**: `tests/server/session-builder.test.ts::snapshotOf（出題時の内容）`、`tests/server/snapshot.test.ts::出題時のスナップショット`、`tests/server/repay_UC-004_sessions.test.ts`::現在の問題（最も小さい位置）
