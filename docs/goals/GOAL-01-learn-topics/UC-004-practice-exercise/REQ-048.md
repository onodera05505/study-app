# REQ-048

> 利用者が練習テストを開いたとき、システムは、選べる分野と、選んだ分野の単元を演習の範囲として示し、進行中のテストがあるかどうかを併せて示す。

## 検証方針

- **分割クラス**:
  - `#fields-listed` — 範囲の一覧に選べる分野が並び、そこから分野を選べる
  - `#categories-after-field` — 分野を選んだときだけ、その分野の単元が選べる形で出る（選んだだけでは始まらない）
- **尽きている根拠**: 示すものは「選べる分野」「選んだ分野の単元」の 2 段で、分野を選ぶ前と選んだ後の両方を見ている。
- **検証しない**: 進行中のテストがあるかどうかの表示（同じ振る舞いを UC-006 の REQ-087 が持ち、練習テストの画面の案内のテストはそちらに属する。要件の重複として報告済み）。単元の一覧の取得が失敗したとき（上流に文が無く、クラス化できない）。
- **参照先**: `tests/client/practice.test.tsx::練習テストの画面`
