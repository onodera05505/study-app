# REQ-346

> システムは、現在の問題の応答に添えるテストの記録を、テストの識別子・種別・範囲の名前・問題数・回の識別子に限り、テストが終わっているときも同じにする。

## 検証方針

- **分割クラス**:
  - `#in-progress-record` — 進行中のテストの現在の問題の応答に添う記録が、識別子・種別・範囲の名前・問題数・回の識別子の 5 つだけ（演習と模試を値の変種に持つ）
  - `#finished-record` — 終わっているテストの応答（未回答なし・締めた・時間切れ）に添う記録も、同じ 5 つだけ
- **尽きている根拠**: 契約 `getCurrentQuestion` の応答は `finished` の 2 値に分かれ、文は両方で同じ記録を添えることを求める。終わっている側の入り方は未回答なし・締めた・時間切れの 3 つに尽き、どれも値の変種として持つ。
- **検証しない**: テストが見つからないとき（記録を添えず断る側で、REQ-237・REQ-348 が持つ）。5 つの値の作り方（範囲の名前は REQ-050・REQ-105・REQ-286、問題数は REQ-051・REQ-105 が持つ）。
- **参照先**: `tests/server/UC-004_sessions_sqlite.test.ts::現在の問題の応答に添えるテストの記録（GET /api/sessions/:id/current。UC-004）`
