# REQ-246

> システムは、BR-036 に従い選択肢を整形して示す。

## 検証方針

- **分割クラス**:
  - `#split-by-separator` — 区切りと項目名の記号で並ぶ組合せを、項目ごとに行へ分ける
  - `#split-by-item-head` — 読点のあとに短い項目名と記号が続く並びを、項目の切れ目で分ける
  - `#kept-as-one-line` — 普通の読点を含む文や短い選択肢は分けず、文字列をそのまま返す
- **尽きている根拠**: 入力は選択肢の文字列 1 つで、項目の切れ目を示す形は（区切りの記号で並ぶ）（読点と短い項目名で並ぶ）（どちらでもない）に尽きる。前 2 つが分ける側、最後が分けない側で、どちらの側でも選択肢の文字列そのものが変わらないことを同じ観測に含む。
- **境界の扱い**: 分ける側と分けない側の境目として、項目名と値の組の形を持ちながら短い入力を取る（値はテストが持つ）。
- **検証しない**: 分けた行の画面上の見せ方（出題の画面の範囲）。選択肢の記号の描き方（REQ-059）。
- **参照先**: `tests/client/choice_figure.test.ts::組合せ選択肢の表示整形`
