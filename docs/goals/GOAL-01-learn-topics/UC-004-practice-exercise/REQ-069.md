# REQ-069

> 未回答の問題が残っている進行中のテストを利用者が締めようとしたとき、システムは、未回答の残りの問数を示して確かめ、確かめが取れたときだけ、そのテストを完了にし、正解した問題の数を正答数として確定して結果を示す。

## 検証方針

- **分割クラス**:
  - `#finish-with-unanswered` — 未回答が残る進行中のテストで、利用者が締めたときにだけ締めが行われる
  - `#correct-count-confirmed` — 締めたテストが完了になり、正解した問題の数が正答数として確定して結果が出る
- **尽きている根拠**: 締める操作は行われるか取り消されるかに尽き（前者のクラス）、その結果として残る値を別に見ている。
- **検証しない**: 未回答が無くなって締めに進む場合（REQ-071・REQ-073 が持つ）。締めに失敗した場合（REQ-074 が持つ）。
- **参照先**: `tests/client/session.test.tsx::出題の画面`
