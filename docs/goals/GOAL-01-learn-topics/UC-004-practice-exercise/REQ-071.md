# REQ-071

> 進行中のテストに未回答の問題が 1 問も残っていないあいだ、システムは、現在の問題を示さず、そのテストの締めに進む。

## 検証方針

- **分割クラス**:
  - `#no-current-when-all-answered` — 未回答が 1 問も残っていないあいだ、現在の問題を示さずに締めへ進む
- **尽きている根拠**: 未回答は残っているか残っていないかに尽き、残っている側は REQ-058 が持つ。
- **検証しない**: 締めた結果（REQ-073 が持つ）。
- **参照先**: 未検証（`tests/client/session.test.tsx::出題の画面` の締めの失敗のテストが、締めが呼ばれることを併せて観測している）
