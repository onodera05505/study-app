# REQ-056

> 進行中のテストがあるあいだ、システムは、練習テストのどの範囲からも新しい演習を始められないようにする。

## 検証方針

- **分割クラス**:
  - `#block-middle` — 進行中のテストがあるあいだ、単元から始められない
  - `#block-field-and-review` — 進行中のテストがあるあいだ、分野と弱点復習から始められない
- **尽きている根拠**: 練習テストの画面から始められる入口は分野・単元・弱点復習の 3 つで、その全部が止まることを 2 クラスで見ている。範囲を選ぶだけの操作が止まらないことも同じテストが見ている。
- **検証しない**: 要求が届いたときにサーバが作らないこと（REQ-057 が持つ）。論点ドリルの入口（論点の画面にあり、この UC のテストのファイルに無い）。
- **参照先**: `tests/client/practice.test.tsx::練習テストの画面`
