# REQ-076

> 利用者が自分のものでないテストを指して現在の問題・回答・締めを行おうとした場合、システムは、その要求をテストが見つからないものとして扱い、そのテストの内容も存在も示さない。

## 検証方針

- **分割クラス**:
  - `#other-users-session-not-found` — 自分のものでないテストを指した現在の問題・回答・締めは、テストが無いものとして扱われる
- **尽きている根拠**: テストの持ち主は本人か他人かに尽き、本人の側は各操作の REQ が持つ。他人のものと在りもしない ID が同じ扱いになることで、存在も内容も漏れないことが決まる。
- **検証しない**: ログインしていない要求（事前条件で、別のゴールが持つ）。
- **参照先**: 未検証（本番相当の API の検査が見ている）
