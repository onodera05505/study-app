# REQ-237

> 完了したテストについて現在の問題を求められた場合、システムは、BR-034 に従い、出題を示さずそのテストが終わっていることを示し、破棄されて残っていないテストについては見つからないものとして断る。

## 検証方針

- **分割クラス**:
  - `#current-of-completed` — 完了したテストの現在の問題を求められたとき、出題を示さず終わっていることを示す
  - `#current-of-discarded` — 破棄されて残っていないテストの現在の問題を求められたとき、見つからないものとして断る（404）
- **尽きている根拠**: 終わったテストは完了したものと破棄されたものの 2 通りに尽き、進行中は REQ-058・REQ-071 が持つ。
- **検証しない**: 再開を求められたとき（UC-006 の REQ-240 が持つ）。
- **参照先**: `tests/server/finished_session.test.ts::完了・破棄したテストの現在の問題（GET /api/sessions/:id/current。UC-004）`
