# REQ-237

> 完了したテスト、または破棄されて残っていないテストについて現在の問題を求められた場合、システムは、出題を示さず、そのテストが終わっていることを示す。

## 検証方針

- **分割クラス**:
  - `#current-of-completed` — 完了したテストの現在の問題を求められたとき、出題を示さず終わっていることを示す
  - `#current-of-discarded` — 破棄されて残っていないテストの現在の問題を求められたとき、出題を示さず終わっていることを示す
- **尽きている根拠**: 終わったテストは完了したものと破棄されたものの 2 通りに尽き、進行中は REQ-058・REQ-071 が持つ。
- **検証しない**: 再開を求められたとき（UC-006 の REQ-240 が持つ）。
- **参照先**: 未検証（本番相当の API の検査が見ている）
