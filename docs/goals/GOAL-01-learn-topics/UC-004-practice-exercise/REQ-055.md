# REQ-055

> 選んだ範囲に出題できる過去問が 1 問も無い場合、システムは、テストを作らず、始められない理由を示す。

## 検証方針

- **分割クラス**:
  - `#empty-scope` — 選んだ範囲に出題できる過去問が 1 問も無いとき、テストを作らず始められない理由を示す
- **尽きている根拠**: 範囲の過去問は 1 問以上か 0 問かに尽き、1 問以上の側は REQ-051 が持つ。
- **検証しない**: 範囲が空になる作り方の内訳（紐づく過去問が無い／定着した問題の除外で空になる。後者は BR-019 により除外しないので空にならず、REQ-052 の `#mastered-all-fallback` が持つ）。
