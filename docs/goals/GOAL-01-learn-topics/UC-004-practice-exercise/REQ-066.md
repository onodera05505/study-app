# REQ-066

> 同じ問題への回答が続けて 2 回以上送られた場合、システムは、その問題の回答を 1 件だけ残す。

## 検証方針

- **分割クラス**:
  - `#duplicate-answer-kept-once` — 同じ問題への回答が続けて 2 回以上送られても、残る回答は 1 件だけ
- **尽きている根拠**: 同じ問題への回答は 1 回だけ送られるか 2 回以上送られるかに尽き、1 回の側は REQ-061 が持つ。
- **検証しない**: 画面が送信中と判定後に 2 回目の送信を抑えること（同じ要求を起こさせない側で、REQ-061 の `#send-current-idx-and-choice` のテストが併せて観測している）。
- **参照先**: 未検証（記録が 1 件に収まることは本番相当の API の検査が見ている）
