# REQ-067

> 送られた回答が指す問題の位置が、そのテストの現在の問題の位置と違う場合、システムは、採点せず回答も残さず、その回答を受け付けずに断る。

## 検証方針

- **分割クラス**:
  - `#stale-idx-rejected` — 送られた位置が現在の問題の位置と違うとき、採点も記録もせず、その回答を受け付けずに断る
- **尽きている根拠**: 送られた位置は現在の問題と同じか違うかに尽き、同じ側は REQ-061 が持つ。
- **検証しない**: 違う位置の内訳（前の問題・先の問題）。どちらも現在の位置と一致しないという 1 つの条件で決まる。断りの本文の形（正本は契約の `ErrorBody`。位置は載らず、位置の正本は現在の問題の取得だけが持つ＝BR-022）。
- **参照先**: `tests/server/repay_UC-004_sessions.test.ts`::回答
