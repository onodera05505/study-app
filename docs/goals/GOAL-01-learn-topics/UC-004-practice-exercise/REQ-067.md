# REQ-067

> 送られた回答が指す問題の位置が、そのテストの現在の問題の位置と違う場合、システムは、採点せず回答も残さず、位置が食い違っていることと現在の問題の位置を示す。

## 検証方針

- **分割クラス**:
  - `#stale-idx-rejected` — 送られた位置が現在の問題の位置と違うとき、採点も記録もせず、食い違いと現在の位置を示す
- **尽きている根拠**: 送られた位置は現在の問題と同じか違うかに尽き、同じ側は REQ-061 が持つ。
- **検証しない**: 違う位置の内訳（前の問題・先の問題）。どちらも現在の位置と一致しないという 1 つの条件で決まる。
- **参照先**: 未検証（本番相当の API の検査が見ている）
