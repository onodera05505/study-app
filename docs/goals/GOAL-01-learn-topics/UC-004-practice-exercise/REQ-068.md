# REQ-068

> 位置が食い違っていることを示されたとき、システムは、表示がずれていたことを利用者に伝え、現在の問題を取り直して示す。

## 検証方針

- **分割クラス**:
  - `#stale-idx-refetch` — 位置の食い違いを返されたとき、ずれていたことを伝えて現在の問題を取り直す
- **尽きている根拠**: 食い違いを示されたときの振る舞いは 1 通り（伝える・取り直す）で、場合分けが無い。
- **検証しない**: 取り直した結果が現在の問題になること（REQ-058 が持つ）。
