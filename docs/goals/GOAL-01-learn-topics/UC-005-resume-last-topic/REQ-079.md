# REQ-079

> 前回の続きを覚えていない間、システムは、ホームに前回の続きの導線を出さず、論点の一覧へ進む導線を出す。

## 検証方針

- **分割クラス**:
  - `#not-remembered-topics-link` — 端末が前回の続きを覚えていない状態でホームを開いた入力。前回の続きの導線を出さず、論点の一覧へ進む導線を出す
- **尽きている根拠**: ホームを開いたときの入力は、前回の続きが読めて値がある／無いの 2 つで尽き（契約 readLastTopic は errors を持たず、読めない・使えないもすべて無しに畳む）、この要件は無い側だけを言う。値がある側は REQ-080、無しに畳んだ原因が端末の失敗である側は REQ-082 が持つ。UC.md の表の「まだ論点を開いていない」と「捨てられた」は、ホームから見た入力が同じ（前回の続きが無し）なので 1 クラス。
- **検証しない**: 捨てる側の振る舞い（BR-010。UC-013 の REQ-198 が持つ）。ロードマップ型の先頭の導線（事前条件で資格対策の学びに限っており、UC-009 の REQ-144 が持つ）。
- **参照先**: `tests/client/home.test.tsx::前回の続き`（持ち主は UC-003）
