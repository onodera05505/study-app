# REQ-080

> 前回の続きを覚えている間、システムは、ホームに、覚えた論点の名前とその単元を添えた前回の続きの導線を出す。

## 検証方針

- **分割クラス**:
  - `#remembered-shows-term-and-middle` — 覚えた前回の続きがある状態でホームを開いた入力。覚えた論点の名前とその単元を添えた導線が出る
  - `#remembered-topic-gone` — 覚えた論点がもう無い状態でホームを開いた入力（UC.md の表 3 行目）。ホームは端末に覚えた値から同じ導線を出す
- **尽きている根拠**: 覚えがある状態の入力は、覚えた論点が今もある／もう無いの 2 つで尽きる。ホームは端末に覚えた値だけで導線を組むので、添える名前と単元の出所は両方の入力で同じ。
- **検証しない**: 導線を選んだ先（REQ-081 が持つ）。覚えが無いとき・読めないとき（REQ-079・REQ-082 が持つ）。導線を置く位置と見た目（要件は名前と単元を添えることだけを言う）。
- **参照先**: `tests/client/home.test.tsx::前回の続き`（持ち主は UC-003）
