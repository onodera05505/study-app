# REQ-081

> 利用者が前回の続きの導線を選んだとき、システムは、覚えた論点の画面を開く。

## 検証方針

- **分割クラス**:
  - `#follow-link-opens-topic` — 前回の続きの導線を選んだ入力。覚えた論点の画面が開く
- **尽きている根拠**: 導線を選べるのは導線が出ているとき（＝覚えた前回の続きがあるとき）だけなので入力は 1 つで、導線が出ていない状態では選べない（UC.md の表の「不可」）。
- **検証しない**: 覚えた論点がもう無いときに導線を選んだ先（UC.md の表 3 行目が未決の `?` のままで、決まるまでクラスにしない）。導線の見え方と添える名前・単元（REQ-080 が持つ）。
- **参照先**: `tests/client/home.test.tsx::前回の続き`（持ち主は UC-003。現状は導線の行き先だけを見ており、選ぶ操作をするテストが無い）
