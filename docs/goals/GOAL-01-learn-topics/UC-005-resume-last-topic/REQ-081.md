# REQ-081

> 端末が覚えた前回の続きの論点が今もあるときに利用者が前回の続きの導線を選んだとき、システムは、覚えた論点の画面を開く。

## 検証方針

- **分割クラス**:
  - `#follow-link-opens-topic` — 覚えた論点が今もあるときに前回の続きの導線を選んだ入力。覚えた論点の画面が開く
- **尽きている根拠**: 導線を選べるのは導線が出ているとき（＝覚えた前回の続きがあるとき）だけで、導線が出ていない状態では選べない（UC.md の表の「不可」）。導線を選んだ入力は、覚えた論点が今もある・もう無いの 2 つで尽き、もう無い方は REQ-342 が持つ（UC.md の表 3 行目）ので、この REQ の入力は 1 つ。
- **検証しない**: 覚えた論点がもう無いときに導線を選んだ先（REQ-342 が持つ）。導線の見え方と添える名前・単元（REQ-080 が持つ）。
- **参照先**: `tests/client/repay_UC-005_home_resume.test.tsx::ホームの前回の続き（UC-005）`
