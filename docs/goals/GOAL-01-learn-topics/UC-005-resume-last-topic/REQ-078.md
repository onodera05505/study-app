# REQ-078

> 端末が前回の続きを覚えられない場合、システムは、論点の画面の操作を止めない。

## 検証方針

- **分割クラス**:
  - `#storage-blocked-keeps-going` — 端末の記憶に書けない入力（契約 saveLastTopic の STORAGE_UNAVAILABLE）。覚える操作が断りの種類の名前を持つ失敗を渡しても、論点の画面の操作が止まらない
- **尽きている根拠**: 端末が覚えられる／覚えられないの 2 つのうち、この要件は覚えられない側だけを言い、覚えられる側は REQ-077 が持つ。覚えられない理由（端末の設定・容量・私的閲覧）はいずれも書き込みが失敗することに畳めるので 1 クラスで尽きる。
- **検証しない**: 覚えられなかったことを利用者に知らせること（BR-011 は出さないだけにすると決めており、知らせは要件に無い）。ホームの側の振る舞い（REQ-082 が持つ）。
- **参照先**: `tests/client/cache_lasttopic.test.ts::前回の続き（UC-005）`
