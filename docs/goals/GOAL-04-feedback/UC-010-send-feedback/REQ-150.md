# REQ-150

> 利用者は、学びのどの画面からでもフィードバックの画面へ移れる。

## 検証方針

- **分割クラス**:
  - `#from-any-screen` — 学びの画面に居るとき、フィードバックの画面へ移る導線があり、選ぶとフィードバックの画面が出る入力
- **尽きている根拠**: 導線は全画面に共通の上部メニュー 1 か所が出すので、1 つの画面で導線が出て移れれば「どの画面からでも」が尽きる。
- **検証しない**: 上部メニューの項目の構成（対象の型ごとに何を出すか）。フィードバックの導線が在ることとは別の振る舞いで、UC-010 の範囲外。
- **参照先**: `tests/client/update_bar.test.tsx::上部メニューのフィードバック`（他の持ち主のファイル。@covers の付与は別の担当）
