# REQ-151

> 添え先を覚えていない間、フィードバックの画面は添え先を示さず、利用者は添える物が無いままフィードバックを送れる。

## 検証方針

- **分割クラス**:
  - `#attachment-not-shown` — 添え先を覚えていない状態でフィードバックの画面を開く入力（添え先が示されない）
  - `#send-without-attachment` — 添え先を覚えていない状態で本文だけを送る入力
- **尽きている根拠**: 「覚えていない間」の観測は、示さないことと送れることの 2 つで、REQ の文の 2 つの帰結に 1 対 1。
- **検証しない**: 覚えた値が読めない・端末が覚えられない状態（BR-011。UC.md の表 1 はそのセルを BR-011 に当てている）。
- **参照先**: `tests/client/feedback.test.tsx::フィードバックの送信（UC-010）`（`#send-without-attachment`）／`tests/client/repay_UC-010_feedback_screen.test.tsx::フィードバックの画面の添え先（UC-010）`（`#attachment-not-shown`）
