# REQ-283

> 印を持つ学びで利用者が印の絞り込みを選び直したとき、システムは選んだ印の単位だけを回ごとの並びと補足の別枠に残し、残る単位が無い補足の別枠は示さず、一覧の「ここから」と、先頭の続きの導線が「ここから」を行き先にしているときのその行き先を、残した単位のうち学ぶ順で最初の未理解の単位に付け直し（残した単位に未理解が無ければ、その行き先は学ぶ順で最初の論点に下げ）、各回の見出しと回ごとの確認の範囲・問数、先頭の数、進行中の案内は絞り込む前のまま示す。

## 検証方針

- **分割クラス**:
  - `#selected-tiers-only` — 一部の印（1 つでも複数でも）を選んだとき、その印の単位だけが回ごとの並びと補足の別枠に残る
  - `#all-selected-shows-all` — 全ての印を選び直したとき、全ての単位が出て、「ここから」が REQ-130 の位置に戻る
  - `#round-without-match-keeps-heading` — 選んだ印の単位を 1 つも持たない回でも、回の見出しと回ごとの確認の入口が残る
  - `#extra-section-hidden-when-empty` — 補足の論点に選んだ印の単位が 1 つも無いとき、補足の別枠そのものを出さない（REQ-134 と同じ扱い）
  - `#here-moves-within-filter` — 学ぶ順で最初の未理解の単位が絞り込みで隠れたとき、残した中の最初の未理解の単位に「ここから」が付く
  - `#continue-link-follows-filter` — 先頭の続きの導線が「ここから」を行き先にしているとき、絞り込んでいるあいだはその行き先が一覧の「ここから」と同じ単位になり、全部の印に戻すと元の行き先に戻る
  - `#no-unlearned-in-filter-no-here` — 残した単位が全て理解のとき、「ここから」を出さない
  - `#no-unlearned-in-filter-continue-falls-back` — 先頭の続きの導線が「ここから」を行き先にしていて、残した単位が全て理解のとき、行き先が REQ-144 の 3 段目（学ぶ順で最初の論点）に下がり、絞り込みの外の「ここから」を指さない
  - `#scope-and-summary-unchanged` — 絞り込んでも、回ごとの確認の範囲と問数、先頭の数が変わらない
  - `#progress-notice-kept` — 進行中の案内が出ているあいだに絞り込みを選び直しても、案内は残る
- **尽きている根拠**: 入力は選んだ印の組（空でない部分集合。空にできないことは REQ-288）と、各回・補足の別枠に残る単位の数、残る単位の理解度、進行中の案内の有無。組が全部か一部か、残る単位が回で 0 か・別枠で 0 か、残る中に未理解があるか・最初の未理解が隠れたか、で表示の側のクラスに尽き、数と範囲に効かないことと案内に効かないことを 1 クラスずつ足す。
- **境界の扱い**: REQ-130 は全ての単位を示しているときの「ここから」を持ち、この文は印で絞り込んでいるときの「ここから」を持つ（全部に戻すと REQ-130 の位置に戻る）。先頭の続きの導線の行き先の段（前回の続き → 「ここから」 → 一覧の先頭）は REQ-144 が持ち、この文が変えるのは「ここから」の段が指す単位だけ。
- **検証しない**: 開いたときの選択の初期値と、開き直したときに選択を覚えないこと（REQ-287）。最後の 1 つを外せないこと（REQ-288）。先頭の続きの導線の行き先の段の決め方と、前回の続きが行き先のとき（REQ-144）。絞り込みの入口の見た目。
