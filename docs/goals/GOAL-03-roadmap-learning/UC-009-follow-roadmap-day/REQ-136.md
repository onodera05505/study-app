# REQ-136

> ロードマップの論点の並びは取れたが、回ごとの確認の結果または連続記録が取れなかったとき、システムは取れた並びを示したまま、取れなかった部分だけを示さない。

## 検証方針

- **分割クラス**:
  - `#both-missing-list-kept` — 回ごとの確認の結果と連続記録の両方が取れないとき、並びを出したままその 2 つを出さない
  - `#exams-missing-only` — 回ごとの確認の結果だけが取れないとき、並びと連続記録は出したまま
  - `#streak-missing-only` — 連続記録だけが取れないとき、並びと回ごとの確認の結果は出したまま
- **尽きている根拠**: 前提（並びは取れた）の下で取れない対象は回ごとの確認の結果と連続記録の 2 つなので、空でない組み合わせは 3 通りに尽きる。
- **検証しない**: 並び自体が取れなかったとき。この REQ の前提の外で、REQ-241 が持つ。
- **参照先**: `tests/client/roadmap.test.tsx`::取れなかったとき（UC-009）（`#both-missing-list-kept`）、一部が取れなかったとき（UC-009）（残りのクラス）
