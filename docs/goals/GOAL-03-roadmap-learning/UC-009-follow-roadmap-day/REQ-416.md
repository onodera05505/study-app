# REQ-416

> 利用者がロードマップ型の学びで論点を開いたとき、システムは論点の見出しを論点の名前だけとし、副題を持つ論点ではその副題を見出しに含めずに見出しに添えて示す。

## 検証方針

- **分割クラス**:
  - `#heading-name-subtitle-beside` — 副題を持つ論点で、見出しの文字が名前だけになり、副題は見出しの外で、見出しの後ろかつ教材の本文より前に出る
  - `#heading-name-only` — 副題を持たない論点で、見出しの文字が名前だけ（括弧書きを含む名前はそのまま）になり、副題の代わりの文字が出ない
- **尽きている根拠**: 論点ごとの入力は subtitle の文字列／null の 2 通り。印を持つ学び・持たない学びは見出しの決まりに効かないので値の変種。
- **検証しない**: 見出しの段（h1 か h2 か）と副題の見た目。資格対策の論点の画面（この要件はロードマップ型だけを決める）。
- **参照先**: `tests/client/UC-009_topic_heading.test.tsx::論点の見出しと副題（UC-009）`
