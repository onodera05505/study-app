# REQ-140

> 開いている論点が学ぶ順の端にある、または学ぶ順を持たないとき、システムは学ぶ順の前後のうち相手の論点が無い向きの導線を、押せない形で残して示す。

## 検証方針

- **分割クラス**:
  - `#one-side-missing-disabled` — 学ぶ順の端で、相手が無い向きの導線が押せない形で残る
  - `#both-sides-missing-disabled` — 学ぶ順を持たない補足の論点で、前後どちらの導線も押せない形で残る
- **尽きている根拠**: 相手が無い向きは前だけ・次だけ・両方の 3 通り。前だけと次だけは同じ振る舞いの境界点で 1 クラス、両方（学ぶ順を持たない論点）が別クラス。
- **境界の扱い**: 学ぶ順の先頭（前が無い）と末尾（次が無い）は `#one-side-missing-disabled` の 2 つの境界点。
- **参照先**: `tests/client/topic_detail.test.tsx::ロードマップ型の論点の画面`（持ち主は UC-002。`#both-sides-missing-disabled` は観測するテストが未配置）
