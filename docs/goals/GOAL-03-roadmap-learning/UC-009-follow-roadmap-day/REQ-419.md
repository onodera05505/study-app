# REQ-419

> ロードマップ型の学びでは、システムは各回の回ごとの確認への入口を、その回の単位の並びの後に示す。

## 検証方針

- **分割クラス**:
  - `#entry-after-own-units` — 各回の回ごとの確認の入口が、文書の順でその回の最後の単位より後ろ、次の回の最初の単位より前に出る
- **尽きている根拠**: 入口の位置の決まりは回の形（日・章）にも回の単位の数にもよらず 1 つなので 1 クラス。日・章と、単位の数が違う回（1・2・3・4 単位）は値の変種。
- **検証しない**: 印の絞り込みで回の単位が 0 件になったとき（入口が残ることは REQ-283）。回ごとの確認の一覧が取れないとき（REQ-136・REQ-279）。
- **参照先**: `tests/client/UC-009_roadmap_units.test.tsx::回ごとの確認の入口の位置（UC-009）`
