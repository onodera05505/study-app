# REQ-282

> 印を持つ学びでは、システムはロードマップの各単位に、投入されたその単位の印を、登録簿の印の語を読み上げで分かる名前として持たせて示す。

## 検証方針

- **分割クラス**:
  - `#tier-label-per-unit` — 回ごとの並びと補足の別枠の各単位に、その単位の印の段に当たる登録簿の語が出る
  - `#tier-label-as-accessible-name` — 各単位の印が、読み上げで得られる文字（読み上げから隠されていない文字か aria-label）として登録簿の印の語を持つ
- **尽きている根拠**: 入力は各単位の印の段で、段 → 登録簿の語の決まり方は段によらず 1 つ。語が画面に出ることと、その語が読み上げで得られる名前になっていることは別の観測なので 2 クラスで、段はどちらでも値の変種。
- **検証しない**: 印の語と段の値（登録簿と投入データが正本。BR-005）。印が欠けた単位（BR-037 で投入されない）。印が並びに効かないこと（REQ-129）。印を持たない学び（REQ-285）。印の記号の字形。
- **参照先**: `tests/client/roadmap.test.tsx`::印（印を持つ学び）（UC-009）（`#tier-label-per-unit`）／`tests/client/UC-009_roadmap_units.test.tsx::印の読み上げの名前（UC-009）`（`#tier-label-as-accessible-name`）
