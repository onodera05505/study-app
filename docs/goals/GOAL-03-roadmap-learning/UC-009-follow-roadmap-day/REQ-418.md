# REQ-418

> ロードマップが回の見出しの下に単位を並べているあいだ、システムはその単位に、属する回の見出しの語も章の名前も繰り返して示さない。

## 検証方針

- **分割クラス**:
  - `#day-word-not-in-unit` — 日で束ねる学びで、各単位の行にその日の見出しの語（〇日目）が出ない
  - `#chapter-word-and-name-not-in-unit` — 章で束ねる学びで、各単位の行に章の見出しの語（第 n 章）も章の名前も出ない
- **尽きている根拠**: 回の見出しの形は日・章の 2 通り（REQ-279）で、章の見出しは見出しの語と章の名前の 2 つを持つので、章のクラスで両方を見る。
- **検証しない**: 補足の別枠の単位と先頭の続きの導線（回の見出しの下に並ぶ単位ではない）。
- **参照先**: `tests/client/UC-009_roadmap_units.test.tsx::回の見出しの語を単位に繰り返さない（UC-009）`
