# REQ-131

> 利用者がロードマップを開いたとき、システムは理解になっている論点の数と論点の総数を先頭に示す。

## 検証方針

- **分割クラス**:
  - `#understood-count-and-total` — 先頭に理解の件数と論点の総数が出る
- **尽きている根拠**: 入力は理解の件数だけで、示す値は件数と総数の 2 つ。どの件数でも同じ振る舞いなので 1 クラスで尽きる。
- **境界の扱い**: 理解 0 件と全件理解はこのクラスの境界点として同じクラスに入れる（別クラスにしない）。
- **検証しない**: 件数の集計そのもの（UC-003 の本人の記録が正本）。
- **参照先**: `tests/client/roadmap.test.tsx::先頭の 1 行`
