# REQ-413

> ロードマップ型の学びで論点の並びまたは論点の教材が求められたとき、システムは各論点の名前と副題を分けて返し、副題が投入されていない論点では副題が無いことを返す。

## 検証方針

- **分割クラス**:
  - `#list-name-and-subtitle-apart` — 論点の並び（listTopics）で、副題が投入された単位は term が名前だけ、subtitle がその副題として返る
  - `#list-no-subtitle-null` — 論点の並びで、副題が投入されていない単位は subtitle が null で、term は投入された名前のまま返る
  - `#detail-name-and-subtitle-apart` — 論点の教材（getTopicDetail）で、副題が投入された論点は term が名前だけ、subtitle がその副題として返る
  - `#detail-no-subtitle-null` — 論点の教材で、副題が投入されていない論点は subtitle が null で、term は投入された名前のまま返る
- **尽きている根拠**: 入力は（求めた操作: 並び／教材）×（その論点への副題の投入: あり／なし）の 4 通りで、副題と名前の文字の中身は値の変種。
- **境界の扱い**: 名前に括弧書きを含み副題が投入されていない単位は「なし」の側に置き、応答が名前を切り分けずにそのまま返し subtitle を null にすることを同じクラスで見る。
- **検証しない**: 資格対策の学びの応答（この要件はロードマップ型だけを決める。null になることは契約の形が持つ）。投入データの組み立て（REQ-414）。未認証と存在しない論点（契約の errors と例の実行が持つ）。
- **参照先**: `tests/server/UC-009_subtitle_dataset.test.ts::副題を分けて返す（UC-009）`
