# REQ-137

> 利用者がロードマップ型の学びで論点を開いたとき、システムはその論点の教材と、その論点の確認問題を示す。

## 検証方針

- **分割クラス**:
  - `#material-and-questions-shown` — 開いた論点の教材と、その論点の確認問題が出る
  - `#own-questions-without-source` — 自前に作った確認問題には出典を出さない（BR-027）
- **尽きている根拠**: 示すのは教材と確認問題の 2 つ。確認問題は自前に作った素材なので、出すことと出典を出さないことの 2 クラスで尽きる。
- **検証しない**: 確認問題を持たない論点の見せ方（UC.md がこの場合を決めていない）。教材の記法の解釈（UC-001 の REQ が持つ）。
- **参照先**: `tests/client/topic_detail.test.tsx::ロードマップ型の論点の画面`（持ち主は UC-002。どちらのクラスも、観測するテストが未配置）
