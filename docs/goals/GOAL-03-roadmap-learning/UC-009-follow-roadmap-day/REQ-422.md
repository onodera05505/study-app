# REQ-422

> 作り手がロードマップ型の学びの投入データを組み立てたときに、ロードマップのデータに副題の欄が空の文字列・空白だけの文字列・文字列でも null でもない値である単位があれば、システムは投入データを書き出さずに組み立てを止め、その単位の名前を示す。

## 検証方針

- **分割クラス**:
  - `#empty-string-stops` — 副題の欄が空の文字列の単位があると、投入データを書き出さずに止まり、その単位の名前を示す
  - `#blank-only-stops` — 副題の欄が空白だけの文字列（半角・全角の空白、タブ・改行の混ざり）の単位があると、投入データを書き出さずに止まり、その単位の名前を示す
  - `#non-string-stops` — 副題の欄が文字列でも null でもない値（数・真偽・配列・入れ物）の単位があると、投入データを書き出さずに止まり、その単位の名前を示す
  - `#null-or-text-not-stopped` — 副題の欄が null の単位、または空白以外の文字を含む文字列（前後に空白があっても）の単位だけなら止まらない
- **尽きている根拠**: 副題の欄の値は（欄が無い／null／文字列／それ以外の型）で、文字列は（空／空白だけ／空白以外を含む）に分かれる。止める側は文が挙げる 3 つで、それぞれ 1 クラス。止めない側のうち null と空白以外を含む文字列を 1 クラスに置いて上限を見る（欄が無い単位は REQ-414 の `#no-subtitle-none` が組み立てが通ることまで見る）。値の中身は値の変種。
- **境界の扱い**: 空白だけと空白以外を含むの境目は、前後に空白を持ち中に文字のある副題を `#null-or-text-not-stopped` の点に置く。「止まる」は終了コードが 0 でないこと、「書き出さない」は作業場の投入データ（`topics.json`）が組み立ての前から書き換わっていないこと、「名前を示す」は組み立ての出力にその単位の名前が出ることで見る。
- **検証しない**: 不正な単位が 2 つ以上あるときに名前をいくつ示すか（文が 1 単位の場合しか決めていない。問いとして返した）。止めない側で前後の空白を投入データに残すか削るか（この文も REQ-414 も決めていない）。
- **参照先**: `tests/server/UC-009_subtitle_invalid_dataset.test.ts::副題の欄の不正な値で組み立てを止める（UC-009）`
