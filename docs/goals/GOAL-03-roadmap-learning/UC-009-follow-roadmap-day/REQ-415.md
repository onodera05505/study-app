# REQ-415

> 利用者がロードマップを開いたとき、システムは副題を持つ単位では単位の名前と副題を分けて示し、副題を持たない単位では名前だけを示す。

## 検証方針

- **分割クラス**:
  - `#name-and-subtitle-apart` — 副題を持つ単位の行で、名前と副題がそれぞれ別の要素として出て、副題が名前の後ろに出る
  - `#name-only` — 副題を持たない単位の行には名前だけが 1 つの要素として出て、副題の代わりの文字（空の括弧・null など）が出ない
- **尽きている根拠**: 単位ごとの入力は subtitle の文字列／null の 2 通り。日で束ねる・章で束ねる学び、回ごとの並び・補足の別枠は示し方に効かないので値の変種として同じクラスで回す。
- **境界の扱い**: 名前が括弧書きを含み副題が null の単位を `#name-only` の点に置き、画面が名前から副題を切り出して別に示さないことを見る。
- **検証しない**: 副題の見た目（字の大きさ・色・区切りの記号）。要件が決めていない。
- **参照先**: `tests/client/UC-009_roadmap_units.test.tsx::単位の名前と副題（UC-009）`
