# REQ-436

> 作り手が単位の論点の ID と新しい要約を渡して要約を差し替えるときに、渡した論点の ID のどれかがロードマップのデータのどの単位にも当たらなければ、システムはロードマップの設定もロードマップのデータも書き換えずに止め、その ID を示す。

## 検証方針

- **分割クラス**:
  - `#unknown-id` — どの単位にも当たらない ID だけを渡すと、設定もロードマップのデータも書き換えずに止め、その ID を示す
  - `#unknown-among-known` — 当たる組と当たらない組を一緒に渡すと、当たる組の分も含めてどちらも書き換えずに止め、当たらない ID を示す（組の順を変えても同じ）
  - `#id-only-in-config` — 設定に鍵としてあってもロードマップのデータの単位に無い ID は当たらないとして止める
  - `#name-in-place-of-id` — ID の代わりに単位の名前を渡すと、名前で当てずに止め、その値を示す
- **尽きている根拠**: 当たらない入力は、どこにも無い数・設定にだけある ID・単位の名前の 3 種で、当たる組と混ざるかどうかで書き換えの一部が残る道が分かれる。書き換えないことは 2 つのファイルの中身が文字単位で前と同じことで見る。
- **検証しない**: 当たらない ID が複数あるときに全部を示すか（文は「その ID」を示すことだけを決める）。
- **参照先**: `tests/server/UC-009_apply_summary_override.test.ts::当たらない ID なら書き換えずに止める（UC-009）`
