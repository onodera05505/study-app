# REQ-434

> 作り手が論点の候補からロードマップのデータを組み立て直すときに、ロードマップの設定が指す論点の ID のどれかがどの候補の単位にも当たらなければ、システムはロードマップのデータを書き出さずに組み立てを止め、その ID を示す。

## 検証方針

- **分割クラス**:
  - `#unknown-key` — 単位ごとの設定（前提を足す・置き換える・要約を差し替える）の鍵の ID が当たらないと、書き出さずに止め、その ID を示す
  - `#unknown-in-value` — 前提を足す・置き換える設定の値の ID が当たらないと、書き出さずに止め、その ID を示す
  - `#unknown-in-list` — 含める・除く・続けて並べる単位の一覧の ID が当たらないと、書き出さずに止め、その ID を示す
  - `#name-in-place-of-id` — ID の所に候補の名前を書くと、名前で当てずに書き出さずに止め、その値を示す
- **尽きている根拠**: 設定が ID を持つ所は鍵・値・一覧の 3 つの形に尽き、形ごとに該当する設定を値の変種として回す。当たらない値には、どの候補にも無い数と、候補の名前（ID として読めば当たらない）の 2 種があり、後者を別クラスにする。
- **検証しない**: 候補の前提の ID が当たらないとき（文は設定が指す ID だけを決める）。当たらない ID が複数あるときに全部を示すか（文は「その ID」を示すことだけを決める）。
