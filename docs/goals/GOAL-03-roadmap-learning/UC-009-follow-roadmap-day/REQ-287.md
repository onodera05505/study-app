# REQ-287

> 印を持つ学びで利用者がロードマップを開いたとき、システムは全ての印を選んだ状態の印の絞り込みを添える。

## 検証方針

- **分割クラス**:
  - `#filter-offered-all-selected` — 開いたとき、登録簿にある全ての印の段が選ばれた状態で絞り込みが出る
  - `#reopen-resets-to-all` — 絞り込みを選び直したあとに開き直すと、全ての印を選んだ状態に戻る
- **尽きている根拠**: 入力は開く前の選択の有無で、初めて開く（選択が無い）と、選び直したあとに開き直す（前の選択がある）の 2 クラスに尽きる。どちらも結果は同じ全部選んだ状態で、前の選択を覚えないことを後者が見る。
- **検証しない**: 印の段の数と語（登録簿が正本）。印を持たない学び（REQ-285）。選び直したあとの表示（REQ-283）。
- **参照先**: 未配置
