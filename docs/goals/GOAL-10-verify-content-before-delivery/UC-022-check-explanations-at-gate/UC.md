# UC-022 資格対策の問題解説を配る前に教材の門で確かめる

## 概要

作り手が、書き手から上がった資格対策の学びの問題解説を教材の門にかけ、止める理由が無ければ通し、あればその問題と理由を受け取って書き手へ戻す。

## 事前条件

- 資格対策の学びが登録簿にあり、過去問・正解表・問題解説の入力の束と書き手の問題解説が学びの置き場にある
- 適用される業務規則: BR-004, BR-028, BR-042, BR-043

## 主シナリオ

1. 作り手が、資格対策の学びの問題解説を教材の門にかける
2. システムが、入力の束のどの問題にも問題解説が 1 つあることを確かめる
3. システムが、各問題解説が必須の要素を持ち、正解・指す過去問・同一内容の鍵・正誤の印が過去問と正解表に合い、用語が学びで解決でき、過去問の原文を写していないことを確かめる → BR-028
4. システムが、情報の量を見ずに、表示の制約と書き方を警告として挙げる → BR-042, BR-043
5. システムが、見た問題の数、警告、止める理由を返し、止める理由が無いので通す
6. 作り手が、通ったことを見て、問題解説を投入に回す

## 状態 × イベント表

| 問題解説の状態 \ イベント | 資格対策の問題解説を門にかける |
| --- | --- |
| 止める理由が無い（警告だけが当たるものを含む） | REQ-393 |
| 学びが登録簿に無いか資格対策でない、または入力の束の置き場が無い | REQ-394 |
| 問題解説のファイルが読めない、入力の束の問題に問題解説が無い、同じ問題の問題解説が 2 つ以上ある | REQ-395 |
| 書き手が書いている途中の問題解説のファイルを門にかける | REQ-395 |
| 正解の根拠・選択肢ごとの説明の字数・文数が多い、または少ない | REQ-396 |
| 選択肢ごとの説明の字数が表示の制約から外れる | REQ-397 |
| 必須の要素が欠けている | REQ-398 |
| 正解・指す過去問・同一内容の鍵・正誤の印が食い違う | REQ-399 |
| 過去問の原文と長く一致する | REQ-400 |
| 用語として示した語が学びで解決できない | REQ-401 |
| 書き方が問題解説の警告に当たる | REQ-402 |
| 指す図の画像が置き場所に無い | 不可: 問題解説は図を指さず、過去問の図は過去問の側にある |
| 出典の名前が集めた資料に無い | 不可: 問題解説は出典の欄を持たず、出典は過去問の側にある（BR-027） |
| 独立解答を添える | 不可: 資格対策の正解は公開元の正解表にあり、この門の入口は独立解答を受け取らない |

## 例外系の走査（4 分類）

| 軸 | 該当ステップ | 導出 |
| --- | --- | --- |
| 権限 | 1 | なし（門は読むだけで書き換えず、かける人を区別しない。かけられる学びは登録簿の資格対策に閉じる: REQ-394） |
| 不変条件違反 | 2・3 | REQ-395・REQ-398・REQ-399・REQ-400・REQ-401 |
| 並行性 | 1・2 | REQ-395（書き手が書いている途中で読めないファイル、別の書き手と同じ問題の問題解説） |
| 外部依存 | 3 | REQ-399（正解表と過去問）／REQ-401（用語の上書き） |

## 事後条件

- 成功時: 作り手が、資格対策の学びの問題解説について「止める理由が無い」という門の結果と、見た問題の数と警告を見ている
- 失敗時: いかなる状態変更も残っていない（部分適用なし。門は問題解説を書き換えず、止める理由の問題と理由だけが結果に残る）
