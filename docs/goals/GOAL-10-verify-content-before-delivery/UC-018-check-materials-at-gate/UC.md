# UC-018 資格対策の教材を配る前に教材の門で確かめる

## 概要

作り手が、資格対策の学びの教材の世代を教材の門にかけ、止める理由が無ければ通し、あればその論点と理由を受け取って書き手へ戻す。

## 事前条件

- 資格対策の学びが登録簿にあり、論点と過去問と教材の世代が学びの置き場にある
- 適用される業務規則: BR-004, BR-025, BR-026, BR-042, BR-043

## 主シナリオ

1. 作り手が、資格対策の学びの教材を教材の門にかける
2. システムが、教材の論点が学びの論点と一致し、どの論点にも教材があることを確かめる
3. システムが、各教材が必須の要素を持ち、決めた記法で書かれ、指す図と用語が実在し、過去問の原文を写していないことを確かめる → BR-025, BR-026
4. システムが、情報の量を見ずに、表示の制約と書き方を警告として挙げる → BR-042, BR-043
5. システムが、見た論点の数、警告、止める理由を返し、止める理由が無いので通す
6. 作り手が、通ったことを見て、教材を配る本文の組み立てに回す

## 事後条件

- 成功時: 作り手が、資格対策の学びの教材について「止める理由が無い」という門の結果と、見た論点の数と警告を見ている
- 失敗時: いかなる状態変更も残っていない（部分適用なし。門は教材を書き換えず、止める理由の論点と理由だけが結果に残る）
