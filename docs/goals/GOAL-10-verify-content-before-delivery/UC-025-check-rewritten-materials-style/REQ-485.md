# REQ-485

> 様式の門は、通すときも止めるときも断るときも、教材・単元の構成・図の仕様のどのファイルも書き換えない。

## 検証方針

- **分割クラス**:
  - `#unchanged-on-pass` — 警告を出して通すとき、作業場のどのファイルも書き換えず、足しも消しもしない
  - `#unchanged-on-stop` — 読めない束・使えない単元の構成・読めない図の仕様・図の上限超えで止めるとき、作業場のどのファイルも書き換えない
  - `#unchanged-on-refuse` — 資格対策でない学び・書き直した世代でない名前・読めない論点の一覧で断るとき、作業場のどのファイルも書き換えない
- **尽きている根拠**: 文の 3 つの終わり方（通す・止める・断る）が 1 クラスずつ。止める側は止める理由の 4 つの読み物（束・単元の構成・図の仕様と図の数）を 1 回に重ねて当て、断る側は errors の 3 種類（学び・世代・一覧）を代表に試す。
- **検証しない**: 作業場の外（リポジトリの scripts や登録簿の正本）への書き込み（作業場を cwd にして呼ぶので、門が読む学びの置き場はすべて作業場の中にある）。ファイルの更新時刻だけが変わる書き換え（中身とファイルの有無で見る）。
