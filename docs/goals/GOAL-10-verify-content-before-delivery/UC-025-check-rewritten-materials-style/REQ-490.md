# REQ-490

> 書き直した世代に論点がある単元の単元の構成が無いか読めないとき、または学びの全部の単元の構成と合わせて判定した単元の構成の門の止める理由のうちその単元に関する物（前提の循環のように複数の単元の構成にまたがる止める理由は、それに入るすべての単元に関する物とする）があるとき、様式の門はその単元を挙げて止め、書き直した世代に論点の無い単元の単元の構成はどの状態でも止める理由にしない。

## 検証方針

- **分割クラス**:
  - `#unit-without-plan` — 書き直した世代に論点がある単元に単元の構成が無ければ、その単元を unitPlanStops で挙げて止め、その単元の論点を topicNotInPlan で重ねて挙げない
  - `#plan-has-stops` — 書き直した世代に論点がある単元の単元の構成が単元の構成の門の止める理由（実在しない論点・まとまりの上限超え・必須の要素の欠け）に当たれば、その単元を挙げて止め、論点を重ねて挙げない
  - `#plan-file-unreadable` — 書き直した世代に論点がある単元の単元の構成のファイルが書きかけで読めなければ、その単元を挙げて止め、論点を重ねて挙げない
  - `#cross-unit-cycle` — 前提の循環が 2 つの単元の構成にまたがるとき、書き直した世代に論点がある側の単元は、循環の止める理由がどちらの単元を指していても、その単元を挙げて止め、論点を重ねて挙げない
  - `#cycle-outside-units` — 前提の循環に入らない単元にだけ書き直した世代の論点があるときは、学びの別の単元の構成どうしの循環があっても止めない
  - `#plan-outside-scope` — 書き直した世代に論点が無い単元の単元の構成は、無くても読めなくても止める理由に当たっても見ずに通す
- **尽きている根拠**: 単元の構成は、見る範囲（書き直した世代に論点がある単元）の内で、無い・読めない・止める理由に当たるの 3 つと、範囲の外で尽きる。止める理由は、その単元の構成だけで決まる物（`#plan-has-stops`）と、複数の単元の構成にまたがる前提の循環（入る単元の側 `#cross-unit-cycle`・入らない単元の側 `#cycle-outside-units`）で尽きる。使えない単元の論点を重ねないことは、構成のクラスがそれぞれ見る。
- **境界の扱い**: 単元の構成の止める理由の種類ごとの判定は UC-024 のクラスが受け持ち、ここでは 3 種類と読めないファイルを代表に、様式の門が単元を挙げて止めることだけを見る。単元は where か reason に単元の番号（0 詰めかどうかによらない）が出ることで見る。
- **検証しない**: 止める理由の種類ごとの判定そのもの（UC-024 の REQ が持つ）。
