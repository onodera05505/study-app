# UC-024 資格対策の単元の構成を教材の門で確かめる

## 概要

作り手が、書き手から上がった資格対策の学びの単元の構成を教材の門にかけ、止める理由が無ければ通し、あればその単元と理由を受け取って書き手へ戻す。

## 事前条件

- 資格対策の学びが登録簿にあり、論点とシラバスと単元の構成が学びの置き場にある
- 単元の構成の書き方は執筆の仕様書（`scripts/prompts/unit_plan.md`）が決める
- 適用される業務規則: BR-004, BR-057, BR-058（保証点は ADR-0009）

## 主シナリオ

1. 作り手が、資格対策の学びの単元の構成を教材の門にかける
2. システムが、各単元の構成が必須の要素を持ち、シラバスに実在する単元を指すことを確かめる
3. システムが、構成のある単元の論点が、どれもちょうど 1 つのまとまりに入り、まとまりの論点の数が上限の内にあることを確かめる
4. システムが、受け持ちと前提が実在する論点を指し、学ぶ順と食い違わないことを確かめる
5. システムが、見た単元と論点の数、警告、止める理由を返し、止める理由が無いので通す
6. 作り手が、通ったことを見て、書き直しの束を作るのに回す

| 書き手が書いている途中の単元の構成のファイルを門にかける | REQ-444 |
| 単元の論点がどのまとまりにも入っていない、2 つ以上のまとまりに入る、同じまとまりに 2 回以上並ぶ、他の単元の論点か実在しない論点がまとまりにある | REQ-445 |
| まとまりの論点の数が上限を超える | REQ-446 |

## 事後条件

- 成功時: 作り手が、資格対策の学びの単元の構成について「止める理由が無い」という門の結果と、見た単元と論点の数と警告を見ている
- 失敗時: いかなる状態変更も残っていない（部分適用なし。門は単元の構成を書き換えず、止める理由の単元と理由だけが結果に残る）
