# REQ-097

> システムは、受験履歴に、要求した本人の締めたテストだけを一覧し、他の人のテストと締めていないテストを含めない。

## 検証方針

- **分割クラス**:
  - `#only-own-sessions` — 他の人の締めたテストがある状態で本人が受験履歴を開いた入力（本人の分だけが出る）
  - `#excludes-unfinished` — 進行中のテストと破棄されたテストがある状態の入力（締めていないものが出ない）
- **尽きている根拠**: 一覧に混ざり得る余計な行は「他の人のテスト」と「締めていないテスト」の 2 種で、BR-018 の持ち主の軸と、締めたかどうかの軸に対応する。本人の締めたテストが出ること自体は REQ-095 が持つ。
- **検証しない**: 他の人のテストの結果を直に指したとき（結果の中身を持つ UC が BR-018 として持つ）。
- **参照先**: 未検証（単体テストは無い。system suite の `scripts/check_api.py` が、別のアカウントの履歴が空であること・締めたテストが履歴に出ること・破棄したテストが履歴に出ないことを本番相当の経路で見ている）
