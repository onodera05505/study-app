# REQ-101

> 受験履歴の取得に失敗した状態で利用者が読み直しを選んだとき、システムは、受験履歴を取り直す。

## 検証方針

- **分割クラス**:
  - `#reload-refetches` — 取得に失敗した状態で読み直しを選んだ入力（受験履歴を取り直す）
- **尽きている根拠**: 読み直しが出るのは取得に失敗した状態だけで、他の状態は表の不可セルなので入力は 1 つ。取り直した結果の表示は REQ-095・REQ-099・REQ-100 が持つ。
- **検証しない**: 取り直した結果ごとの表示（上の 3 件が持つ）。一覧を出したあとに別の画面でテストが締められた場合（読み直しで取り直す以外の約束を要件が置いていない）。
- **参照先**: `tests/client/history.test.tsx::履歴の画面（UC-007）`
