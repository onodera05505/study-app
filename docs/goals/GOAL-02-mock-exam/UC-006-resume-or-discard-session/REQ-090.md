# REQ-090

> 利用者が破棄を了承したとき、システムは、進行中のテストと、そのテストの回答を消す。

## 検証方針

- **分割クラス**:
  - `#discard-on-consent` — 破棄の確認を了承した入力（破棄が頼まれる）
  - `#answers-removed` — 破棄が済んだあとの状態（進行中のテストもそのテストの回答も残らない）
- **尽きている根拠**: 了承したあとに約束しているのは「破棄を頼むこと」と「テストと回答が消えていること」の 2 つで、前者は画面から、後者はサーバの状態から観測する別の同値クラス。取り消した枝は REQ-091、失敗した枝は REQ-092 が持つ。
- **検証しない**: 破棄したテストが受験履歴に出ないこと（UC-007 の REQ-097 が持つ）。
- **参照先**: `#discard-on-consent` は `tests/client/repay_UC-006_practice.test.tsx::練習テストの画面（UC-006。進行中のテストの案内・再開・破棄）`、`#answers-removed` は `tests/server/repay_UC-006_discard.test.ts::進行中のテストの破棄（DELETE /api/sessions/current。UC-006）`（system suite の `scripts/check_api.py::check_discard` は本番相当の経路で同じことを見る）
