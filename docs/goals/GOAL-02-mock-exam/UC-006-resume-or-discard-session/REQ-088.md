# REQ-088

> 利用者が進行中のテストの再開を選んだとき、システムは、そのテストの出題へ移し、未回答のうち最も小さい位置の問題から続けられるようにする。

## 検証方針

- **分割クラス**:
  - `#resume-moves-to-session` — 進行中のテストがある状態で再開を選んだ入力（そのテストの出題へ移る）
- **尽きている根拠**: 再開を選べるのは進行中がある状態だけで、進行中が無い状態は表の不可セル、終わっている状態は REQ-240 が持つ。よって入力は 1 つ。
- **検証しない**: 未回答のうち最も小さい位置の決定（UC-004 の REQ-058#smallest-unanswered が持つ。OQ-127 の重複）。
