# REQ-093

> 進行中のテストの有無が取れていない間、システムは、ホームに進行中のテストの案内を出さないだけにし、ホームの他の部分を出す。

## 検証方針

- **分割クラス**:
  - `#home-notice-omitted-only` — 進行中のテストの有無が取れていない入力（案内だけが落ち、ホームの他の部分は出る）
- **尽きている根拠**: ホームの 3 状態のうち取れていない側の入力で、観測は「案内が無い」と「他の部分が在る」の 2 つだが、同じ 1 つの入力に対する観測なので 1 クラス。
- **検証しない**: 取得前（まだ取りに行っている間）と取得の失敗の区別（ホームでの見せ方を決めた文が無い。`OPEN-QUESTIONS.md` の OQ-94 で BR-015 の射程を広げる判断を待っている）。
- **参照先**: 未検証（`tests/client/home.test.tsx` の応答はどれも成功で、進行中の有無が取れていない入力を作っていない）
