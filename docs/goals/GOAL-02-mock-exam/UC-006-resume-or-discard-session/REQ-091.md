# REQ-091

> 利用者が破棄の確認を取り消したとき、システムは、進行中のテストとその回答を消さず、破棄を行わない。

## 検証方針

- **分割クラス**:
  - `#cancel-keeps-session` — 破棄の確認を取り消した入力（破棄が頼まれず、進行中のテストとその回答が残る）
- **尽きている根拠**: 確認の答えは了承と取り消しの 2 つで、了承は REQ-090 が持つ。
- **検証しない**: 取り消したあとに再び破棄を選べること（REQ-087 の導線が残っていることと同じ観測）。
- **参照先**: `tests/client/repay_UC-006_practice.test.tsx::練習テストの画面（UC-006。進行中のテストの案内・再開・破棄）`
