# REQ-084

> 進行中のテストが無い間、システムは、練習テストの画面に進行中のテストの案内と、再開・破棄の導線を出さない。

## 検証方針

- **分割クラス**:
  - `#practice-no-notice` — 進行中のテストが無いと取れた状態で練習テストの画面を開いた入力（案内も再開・破棄の導線も出ない）
- **尽きている根拠**: 練習テストの画面の入力も進行中のテストの有無の 3 状態で尽き、ある側は REQ-087、取れていない側は REQ-094 が持つ。
- **検証しない**: 範囲の一覧そのものの出方（UC-004 の REQ-048 が持つ）。
- **参照先**: 未検証（`tests/client/practice.test.tsx::練習テストの画面` の既定の応答は進行中なしだが、案内と再開・破棄の不在を断定するテストが無い）
