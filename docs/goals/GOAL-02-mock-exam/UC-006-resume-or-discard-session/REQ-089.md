# REQ-089

> 利用者が破棄を選んだとき、システムは、回答済みの問数を示して、破棄してよいかを確かめる。

## 検証方針

- **分割クラス**:
  - `#confirm-shows-answered-count` — 破棄を選んだ入力（確認が出て、そこに回答済みの問数が入る）
- **尽きている根拠**: 破棄を選べるのは進行中がある状態だけで、確認は 1 度だけ出る。了承と取り消しの枝は REQ-090・REQ-091 が持つ。
- **境界の扱い**: 回答済みが 0 問の進行中でも確認は出る（同じクラス）。
- **検証しない**: 確認の文の全文（文言の正本は画面のコード）。
- **参照先**: `tests/client/practice.test.tsx::練習テストの画面`（ファイルの持ち主は UC-004）
