# REQ-240

> すでに締められたテストの再開を求められた場合、システムは、BR-034 に従い、出題を示さずそのテストが終わっていることを示し、破棄されて残っていないテストについては見つからないものとして断る。

## 検証方針

- **分割クラス**:
  - `#resume-completed` — 締めたテストの再開を求めた入力（出題を示さず、そのテストが終わっていることを示す）
  - `#resume-discarded` — 破棄されて残っていないテストの再開を求めた入力（見つからないものとして断る（404））
- **尽きている根拠**: 終わったテストは締めたものと破棄されたものの 2 通りに尽き、進行中のものは REQ-088 が持つ。
- **検証しない**: 現在の問題を求められたとき（同じ BR-034 の射影として UC-004 の REQ-237 が持つ。OQ-127）。古い案内を出している画面の直し方（要件が決めていない）。
- **参照先**: `tests/server/finished_session.test.ts::終わったテストの再開（GET /api/sessions/current と戻り先の出題。UC-006）`（本番相当の経路は system suite の `scripts/check_api.py` も見ている）
