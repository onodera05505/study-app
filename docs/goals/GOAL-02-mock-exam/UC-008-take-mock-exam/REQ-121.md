# REQ-121

> システムは合否の目安を、総合の正答率が基準以上で、かつ分野ごとの基準点がある学びでは全ての分野も基準以上であるときに限り、届いているものとして示す。

## 検証方針

- **分割クラス**:
  - `#overall-threshold` — 総合の正答率が基準以上かどうかで判定が変わる
  - `#field-threshold-and` — 分野ごとの基準点がある学びでは、1 つでも基準未満の分野があれば届かない
  - `#no-field-threshold-learning` — 分野ごとの基準点を置かない学びでは総合だけで判定する
- **尽きている根拠**: 判定の入力は「総合の正答率」「分野ごとの正答率の集合」「分野の基準点があるか」の 3 つで、AND の各項と条件の有無に対応する 3 クラスで尽きる。
- **境界の扱い**: 基準ちょうどは届く側（以上）。総合・分野のどちらの基準でも同じ切り方。
- **検証しない**: 基準の値そのもの。正本は登録簿（BR-005 / R-102）で、応答の criteria が運ぶ。
