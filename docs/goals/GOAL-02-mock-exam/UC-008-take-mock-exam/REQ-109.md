# REQ-109

> 出題できる問題が 1 問も無い範囲で模試を始めようとしたとき、システムはテストを作らず、出題できる問題が無い旨を示す。

## 検証方針

- **分割クラス**:
  - `#empty-scope-no-session` — 出題できる問題が 1 問も無い範囲ではテストが作られない
  - `#empty-scope-message` — 出題できる問題が無い旨が、始めようとした画面に出る
- **尽きている根拠**: この文は「作らない」と「示す」の 2 つしか述べない。範囲が回かランダム構成かは結果を変えないので分けない。
- **検証しない**: 進行中のテストがあり、かつ範囲が空のときどちらを返すか。隣り合う失敗条件の優先は contract.yaml の errors の順と例（conflictWinsOverEmptyScope）が持ち、contract-run が執行する（R-1207）。
- **参照先**: `tests/client/exams.test.tsx::模擬試験の画面`（empty-scope-message を観測する 1 件は REQ-110 に付く）
