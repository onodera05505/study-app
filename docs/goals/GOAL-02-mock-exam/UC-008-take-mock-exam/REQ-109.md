# REQ-109

> 出題できる問題が 1 問も無い範囲で模試を始めようとしたとき、システムはテストを作らず、出題できる問題が無い旨を示す。

## 検証方針

- **分割クラス**:
  - `#empty-scope-no-session` — 出題できる問題が 1 問も無い範囲ではテストが作られない
  - `#empty-scope-message` — 出題できる問題が無い旨が、始めようとした画面に出る
- **尽きている根拠**: この文は「作らない」と「示す」の 2 つしか述べない。範囲が回かランダム構成かは結果を変えないので分けない。
- **検証しない**: 進行中のテストがあり、かつ範囲が空のときどちらを返すか。隣り合う失敗条件の優先は UC-004 の contract.yaml の startSession の errors の順と例（inProgressBeforeEmptyScope）が持ち、contract-run が執行する（R-1207）。
- **参照先**: `tests/server/repay_UC-008_exams_api.test.ts::模試の開始（POST /api/sessions。UC-008）`（empty-scope-no-session）、`tests/client/repay_UC-008_exams_screen.test.tsx::模擬試験の入口の画面（UC-008）`（empty-scope-message）
