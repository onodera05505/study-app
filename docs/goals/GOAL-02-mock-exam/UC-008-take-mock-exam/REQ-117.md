# REQ-117

> 制限時間を過ぎた進行中のテストであるあいだ、システムは現在の問題を求められても問題を渡さず、時間切れの終了として返す。

## 検証方針

- **分割クラス**:
  - `#expired-finished` — 制限時間を過ぎた進行中のテストでは、問題を渡さず時間切れの終了として返る
- **尽きている根拠**: 制限時間に対する現在時刻は内か外かの 2 値で、内は REQ-111。この文は外の側だけを持つ。
- **境界の扱い**: 残りちょうど 0 も過ぎた側に入る。
- **検証しない**: 時間切れの判定に使う時刻の出どころ。サーバの時刻で、この文は述べない。
