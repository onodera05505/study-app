# REQ-117

> 残り時間が 0 に達した進行中のテストであるあいだ、システムは現在の問題を求められても問題を渡さず、時間切れの終了として返す。

## 検証方針

- **分割クラス**:
  - `#expired-finished` — 残り時間が 0 に達した進行中のテストでは、問題を渡さず時間切れの終了として返る
- **尽きている根拠**: 残り時間は 0 に達する前と達した後（0 を含む）の 2 値で、前は REQ-111。この文は後の側だけを持つ。
- **境界の扱い**: 残り 0 ちょうどは時間切れの側（用語集「時間切れ」・REQ-118 の自動の締めと同じ時点。REQ-119・REQ-123 と同じ切り方）。時間切れでない側の端は残り 1 秒で、時間切れの側は 0 ちょうどと十分に過ぎた点の両方を取る。
- **検証しない**: 時間切れの判定に使う時刻の出どころ（サーバの時刻で、この文は述べない）。時間切れのまま残った行を締めるかどうか（この文は渡すものだけを述べる）。
- **参照先**: `tests/server/finished_session.test.ts::残り時間が 0 に達した進行中の模試の現在の問題（GET /api/sessions/:id/current。UC-008）`
