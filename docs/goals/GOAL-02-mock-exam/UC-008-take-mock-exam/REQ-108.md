# REQ-108

> ランダム構成の模試で、分野比率に沿って選んだだけでは 1 回の問題数に届かないとき、システムは分野の付いていない過去問で残りを埋める。

## 検証方針

- **分割クラス**:
  - `#fill-with-unclassified` — 比率に沿って選ぶだけでは届かない分を、分野の付いていない過去問で埋める
  - `#no-fill-when-enough` — 比率に沿って選ぶだけで届くときは埋めない
- **尽きている根拠**: 入力は「比率で選べた数」と「1 回の問題数」の大小だけで、足りない側と足りる側の 2 クラスで尽きる。
- **境界の扱い**: ちょうど届くときは埋めない側（no-fill-when-enough）に入る。
- **検証しない**: 分野の付いていない過去問を足しても届かないとき。足りないまま作るのか作らないのかを決めた文が上流に無い（UC.md の例外系の走査でも「?」のまま）。
