# REQ-252

> 結果で過去問を振り返っているあいだ、システムは、問題ごとの出典を利用者に読める回の名前で示して回の内部の値はそのまま出さず、原本から変えた問題には一部改変を併記する。

## 検証方針

- **分割クラス**:
  - `#citation-per-item` — 振り返る問題ごとに、利用者に読める回の名前の出典が出て、回の内部の値は出ない
  - `#modified-item` — 原本から変えた印の有無で「一部改変」の併記が切り替わる
- **尽きている根拠**: 併記する物は出典と「一部改変」の 2 つ（BR-027）。出典は（読める名前で出る）か（内部の値が漏れる）の 1 観測に尽き、「一部改変」は改変の印の真偽の 2 値に尽きる。
- **検証しない**: 出典の文字列の組み立て（画面は契約の `citation` をそのまま出す）。間違えた問題だけを先に出す切り替えと問題解説・論点への導線（REQ-125）。同一内容の件数と他の出典（REQ-249）。出題中の出典（REQ-245）。
