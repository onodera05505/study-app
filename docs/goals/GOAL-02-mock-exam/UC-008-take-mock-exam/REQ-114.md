# REQ-114

> 利用者が未回答を残したまま模試を締めようとしたとき、システムは未回答の残りの問数を示して確かめ、確かめが取れたときだけ未回答のまま締める。

## 検証方針

- **分割クラス**:
  - `#confirm-with-unanswered-count` — 未回答の残りの問数を示して確かめ、了承したときだけ未回答のまま締める
- **尽きている根拠**: 入力は確かめの応答の 2 値だけで、既存の 1 件が両端（取り消し／了承）を続けて見る。未回答が 0 問のときは締めの確かめに入らない（REQ-116 の状態）。
- **検証しない**: 締めそのものの冪等（BR-024）。2 回締めたときの結果は別の規則の射程。
- **参照先**: `tests/client/session.test.tsx::出題の画面`（持ち主は UC-004 の担当）
