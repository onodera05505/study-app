# REQ-112

> 利用者が制限時間のあるテストを解いているあいだ、システムは残り時間を示し、時間の経過に従って減らす。

## 検証方針

- **分割クラス**:
  - `#countdown-ticks` — 残り時間が時分秒で出て、時間の経過に従って減る
- **尽きている根拠**: この文の入力は経過時間だけで、示す形と減ることの 2 つが 1 本の観測に収まる。
- **境界の扱い**: 残り 0 に達したあとは REQ-118 の射程。
- **検証しない**: 残り時間が少なくなったときの強調。この文は「示し、減らす」までで、強調を述べた文が上流に無い。
- **参照先**: `tests/client/session.test.tsx::出題の画面の時計（制限時間つき）`（持ち主は UC-004 の担当）
