# REQ-286

> 利用者がロードマップ型の学びのある回を範囲にテストを始めたとき、システムはそのテストの範囲の名前を、登録簿が定める回の見出しの語と回ごとの確認の語で作り、章で束ねる学びでは回のラベルが持つ章の名前を含め、補足の回では登録簿の補足の回のラベルを使う。

## 検証方針

- **分割クラス**:
  - `#day-round-scope-name` — 日で束ねる学びの回から作ったテストの範囲の名前が、その学びの日の語でその回を指す
  - `#chapter-round-scope-name` — 章で束ねる学びの回から作ったテストの範囲の名前が、章の語と章の名前でその回を指し、日の語を含まない
  - `#extra-round-scope-name` — 補足の回から作ったテストの範囲の名前に、登録簿の補足の回のラベルが使われる
- **尽きている根拠**: 入力は範囲にした回の種類（日の回・章の回・補足の回）で、種類ごとに名前の作り方が 1 つずつなので 3 クラスに尽きる。
- **検証しない**: 資格対策の公開回とランダム構成の範囲の名前（REQ-105 が持つ）。語とラベルの値（登録簿と投入データが正本。BR-005）。範囲の名前が後から示される場所（進行中の案内・受験履歴。それぞれの UC が持つ）。
- **参照先**: `tests/server/roadmap_round_exam.test.ts`::回を範囲にしたテストの範囲の名前（UC-008）
