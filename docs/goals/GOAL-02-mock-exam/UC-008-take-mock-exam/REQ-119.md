# REQ-119

> 残り時間が 0 に達したテストへ回答が送られたとき、システムは、正誤も記録もせず、その回答を受け付けずに断る。

## 検証方針

- **分割クラス**:
  - `#expired-answer-rejected` — 残り時間が 0 に達したテストへ回答を送ると、正誤も記録も返らず、その回答が受け付けられずに断られる
- **尽きている根拠**: 回答を送る入力のうちこの文が持つのは時刻の軸だけで、残り時間が 0 に達する前（REQ-113）と達した後（0 を含む）の 2 値。
- **境界の扱い**: 残り 0 ちょうどは断る側（REQ-117・REQ-123 と同じ切り方）。受け付ける側の端は残り 1 秒で、両側の端を取る。
- **検証しない**: 締め済み・未回答なしのテストへの回答（BR-023 の他の 2 つの入口）。errors の順と例が優先を持つ（R-1207）。断りの本文に時間切れの印を載せること（本文の正本は契約の `ErrorBody` だけで、時間切れであることは現在の問題の取得の `expired` が示す）。
- **参照先**: `tests/server/finished_session.test.ts::残り時間が 0 に達した模試への回答（POST /api/sessions/:id/answer。UC-008）`
