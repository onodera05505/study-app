# REQ-119

> 制限時間を過ぎたテストへ回答が送られたとき、システムは正誤を返さず、時間切れである旨を示す。

## 検証方針

- **分割クラス**:
  - `#expired-answer-rejected` — 制限時間を過ぎたテストへ回答を送ると、正誤が返らず時間切れである旨が返る
- **尽きている根拠**: 回答を送る入力のうちこの文が持つのは時刻の軸だけで、制限時間の内（REQ-113）と外の 2 値。
- **境界の扱い**: 制限時間ちょうどは外に入らない（REQ-123 と同じ切り方）。
- **検証しない**: 締め済み・未回答なしのテストへの回答（BR-023 の他の 2 つの入口）。errors の順と例が優先を持つ（R-1207）。
