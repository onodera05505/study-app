# REQ-125

> 利用者が完了したテストの結果を開いたとき、システムははじめに間違えた問題だけを一覧し、すべての問題への切り替えと、問題ごとの自分の回答・正解・その問題に在る問題解説と論点への導線を示す。

## 検証方針

- **分割クラス**:
  - `#wrong-first-and-review-links` — はじめは間違えた問題だけが出て、すべてへの切り替えと、問題ごとの自分の回答・正解・問題解説・論点への導線を持つ
  - `#item-without-explanation` — 問題解説や論点が無い問題でも振り返りが出る（導線だけが落ちる）
- **尽きている根拠**: 振り返りの入力は「問題ごとの正誤（未回答を含む）」と「その問題に問題解説と論点が在るか」の 2 軸。前者の出し分けと導線が wrong-first-and-review-links、後者の欠けが item-without-explanation。
- **境界の扱い**: 未回答の問題も間違えた側として先に出る。
- **検証しない**: 出典と「一部改変」の出方。`tests/client/screens.test.tsx` が横断で見る（BR-027・BR-028 の射程）。
- **参照先**: `tests/client/result_screen.test.tsx::結果の画面`
