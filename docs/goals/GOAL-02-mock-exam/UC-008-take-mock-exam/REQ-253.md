# REQ-253

> 締めた模試、または未回答の問題が 1 問も残っていない模試へ回答が送られた場合、システムは、BR-023 に従い、採点も記録もせず、回答を受け付けられない理由を示す。

## 検証方針

- **分割クラス**:
  - `#answer-to-finished` — すでに締めた模試への回答（採点も記録もせず、受け付けられない理由を示す）
  - `#answer-with-no-unanswered` — 未回答の問題が 1 問も残っていない模試への回答
- **尽きている根拠**: この文が挙げる状態は「締めた模試」と「未回答が 1 問も残っていない模試」の 2 つで、クラスもその 2 つ。UC-004 の契約 `answerQuestion` の errors が別の行として持つ「残り時間が 0 に達している」は REQ-119、「位置が違う」は REQ-250 が持つ。
- **検証しない**: 制限時間を過ぎた模試への回答（REQ-119）。位置の食い違い（REQ-250）。2 つの状態が同時に成り立つときにどちらの理由を先に返すか（契約の errors の並びは評価の順を持つが、どちらでも結果は「受け付けない」で同じで、理由の文言は正本がコード）。
- **参照先**: `tests/server/repay2_UC-008_reject_and_refinish.test.ts::締めた模試・未回答の無い模試への回答（POST /api/sessions/:id/answer。UC-008）`（`#answer-to-finished` の本番相当は system suite の `scripts/check_api.py`（終了後の回答））
