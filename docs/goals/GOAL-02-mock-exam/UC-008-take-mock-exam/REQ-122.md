# REQ-122

> システムは分野別の正答率に、分野ごとの基準点がある学びでだけ基準への達否を添え、基準点を置かない学びでは添えない。

## 検証方針

- **分割クラス**:
  - `#marked-when-threshold-exists` — 分野ごとの基準点がある学びで、分野別の正答率に基準への達否が添う
  - `#not-marked-without-threshold` — 基準点を置かない学びでは達否を添えない
- **尽きている根拠**: 入力は「分野の基準点があるか」と「その分野の正答率」の 2 つ。基準点が無い側は正答率に依らず添えないので 1 クラス、ある側は達否の両端を 1 クラスで見る。
- **境界の扱い**: 基準点ちょうどは達した側、その 1 つ下は未達。0 と 100 の両端も同じクラスで見る。
- **検証しない**: 基準点の値。正本は登録簿（BR-005 / R-102）。
