# REQ-118

> 残り時間が 0 になったとき、システムはそのテストを自動で締め、結果を示す。

## 検証方針

- **分割クラス**:
  - `#auto-finish-at-zero` — 残り時間が 0 になった時点で自動的に締まり、結果へ移る
- **尽きている根拠**: 入力は残り時間が 0 に達するという 1 つの出来事だけ。締めが成功するか失敗するかは BR-014 の射程。
- **境界の扱い**: 0 に達する前に締めが起きないことも同じ 1 件で見る。
- **検証しない**: 自動の締めと利用者の締めが重なったとき。結果が変わらないことは BR-024 の射程で、この文は述べない。
- **参照先**: `tests/client/session.test.tsx::出題の画面の時計（制限時間つき）`（持ち主は UC-004 の担当）
