# REQ-111

> 利用者が進行中のテストの現在の問題を求めたとき、システムは未回答のうち最も小さい位置の問題を、回答済みの件数と残り時間とともに渡す。

## 検証方針

- **分割クラス**:
  - `#lowest-unanswered` — 未回答のうち最も小さい位置の問題が渡る（途中の位置に回答が飛んでいても最小が出る）
  - `#progress-and-remaining` — 回答済みの件数と残り時間が添う
  - `#no-answer-leak` — 出題中の応答に正解と問題解説が入らない（BR-021）
- **尽きている根拠**: getMockCurrentQuestion の応答は「どの問題を選ぶか」「何を添えるか」「何を渡さないか」の 3 軸。進行中・未回答ありの状態での入力は回答済みの位置の集合だけで、最小位置の選び方に落ちる。
- **境界の扱い**: 未回答が 1 問だけの状態も lowest-unanswered に入る（0 問は REQ-116）。
- **検証しない**: 他人のテストと存在しない ID（NOT_FOUND）。BR-018 の横断の守りで、REQ の文は述べない。
- **参照先**: `tests/client/session.test.tsx::出題の画面`（progress-and-remaining を観測。持ち主は UC-004 の担当）
