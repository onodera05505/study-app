# REQ-120

> 利用者が完了した模試の結果を開いたとき、システムは総合と分野別の正答率、合否の目安とその基準、および公式のスコアとは算出が違う旨を示す。

## 検証方針

- **分割クラス**:
  - `#mock-result-sections` — 模試の結果に総合と分野別の正答率・合否の目安とその基準・算出が違う旨が出て、演習の結果には出ない
  - `#verdict-label` — 合否の目安が、届いている／未達として読み分けられる形で出る
- **尽きている根拠**: 結果の画面で出し分けを決める入力はテストの種別（模試か演習か）と合否の目安の真偽の 2 つだけで、前者が mock-result-sections、後者が verdict-label。正答率の値は応答が持つ。
- **検証しない**: 断り書きの文そのもの。応答（contract の approximation）が正本で、画面は値を持たない（R-102）。
- **参照先**: `tests/client/result_screen.test.tsx::結果の画面` / `tests/client/result.test.ts::合否の目安の表示`
