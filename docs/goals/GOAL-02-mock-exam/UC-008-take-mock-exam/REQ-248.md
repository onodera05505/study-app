# REQ-248

> 制限時間の残りが決めのしきい値を下回っているあいだ、システムは、残り時間の示し方をそれより前と見分けられる形に変える。

## 検証方針

- **分割クラス**:
  - `#below-threshold-distinct` — 残りがしきい値を下回ったとき、残り時間の示し方が下回る前と見分けられる
- **尽きている根拠**: 残り時間としきい値の関係は（上）（下）の 2 つで、この文は下回っているあいだの示し方が「それより前」と違うことだけを述べる。両側は 1 件の中で境界のすぐ上とすぐ下を取って比べ、見分けられることを観測する。
- **境界の扱い**: しきい値のすぐ上とすぐ下の 2 点（値はテストが持つ）。
- **検証しない**: 示し方の中身（色・太さなどの見た目の正本は画面のコード。この文は「見分けられる」ことだけを要求する）。残り時間の減り方（REQ-112）。残りが 0 になったときの自動の締め（REQ-118）。
- **参照先**: `tests/client/session.test.tsx::出題の画面の時計（制限時間つき）`
