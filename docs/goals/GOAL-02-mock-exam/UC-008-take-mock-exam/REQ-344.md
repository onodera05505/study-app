# REQ-344

> システムは、制限時間のあるテストの残り時間を、1 秒に満たない端数を切り上げた秒数で渡し、残り時間が 0 に達するまでは 0 を渡さない。

## 検証方針

- **分割クラス**:
  - `#fraction-rounded-up` — 残り時間に 1 秒に満たない端数があると切り上げた秒で渡り、端数が無いとその秒のまま渡る
  - `#not-zero-before-limit` — 残り時間が 0 に達する前は、残りが 1 秒に満たなくても 0 でなく 1 が渡り、問題も渡る
- **尽きている根拠**: 残り時間は（1 秒以上で端数あり）（1 秒以上で端数なし）（0 より大きく 1 秒未満）（0 以下）に尽きる。前の 2 つが切り上げの規則、3 つ目が「0 を渡さない」の規則、0 以下は時間切れで REQ-117 が持つ。
- **境界の扱い**: 端数は 0.25 秒・ほぼ 1 秒（0.999 秒）・ちょうど 0 の 3 点と開始直後（0.5 秒経過）。1 秒未満の側は残り 999・500・1 ミリ秒。
- **検証しない**: 制限時間の無いテスト（残り時間は null で、この文の対象外）。画面の時計の減り方（REQ-112）。残り時間を渡す経路は契約で現在の問題の取得だけ。
