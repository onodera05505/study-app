# REQ-123

> システムは、締めた時刻までに残り時間が 0 に達していたテストだけを時間切れとして扱い、残り時間が 0 に達する前に締めたテストは時間切れとして扱わない。

## 検証方針

- **分割クラス**:
  - `#expired-by-finished-at` — 締めた時刻までに残り時間が 0 に達していたテストが時間切れになる
  - `#in-time-not-expired` — 残り時間が 0 に達する前に締めたテストは時間切れにならない
- **尽きている根拠**: 入力は「締めた時刻 − 開始時刻」と制限時間の大小だけで、0 に達していた側（制限時間以上）と達する前の側（制限時間未満）の 2 クラスで尽きる。
- **境界の扱い**: ちょうど制限時間で締めたときは 0 に達した側（`#expired-by-finished-at`。REQ-118 の自動の締めが落ちる点で、REQ-117・REQ-119 と同じ切り方）。達する前の側の端は残り 1 秒で締めた回。
- **検証しない**: 制限時間を置かない学びのテスト。時間切れの入力空間に入らない。
- **参照先**: `tests/server/finished_session.test.ts::完了した模試を時間切れとして扱うかは締めた時刻で決まる（UC-008）`（各クラスを現在の問題の取得（`getMockCurrentQuestion` の finished 側）と結果（`getMockResult`）の 2 本で見る。`#in-time-not-expired` は残り時間が 0 に達する時刻を過ぎた「いま」で開き直して観測する）
