# REQ-123

> システムは、締めた時刻が制限時間を過ぎていたテストだけを時間切れとして扱い、制限時間内に締めたテストは時間切れとして扱わない。

## 検証方針

- **分割クラス**:
  - `#expired-by-finished-at` — 締めた時刻が制限時間を過ぎていたテストが時間切れになる
  - `#in-time-not-expired` — 制限時間内に締めたテストは時間切れにならない
- **尽きている根拠**: 入力は「締めた時刻 − 開始時刻」と制限時間の大小だけで、過ぎている側と過ぎていない側の 2 クラスで尽きる。
- **境界の扱い**: ちょうど制限時間で締めたときは過ぎていない側（in-time-not-expired）。
- **検証しない**: 制限時間を置かない学びのテスト。時間切れの入力空間に入らない。
