# REQ-115

> 利用者が完了していないテストの結果を開こうとしたとき、システムは結果を示さず、そのテストがまだ終わっていない旨を示す。

## 検証方針

- **分割クラス**:
  - `#not-finished-not-shown` — 完了していないテストの結果は示さず、まだ終わっていない旨が返る
- **尽きている根拠**: 結果を開く入力はテストの状態だけで、完了（REQ-120 以降）と完了していないの 2 値。この文が持つのは後者。
- **検証しない**: 他人のテストと存在しない ID（NOT_FOUND）。BR-018 の横断の守り。
