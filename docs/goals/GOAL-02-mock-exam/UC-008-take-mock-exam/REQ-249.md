# REQ-249

> 公開回をそのまま通しで受ける模試であるあいだ、システムは、同一内容の件数と他の出典を、出題にも結果の振り返りにも添えない。

## 検証方針

- **分割クラス**:
  - `#sourced-exam-question-no-marks` — 公開回をそのまま通しで受ける模試の出題で、同一内容の件数と他の出典を添えない（演習・ランダム構成では添える）
  - `#sourced-exam-result-no-marks` — 同じ模試の結果の振り返りで添えない（演習では添える）
- **尽きている根拠**: 添えない場所は出題と結果の振り返りの 2 つ（文がそう挙げる）で、クラスを場所で分ける。模試の構成は（公開回をそのまま）と（それ以外＝ランダム構成・演習）の 2 値に尽き、どちらのクラスも 1 件の中で両方を取って出し分けが構成で決まることを見る。
- **検証しない**: 畳む側の規則（同一内容を 1 件にまとめる・代表を新しい回にする・件数の数え方）。BR-028 の別の面で、REQ-053 と seed の検査が持つ。出題頻度が同一内容を数えたまま残ること（同上）。
- **参照先**: `tests/client/session.test.tsx::同一内容の印` / `tests/client/result_screen.test.tsx::結果の画面`
