# REQ-106

> 利用者が回を選んで模試を始めたとき、システムはその回の過去問だけを問番号の昇順で出題する。

## 検証方針

- **分割クラス**:
  - `#exam-as-printed` — 選んだ回の過去問だけが、同一内容も畳まず問番号の昇順で出る（BR-028）
  - `#no-mastered-exclusion` — 連続して正解した問題も外さず原本どおり出る（BR-019）
- **尽きている根拠**: 回を指定した出題の入力は「その回の行の集合」だけで、変わり得るのは範囲の絞り・並び・畳み（exam-as-printed）と、利用者の実績による除外の有無（no-mastered-exclusion）の 2 軸。
- **検証しない**: 回の ID の表記ゆれ。ID の正本は投入データで、未知の回は REQ-109 の入力空間に入る。
- **参照先**: `tests/server/session-builder.test.ts::buildQuestions（出題の組み立て）`（持ち主は UC-004 の担当）
