# REQ-116

> 未回答が 1 問も残っていない進行中のテストであるあいだ、システムは現在の問題を求められても問題を渡さず、終了として返す。

## 検証方針

- **分割クラス**:
  - `#no-unanswered-finished` — 未回答が 1 問も無い進行中のテストでは、問題を渡さず終了として返る
- **尽きている根拠**: 未回答の数が 0 か 1 以上かの 2 値で、1 以上は REQ-111。この文は 0 の側だけを持つ。
- **境界の扱い**: 最後の 1 問に回答した直後がこのクラスの入口。
- **検証しない**: その状態への回答を受け付けないこと（BR-023）。出題ではなく回答の側の規則。
