# REQ-105

> 利用者が受験を始めたとき、システムはその学びに設定された 1 回の問題数と制限時間で模試のテストを作り、範囲の名前・問題数・制限時間を示す。

## 検証方針

- **分割クラス**:
  - `#created-with-registry-values` — 作られたテストの問題数と制限時間が、その学びに設定された値になる
  - `#scope-summary-shown` — 受験を始めた時点で範囲の名前・問題数・制限時間が示される
- **尽きている根拠**: この文は「作る」と「示す」の 2 つしか述べず、入力は回を選んだかランダム構成かに依らない（範囲の作り方は REQ-106・REQ-107 が持つ）。
- **検証しない**: 問題数・制限時間の値そのもの。正本は登録簿（BR-005 / R-102）で、コードもテストも値を持たない。
