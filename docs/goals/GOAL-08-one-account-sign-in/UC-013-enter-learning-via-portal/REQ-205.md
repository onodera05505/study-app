# REQ-205

> 画面から認証の形を問われたとき、学び側はまなびばの場所が与えられているかとその場所、および対象の学びを答え、共有秘密が与えられているかは答えない。

## 検証方針

- **分割クラス**:
  - `#config-shape` — まなびばの場所が与えられている配備で、場所の有無・その場所・対象の学びだけが答えとして返り、共有秘密の有無が返らない状態
  - `#no-portal-config` — まなびばの場所が与えられていない配備で、場所が無いことが答えとして返る状態
- **尽きている根拠**: 配備は（場所が与えられている）（与えられていない）の 2 クラスで尽きる。共有秘密の有無は答えないと決まっているので、秘密の有無でクラスは分かれない（分かれたら要件違反で、`#config-shape` が捕まえる）。
- **参照先**: `tests/server/app.test.ts::SSO の環境（まなびばが認証の正本。UC-013）`・`tests/server/repay_UC-013_learning_sso.test.ts::REQ-205 認証の形の問い合わせ`
