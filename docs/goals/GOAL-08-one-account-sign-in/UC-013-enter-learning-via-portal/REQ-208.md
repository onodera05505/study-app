# REQ-208

> 使い捨てコードを換えに行ったまなびばに要求が届かないとき、学び側はトークンを渡さず、その学びに本人の記録も作らず、もう一度試せることを伝える。

## 検証方針

- **分割クラス**:
  - `#portal-unreachable` — まなびばへの呼び出しが届かず、トークンが渡らない状態
  - `#retry-hinted` — もう一度試せることが伝わっている状態
  - `#no-person-record` — その学びに本人の記録が作られない状態
- **尽きている根拠**: 届かなかったときの事後条件は（トークンを渡さない）（記録を作らない）（もう一度試せると伝える）の 3 面で尽きる。まなびばが届いた上で断った場合は REQ-193 が受け持つ。
- **検証しない**: 届かない理由の種類（名前が引けない・接続できない・応答が遅い）。外から見た結果は同じで、要件は理由で振る舞いを分けていない。
- **参照先**: `tests/server/app.test.ts::SSO のコード交換（学び側。UC-013）`
