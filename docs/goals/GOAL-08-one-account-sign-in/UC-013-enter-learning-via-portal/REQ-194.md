# REQ-194

> トークンを添えずに行った学び側への要求が断られたとき、画面はログイン画面を出し、ログインの期限が切れたとは知らせない。

## 検証方針

- **分割クラス**:
  - `#no-expiry-notice` — トークンを添えない要求が断られても、ログインの期限が切れたと知らせない状態
  - `#login-screen` — 断られたあと、画面がログイン画面を出している状態
- **尽きている根拠**: トークンを添えない要求が断られたときに画面について観測できるのは「どこへ行くか」と「何を知らせるか」の 2 面。断り自体（学び側のサーバが本人と分からない要求を断ること）はこの要件の前提で、要件の文はそこを決めていない。
- **検証しない**: トークンを添えた要求が断られた場合（REQ-197）。
- **参照先**: `tests/client/api_helpers.test.ts::API 呼び出しの失敗の形`・`tests/client/repay_UC-013_login_gate.test.tsx::REQ-194 トークンを添えない要求が断られたとき`
