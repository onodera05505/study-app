# REQ-202

> 使用済みのコード・期限を過ぎたコード・別の学びに宛てて発行されたコードを換えに来たとき、まなびばは合う共有秘密の呼び出しであっても換えず、本人のメールも名前も渡さない。

## 検証方針

- **分割クラス**:
  - `#used-code` — 一度換えたコードをもう一度換えに来た状態
  - `#expired-code` — 期限を過ぎたコードを換えに来た状態
  - `#code-for-other-learning` — 別の学びに宛てて発行されたコードを換えに来た状態
- **尽きている根拠**: UC の表「使い捨てコード」の、合う共有秘密で断られる行がそのまま 3 クラスになる（使用済み・期限切れ・宛先違い）。発行後に権限が外れた行は REQ-203 が受け持つ。
- **境界の扱い**: 期限は「過ぎた直後」を境界点に取る（期限の値の正本はまなびばの DDL と交換の経路。R-102）。
- **検証しない**: 合わない共有秘密の呼び出し（REQ-201 が先に断る）。
- **参照先**: なし（Phase 6 時点でこの要件を被覆するテストが無い）
