# REQ-198

> 利用者が学び側でログアウトしたとき、学び側はその端末のトークンだけを捨ててログイン画面に戻し、他の端末のトークンには触れず、ログインの期限が切れたとは知らせない。

## 検証方針

- **分割クラス**:
  - `#token-and-device-memory-cleared` — ログアウトでトークンを捨てるとき、端末に覚えた学びの記憶も一緒に消える状態（BR-010）
  - `#no-expiry-notice` — 自分でログアウトしたあとのログイン画面に、期限切れの知らせが出ない状態
  - `#other-devices-untouched` — 他の端末のトークンに触れていない状態
- **尽きている根拠**: ログアウトの事後条件は（この端末の記憶が消える）（他の端末に触れない）（期限切れと知らせない）の 3 面で尽きる。
- **参照先**: `tests/client/api_helpers.test.ts::トークンの保存（UC-013）`・`tests/client/screens.test.tsx::ログイン画面（UC-013）`
