# REQ-203

> 発行のあとでその学びの権限が外れたアカウントの使い捨てコードを換えに来たとき、まなびばは換えず、本人のメールも名前も渡さない。

## 検証方針

- **分割クラス**:
  - `#grant-revoked-after-issue` — 発行のあとでその学びの権限が外れたアカウントのコードを、合う共有秘密で換えに来た状態
- **尽きている根拠**: 発行時に権限があったことは REQ-186 が保証するので、この要件の入力は「発行後に権限が外れた」1 クラスだけ。コード自体の状態による断りは REQ-202 が受け持つ。
- **参照先**: `tests/portal/repay_UC-013_exchange_code.test.ts::REQ-203 発行のあとで権限が外れたコードは換えない`
