# REQ-525

> 学び側のログイン画面が認証の形を問い合わせて、まなびばの場所が与えられていないという答えか、答えの無い失敗を受けたとき、画面はまなびばへの導線を登録簿にあるまなびばの場所に向けて出す。

## 検証方針

- **分割クラス**:
  - `#no-portal-answer` — 認証の形の問い合わせに、まなびばの場所が与えられていない（場所が無い）という答えが返った画面の入力
  - `#no-answer-failure` — 認証の形の問い合わせが答えを返さずに終わった画面の入力（問い合わせが届かない、または失敗の状態で返る）
- **尽きている根拠**: 文の入力は「場所が無いという答え」と「答えの無い失敗」の 2 つで、導線の行き先はどちらも登録簿のまなびばの場所に決まる。答えの無い失敗は、届かないことと失敗の状態で返ることのどちらでも答え（場所）が得られない点で同じクラスで、テストは両方の実例を置く。場所のある答えを受けた画面の導線は REQ-190・REQ-205 の範囲。
- **検証しない**: 導線の経路と付ける学びの key（答えの無い失敗では学びの key が答えから得られず、文は行き先の場所だけを決める）。行き先は href の origin を登録簿の場所と照らす。
- **参照先**: `tests/client/UC-013_portal_link_fallback.test.tsx::UC-013 まなびばの場所を得られないときのログイン画面の導線`
