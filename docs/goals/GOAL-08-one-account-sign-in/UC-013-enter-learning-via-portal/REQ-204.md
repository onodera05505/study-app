# REQ-204

> まなびばの場所が与えられている配備では、学び側は学び側のパスワードでのログインと登録を受け付けない。

## 検証方針

- **分割クラス**:
  - `#password-login-rejected` — まなびばの場所が与えられている配備で、学び側のパスワードでのログインが受け付けられない状態
  - `#register-rejected` — 同じ配備で、学び側の登録が受け付けられない状態
- **尽きている根拠**: 学び側のパスワードの経路は契約の signInWithPassword と register の 2 つだけなので、その 2 つで尽きる。
- **検証しない**: まなびばの場所が与えられていない配備でのこの 2 つの振る舞い。UC の表「まなびばの場所が無い × 学び側のパスワードでログイン・登録を試す」が未決の `?` なので、クラスにできない。
- **参照先**: `tests/server/app.test.ts::SSO の環境（まなびばが認証の正本。UC-013）`
