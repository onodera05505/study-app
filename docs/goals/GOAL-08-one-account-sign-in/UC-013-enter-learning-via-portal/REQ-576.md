# REQ-576

> 端末の記憶が使えずトークンを捨てられないとき、学び側は捨てることを何もせずに終え、ログアウト・断られた要求・トークンの入れ替えのそれぞれの続きを止めない。

## 検証方針

- **分割クラス**:
  - `#clear-no-failure` — 端末の記憶が使えない状態で、トークンを捨てる操作が失敗を渡さない（契約 `clearToken` の `errors: []`）
  - `#logout-continues` — 同じ状態でログアウトすると、ログイン画面に戻る
  - `#refused-request-continues` — 同じ状態で学び側への要求が本人と分からないとして断られると、断りがそのまま画面に届く（REQ-194・REQ-197 の扱いが止まらない）
  - `#replace-continues` — 同じ状態で使えるコードを持って戻ると、前のトークンを捨てる所で止まらずにトークンの保存へ進む（保存も使えなければ REQ-574）
- **尽きている根拠**: トークンを捨てるのは、ログアウト・本人と分からないとして断られた要求・コードを持って戻ったときの入れ替えの 3 つの場面に尽き、それぞれの続きを 1 クラスずつ見る。捨てる操作そのものが失敗を渡さないことをクラス 1 で見る。
- **検証しない**: 捨てられなかったトークンが端末に残るかどうか（記憶が使えない原因によって変わり、文は何もしないことだけを決める）。前回の続きを一緒に捨てること（BR-010。REQ-198 が持つ）。
- **参照先**: `tests/client/UC-013_token_storage_blocked.test.tsx::REQ-576 端末の記憶が使えずトークンを捨てられない`
