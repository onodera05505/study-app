# REQ-195

> 端末にトークンがある間、学び側は学びのどの場所を開かれてもログイン画面を出さず、その場所を出す。

## 検証方針

- **分割クラス**:
  - `#route-shown-not-login` — トークンがある端末がどの場所を開いてもログイン画面に置き換わらず、その場所が出る状態
- **尽きている根拠**: トークンがある間に観測できるのは 1 面（ログイン画面に置き換わらずその場所が出る）だけ。UC の表は「通る」行と「通らない」行をこの要件に寄せているので、トークンが通らないことが分かるのは要求を出したあとで、それは REQ-197 が受け持つ。
- **検証しない**: トークンが無い間（REQ-190）。
- **参照先**: `tests/client/repay_UC-013_login_gate.test.tsx::REQ-195 トークンがある間はどの場所でもその場所を出す`
