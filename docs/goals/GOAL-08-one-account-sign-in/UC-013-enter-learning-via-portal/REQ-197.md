# REQ-197

> 端末に保存したトークンを添えた要求が本人と分からないとして断られたとき、学び側はそのトークンを捨ててログイン画面に戻し、ログインの期限が切れたことを 1 度だけ知らせる。

## 検証方針

- **分割クラス**:
  - `#expired-token-401` — トークンを添えた要求が本人と分からないとして断られ、そのトークンが捨てられる状態
  - `#notice-on-login-screen` — ログイン画面で、ログインの期限が切れたことが知らされている状態
  - `#notice-once` — 同じ期限切れを 2 度目には知らせない状態
- **尽きている根拠**: この要件の事後条件は（捨てる）（ログイン画面へ戻して知らせる）（知らせるのは 1 度だけ）の 3 面で尽きる。トークンを添えない断りは REQ-194、自分でログアウトした場合は REQ-198 が受け持つ。
- **検証しない**: 端末に覚えた学びの記憶を一緒に捨てること（BR-010 の同じ 1 か所を REQ-198 のクラスが観測する）。
