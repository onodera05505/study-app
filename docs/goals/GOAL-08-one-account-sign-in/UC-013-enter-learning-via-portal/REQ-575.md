# REQ-575

> 端末の記憶が使えずトークンを読めないとき、学び側はトークンが無いものとして扱い、学びのどの場所を開かれてもログイン画面を出す。

## 検証方針

- **分割クラス**:
  - `#unreadable-as-no-token` — 端末の記憶を読む操作が使えない状態で、トークンを読む操作が失敗を渡さずトークン無しを返す（契約 `readToken` の `errors: []`）
  - `#any-route-shows-login` — 同じ状態で、学びのどの場所を開いてもログイン画面になり、画面が止まらない
- **尽きている根拠**: 読めないときに観測できるのは、読む操作の返す物と、開いた場所の画面の 2 つ。読めたあとの振る舞いはトークンが無い間（REQ-190）・ある間（REQ-195）が持つ。
- **検証しない**: 読めない原因（端末の設定・私的閲覧）の区別。要求にトークンを添えないことで断られたあとの画面（REQ-194）。
- **参照先**: `tests/client/UC-013_token_storage_blocked.test.tsx::REQ-575 端末の記憶が使えずトークンを読めない`
