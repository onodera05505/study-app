# REQ-199

> 端末にトークンがある間、学び側はそのトークンが指す本人の名前を、トークンを保存した時点から画面の読み直しを待たずに添えて出し、名前が分からないときは出さない。

## 検証方針

- **分割クラス**:
  - `#name-from-token` — 名前の出所がトークンの中身で、サーバに聞きに行かない状態
  - `#name-shown` — 名前が画面に添えられている状態
  - `#name-without-reload` — トークンを保存した時点から、画面の読み直しを待たずに名前が出る状態
  - `#name-unknown` — トークンが無い・壊れている・名前を持たないため、名前を出さない状態
- **尽きている根拠**: 入力は（名前が読めるトークンがある）（名前が読めない、またはトークンが無い）の 2 クラスで尽き、読める側は出所（`#name-from-token`）・見え方（`#name-shown`）・いつから出るか（`#name-without-reload`）の 3 面に分かれる。
- **参照先**: `tests/client/api_helpers.test.ts::ヘッダーの本人の名前（UC-013）`・`tests/client/screens.test.tsx::ヘッダーの本人の名前（UC-013）`
