# REQ-572

> 端末の記憶に書けないか読めないとき、画面の端末の記憶を読み書きする操作は、その操作を呼んだ側に断りの種類の名前を渡す。

## 検証方針

- **分割クラス**:
  - `#write-blocked` — 端末の記憶に書けない入力で、書く操作が呼んだ側に名前を渡す
  - `#read-blocked` — 端末の記憶が読めない入力で、読む操作が呼んだ側に名前を渡す
- **尽きている根拠**: 端末の記憶の失敗は、書けない・読めないの 2 つに尽きる（消すことは書くことに含める）。
- **検証しない**: 名前を受けた画面の見た目と動き（各 UC の要件のまま変えない。REQ-078 などのテストが持つ）。
- **参照先**: テスト設計の担当が決める
