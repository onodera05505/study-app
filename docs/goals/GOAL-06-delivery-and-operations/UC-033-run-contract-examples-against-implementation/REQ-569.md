# REQ-569

> 契約の実例が本番の保存先・配備先・外の相手に触れる操作の物であっても、システムは契約の実例の確かめの中でそれらに何も送らない。

## 検証方針

- **分割クラス**:
  - `#production-store` — 本番の保存先を読み書きする操作の実例（投入の手続き・保存先の控えなど）を回しても、本番の保存先に要求も書き込みも届かない
  - `#deploy-target` — 配備先に触れる操作の実例（配備の手続き・配備先のログインの確かめなど）を回しても、配備先に何も届かない
  - `#external-party` — 外の相手を呼ぶ操作の実例（学び側からまなびばへの要求・外から叩く死活確認など）を回しても、外の相手に何も届かない
- **尽きている根拠**: 手元の外にあるものは、本番の保存先・配備先・外の相手の 3 つに尽きる。
- **検証しない**: 手元に用意した代わりの相手の作り（実装の手段）。
- **参照先**: テスト設計の担当が決める
