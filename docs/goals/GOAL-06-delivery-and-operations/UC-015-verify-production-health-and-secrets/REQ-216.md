# REQ-216

> 本番の検査が結果を返すとき、見たすべての配備と項目に足りない物が無ければ、全体が通ったことを運用者に返す。

## 検証方針

- **分割クラス**:
  - `#all-pass-overall-pass` — 見たすべての配備と項目に足りない物が無いとき、全体が通ったことを運用者への出力と終了状態で返す
  - `#seen-items-listed` — 結果に、見た配備と項目が現れる（運用者が何を見たかを数えられる）
- **尽きている根拠**: 結果を返す入口の入力は「見た配備と項目」と「足りなかった物」の 2 つで、足りなかった物が 0 件のときだけがこの要件（1 件以上は REQ-220）。0 件のときに観測できるのは（全体が通ったこと）と（何を見たか）の 2 つに尽きる。
- **境界の扱い**: 足りない物 0 件（この要件）と 1 件（REQ-220 の `#one-problem-overall-fail`）が隣接の境界で、対で取る。
- **検証しない**: 出力の文言と並び（運用者が読む形で、契約の語彙に無い。OQ-119）。
- **参照先**: `tests/server/repay_UC-015_prod_check.test.ts::UC-015 本番の検査`（終了状態と、見た配備が出力に現れることで見る。文言は照合しない）。配備ごとに外から叩く本体は `scripts/check_sso_prod.sh`（system suite なので `@covers` を持たない）。
