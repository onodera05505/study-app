# REQ-552

> 運用者が投入を流すときに、登録簿に無い学びを渡したか、その学びの投入が書き出されていなければ、システムは保存先に触れずに断る。

## 検証方針

- **分割クラス**:
  - `#unknown-learning` — 登録簿に無い学びを渡す入力（本番へ・手元へのどちらでも、保存先に向けた操作を何もせず失敗で終わる）
  - `#seed-not-written` — 登録簿にある学びだが、その学びの置き場に投入が書き出されていない入力（同上）
- **尽きている根拠**: 断る理由は「登録簿に無い」「投入が無い」の 2 つに尽き、流す先（本番・手元）の 2 つの列は同じ振る舞いなので各クラスの中で両方を回す。観測は終了の状態と、保存先に向けた操作（構造の変更の確かめ・控え・投入）が 1 つも無いこと。
- **検証しない**: 断ったときの文言と、断る理由どうしの順（両方に当たる入力。契約の断りのコードは終了の状態だけでは見分けられない）。
- **参照先**: `tests/server/UC-032_seed_procedure.test.ts::UC-032 配備と投入の前に門を回し、通らない物を本番に出さない（投入の手続き）`（土台は `tests/server/UC-032_fixture.ts`。本番と手元の保存先は偽の SQLite、流す前の投入の検査・突き合わせ・控えの道具は決めた終了の状態で返す包み）
