# REQ-558

> 運用者が登録簿に無い学びを渡して学び側を配信しようとしたら、配備の手続きは登録簿の学びの一覧を示し、門を回さず何も配信しないまま断る。

## 検証方針

- **分割クラス**:
  - `#unknown-learning` — 登録簿に無い学びを渡して学び側を配信する入力（登録簿の学びの key をすべて示し、門を 1 つも回さず、配信しないまま失敗で終わる）
- **尽きている根拠**: 学びは登録簿にある・無いの 2 つで、ある側は REQ-561 の正常の入力が覆う。
- **検証しない**: 一覧の並び順と文言。
- **参照先**: `tests/server/UC-032_deploy_gates.test.ts::UC-032 配備と投入の前に門を回し、通らない物を本番に出さない（学び側の配備の手続き）`（土台は `tests/server/UC-032_fixture.ts`。門と描画の検査は決めた終了の状態で返す包み、本番の保存先は偽の SQLite）
