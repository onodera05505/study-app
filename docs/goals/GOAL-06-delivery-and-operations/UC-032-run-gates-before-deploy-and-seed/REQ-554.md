# REQ-554

> 運用者が投入を流すときに、流す前の投入の検査が問題を示したら、システムは控えも投入もせずに失敗で終える。

## 検証方針

- **分割クラス**:
  - `#seed-check-problem` — 流す前の投入の検査が問題を示す入力（本番へ・手元へのどちらでも、控えも投入もせず失敗で終わる）
- **尽きている根拠**: 流す前の投入の検査の結果は通る・問題を示すの 2 つで、通る側は REQ-555・557 の正常の入力が覆う。どの問題か（出典・正解の割れ・問題数）は UC-027 の checkSeed の分割が持つ。
- **検証しない**: 検査が見る問題の種類ごとの入力（UC-027 の checkSeed の範囲）。検査そのものが断る入力（投入が無い・登録簿に無い学び）は REQ-552 の範囲。
- **参照先**: `tests/server/UC-032_seed_procedure.test.ts::UC-032 配備と投入の前に門を回し、通らない物を本番に出さない（投入の手続き）`（土台は `tests/server/UC-032_fixture.ts`。本番と手元の保存先は偽の SQLite、流す前の投入の検査・突き合わせ・控えの道具は決めた終了の状態で返す包み）
