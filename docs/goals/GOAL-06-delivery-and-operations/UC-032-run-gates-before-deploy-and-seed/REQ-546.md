# REQ-546

> 運用者が学びを 1 つ渡して登録簿の門を回したとき、その学びが資格対策の学びなら見る物が無いことを、ロードマップ型の学びで回の語・印の語・束ね方に合う値が登録簿にそろっていれば束ね方とともに通したことを示して、システムは成功で終える。

## 検証方針

- **分割クラス**:
  - `#qualification-nothing-to-check` — 資格対策の学びを 1 つ渡したとき
  - `#chapter-roadmap-passes-with-grouping` — 章で束ねるロードマップ型の学びで、回の語・印の語・束ね方に合う値がそろっているとき
  - `#day-roadmap-passes-with-grouping` — 日で束ねるロードマップ型の学びで、回の語・束ね方に合う値がそろっているとき
- **尽きている根拠**: 文は通る学びを資格対策とロードマップ型に分け、ロードマップ型は束ね方を示すので、束ね方の 2 種（章・日）を別に置く。学びは登録簿の今の値から条件（種類・日の論点数の有無）で選ぶ。
- **境界の扱い**: 束ね方を示したことは、出力に束ね方の語（章・日、または chapter・day）があるかで見る。示す文言は文が決めていない。
- **検証しない**: 通したことを示す文言の形（文と契約が決めていない。終了コードで見る）。登録簿の値が欠けるとき（REQ-547）。
