# REQ-564

> 運用者が投入を流すときに、学びの次に渡した引数が手元の保存先へ流す指定でなければ、システムは門も控えも回さず、どの保存先にも何も流さずに断る。

## 検証方針

- **分割クラス**:
  - `#not-local-flag` — 学びの次に、手元へ流す指定でない引数（打ち間違えた指定・指定でない語・本番を名指す指定）を渡す入力（流す前の投入の検査も控えも回さず、どの保存先にも触れずに失敗で終わる）
  - `#before-seed-missing` — 投入が書き出されていない学びに、打ち間違えた指定を渡す入力（投入が無い断りより先に、同じく何も回さず失敗で終わる。契約の例 mistypedLocalBeforeSeedMissing）
- **尽きている根拠**: 第 2 引数は、無い・手元へ流す指定・それ以外の 3 つに尽き、前の 2 つは REQ-555 の 2 つのクラスが覆う。それ以外は打ち間違い・語・本番の名指しの 3 つの形を 1 つのクラスの中で回す。投入の有無で断る順が変わらないことを別のクラスで見る。
- **検証しない**: 空の文字列を第 2 引数に明示して渡す入力と、第 3 引数以降を渡す入力（文が「空」と「学びの次の引数」の読みを決めていない）。断ったときの文言。断りのコード（INVALID_INPUT と NOT_FOUND）の見分け（契約は終了の状態だけを決める）。
- **参照先**: `tests/server/UC-032_seed_procedure.test.ts::UC-032 配備と投入の前に門を回し、通らない物を本番に出さない（投入の手続き）`（土台は `tests/server/UC-032_fixture.ts`。本番と手元の保存先は偽の SQLite、流す前の投入の検査・突き合わせ・控えの道具は決めた終了の状態で返す包み）
