# REQ-353

> 学び側は、配備に与えられた学びの key に当たる登録簿の学びとして、その学びの名前・種類・1 回の問題数・制限時間・合否の目安・分野比率を登録簿の値のとおりに使って応える。

## 検証方針

- **分割クラス**:
  - `#every-registered-key-resolves` — 登録簿にあるどの学びの key を与えても、その学びとして応える（登録簿にある学びのどれも、解決できない側に落ちない）
  - `#values-from-registry` — 解決した学びの値が、その key の登録簿の値と同じ
- **尽きている根拠**: 入力は与えられた key で、登録簿にある key の側はこの文、無い・与えられていない側は REQ-354。登録簿にある側の観測は「どの key も解決する」と「解決した値が登録簿のとおり」の 2 つに尽きる。
- **検証しない**: 値そのもの（R-102。値の SSOT は `src/shared/targets.json`）。コードが学びの名前を列挙しないこと（BR-005 の配備の前の検査が持つ）。
- **参照先**: `tests/server/exam.test.ts::REQ-353 登録簿にある学びとして応える`（登録簿の値は書き写さず `src/shared/targets.json` から読む。どの key も解決することは、登録簿の解決と、その key の配備の死活確認と認証の形の応答の両方で見る）
