# REQ-262

> 学び側への要求が相手に届かず応答が返らないとき、画面は通信できなかったことを伝える固定の日本語の 1 文を利用者に伝え、内部の失敗の文をそのまま出さない。

## 検証方針

- **分割クラス**:
  - `#no-response-fixed-sentence` — 要求が相手に届かず応答が返らない（固定の日本語の 1 文で、内部の失敗の文を出さない）
- **尽きている根拠**: 入力は（応答が返る）（返らない）の 2 つで、返る側は REQ-261 の領域。返らない原因（圏外・名前の解決の失敗・遮断）は画面から区別できず、どれも同じ 1 文に倒れるので 1 クラスに畳む。
- **境界の扱い**: 返らないことと「返ったが失敗」の切れ目は応答の有無で、後者は REQ-261。
- **検証しない**: 固定の 1 文の語そのもの（実装が正本。R-102）。送り直しの仕組み（この文が述べていない）。
- **参照先**: `tests/client/api_helpers.test.ts::API 呼び出しの失敗の形`。
