# REQ-233

> 画面を開いたときに版の印が取れず最初の印を覚えていないときは、システムは次に取れた印を最初の印として覚え、その回は新しい版の知らせを出さない。

## 検証方針

- **分割クラス**:
  - `#adopt-and-silence` — 最初の印を覚えていない状態で印が取れた入力（その回は知らせを出さず、取れた印を最初の印として覚える＝次に同じ印でも知らせが出ないことで観測する）
  - `#adopted-then-changed` — 覚え直したあとに違う印が取れた入力（覚え直した印が見比べの相手になり、知らせが出る）
- **尽きている根拠**: UC.md の表「画面が覚えている最初の版の印」3 行目の「違う」「同じ」2 列はどちらも REQ-233 で、覚えていない状態では見比べる相手が無いので同じ観測（知らせを出さずに覚える）に落ちる。覚え直したあとの振る舞いが要件の後半で、2 つ目のクラスに置いた。その回も取れない入力は REQ-232 の範囲。
- **検証しない**: 何回取れなかったあとに取れたか（回数は振る舞いを変えない）。
- **参照先**: `tests/client/version.test.ts::新しい版の検知（UC-016）`（`#adopted-then-changed` は未被覆）
