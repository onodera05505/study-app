# REQ-543

> 運用者が学び側を配信するときにその学びの key に保存先が結んでいなければ、配備の手続きはその学びを配信しないまま止まる。

## 検証方針

- **分割クラス**:
  - `#learning-env-missing` — 設定にその学びの key の節そのものが無い入力（配信されず、手続きが失敗で終わる）
  - `#databases-missing` — その学びの key の節はあるが保存先の項目が無い入力（同上）
  - `#databases-empty` — その学びの key の節に保存先の項目はあるが 1 つも並んでいない入力（同上）
- **尽きている根拠**: 学びの key に保存先が結んでいない形は、key の節が無い・節に保存先の項目が無い・項目が空の 3 つに尽きる（どれも最上位の既定の保存先は残したままにし、既定に倒して配信する誤りを観測できるようにする）。観測は「配信されない・失敗で終わる」の 1 つ。
- **検証しない**: 止まったときの文言（運用者が読む形）。保存先を結び直す手順（運用の手順書が持つ）。まなびばの配備（要件は学び側だけ）。
