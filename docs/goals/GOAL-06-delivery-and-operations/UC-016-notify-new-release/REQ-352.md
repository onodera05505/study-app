# REQ-352

> プロジェクトが固定した版の配備の道具が入っていないとき、配備の手続きは別の版の配備の道具に倒さず、何も配信しないまま止まる。

## 検証方針

- **分割クラス**:
  - `#learning-stops-without-pinned-tool` — 固定した版の道具が入っていない状態で学び側の配備の手続きを回した入力（何も配信されず、手続きが失敗で終わる）
  - `#portal-stops-without-pinned-tool` — 同じ状態でまなびばの配備の手続きを回した入力（同上）
- **尽きている根拠**: 配備の手続きは 2 本に尽き、固定した版が入っていない入力への観測は「配信されない・失敗で終わる」の 1 つ。入っている側は REQ-351。
- **検証しない**: 止まったときの文言（運用者が読む形）。道具を入れ直す手順（運用の手順書が持つ）。
- **参照先**: `tests/server/repay_UC-016_deploy_procedure.test.ts::UC-016 配備の手続き（偽の配備の道具と組み立ての道具で回す）`（REQ-351 と同じ土台で、固定した版の位置を空にし、別の版の偽の道具だけを置いて回す）
