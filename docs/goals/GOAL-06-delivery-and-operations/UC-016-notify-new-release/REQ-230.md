# REQ-230

> 画面が開かれている間、システムは一定の間隔ごとに配信物から版の印を取り直し、覚えている最初の印と見比べる。

## 検証方針

- **分割クラス**:
  - `#interval-recheck` — 画面を開いたまま見比べの間隔が過ぎた入力（配信物から印を取り直して覚えている印と見比べる）
- **尽きている根拠**: 間隔ごとの見比べは「間隔が過ぎた」の 1 つの出来事で起き、見比べの結果の分岐は REQ-231・REQ-232・REQ-235 が持つ。
- **境界の扱い**: 間隔が過ぎる前は取り直さない（取りに行った回数で観測する）。
- **検証しない**: 間隔の値そのもの（機械可読な値なのでコードが正本。R-102。値を写すだけのテストには仕様外の印を付けた）。ログインしていない画面（事前条件の外。OQ-120）。
- **参照先**: 未検証（偽のタイマーで間隔を進めて取り直しを観測するテストが無い）
