# 用語集（ユビキタス言語）

**この表が業務の語彙の SSOT。** 新しい語をコードへ導入する前に、必ずここへ追加する。
同義語は「禁止同義語」列で明示的に殺す。空欄（—）は、材料に揺れが見つからなかった語。

型・識別子・値の並びはここに書かない（機械可読な物の SSOT はコード・DB・契約。R-102）。
画面に出す語が学びごとに違う概念（過去問／確認問題、模試）は、語の対応を登録簿が持つ。
この表の順守を見られるのは人のレビューだけで、機械の検査は無い（R-901 の説得的統制）。
領域の見出しは読む場所を絞るための区切りで、語の分類ではない（1 語は 1 行、1 か所）。

| 本人の記録 | 学び側にその利用者の分として作られる行で、その学びの理解度と受験履歴の持ち主。 | — |

## テストと演習

| 用語 | 定義 | 禁止同義語 |
| --- | --- | --- |
| テスト | 問題を出して回答を受け、締めて正答数を確定させる 1 回のまとまり。 | セッション（テストの意味で） |
| 回答 | 1 問について利用者が選んだ選択肢と、その正誤の記録。 | 解答（回答の意味で） |
| 演習 | 範囲を絞って問題を解くこと。 | — |
| 練習テスト | 演習の範囲と種別を選ぶ入口。 | — |
| 論点ドリル | 1 つの論点の問題だけを解く演習。 | 論点別ドリル・ドリル |
| 分野別演習 | 1 つの分野を範囲にした演習。 | — |
| 単元演習 | 1 つの単元を範囲にした演習。 | カテゴリ別演習・中分類演習 |
| 弱点復習 | 間違えた問題と、理解度の低い論点の問題を優先して解く演習。 | 復習 |

| ランダム構成 | 公開回によらず、分野の比率に沿って学びの全範囲から組む模試の構成。 | — |
| この日の確認 | ロードマップ型で、その日の単位だけを範囲に受けるテスト。 | — |
| 定着した問題 | 連続して正解したため、当面は出題しない問題。 | — |
| 出題時スナップショット | 出題した時点の問題文・選択肢・正解・出典の控えで、採点と振り返りはこれで行う。 | — |
| 進行中 | テストのうち、まだ締めていない状態。 | — |

| 中断 | 回答を残したまま、テストから抜けること。 | — |
| 再開 | 中断したテストを、現在位置から続けること。 | — |
| 破棄 | 進行中のテストと、その回答を捨てること。 | — |
| 締め | テストを終わらせて、正答数と時刻を確定させること。 | — |

| 受験履歴 | 締めたテストを新しい順に並べた一覧。 | — |
