# 用語集（ユビキタス言語）

**この表が業務の語彙の SSOT。** 新しい語をコードへ導入する前に、必ずここへ追加する。
同義語は「禁止同義語」列で明示的に殺す。空欄（—）は、材料に揺れが見つからなかった語。

型・識別子・値の並びはここに書かない（機械可読な物の SSOT はコード・DB・契約。R-102）。
画面に出す語が学びごとに違う概念（過去問／確認問題、模試）は、語の対応を登録簿が持つ。
この表の順守を見られるのは人のレビューだけで、機械の検査は無い（R-901 の説得的統制）。

| 用語 | 定義 | 禁止同義語 |
| --- | --- | --- |
| 学び | 1 つの学習対象（資格・分野・職種・業務）ごとに用意した学習の場。 | 対象・題材・試験（学びの意味で） |
| 資格対策 | 公開された試験問題を素材にする学びの種類。 | 資格版 |
| ロードマップ型 | 学ぶ順を自前に決め、教材と問題を自前に作る学びの種類。 | — |
| まなびば | 学びの入口で、アカウントと権限の正本。 | — |
| 利用者 | 権限を与えられた学びを使う人。 | ユーザー |
| 管理者 | アカウントと権限を作り変えられる人。 | — |
| アカウント | 1 人 1 つの認証の単位で、正本はまなびばが持つ。 | — |
| 権限 | アカウントごとに、どの学びを使えるかを決める許し。 | 役割（権限の意味で） |
| 役割 | アカウントが管理者か利用者かの区分。 | 権限（役割の意味で） |
| 分野 | 学びの最上位の区分で、資格対策では合否の判定の単位。 | — |
| 大項目 | 分野の下の大きな区分で、単元の一覧の見出しに出す。 | 大分類・テーマ |
| 単元 | 論点をぶら下げる区分。 | 中分類・カテゴリ |
| 論点 | 学習の最小単位となる知識項目で、紐づく問題の件数がその重要度になる。 | 単位 |
| 教材 | 論点の解説と周辺知識。 | — |
| 用語 | 本文の中で押すと 1 行の説明が出る語。 | — |
| 出題頻度 | その論点に紐づく過去問の件数で、そのまま学習の優先順位になる。 | — |
| 過去問 | 公開された試験問題 1 問。 | — |
| 確認問題 | ロードマップ型の学びのために自前に作った問題 1 問。 | — |
| 回 | 1 度の試験の実施単位。ロードマップ型では 1 日がこれに当たる。 | — |
| 出典 | その過去問がどの回の何問目かを示す表示。 | — |
| 一部改変 | 原本から変えた過去問に併記する印。 | — |
| 同一内容 | 本文と選択肢が同じ過去問どうしの関係。 | 重複 |
| 他の出典 | 同一内容の過去問のうち、代表以外の回の出典。 | — |
| 問題解説 | 1 問ごとの正解の根拠と、選択肢ごとの 1 行の説明。 | — |
| 理解度 | 論点ごとに利用者が自分で残す、理解の段階。 | — |
| 未理解 | 理解度の段階のうち、まだ理解していない状態。記録の無い論点もこれとして扱う。 | — |
| やや理解 | 理解度の段階のうち、途中まで理解した状態。 | — |
| 理解 | 理解度の段階のうち、理解できた状態。 | — |
| 演習 | 範囲を絞って問題を解くこと。 | — |
| 練習テスト | 演習の範囲と種別を選ぶ入口。 | — |
| 論点ドリル | 1 つの論点の問題だけを解く演習。 | 論点別ドリル・ドリル |
| 分野別演習 | 1 つの分野を範囲にした演習。 | — |
| 単元演習 | 1 つの単元を範囲にした演習。 | カテゴリ別演習・中分類演習 |
| 弱点復習 | 間違えた問題と、理解度の低い論点の問題を優先して解く演習。 | 復習 |
| 模試 | 本番形式で通しで受けるテスト。画面に出す語は学びごとに違う。 | 模擬試験・本番形式 |
| この日の確認 | ロードマップ型で、その日の単位だけを範囲に受けるテスト。 | — |
| 定着した問題 | 連続して正解したため、当面は出題しない問題。 | — |
| 出題時スナップショット | 出題した時点の問題文・選択肢・正解・出典の控えで、採点と振り返りはこれで行う。 | — |
| 進行中 | テストのうち、まだ締めていない状態。 | — |
| 完了 | テストのうち、締めて正答数が確定した状態。 | — |
| 中断 | 回答を残したまま、テストから抜けること。 | — |
| 再開 | 中断したテストを、現在位置から続けること。 | — |
| 破棄 | 進行中のテストと、その回答を捨てること。 | — |
| 締め | テストを終わらせて、正答数と時刻を確定させること。 | — |
| 時間切れ | 制限時間を過ぎたために自動で締められた回。 | — |
| 制限時間 | 模試で与えられる持ち時間。時間を置かない学びもある。 | — |
| 合否の目安 | 素点の割合から出す近似の判定で、公式のスコアとは算出が違う。 | — |
| 受験履歴 | 締めたテストを新しい順に並べた一覧。 | — |
| 次に学ぶ | 出題頻度が高く、まだ理解していない論点の提示。 | 次の一手 |
| 前回の続き | 最後に開いた論点と画面へ戻る導線。 | — |
| 連続記録 | 学びを開いた日が続いている日数。 | 連続日数 |
| ロードマップ | ロードマップ型で、学ぶ順に日ごとに並べた単位の一覧。 | — |
| フィードバック | 利用者が、開いていた画面を添えて送る自由記述の声。 | — |
| 版の印 | 配信のたびに配信物へ書き出す、その版を見分ける値。 | — |
| 新しい版 | 画面が持っている版より新しい版が配信されている状態。 | — |
| 死活確認 | 認証なしで、学びとまなびばが生きていることを確かめる応答。 | — |
| 登録簿 | 学びごとの名前・種類・値をまとめた 1 か所で、値の正本。 | — |
