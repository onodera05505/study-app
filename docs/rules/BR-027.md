# BR-027 過去問には出典を併記し、原本から変えたものには一部改変を併記する

公開された試験問題を出すときは、回と問番号の出典を必ず併記し、原本から変えた問題には一部改変を併記する。自前に作った確認問題には出典を出さない。

**意図**: 公開された試験問題の利用条件（出典の明記・改変の明記）は必須で、破れば利用そのものが成り立たないこと（要件定義書 §9）。
