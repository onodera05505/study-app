# BR-038 回の並びは実施の時期の順

回の一覧は、回の実施の時期で並べる。資格対策の学びでは実施が新しい回を先にし、同じ年度の中は秋期・10 月・特別（夏）・春期の順に置き、季節の記号の無い回はその年度の中で最も新しい回として、その年度の先頭（秋期より前）に置く。資格対策の学びでは投入データの並びや鍵の順には頼らない。ロードマップ型の学びでは回の識別子の順を学ぶ順の正本として最初の回から並べ、補足の回は一覧の末尾に置く。値の SSOT は回の一覧を返すサーバの経路にある季節の記号と順位の定数で、学びの種類は登録簿（`src/shared/targets.json`）が持つ。

**意図**: 資格対策では直近の回から解くと出題の傾向に近い順に模試を受けられ、ロードマップ型では学ぶ順のまま回を受けられるようにすること。学びごと・年度ごとに並びが揺れ、利用者が回を探し違えるのを防ぐ（GOAL-02）。
