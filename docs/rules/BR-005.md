# BR-005 学びごとの値と運用の設定値の正本は、登録簿と app_settings の 1 か所

学びの名前・種類・1 回の問題数・制限時間・合否の目安・分野比率は登録簿が正本で、運用で変える設定値は `app_settings` が正本。文書とコードはこれらの値を持たず、コードは学びの名前を列挙しない。

**意図**: 学びを足したときに、足し忘れた場所で黙って別の値になるのを防ぐこと（不変条件 D14・D15）。
