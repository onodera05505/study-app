# BR-054 教材の本文で図として扱うのは図の行の形に合う行だけで、図の置き場を指すのに形に合わない行は図としても文字としても配らない

教材の本文の行のうち図として扱うのは、行全体が 1 つの画像の記法で、その指す先が配信の置き場の図の画像を指す形に合う行（図の行）だけ。図の行の形（行頭と行末に置ける空白・図の説明文・指す先の段と字）の値の SSOT は `docs/_shared/components.yaml` の `MaterialFigureLine`、図の行の指す先は `MaterialFigureSrc`、図を PNG に描いて出力先に置く先は `MaterialFigurePng`。本文の行が配信の置き場の図を指す前置き（`MaterialFigureRefPrefix`）を含むのに図の行の形に合わないとき、その行は図の行でも本文の文でもない。本文を読む道具はその行を図としても文字としても扱わず、その行を挙げて止める。画面はその行を図として出さない。図の行の画像が置き場所に実在することは BR-026 が持つ。

**意図**: 同じ配る本文が、画面・図の差し込み・学習者役のパック・単元の読み物・教材の門で別の物に読まれると、学習者役が読んだ物と利用者が見る物がずれて測った結果が利用者の見え方に結び付かず、図が出力先や置き場所の外を指す。図の行の読みを 1 つにし、どの読み手でも図か壊れた行かが同じに決まるようにする（GOAL-12。図が黙って空欄になる・別の物が出ることを止める点で BR-026 と同じ不変条件 D6）。
