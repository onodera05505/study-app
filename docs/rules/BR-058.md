# BR-058 資格対策の単元の構成は、全体像とまとまりの名前と説明を空でなく持ち、論点に自分自身を前提にさせない

資格対策の単元の構成は、単元の全体像と、まとまりごとの名前と説明を、どれも空でない文として持つ。論点の前提の論点は、その論点自身でない。単元の構成の形の SSOT は単元の構成の門の `contract.yaml`、保存の形の SSOT は `src/server/db/schema.ts`。

**意図**: 全体像とまとまりの名前と説明は、利用者が単元の一覧で読む単元の中の区分の見出しと説明で、空のまま届くと中身の分からない区分が出る。自分自身を前提に示すと、論点の画面に同じ論点へ戻るだけの導線が出る。門を通らない経路で表に入っても、保存の側でこの形を崩さない（GOAL-10）。
