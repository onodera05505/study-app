# BR-062 用語集は、問題解説の注記と教材から作る

学びの用語集は、人が別に書かず、問題解説の選択肢ごとの用語と注記から作る。同じ語が複数の問題にあるときは、回の最も新しい問題の注記を採り、その注記から正解の印を除いた 1 文目を語の 1 行の説明にする。説明には用語と強調の記法を残さない。学びの置き場に用語の上書きがあれば、その説明と論点の結び付けを使う。教材や問題解説の本文で用語として示した語のうち説明の無い語は、名前か別名が一致する論点の短い説明の 1 文目で補い、補えない語は用語集に入れない。語に論点を結ぶのは、語が論点の名前か別名と完全に一致するときだけ。上書きと別名の置き場の値の SSOT は `scripts/build_seed.py` の `build_glossary`。

**意図**: 用語の説明に、その問題の正解との対比（注記の 2 文目）が持ち込まれて他の問題の文脈で浮くのを防ぎ、説明を新しい回の言い回しにそろえる。部分一致で別の論点へ飛ばさず、本文で用語として示した語が黙って素の文字のまま出るのを、どの道具でも同じ用語集で見つけられるようにする（GOAL-01・UC-001 の用語の説明）。
