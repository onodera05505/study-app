# BR-048 単元の構成は、教材の門を通ったものだけを使う

資格対策の学びの単元の構成は、教材の門（単元の構成の門）の止める理由に当たらないものだけを、書き直しの束を作るとき、書き直した世代の教材を確かめるとき、配る本文と単元の構成を投入に組み立てるとき、単元の読み物を作るときに使う。学びの全部の単元の構成と合わせて判定した単元の構成の門の止める理由のうち、その道具が使う単元（束を作る単元、確かめる論点がある単元、投入に組み立てる単元、読み物にする単元）に関する物があれば、それを読む道具は使わずに止め、その単元を示す。前提の循環のように複数の単元の構成にまたがる止める理由は、それに入るすべての単元に関する物とする。単元の構成の形と上限の値の SSOT は単元の構成の門の `contract.yaml`。

**意図**: 論点の抜けや重なり、実在しない前提を持つ単元の構成から束や画面が作られると、学ぶ順の欠けた論点が書き直されずに残るか、利用者に存在しない論点への導線が出る。教材と分類がそろっている論点の割合を保つ（GOAL-10・KPI-02）。
