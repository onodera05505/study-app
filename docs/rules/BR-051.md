# BR-051 出題回数の印は、論点の出題頻度を 3 段に切る

資格対策の学びでは、論点に出題回数の印を添える。段は論点の出題頻度（取り込み済みの回での件数。同一内容を数えたまま。BR-028）から求め、1 なら最も低い段（★）、2 なら中の段（★★）、3 以上なら最も高い段（★★★）とする。出題頻度が 0 の論点には印を付けない。段は投入データに持たせず、出題頻度から求める（回を取り込むと段も変わる）。段の境目の値の SSOT は `src/server/lib/frequency-tier.ts` の `FREQUENCY_TIER_FLOORS`。

出題回数の印はロードマップ型の印（各単位の段を投入データが持つ）とは別の物で、ロードマップ型の学びには付けない。

**意図**: 単元の中を学ぶ順に並べても（BR-031）、出題頻度＝重要度（設計の中核）を一目で分かるように残す。世の中の教材は頻度を並び順ではなく印に使っている。段を出題頻度という事実に結ぶのは、順位の分位で切ると回を足すたびに境目が動くため。
