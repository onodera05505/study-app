# BR-043 表示の制約は警告にとどめ、止めない

教材の門は、表の列の数・行の数・セルの字数と、用語の説明に使う選択肢ごとの説明の字数が表示の制約から外れるとき、その箇所を警告として挙げ、止める理由にはしない。列か行が 1 つだけの表も表示の制約から外れる表に数える。区切りの行が無い表と行ごとのセルの数がそろわない表は、表示の制約でなく記法の誤り（BR-025）として扱う。値の SSOT は各教材の門の `contract.yaml` の `limits`。

**意図**: 画面の横幅や用語の説明の 1 行に収まらない本文は人が見て直すが、それを理由に必要な情報を通さないことはしない（GOAL-10・KPI-02）。
