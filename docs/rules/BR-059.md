# BR-059 論点は、学びの中で小項目と名前の組ごとに 1 つ

1 つの学びの中で、同じ小項目に同じ名前の論点は 2 つ存在せず、同じ組の論点を別の論点として保存しようとしても保存されない。値の SSOT は `src/server/db/schema.ts` の topics の一意制約 `uq_topic_term`。

**意図**: 同じ論点が 2 つの行に割れると、紐づく過去問の件数である出題頻度が 2 つに分かれ、出題頻度を重要度として並べる学び方（GOAL-01）が崩れること。
