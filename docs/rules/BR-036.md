# BR-036 項目名と値の組を並べた選択肢は項目ごとに行を分ける

項目名と値の組を区切りで並べた選択肢は、項目ごとに行を分けて示す。短い選択肢は分けない。どちらの場合も選択肢の文字列そのものは変えない。分ける・分けないの判定の値の SSOT は、整形を行うコードの定数。

**意図**: 組合せを問う過去問の選択肢を 1 行に詰めると読み違えが起き、正誤が理解の有無ではなく読み取りの失敗で決まってしまうのを防ぐこと（GOAL-01 / KPI-03）。出題の画面と結果の振り返りのどちらでも同じ形で示す。
