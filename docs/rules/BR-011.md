# BR-011 端末の記憶が使えないときは、その機能を出さないだけにする

端末が値を覚えられないとき、または覚えた値が読めないときは、その記憶に頼る機能を出さないだけにして、画面の他の部分を止めない。

**意図**: 端末の設定や容量の事情で学び全体が使えなくなるのを防ぐこと（要件定義書 §16.5）。
