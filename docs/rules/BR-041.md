# BR-041 外から取る値が取れないときは、誤った知らせを出さない側に倒す

画面が配信物や端末の記憶など外から取る値を取れなかったとき、または取れた値が決められた形でないときは、その値が無いものとして扱い、その値を根拠にした知らせや導線を出さない。取れなかったことそのものを利用者に知らせる義務は持たない。

**意図**: 取れなかった値から「新しい版がある」「前回の続きがある」と誤って伝え、利用者が要らない読み直しや存在しない行き先へ導かれるのを防ぐこと（配信した版が使っている人に正しく届く GOAL-06・KPI-07）。
