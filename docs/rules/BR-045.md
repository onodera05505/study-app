# BR-045 理解度は色によらず段階の名前で分かるように示す

理解度を示す所と理解度を選ぶ操作は、学びの種類によらず、どの段階かと、どの選択肢が今記録されている段階かを、色を見分けられなくても段階の名前で分かるようにする。段階の名前の値の SSOT は `src/client/lib/api.ts` の `STATUS_LABEL`。

**意図**: 色だけで段階を伝えると、色を見分けにくい利用者や読み上げで使う利用者には理解済みかどうかも、押したら何が記録されるかも分からず、理解度を付けて辿る学び方（GOAL-01・GOAL-03）が成り立たないこと。
