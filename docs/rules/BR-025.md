# BR-025 本文は、決めた記法だけを解釈する

教材・問題解説・確認問題の本文は、決めた記法だけを解釈し、それ以外は書かれた文字のまま出す。用語のポップも同じ本文から出る。

**意図**: 記法が文字のまま出ることと、意図しない記法が解釈されることは、どちらも本文の信頼を崩すこと（不変条件 D10・要件定義書 §16.1）。
