# BR-055 学習者役で教材を測る道具の入口は、コマンドの引数を 1 つの読み方で契約の request に写し、形の外の引数を名前で挙げる

学習者役で教材を測る道具の入口は、コマンドの引数を次の 1 つの読み方で契約の request に写す。`--` で始まる語は常に引数の名前で、`--名前=値` はその名前と `=` より後の値の組、`=` を持たない `--名前` はすぐ後の語が `--` で始まらなければその語を値とする組とする（`-` 1 字で始まる語もそのまま値）。引数の名前は契約の request の欄の名前とちょうど同じときだけその欄に写し、前の部分だけが同じ名前（省略形）は契約に無い名前とする。整数の欄は 10 進の数字だけの値を整数として写す。

次のどれかに当たる引数は契約の引数の形の外とする。値を持たない名前、2 回以上現れる名前（値を問わない）、契約の request に無い名前、どの名前の値でもない語、欄の型と形に合わない値、渡されない必須の欄。形の外の引数があるとき、入口が返す断りの `arguments` には当たった物を 1 回ずつ挙げる。名前は先頭の `--` と `=` より後を除いた名前で挙げ、どの名前の値でもない語はその語のまま挙げる。並びは、契約の request の欄を request に並ぶ順に、続けて契約に無い名前と語をコマンドに現れた順にする。

**意図**: 作り手が断られたときに直す引数を 1 回で全部知り、道具が作り手の意図と違う値（重なった名前の後ろの値・省略形の名前・値と見分けのつかない語）で黙って作られないようにする。入口ごとに引数の読み方が分かれると、同じコマンドが入口によって通ったり断られたりし、契約から期待が立たない（GOAL-12）。
