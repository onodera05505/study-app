# BR-003 学びへ渡す使い捨てコードは、発行する時点と交換する時点の両方で権限を確かめる

学びへ入るための使い捨てコードは、発行する時点で権限を確かめ、学び側から交換される時点でもう一度確かめる。1 度使ったコードと期限を過ぎたコードは交換しない。使える回数と期限の値の正本は、まなびばの DDL と交換の経路。

**意図**: 権限を外した直後の要求や、拾われたコードで学びに入れないこと（不変条件 D18）。
