# BR-039 パスワードの記録の形

まなびばが保存するパスワードの記録は、同じパスワードでだけ照合に通り、違うパスワードと記録として成り立たない値では通らない。同じパスワードを保存し直しても、記録は前の記録と一致しない。記録を作る計算と照合の計算は、配備先の実行環境が課す上限の内に収まる。上限の値の SSOT は `scripts/check_source.py` の上限の定数（不変条件 O5）で、記録を作る計算量の値の SSOT はコード。

**意図**: 記録が漏れても、同じパスワードを使う人どうしが記録の一致から分からないようにすること。開発の環境が上限を課さないために本番の配備でだけログインが想定外の失敗になることを防ぎ、まなびばのアカウント 1 つで学びに入れる状態（GOAL-08・KPI-08）を本番で保つこと。
