# BR-039 パスワードの記録の形

まなびばが保存するパスワードの記録は、同じパスワードでだけ照合に通り、違うパスワードと記録として成り立たない値では通らない。同じパスワードを保存し直しても、記録は前の記録と一致しない。配備された版が保存した記録は、以後の版でも、作ったときと同じパスワードでだけ照合に通り続ける（時間の境界 R-1202）。記録の形の SSOT は、配備された版が作った記録を追記だけで残す `contracts/fixtures/` の見本。記録を作る計算と照合の計算は、配備先の実行環境が課す上限の内に収まる。上限の値の SSOT は `scripts/check_source.py` の上限の定数（不変条件 O5）で、記録を作る計算量の値の SSOT はコード。

**意図**: 版を差し替えても、本番の保存先に今ある記録の持ち主がそれまでのパスワードで入れ続けること。記録が漏れても、同じパスワードを使う人どうしが記録の一致から分からないようにすること。開発の環境が上限を課さないために本番の配備でだけログインが想定外の失敗になることを防ぎ、まなびばのアカウント 1 つで学びに入れる状態（GOAL-08・KPI-08）を本番で保つこと。
