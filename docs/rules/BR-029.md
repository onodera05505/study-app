# BR-029 回答も理解度の記録も無い論点の扱いは、学びの種類で決まる

資格対策の学びでは、論点に紐づく過去問への回答も理解度の記録も無い論点を「未」とし、未理解とは別の段階として示し、集計で数え、理解度の絞り込みで選べるようにする。次に学ぶの候補とおすすめ順では、未を「まだ理解していない論点」に含める（BR-030）。

ロードマップ型の学びでは、理解度の記録が無い論点を未理解として扱い、未は使わない。

どちらの学びでも、この扱いは論点の示し方・分野と単元の集計・理解度の絞り込み・「次に学ぶ」の候補・おすすめ順のすべてで同じにする。

**意図**: 同じ既定にすべてが依るため、ここがずれると同じ論点が画面ごとに違う段階に見えること（要件定義書 §5.1）。資格対策で「まだ解いていない」と「解いて間違えた」を分けるのは、理解度が回答から判定されるようになり（BR-049）、解いていない論点を未理解と出すと、間違えた論点と見分けられなくなるため。
