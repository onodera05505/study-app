# BR-007 パスワードを変えた人によって、開いているログインの扱いが変わる

管理者が他人のパスワードを再設定したときは、その人が開いている全ての端末のログインを切る。本人が自分のパスワードを変えたときと、本人がログアウトしたときは、他の端末のログインを残す。

**意図**: 乗っ取りの疑いで再設定したとき、開いたままの端末から入り続けられないようにすること。本人による変更で他の端末まで切って使い勝手を落とさないこと（要件定義書 §4・§15）。
