# BR-002 利用者向けの失敗の応答は、内部の事情を明かさない

利用者向けの経路で認証・権限・想定外の失敗を伝える応答は、アカウントが登録されているかどうか、設定や共有秘密があるかどうか、例外の中身で文を変えない。

**意図**: 断りの文の違いからアカウントの存在を探れないようにし、設定の不足や内部の作りを外へ出さないこと（要件定義書 §10・§15）。
