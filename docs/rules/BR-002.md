# BR-002 利用者向けの失敗の応答は、内部の事情を明かさない

利用者向けの経路で認証・権限・想定外の失敗を伝える応答は、アカウントが登録されているかどうか、秘密が与えられているかどうか、例外の中身で文を変えない。配備にまなびばの場所が与えられているかどうかは、画面の分岐のために公に答える設定なので、この規則の射程に入らない。

**意図**: 断りの文の違いからアカウントの存在と配備の秘密の状態を探れないようにし、内部の作りを外へ出さないこと。GOAL-08「1 つのアカウントで学びに入る」を、入口を探る手がかりを与えずに成り立たせる。
