# BR-052 問題解説は、同一内容の過去問の組に結ぶ

資格対策の学びの問題解説は、同一内容の過去問の組（BR-028）ごとに 1 つ書き、過去問への結び付けは問題の番号でなく同一内容の判定で行う。過去問の側を同一内容の組で 1 件に畳む道具は、問題解説も同じ判定で結ぶ。同一内容の判定の作り方（本文と選択肢のどの文字を、どの順に、どう正規化して要約するか）の値の SSOT は `scripts/build_seed.py` の `content_key_of`。境界でその値を受け渡す道具は、作り方をその契約に写して持つ。

**意図**: 同じ問題が回をまたいで出ても解説を 1 つに保ち、学習の側で 1 件に畳んだ過去問とその解説が食い違わないようにする（設計の中核「同一内容の過去問は DB に全問残し、学習側だけで 1 問にまとめる」。GOAL-11・KPI-02）。
