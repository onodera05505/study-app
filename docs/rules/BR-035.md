# BR-035 図は押すと原寸と画面幅との間で表示が切り替わる

教材の図も過去問の図も、押すと表示が原寸と画面幅との間で切り替わる。図の表示はこの 2 つだけで、押す操作はその往復。切り替えたあとの実際の寸法は画面に依るのでこの規則は持たない。

**意図**: 画面幅に収めると読めない細かい図を、画面を離れずに原寸で読めるようにし、図のある論点が読み切れずに残るのを防ぐこと（GOAL-01 / KPI-03）。
