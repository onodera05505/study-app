# BR-026 教材と過去問の図は、置き場所に実在する画像だけを指す

教材と過去問が指す図は、配信の置き場所に実在する画像だけ。実在を保証するのは投入の検査で、画面は図が無いときの分岐を持たない。図の置き場所は学びごとに分け、学びをまたぐ識別子の一意性を仮定しない。

**意図**: 図が黙って空欄になること、別の学びの図が出ることを、投入の時点で止めること（不変条件 D6）。
