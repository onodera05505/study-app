# BR-044 学び側のトークンは、その配備の秘密で作られ期間内のものだけが通る

学び側が本人の要求として扱うトークンは、その配備の署名の秘密で作られ、発行から決められた期間を過ぎていないものだけ。それ以外のトークンは本人のものとして通らない（断りの形は BR-001）。期間の長さの値の SSOT は学び側のサーバのコードの定数。

**意図**: 書き換えたトークン・別の配備のトークン・古いトークンで他人や過去の本人として入り続けられないようにし、まなびばで権限を与えられた人だけが学びに入れる状態（GOAL-08・KPI-08）を保つこと。
