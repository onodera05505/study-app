# BR-040 テストの範囲の名前は空にならない

どの種別のテストも、作られた時点から範囲の名前を持ち、範囲の名前の無いテストは保存されない。値の SSOT は `src/server/db/schema.ts` の sessions の `scope_label` の列の制約（NULL も空の文字列も拒む）。

**意図**: 受験履歴・ホームの最近の結果・進行中のテストの案内が、どのテストかを範囲の名前で示せない行を生まないこと（GOAL-01・GOAL-02）。
