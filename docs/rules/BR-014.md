# BR-014 取得の失敗は読み直す手段を添え、操作の失敗は押し直せるようにする

取得（一覧・集計・教材・問題・結果）の失敗は、その中身が出るはずだった場所に失敗した旨と理由を出し、読み直す手段を添える。操作（理解度の記録・回答・締め・破棄・送信）の失敗は、理由を出して押し直せるようにし、画面の中身を消さない。画面の一部だけが取れなかったときは、取れた部分を出す。

**意図**: 失敗を黙って空にすると、利用者が「無い」と「取れなかった」を区別できないこと（要件定義書 §16.5）。
