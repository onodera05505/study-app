# BR-037 ロードマップの回の語・章の名前・印は、欠けたまま配備も投入もしない

ロードマップ型の学びは、回の見出しの語・回の数の語・回ごとの確認の語を登録簿に持ち、印を持つ学びは印の段ごとの語も登録簿に持つ。投入データは、章で束ねる学びでは各回の名前を、印を持つ学びでは補足の論点を含む各単位の印を、登録簿にある段で持つ。学ぶ順を持つ単位は回を持ち、日で束ねる学びでは、その回は学ぶ順と 1 日の論点数から決まる回と一致する。回ごとの確認の問数は、日で束ねる学びでは登録簿の 1 回の問題数（日で束ねる学びだけの値）、章で束ねる学びではその回の単位数に 1 単位あたりの確認問題の数を掛けた数と一致する。補足の回（登録簿の exemptRounds）は問数の一致を見ない。BR-032 の「回ごとの問題数が合う」はこの数と比べ、補足の回を除いて読む。どれかが欠けた・食い違う学びは配備せず、そのデータは投入しない。画面のコードは欠けたときの代わりの語を持たない。値の SSOT は `src/shared/targets.json` と投入データ。

**意図**: 学びを足したときに、語や印が欠けたまま別の学びの語（「〇日目」など）で黙って出るのを止めること（GOAL-03。BR-005 の「コードは学びの値を持たない」を、表示の語の欠けにまで広げる）。
