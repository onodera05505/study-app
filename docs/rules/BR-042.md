# BR-042 教材の門は、情報の量を見ない

教材の門は、教材・要約・確認問題・問題解説の字数・文数・見出しの数・箇条書きや比較の項目の数を、多くても少なくても、止める理由にも警告にもしない。要る情報かどうかは執筆の仕様書の判断の基準で決め、要らない文は読み直しと学習者役の周で見つける。表示の制約（BR-043）は情報の量でなく画面に収まるかの制約で、この規則の外にある。確認問題の選択肢の長さや読点の数の偏りのように、読まずに正解を当てられる手がかりも、情報の量でなく問題の形の偏りで、この規則の外にある。

**意図**: 字数・文数の上限が執筆の仕様書と門でかみ合わず、必要な情報が量の都合で削られるのを止めること（GOAL-10・KPI-02）。
