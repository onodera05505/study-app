# BR-028 同一内容の過去問は、学習の側だけで 1 件にまとめる

本文と選択肢が同じ過去問は、学習の側と繰り返し使う出題では 1 件にまとめ、代表を回の新しいものにして、同一内容の件数と他の出典を回の新しい順に添える。公開回をそのまま通しで受ける形では畳まない。出題頻度は同一内容を数えたまま残し、DB には全問を残す。

**意図**: 同じ問題が繰り返し出るのを避けながら、出題頻度＝重要度（設計の中核）を崩さず、本番の追体験は原本どおりに保つこと（要件定義書 §3.1・§16.2）。
