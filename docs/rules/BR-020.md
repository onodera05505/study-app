# BR-020 採点と振り返りは、出題した時点の内容で行う

出題した時点の問題文・選択肢・正解・出典を控え、採点と振り返りはその控えで行う。あとで問題データを直しても、締めたテストの結果は変わらない。

**意図**: データの修正が過去の受験結果を書き換えないこと（要件定義書 §5.7）。
