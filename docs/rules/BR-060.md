# BR-060 過去問は、学びの中で回と問番号の組ごとに 1 つ

1 つの学びの中で、同じ回に同じ問番号の過去問は 2 つ存在せず、同じ組の過去問を別の過去問として保存しようとしても保存されない。同一内容の過去問（BR-028）は、回か問番号の違う別の過去問として残る。値の SSOT は `src/server/db/schema.ts` の past_questions の一意制約 `uq_question_exam_number`。

**意図**: 出典（BR-027）が指す過去問が 1 つに決まり、公開回をそのまま通しで受ける模試が原本の問番号どおりに 1 問ずつ並ぶこと（GOAL-02）。
