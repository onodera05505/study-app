# BR-008 アカウントのメールアドレスは一意

同じメールアドレスのアカウントは 2 つ存在しない。同時に作ろうとしたときも、通るのは 1 つだけ。

**意図**: メールアドレスが、学びをまたいで同じ人を指す唯一の鍵であること（要件定義書 §15 の名寄せ）。二重になると権限と本人の記録が別人のものに分かれる。
