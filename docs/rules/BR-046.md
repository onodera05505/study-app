# BR-046 タブの段が別の段に並ぶ狭い画面では、上部のヘッダーは下へ読み進めるとタブの段だけを残して縮み、少しでも上へ動くと元に戻る

学びの種類によらず、学びのどの画面でも、上部のヘッダー（学びの名前・まなびばへの導線・アカウント・タブ）は、タブの段が学びの名前・アカウントの段と別の段に並ぶ狭い画面のときにだけ、利用者が下へ読み進めるとタブの段だけを残して縮み、直前の読み位置から少しでも上へ動くと元の姿に戻る。タブの段が学びの名前・アカウントと同じ段に並ぶ広い画面のときは縮まず、縮んでいる間に画面が広がってタブの段がその同じ段に並んだときは元の姿に戻る。狭い画面でも、アカウントのメニューを開いている間と、縮むと操作できなくなるタブの段の外の部品にフォーカスがある間は、下へ読み進めても縮まない。タブの段の中にフォーカスがあることと、メニューを閉じた後にメニューを開く部品に残ったフォーカスは、縮むのを止めない。メニューを閉じたときとタブの段の外の部品からフォーカスが外れたときは、その瞬間には縮まず、次に下へ読み進めたときに縮む。縮むときに、縮むと操作できなくなる部品にフォーカスがあれば、フォーカスを本文の先頭へ移して失わせない。縮んでいる間もタブの段の項目と行き先は縮む前と同じで、端末が動きを減らす設定のときは、縮みと戻りを動きを伴わずに切り替える。

**意図**: 本文を読み進めている間はヘッダーが読む場所を狭めず、どの画面でも行き先のタブには手が届くままにして、教材を読み切って次の論点へ進む学び方（GOAL-01・GOAL-03）を妨げないこと。ヘッダーが読む場所を狭めない広い画面では縮めず、利用者が開いているメニューや操作している部品を目の前から消さず、読み位置を動かしていない瞬間にヘッダーを動かさず、縮んで見えなくなった部品にフォーカスを置き去りにしない。動きに弱い利用者には動きを見せない。
