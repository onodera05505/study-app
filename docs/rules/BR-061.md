# BR-061 学習者役で測る道具の入口は、結果か断りを契約の形の JSON 1 つで示し、終了の状態で成功と断りを分ける

学習者役で測る道具の入口は、標準出力に JSON を 1 つだけ出す。止まらずに終わったときは契約の response の形の JSON を出して契約が成功に定める終了の状態で終わり、契約の errors に当たって断ったときは契約の `ToolError` の形の JSON を出して契約が断りに定める終了の状態で終わる。

**意図**: 作り手と検査が、出力の文を読み分けずに終了の状態で成功と断りを分け、断ったときに直す物を契約の形の欄から読めるようにする（GOAL-12）。
