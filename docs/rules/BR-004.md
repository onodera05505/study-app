# BR-004 学びを指す値は、登録簿に実在する学びだけを受け付ける

権限の付け外し、学びへの入場の要求など、学びを指す値を受け取る経路は、登録簿に実在する学びだけを受け付ける。学びの一覧の正本は登録簿（BR-005）。

**意図**: 綴りの違う学びの権限が黙って作られ、誰も使えない権限や存在しない学びへの入口が残るのを防ぐこと（要件定義書 §4・§15）。
