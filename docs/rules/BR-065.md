# BR-065 学び側の DB の外部キーは、構造の宣言と構造の変更を流した DB とで同じ

学び側の DB の外部キー（参照する列・参照先の表と列・参照先を消したときの扱い）は、構造の宣言と、構造の変更をはじめから順にすべて流して作った DB とで同じである。外部キーの値の SSOT は構造の宣言で、構造の変更はそれと同じ外部キーを作る。

**意図**: 配備の DB は構造の変更を流して作られ、サーバのコードは構造の宣言を前提に読み書きする。外部キーが 2 つの間で食い違うと、規則のテストが構造の変更を流した DB で確かめた制約と、コードが前提にする制約が別の物になり、利用者の進捗や受験履歴が消える・消えずに残るといった扱いが、確かめたとおりにならない（形の正本を構造の宣言と構造の変更の 2 つに置く決定は ADR-0004）。
