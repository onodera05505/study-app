# BR-030 「次に学ぶ」の定義は、学びの中で 1 つ

「次に学ぶ」は「まだ理解していない論点（未理解・やや理解。記録の無い論点の扱いは BR-029）を、その学びの種類の並び（BR-031）で並べたもの」であり、資格対策の学びでは出題頻度の高い順になる。ホーム・論点の画面・一覧のおすすめ順は、すべてこの 1 つの定義を使う。一覧のおすすめ順は、まだ理解していない論点をこの並びで先に置き、理解にした論点を除かずに最後へ、同じ種類の並びで置く。未理解とやや理解は分けずに 1 つの並びにする。

**意図**: 出題頻度 × 未理解が最短合格経路の実体（設計の中核）で、画面ごとに定義が分かれると別の道を指すこと（要件定義書 §3.1・§5.1）。
