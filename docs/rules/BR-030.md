# BR-030 「次に学ぶ」の定義は、学びの中で 1 つ

「次に学ぶ」は「まだ理解していない論点を、学びの種類で決まる次に学ぶの並びで並べたもの」である。まだ理解していない論点は、資格対策の学びでは理解度が未・未理解・やや理解の論点（段階は BR-049・BR-050・BR-029 で決まる）、ロードマップ型の学びでは未理解・やや理解の論点（記録の無い論点は BR-029）。

資格対策の学びの次に学ぶの並びは出題頻度の降順で、出題頻度が同じ論点どうしは、分野の順、次に論点が紐づくシラバスの項目の順、次に論点の ID の順にする（分野と項目の順の値の SSOT は `data/<学びの key>/syllabus.json`）。単元の構成（BR-031）はこの並びに使わない。ロードマップ型の学びの次に学ぶの並びは学ぶ順（BR-031）。

ホーム・論点の画面・一覧のおすすめ順は、すべてこの 1 つの定義を使う。一覧のおすすめ順は、まだ理解していない論点をこの並びで先に置き、理解の論点を除かずに最後へ、同じ並びで置く。まだ理解していない論点の段階どうし（未・未理解・やや理解）は分けずに 1 つの並びにする。

**意図**: 出題頻度 × 未理解が最短合格経路の実体（設計の中核）で、画面ごとに定義が分かれると別の道を指すこと（要件定義書 §3.1・§5.1）。単元の一覧を単元の構成の順に並べても（BR-031）、次に学ぶだけは出題頻度で頻出から潰す道を示し続ける。
