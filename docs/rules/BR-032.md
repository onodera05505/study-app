# BR-032 初期データの投入は、門を通ったものだけを入れる

初期データの投入は、出典（試験名・年度ラベル・問番号）が欠けている／対象と食い違う過去問、同一内容なのに正解が割れている過去問、回ごとの問題数が合わないデータ（ロードマップ型で何と比べ、どの回を外すかは BR-037）があるときは止める。投入は、利用者が残したデータ（アカウント・理解度・受験履歴・フィードバック・訪問の記録）に触れない。

**意図**: 投入は通るのに中身が違う事故（出典が全問誤ったまま数か月）と、再投入で利用者の記録が消える事故を止めること（不変条件 D2・D4・D12・D14・D16）。
