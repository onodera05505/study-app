# BR-015 取得前と、結果が空を区別する

一覧・集計・進行中のテストの案内は、まだ取得していない状態と、取得できて結果が空の状態を別の状態として持ち、取得前に「該当なし」を出さない。区別の表し方の正本はコード。

**意図**: 読み込み中に「該当する論点がありません」と出て、データが無いと誤解させないこと（不変条件 D11・要件定義書 §16.3）。
