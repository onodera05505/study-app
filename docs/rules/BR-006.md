# BR-006 管理者は 0 人にならない

まなびばの管理者は、常に 1 人以上いる。管理者を減らす操作は、0 人になるときは、2 人の管理者の求めが重なったときも含めて受け付けず、理由を返す。

**意図**: 誰もアカウントと権限を作り変えられない状態に落ちると、まなびばが認証と権限の正本として働かなくなること（要件定義書 §4）。
