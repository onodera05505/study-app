# BR-031 論点の並びと次の導線は、学びの種類で決まる

資格対策の学びは論点を出題頻度の降順に並べ、出題頻度が同じ論点どうしは、分野の順、次に論点が紐づくシラバスの項目の順、次に論点の ID の順に並べる（分野と項目の順の値の SSOT は `data/<学びの key>/syllabus.json`）。ロードマップ型の学びは学ぶ順に並べる。次の導線もそれぞれの並びに従う。学ぶ順を持つのはロードマップ型だけ。

**意図**: 同じコードで 2 種類の学びを出しているため、種類の判定を 1 か所に寄せないと片方の学びが壊れること（不変条件 D13）。
