# BR-001 認証を要する応答は、本人と分からない要求には返さず、何も変えない

学びのデータと、まなびばの本人・権限・管理の応答は、有効なトークンまたはセッションを伴わない要求には返さず、要求された変更も行わない。断りの形は、まなびばと学び側で同じにする。認証を要さない応答は死活確認と学びの一覧だけで、その一覧の正本はサーバの経路の定義。

**意図**: 権限を持たない人に学びの中身と他人のアカウントを渡さないこと。GOAL-08「1 つのアカウントで学びに入る」が成り立つ条件そのもの。
