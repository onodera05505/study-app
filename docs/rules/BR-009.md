# BR-009 共有秘密は、まなびばと全ての学びで同じ 1 つ

使い捨てコードの交換に使う共有秘密は、まなびばと全ての学びで同じ 1 つの値。値の正本は配信先の secret。

**意図**: 値がずれた学びは使い捨てコードの交換が拒まれ、その学びに誰も入れなくなること（不変条件 O13）。
