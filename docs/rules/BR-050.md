# BR-050 資格対策の理解度の記録は、その後に回答が届くまでの本人の上書き

資格対策の学びでは、利用者が論点に選んで残した理解度の記録を、BR-049 の判定に代わる本人の上書きとして扱う。理解度の記録より後に、その論点について BR-049 が数える回答が 1 件でもあれば BR-049 の判定を、1 件も無ければ記録した段階を、その論点の理解度とする。

記録は、判定より高い段階でも低い段階でも残せる。上書きを効かなくするために記録を消したり書き換えたりはせず、記録の時刻と回答の時刻（BR-049 の決める時刻）を比べるだけで決める。記録と同じ時刻の回答は記録より後と数えず、記録が効く。

ロードマップ型の学びでは、理解度の記録がそのまま理解度になる（記録の無い論点の扱いは BR-029）。

**意図**: 理解度は回答の履歴からの判定を主とし、本人の見立ては従とする（読んだ直後の自信は当てにならない。BR-049 の意図）。それでも「解けたが自信が無いので復習に回したい」「別の教材で学んで分かっている」という本人の判断を、次に解くまでは尊重する。失効を時刻の比較で決めるのは、書き込みを増やさないため（GOAL-01）。
