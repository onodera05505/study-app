# BR-049 資格対策の理解度は、過去問への回答の履歴から読むたびに判定する

資格対策の学びでは、論点の理解度を、その利用者がその論点に紐づく過去問に回答した履歴から次のとおり判定する。

- 回答が 1 件も無ければ未（理解度の記録だけがあるときは BR-050、記録も無いときの扱いは BR-029）
- 最新の回答が誤答なら未理解
- 最新の回答が正解で、最後の誤答より後（誤答が無ければ最初の回答から）に正解した日が 2 日以上あれば理解
- それ以外（最新の回答は正解だが、正解した日が 1 日だけ）はやや理解

数え方は次のとおり。同じ日の正解は何回でも 1 日と数え、日は日本時間の暦日で区切る。論点に紐づく過去問と同一内容の過去問（BR-028）への回答も、その論点の回答として数え、同一内容の過去問への回答は同じ 1 問への回答として扱う。演習と模試（公開回の通しとランダム構成を含む）のどのテストの回答も数える。回答の時刻は、演習では回答した時刻、模試ではその模試を締めた時刻とし、模試の回答は締めるまで数えない（締めるまで正誤を見せないため。BR-021）。「最新の回答」「最後の誤答」「正解した日」と、BR-050 の記録との前後は、どれもこの回答の時刻で決め、同じ時刻の回答どうしは出題の順で後の回答を後とする。数えるのは本人の回答だけ（BR-018）。

判定は求められるたびにその時点の回答の履歴から求め、判定の結果を記録として残さない。最後の正解からの日数で段階を下げることはしない。日数の閾値と日の区切りの時差の値の SSOT は `src/server/lib/understanding.ts` の `UNDERSTOOD_CORRECT_DAYS` と `JST_OFFSET_SEC`。

**意図**: 教材を読んだ直後の自己申告は当てにならず、日を変えた正解を数えるほうが 1 週間後の成績に沿う（逐次再学習・ALEKS の learned／mastered の分け方）。過去問が 1 問だけの論点が半数を超えるので、同じ問題の同じ日の正解を数えないことで、答えを覚えただけの正解と区別する。読むたびに求めて残さないのは、本番の DB の 1 日の書き込みの上限を食わないため（GOAL-01）。
