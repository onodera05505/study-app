# 出典表示の修正（2026-08-29）

応用情報の全880問が誤った出典を表示していた件と、その根本原因を直した記録。
**IPA の利用条件で出典表示は必須**なので、間違った出典が出ている状態は放置できない。

## 何が起きていたか

```
出典：2022r04h ITパスポート試験 問1     ← 中身は応用情報の問題
```

2つの不具合が重なっていた。

1. **試験名が「ITパスポート試験」のまま**（全880問）
2. **年度ラベルが内部コードのまま**（6回・480問）

問題文・選択肢・正解は正しく、壊れていたのは表示用の文字列だけだった。

## 原因は3つ

### `--exam-name` の既定値が IT パスポート

`build_seed.py` が `--exam-name` を引数で受け、既定値が `ITパスポート試験` だった。
応用情報のときだけ渡す前提だが、**どの手順書にもその記載がなく**、
`deploy-pages.sh` が出す案内文自体が `--exam-name` 抜きだった。
案内どおりに実行すると必ず間違うので、一度のミスではなく構造的に毎回そうなる。

### `exam_labels.json` に6回分が無い

`build_seed.py` は `labels.get(exam, exam)` とフォールバックするので、
未登録の回は内部コード（`2022r04h`）がそのまま出典とセッション名に出ていた。

### UPSERT の更新列に `exam_label` が無い（これが厄介だった）

ラベルを足して seed を流しても**既存行のラベルが変わらない**。
`ON CONFLICT DO UPDATE SET` に `exam_label` が入っていなかったため。
citation だけ更新されてラベルが古いまま、という中途半端な状態になる。

`exam_label` は出典だけでなく**セッション名（「〜を通しで受験」）にも使われる**ので、
表示に出続ける列だった。

## 直し方

1. `data/ap/exam_labels.json` に欠けていた6回分を追加（11回すべて登録済みにした）
2. `build_seed.py` の `--exam-name` を**`--data` から自動で決める**ように変更。
   `EXAM_NAMES = {"ip": …, "ap": …}` で引き、未知のディレクトリなら
   エラーで止まる（黙って間違った名前を使わない）
3. UPSERT の更新列に `exam_label=excluded.exam_label` を追加
4. seed を作り直して本番へ投入。**UPSERT なので進捗・受験履歴は無事**
   （投入後にユーザー2件・受験履歴3件が残っていることを確認）

## 確認

```bash
npx wrangler d1 execute study-app-ap-db --env ap --remote \
  --command "select exam, exam_label, min(citation) from past_questions group by exam, exam_label"
```

11回すべてが `出典：令和N年度 期 応用情報技術者試験 午前 問N` になり、
内部コードのまま・誤った試験名はゼロ件。IT パスポート側（`study-app-db`）は
元から正しく、今回の変更でも `ITパスポート試験` のまま変わらないことを確認した。

## 教訓

**「手順書に注意書きを足す」で終わらせない。** 引数の渡し忘れで壊れるものは、
渡さなくても正しくなるようにするか、渡さなければ止まるようにする。
今回は `--data` から決まるので、次に回を追加する人は何も意識しなくてよい。

**UPSERT は更新列の書き漏れに気づきにくい。** データを直したのに本番が変わらないときは、
`ON CONFLICT DO UPDATE SET` にその列があるか見る。挿入は正しく、更新だけが漏れる。
