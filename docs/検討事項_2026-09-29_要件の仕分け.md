# 仕分け表 — B 116 件・C 3 件（残す／消す／合わせる）

作成 2026-09-29。元は `scratchpad/audit_X.md`（UC-001〜006・014〜019）と `audit_Y.md`（UC-007〜013・024〜032）。
文の案は `scratchpad/spec_additions.md`。コードは開いていない。

**案の読み方**
- **残す（§x）** — 利用者に要る振る舞い。その節に文を足して仕様書の決まりにする
- **消す** — 仕様書の意図に反する・冗長・誰も求めていない。要件と実装を落とす
- **合わせる** — 仕様書に既にある決まりのほうが正しい。実装（または門）を直す
- **【要決定】** — 本人の決めが要る。`spec_additions.md` に選択肢を並べた
