## 要求と本人の決定

本人の要求は「エンジニア入門というタイトルで、コンピュータが動く仕組みなど基本的な学びを、IT パスポート・基本情報の過去問を参考にしつつ、エンジニアになるために必要な情報をリサーチして作る」。質疑応答で決めたこと（すべて `brain/PREMISES.md` の 2026-11-02 の 3 行）:

- **資格型と学び型のハイブリッド**。目的は「前提知識のない人がエンジニアとして働き始めるのに要る基礎を自分の言葉で説明できる（IT 面接の基本の問答に答えられる）」。**資格の合格を目的にしない**（暗記に寄るため）
- **日付ではなく章で束ねる**。章の大きさは中身で決める。期限なし
- 分野は下の層から上へ 7 つ。範囲は技術 7 分野＋周辺（開発の進め方と管理・運用と障害対応・法律と権利・業務とシステム化の企画・手を動かす道具・クラウドとインフラ・AI と機械学習・仕事の作法）＋数学（2 進数・論理演算・確率と統計）。**会計・経営戦略・マーケティングは外す**
- 入れる／入れないで切らず、**各単位に 3 段の印**（★★★ まず押さえる／★★ 1 年目に要る／★ 必要になったら）。★ が基本情報の水準を受け持ち、2 段の学びには分けない。画面で印ごとに絞り込める
- 細部は推し: プログラムは日本語の擬似的な書き方、絞り込み中は先頭の導線も絞り込みに従う、NoSQL は ★★、補足の単位に確認の入口は出さない

## 本番に出すには（本人の操作）

対話が要るので止めている。

```bash
npx wrangler d1 create study-app-eng-db     # ID を wrangler.jsonc の env.eng に
bash scripts/bootstrap_personal.sh eng       # Pages 作成・migrations --remote・JWT_SECRET
bash scripts/set_sso_secret.sh               # まなびばと同じ SSO_SECRET
bash scripts/finish_remote.sh eng            # 移行 → 投入 → 配備
```

その後 `scripts/pages_projects.json` に url、`build_portal.py`・`deploy_portal.sh`、まなびばの管理画面で権限。

**既存のロードマップ型 6 対象と ip・ap・fe も、次に出し直す前に migration 0007 を本番の D1 に当てる必要がある**。`finish_remote.sh <対象>` がこの順で回す。`deploy-pages.sh` だけを回すと、未適用なら門が止める。
