## 前提条件
- まなびばに本人のアカウントがあり、その人でログイン中（Cookie のセッションがある）

## 基本の流れ
1. 利用者が現在のパスワードと新しいパスワードを送る。まなびばは現在のパスワードを照合し、合っていれば新しいハッシュに入れ替える
2. 利用者がログアウトする。まなびばはこの端末のセッションを消し、Cookie を失効させる

## 例外の流れ
E1. 1 で現在のパスワードが違う。まなびばは 401 を返し、パスワードを変えない
E2. 1 で新しいパスワードが 8 文字未満か 200 文字を超える、または欄が空。まなびばは 400 を返し、パスワードを変えない

## 事後条件
- 新しいパスワードでログインでき、前のパスワードでは入れない
- ログアウトした端末の Cookie は使えず、ログインが要るまなびばの API は 401 になる（要件は UC-014）
