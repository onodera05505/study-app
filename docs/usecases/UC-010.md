## 前提条件
- 過去問には出典（試験名・年度ラベル・問番号）と、原文を改変したかどうかの印が入っている
- 利用者がログインして学び側の画面を開いている

## 基本の流れ
1. 開発側が過去問を本番のデータへ入れる。システムは過去問ごとに「出典：<年度ラベル> <試験名> 問N」を組み立てて列に持たせる
2. 利用者が論点の学習画面を開く。画面は紐づく過去問ごとに出典を出し、改変の印が立つ問題には「一部改変」を併記する
3. 利用者が演習・模試を始める。システムは出題時のスナップショットに出典と改変の印を入れる
4. 利用者が演習・模試の問題を解く。画面は出題中の問題に出典を出し、改変の印が立つ問題には「一部改変」を併記する
5. 利用者が結果画面を開く。画面は問題ごとに出典を出し、改変の印が立つ問題には「一部改変」を併記する

## 例外の流れ
E1. 1 で出典の試験名が対象と違う、または年度ラベルが内部コードのままの過去問がある。システムは投入前の門で止め、投入後の突き合わせでも 0 件であることを確かめる

## 事後条件
- 過去問を出すどの画面にも出典があり、改変した問題には「一部改変」が併記されている
- 教材や解説を後から直しても、出題済みの問題には当時の出典が出る
