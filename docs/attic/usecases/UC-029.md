## 前提条件
- 利用者が理解度をまだ記録していない
- 論点に出題頻度と分野が付いている

## 基本の流れ
1. 利用者が診断テストを始める。システムは分野の比率に沿って、頻出の論点から 20〜30 問を選んで出す
2. 利用者が全問に答える。システムは採点する
3. システムは結果から論点ごとの理解度の初期値を置き、その由来を診断として残す
4. 利用者が論点の学習画面で理解度を自分で記録する。システムは由来を自己申告として残す

## 例外の流れ
E1. 3 で既に自己申告の理解度がある論点がある。システムは診断の結果でそれを上書きしない

## 事後条件
- 理解度に由来（自己申告／診断／演習）が残り、区別して読める
