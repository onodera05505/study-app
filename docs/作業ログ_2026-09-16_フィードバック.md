『フィードバックありがとうございます。改善に活かします。』的なメッセージ。その場で AI 対応は API のこともあるのでしない。DB に入れてこっちからアクセスできるように」。

## 作ったもの
- DB `feedback`（migrations/0006。利用者・種別 text|unclear・画面・論点 ID・問題の位置・本文・状態 new/triaged/done・メモ・日時）
- API `POST /api/feedback`（認証必須。空・2,001 字は 400 で日本語。1 人 1 日 20 件で 429。利用者向けの一覧 API は無い）
- 画面: 上部ナビ「フィードバック」→ 自由記述 1 画面。直前に開いていた画面（論点名・テストの何問目か）を自動で添える（外せる）。送信後は「フィードバックありがとうございます。改善に活かします。」と戻るリンクだけ
- 開発側: `scripts/feedback.py fetch <key>|--every`（未処理を表示し `data/<key>/feedback/inbox_<日付>.json` に保存）、`mark <key> <id…> --status done --note`。`--local` でリハーサル
- 改善フェーズ: `.claude/skills/improve-from-feedback/SKILL.md`（取り出す → 質問／バグ／仕様変更に分ける → 直す → 出す → 閉じる → 還す）
- 門: `check_api.py` に保護経路・失敗の形 3 つ・送信→保存の突き合わせ。`check_seed.py` に D16（seed が利用者データの表に触らない）

## 起きたこと
- 本番 D1 を作って `database_id` を差し替えた直後、ローカル D1 が空になった（ID ごとに別ファイル。中央 reports/126 として新規）。ローカルの seed を流し直して解消
- zod v4 の既定メッセージが英語で出た（「Invalid input: expected string」）。`z.string({ error })` で日本語に。API 検査の「error が日本語でない」警告が拾った
