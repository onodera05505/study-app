# 22. 回の新旧を辞書順で比べると、同じ年の春と秋が逆になる

- **日付/場所**: 2026-08-31 / 同一内容の問題を畳むときの代表選び（`session-builder.ts` の `compareExam`）
- **症状**: 同一内容の過去問を「**最新の回**」で代表させたいのに、同じ年度の春期と秋期で
  新旧が逆になる。
- **原因**: 試験 ID の文字列を**辞書順**で比べていたため。期の文字は
  **h＝春期 / a＝秋期 / o＝10月試験**（令和2年度のみ）で、辞書順では `a` < `h` < `o` となり
  年内の並びが実際の時系列と一致しない。
- **対処**: `compareExam` を「西暦 → `h` < `o` < `a`」の順で比べるようにした。
- **再発防止**: 無し（回の新旧を比べる箇所を足すときは `compareExam` を使う）。
- **関連**: 期の文字は決め打ちしない。令和2年度は春期が中止で10月に1回だけ実施された特殊な回で、
  ID も `2020r02o`（→ 報告 02 の図の取り違えの原因でもある）。
