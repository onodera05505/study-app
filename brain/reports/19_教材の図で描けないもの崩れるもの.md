# 19. 教材の図（仕様 JSON → SVG）で描けないもの・崩れるもの

- **日付/場所**: 2026-09-01 / `data/<試験>/material_figures/*.json` と `render_material_figures.py`
- **症状**: 担当が書いた図の仕様が、描くとラベルが切れる・意図した形にならない。
- **原因と対処**（テンプレートは blocks / sequence / matrix / chart の4型だけ）:
  - **edges / steps のラベルは1行しか描けない**（`\n` は無効）。長い補足は sequence の `note` へ
  - **chart にガント・積み上げ帯は無い**。時間帯は blocks の格子か step で表現する
  - **右端・左端アクターの自己ループ**はラベルがはみ出しやすい。短くして `note` に逃がす
  - **縦軸ラベルは回転させず水平に置く**（回転した日本語は読めない。2026-09-01 に修正）
- **再発防止**: `scripts/prompts/material_figures_spec.md`（担当が最初に読む仕様書）に明記。
  図は LLM に SVG を直接描かせず**仕様 JSON をスクリプトが描く**ので、直すのは JSON 1 行で済む。
  全図を親が PNG で目視してから投入する運用（担当の自己申告は信じない）。
- **注意**: 目視は PNG でするが、**PNG では「ー」「・」が消え破線が実線に見える**（共通 34）。
  PNG だけ見て「直す」と正しいデータを壊す。
- **事前の質問**: 図の型の集合をどこまでにするか（その型で描けないものが出たとき、型を増やすか表現を変えるか描かないか）（→ approaches/図をスクリプトで描く.md 〔q: figure-types〕）（2026-09-15 変換）
