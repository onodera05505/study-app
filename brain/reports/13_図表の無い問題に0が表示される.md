# 13. 図表の無い過去問に「0」が表示される

- **日付/場所**: 2026-08-23 / 論点詳細の画面（React）
- **症状**: 図表を持たない過去問の欄に、意味の無い `0` が描画されていた。
- **原因**: `hasFigure` が D1 から **0/1 の数値**で返るため、`{q.hasFigure && <Figure …/>}` が
  偽のときに `0` を**そのまま描画**していた（JSX は `false` は描かないが `0` は描く）。
- **対処**: 真偽値に変換してから条件に使う（`!!q.hasFigure`）。
- **再発防止**: 無し。SQLite/D1 由来の真偽値は全て同じ形をしているので、他の列でも起こりうる。
- **詳細**: [`docs/作業ログ_2026-08-23.md`](../../docs/作業ログ_2026-08-23.md)「UI のバグ1件」
- **検索語**: 0 が表示される, hasFigure, JSX && 数値, D1 boolean 0/1
