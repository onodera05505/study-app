# 02. IT パスポートの画面に応用情報の図が出ていた（試験をまたぐ同一 ID）

- **日付/場所**: 2026-08-31 発覚（実害は 2026-08-29 から本番）/ `public/figures/` と `build_seed.py`
- **症状**: IT パスポート **令和2年度10月 問55**（アローダイアグラム）の図として、
  応用情報の同回・同問番号の図（逓減課金方式のグラフ）が表示されていた。
- **原因**: 図を `public/figures/<試験ID>-q<問番号>.png` と**平置き**して試験間で共有していた。
  そして **IT パスポートと応用情報には同じ試験 ID がある**（令和2年度10月＝`2020r02o`。
  コロナ禍で春期が中止になり10月に1回だけ実施された回が両試験にある）。
  両方が問55の図を切り出してファイル名を奪い合い、後から切り出した応用情報（8/29）が
  IT パスポートの図（8/23）を**警告なく上書き**していた。
  `crop_figures.py` は上書きを警告せず、`build_seed.py` はファイルの実在しか見ていなかった。
- **対処**: 画像を試験ごとのディレクトリに分けた。
  `public/figures/<試験>/<試験ID>-q<N>.png`、DB の `figure_image` も `/figures/ip/…`。
  `build_seed.py --figures` の既定を `public/figures/<試験>` に、手順書の切り出しコマンドも更新。
  旧い平置きファイルは、進行中セッションのスナップショットが旧 URL を持つため即時には消さず、
  参照 0 件を確認してから 2026-08-31 夜に削除（78枚）。
- **再発防止**: `check_seed.py` が `/figures/<試験>/` 以外の URL を**問題として止める**。
  CLAUDE.md に「**試験をまたぐ ID の一意性を仮定しない**」と明記。
