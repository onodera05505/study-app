# 15. 押せない選択肢に青いホバーが乗り、正誤の色を隠していた

- **日付/場所**: 2026-08-23 / 結果画面・論点詳細の選択肢（`div` で描いている箇所）
- **症状**: マウスを乗せると誤答の赤い着色が青に上書きされ、**どれを間違えたのか分からない**。
  押せないものが押せるように見える。
- **原因**: CSS のホバー指定が `.choice:hover` と**要素を限定していなかった**ため、
  ボタンではない選択肢（`div`）にもホバーが効いていた。
- **対処**: `button.choice:hover` に限定。修正後は誤答が赤、正解が緑で正しく出る。
- **再発防止**: 画面検査（`audit_screens.sh`）が「押せるものが `button`/`a` か」を含む
  アクセシビリティ検査を回す。同種の指摘（押せないカードに `cursor:pointer` が残る）は
  2026-09-02 の一斉検査でも出ている。
- **詳細**: [`docs/作業ログ_2026-08-23.md`](../../docs/作業ログ_2026-08-23.md)「画面を通しで確認して見つかった UI の不具合」
- **検索語**: .choice:hover, 正誤の色が隠れる, 押せないのに押せそう, cursor pointer
