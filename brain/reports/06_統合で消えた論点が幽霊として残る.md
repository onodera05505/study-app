# 06. 表記揺れを統合したのに、消えた側の論点が DB に残る（幽霊論点）

- **日付/場所**: 2026-08-23 / `build_seed.py` と本番 D1
- **症状**: 論点の件数が合わない（DB 386 件 vs `topics.json` 385 件）。
  画面には「1回出題」と表示されるのに、**紐づく過去問が0件**の論点が残っていた。
- **原因**: 表記揺れを統合すると統合された側の ID は `topics.json` から消えるが、
  **初期データ投入は UPSERT なので消してくれない**。
- **対処**: `build_seed.py` に「**現在の論点一覧に無い ID を削除する**」処理を足した。
  `progress` は `ON DELETE CASCADE` なので、その論点に付けた理解度も消える
  （統合先へ引き継ぐのが理想だが、統合はまれなので単純に消す方を選んだ）。
- **再発防止**: この DELETE があるため、**seed 投入前のバックアップが必須**（共通 12）。
  `check_seed.py` が紐付けの無い論点・件数を見る。
- **詳細**: [`docs/作業ログ_2026-08-23.md`](../../docs/作業ログ_2026-08-23.md)「見つかった不具合: 統合で消えた論点が DB に残る」
- **検索語**: 幽霊論点, 出題0回, UPSERT は消さない, topic_aliases 統合, DELETE FROM topics
