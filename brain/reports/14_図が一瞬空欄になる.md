# 14. 図が一瞬空欄になる（`loading="lazy"`）

- **日付/場所**: 2026-08-23 / 過去問の図の表示（学習・演習・結果の3画面）
- **症状**: ページ表示の直後、図の位置に**空の枠**が出る。画像自体は少し遅れて正しく出る。
  **時間制限のある過去問実践で空欄が出るのは不利。**
- **原因**: 図の `<img>` に `loading="lazy"` を付けていた。
- **対処**: 図は問題を解くのに必須なので**遅延読み込みをやめた**。
- **再発防止**: スクリプト検証（API が画像パスを返すか）は通っていたので、**画面を見なければ
  気づけない**類だった。現在は `check_render.sh`（描画）と `audit_screens.sh`（画面）がある。
- **事前の質問**: リンクやボタンを押した直後、次の画面が来るまでの間に何を見せるか。作業に必須の画像と後回しでよい画像をどこで分けるか（→ approaches/画面と入力の設計で先に決めること.md 〔q: loading-state〕）（2026-09-15 変換）
- **詳細**: [`docs/作業ログ_2026-08-23.md`](../../docs/作業ログ_2026-08-23.md)「画面を通しで確認して見つかった UI の不具合」
- **検索語**: loading lazy, 図が一瞬空欄, 画像の遅延読み込み, 画面確認でしか分からない
